## ✅ 可行方法一：微信电脑端查看 URL（推荐）

### 适用场景
- 公众号有历史文章
- 文章可以正常打开

### 步骤

#### 1. 电脑微信打开公众号
```
登录微信 PC 版 → 搜索公众号 → 点击进入
```

#### 2. 打开历史文章
```
点击"查看历史消息" → 点击任意文章
```

#### 3. 文章在微信内置浏览器打开
```
文章会在微信内置浏览器中显示
```

#### 4. 查看文章 URL

**方法 A - 点击右上角"..."**:
```
文章页面 → 右上角"..." → 查看"更多信息"
→ 部分版本会显示完整 URL
```

**方法 B - 使用开发者工具**（需要技术）:
```
按 F12 → Network 标签 → 刷新页面
→ 查看请求 URL 中的 __biz 参数
```

**方法 C - 发送到浏览器**:
```
文章页面 → 点击右上角"..." → "在浏览器打开"
→ 浏览器地址栏显示完整 URL
→ 复制 URL → 提取 __biz
```

## 🎯 推荐方案：动态搜索获取

### 原理
**不预先获取 BIZ 值，采集时动态搜索**

### 实现

#### 1. 配置文件（无需 BIZ）
```json
{
  "重庆房产自媒体": [
    {"name": "铭腾机构"},
    {"name": "重庆锐理数据"},
    {"name": "重庆房市"}
  ]
}
```

#### 2. 采集脚本（自动获取 BIZ）
```python
import requests
import re

def get_biz_from_sogou(account_name):
    """通过搜狗微信搜索获取 BIZ 值"""
    url = "https://weixin.sogou.com/weixin"
    params = {
        "type": 1,
        "query": account_name
    }
    
    headers = {
        "User-Agent": "Mozilla/5.0..."
    }
    
    try:
        response = requests.get(url, params=params, headers=headers)
        # 从搜索结果中提取公众号主页 URL
        match = re.search(r'__biz=([A-Za-z0-9=]+)', response.text)
        if match:
            return match.group(1)
    except:
        pass
    
    return None

# 使用
biz = get_biz_from_sogou("铭腾机构")
if biz:
    print(f"BIZ: {biz}")
else:
    print("未找到 BIZ 值")
```

#### 3. 采集流程
```
1. 读取公众号名称列表
2. 对每个公众号:
   a. 调用搜狗搜索获取 BIZ
   b. 使用 BIZ 采集文章
   c. 缓存 BIZ 值（下次直接用）
3. 输出采集结果
```

## ⚠️ 现实情况

### 微信公众号采集难度

| 平台 | 采集难度 | 说明 |
|------|---------|------|
| 百家号 | ⭐⭐ | Cookie 可用 |
| 头条号 | ⭐⭐ | Cookie 可用 |
| 微信公众号 | ⭐⭐⭐⭐⭐ | 需要 BIZ+Cookie |

### 建议

**优先级**: 百家号 > 头条号 > 微信公众号

**原因**:
1. 百家号/头条号数据公开，采集简单
2. 微信公众号反爬严格，需要登录
3. 公众号采集成本高，收益低
