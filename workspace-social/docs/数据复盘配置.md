## 📈 复盘维度

### 1. 内容表现分析

**核心指标**:
- 阅读量（PV）
- 互动量（点赞 + 评论 + 转发）
- 互动率 = 互动量/阅读量
- 涨粉数
- 完读率

**分析维度**:
```
- TOP10 内容（阅读量/互动率/涨粉）
- 内容类型表现对比（新房/二手房/政策/区域）
- 标题类型效果（疑问式/数字式/对比式）
- 发布时间效果（早/中/晚/深夜）
- 配图效果（有图 vs 无图）
```

### 2. 选题分析

**选题来源**:
- 热点跟进（当日热点）
- 系列策划（连续选题）
- 常青内容（长期价值）

**分析指标**:
```
- 热点跟进及时性与效果
- 系列内容完读率
- 常青内容长尾流量
- 选题命中率（预期 vs 实际）
```

### 3. 标题效果

**标题类型**:
- 疑问式：《XX 楼盘值得买吗？》
- 数字式：《300 万预算，重庆这 5 个楼盘最划算》
- 对比式：《照母山 vs 礼嘉，选哪个？》
- 揭秘式：《房产中介不会告诉你的 5 个秘密》
- 指南式：《重庆购房全流程指南》

**分析指标**:
```
- 各类型标题平均阅读量
- 各类型标题互动率
- 关键词效果（楼盘名/区域名/价格）
- 标题长度与阅读量关系
```

### 4. 粉丝增长

**分析维度**:
```
- 每日涨粉趋势
- 涨粉贡献 TOP10 内容
- 粉丝来源（搜索/推荐/分享）
- 粉丝画像（地域/年龄/兴趣）
```

## ⚙️ Cron 配置

### 已配置任务
```bash
# 每日数据采集（09:00）
python scripts/auto_monitor_system.py --collect

# 每日日报生成（09:30）
python scripts/data_dashboard.py --daily --date yesterday

# 每周周报生成（周一 10:00）
python scripts/data_reviewer.py --weekly --week last

# 每月月报生成（1 日 10:00）
python scripts/data_reviewer.py --monthly --month last
```

### 配置方法
```bash
# 查看现有 Cron 任务
openclaw cron list

# 添加新任务（示例）
openclaw cron add --schedule "0 9 * * *" --command "python scripts/auto_monitor_system.py --collect"
```

## 🚨 异常监控

### 监控指标
| 指标 | 阈值 | 告警方式 |
|------|------|----------|
| 阅读量跌幅 | >50%（环比） | 日报提醒 |
| 互动率跌幅 | >30%（环比） | 日报提醒 |
| 负评率 | >5% | 即时通知 |
| 粉丝负增长 | 连续 3 天 | 周报分析 |

### 应对策略
1. **内容质量检查**: 是否发布低质内容
2. **选题分析**: 是否偏离用户兴趣
3. **平台规则**: 是否触发限流
4. **竞品分析**: 是否有强力竞品
