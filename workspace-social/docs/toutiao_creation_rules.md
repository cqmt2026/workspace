## 📋 一、内容创作基本规则

### 1.1 内容质量要求

| 要求 | 说明 |
|------|------|
| **原创性** | 必须为原创作品，不得抄袭、洗稿 |
| **真实性** | 信息真实可靠，不得造谣传谣 |
| **完整性** | 内容完整，逻辑清晰 |
| **可读性** | 排版整洁，无错别字 |

### 1.2 标题规范

**✅ 推荐**:
- 准确反映文章内容
- 简洁明了（26-30 字以内）
- 突出核心信息
- 使用数字、疑问句增加吸引力

**❌ 禁止**:
- 标题党（夸大、虚假、误导）
- 低俗、色情暗示
- 暴力、恐怖内容
- 封建迷信
- 涉及政治敏感话题

### 1.3 内容规范

**✅ 推荐领域**:
- 时事新闻（需资质）
- 娱乐八卦
- 科技数码
- 历史人文
- 生活技巧
- 美食旅游
- 健康养生（需资质）
- 教育育儿
- 财经房产（需资质）

**❌ 禁止内容**:
- 违反法律法规
- 危害国家安全
- 破坏民族团结
- 传播谣言
- 低俗色情
- 暴力恐怖
- 侵犯他人权益
- 医疗广告（需资质）
- 投资理财建议（需资质）

## 📏 二、发布规范

### 2.1 文章格式要求

| 项目 | 要求 |
|------|------|
| **字数** | 建议 800-3000 字（优质内容可更长） |
| **段落** | 段落清晰，每段 3-5 行 |
| **配图** | 建议 3-9 张，高清无水印 |
| **排版** | 使用头条号编辑器，排版整洁 |

### 2.2 配图规范

**✅ 推荐**:
- 高清图片（建议 1080x720 以上）
- 与内容相关
- 自有版权或已授权
- 头条号正版图片库

**❌ 禁止**:
- 模糊、低质图片
- 水印图片（除官方水印）
- 侵犯他人版权
- 色情、暴力图片
- 二维码、联系方式

### 2.3 视频规范（如发布微头条视频）

| 项目 | 要求 |
|------|------|
| **格式** | MP4、MOV 等常见格式 |
| **时长** | 建议 1-5 分钟 |
| **分辨率** | 720P 以上 |
| **大小** | 不超过 2GB |
| **比例** | 16:9（横屏）或 9:16（竖屏） |

## 💰 三、收益规则

### 3.1 收益来源

| 来源 | 说明 |
|------|------|
| **文章创作收益** | 根据阅读量、阅读时长计算 |
| **广告分成** | 文章底部广告展示 |
| **专栏收益** | 付费专栏销售 |
| **打赏收益** | 读者自愿打赏 |
| **活动奖励** | 参与官方活动获得 |

### 3.2 收益计算因素

- **阅读量**: 有效阅读次数
- **阅读时长**: 用户停留时间
- **互动数据**: 点赞、评论、转发
- **粉丝阅读**: 粉丝阅读权重更高
- **内容质量**: 原创、深度内容收益更高

### 3.3 提现规则

| 项目 | 说明 |
|------|------|
| **提现门槛** | 100 元起提 |
| **提现时间** | 每月 1-10 日申请 |
| **到账时间** | 申请后 7 个工作日内 |
| **税率** | 平台代扣个人所得税 |

## ⚡ 四、违规处罚规则

### 4.1 违规类型

| 等级 | 类型 | 处罚 |
|------|------|------|
| **轻度** | 标题党、低质内容 | 扣除收益、限制推荐 |
| **中度** | 抄袭、洗稿 | 删除内容、封禁 1-7 天 |
| **重度** | 违法、色情、暴力 | 永久封禁 |

### 4.2 处罚措施

- **内容删除**: 违规内容下架
- **收益扣除**: 取消违规内容收益
- **限制推荐**: 限制内容推荐量
- **账号封禁**: 短期或永久封禁
- **信用扣分**: 扣除账号信用分

### 4.3 申诉流程

1. 收到处罚通知
2. 进入「处罚记录」查看
3. 点击「申诉」提交材料
4. 等待官方审核（1-3 个工作日）
5. 申诉成功恢复权益

## 🏆 五、原创保护规则

### 5.1 原创声明条件

- 内容为本人原创
- 非搬运、洗稿
- 非 AI 生成（需标注）
- 非公共内容整理

### 5.2 原创权益

- **原创标识**: 文章显示「原创」标签
- **收益加成**: 原创内容收益更高
- **优先推荐**: 获得更高推荐权重
- **维权保护**: 平台协助维权

### 5.3 侵权处理

发现侵权可：
1. 进入「侵权投诉」页面
2. 提交侵权链接和证据
3. 等待平台处理
4. 侵权内容下架

## 📊 六、推荐算法机制

### 6.1 推荐流程

```
内容发布
   ↓
机器审核（敏感词、违规检测）
   ↓
人工审核（部分抽查）
   ↓
初始推荐（小范围测试）
   ↓
数据反馈（阅读、互动）
   ↓
扩大推荐（优质内容）
```

### 6.2 影响推荐因素

| 因素 | 权重 |
|------|------|
| **点击率** | 高 |
| **阅读完成率** | 高 |
| **互动率** | 中 |
| **粉丝阅读占比** | 中 |
| **账号权重** | 中 |
| **内容时效性** | 低 |

### 6.3 提升推荐技巧

1. **优质标题**: 提高点击率
2. **深度内容**: 提高阅读时长
3. **引导互动**: 增加评论、点赞
4. **固定领域**: 建立账号标签
5. **持续更新**: 保持活跃度

## ⚠️ 九、常见违规案例

### 9.1 标题党案例

**❌ 违规**:
- "震惊！某某明星竟然做出这种事..."
- "不转不是中国人！"
- "医生都不告诉你的秘密..."

**✅ 正确**:
- "某某明星新电影票房破 10 亿"
- "国庆节旅游好去处推荐"
- "健康饮食的 5 个建议"

### 9.2 内容违规案例

**❌ 违规**:
- 未经证实的疫情信息
- 夸大功效的保健品
- 涉及政治敏感话题
- 低俗色情内容

**✅ 正确**:
- 官方发布的疫情信息
- 有科学依据的健康知识
- 正能量的生活分享
- 合法合规的内容
