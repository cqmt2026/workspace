## ⚙️ 自动化集成

### 发布前强制检查
在发布脚本中集成检查：
```python
# auto_publish_baijiahao.py 伪代码
def publish_article(article_path):
    # 1. 运行质量检查
    check_result = run_quality_check(article_path)
    
    if not check_result.passed:
        print("❌ 质量检查未通过，禁止发布")
        print(check_result.issues)
        return False
    
    # 2. 生成预览
    preview = generate_preview(article_path)
    
    # 3. 发送主人确认
    send_for_approval(preview)
    
    # 4. 等待确认后发布
    if wait_approval():
        do_publish(article_path)
        return True
    
    return False
```

## 🔧 配置选项

### 检查阈值配置
在 `scripts/article_quality_checker.py` 中配置：
```python
CHECK_CONFIG = {
    "min_words": 800,
    "max_words": 3000,
    "min_originality": 0.8,
    "min_title_score": 7,
    "require_images": True,
    "min_images": 2,
    "max_images": 5,
    "require_data_source": True,
}
```

### 敏感词库
在 `scripts/真实性保障.py` 中维护敏感词库：
- 绝对化用语（最/第一/顶级）
- 投资承诺（稳赚/升值/回报）
- 政策传闻（据说/内部消息）
- 虚假信息（伪造数据/夸大事实）

## 🚨 异常处理

### 检查失败处理
1. **列出问题清单**：明确必须修复项和建议优化项
2. **提供修复建议**：给出具体修改方案
3. **重新检查**：修复后重新运行检查
4. **人工审核**：连续 3 次不通过 → 人工审核

### 误判处理
如认为检查结果有误：
1. 记录误判项
2. 人工复核确认
3. 更新检查规则/词库
4. 重新检查
