# 微信公众号 BIZ 值提取指南

**更新时间**: 2026-04-08 09:30  
**适用**: 所有微信公众号

---

## 📱 方法一：微信手机 App（推荐）

### 步骤详解

#### 1. 打开微信，搜索公众号

```
微信首页 → 顶部搜索框 → 输入公众号名称
```

例如：搜索"铭腾机构"

#### 2. 进入公众号主页

```
搜索结果 → 点击"公众号"分类 → 点击目标公众号
```

#### 3. 点击右上角"..."

```
公众号主页 → 右上角"..."按钮（三个点）
```

#### 4. 点击"分享"

```
弹出菜单 → 点击"分享"图标
```

#### 5. 选择"发送给朋友"

```
分享方式 → 选择"发送给朋友" → 选择"文件传输助手"
```

#### 6. 复制链接

**在聊天窗口**:
```
长按分享卡片 → 弹出菜单 → 点击"复制"
```

**或者**:
```
点击分享卡片 → 打开公众号主页 → 点击右上角"..." → 复制链接
```

#### 7. 提取 BIZ 值

**粘贴链接到记事本**，格式如下：

```
https://mp.weixin.qq.com/mp/profile_ext?action=home&__biz=MzIwNTY3ODkwMQ==&mid=123456789&sn=abcdef...
                                                              ↑ 这就是 BIZ 值
```

**BIZ 值特征**:
- 位置：`__biz=` 后面
- 格式：`Mz` 开头，`==` 结尾
- 长度：约 20-24 个字符
- 示例：`MzIwNTY3ODkwMQ==`

## 🔍 BIZ 值提取示例

### 示例链接 1

```
https://mp.weixin.qq.com/mp/profile_ext?action=home&__biz=MzIwOTg3NjU0Mw==&mid=100000001&sn=abc123...
```

**提取结果**:
```
BIZ: MzIwOTg3NjU0Mw==
```

```
https://mp.weixin.qq.com/s?__biz=MzIwMTIzNDU2Nw==&mid=2650123456&idx=1&sn=xyz789...
```

**提取结果**:
```
BIZ: MzIwMTIzNDU2Nw==
```

### 示例链接 3（URL 编码）

```
https://mp.weixin.qq.com/s?__biz%3DMzIwMjM0NTY3OA%3D%3D&mid=2650123457...
```

**提取结果**（需要 URL 解码）:
```
BIZ: MzIwMjM0NTY3OA==
```

## 🛠️ 方法三：公众号文章链接

如果已经有公众号的文章链接，也可以提取 BIZ：

### 文章链接格式

```
https://mp.weixin.qq.com/s?__biz=MzIwNTY3ODkwMQ==&mid=2650123456&idx=1&sn=abc123...
```

### 提取方法

**正则表达式**:
```
__biz=([A-Za-z0-9=]+)
```

**Python 示例**:
```python
import re

url = "https://mp.weixin.qq.com/s?__biz=MzIwNTY3ODkwMQ==&mid=2650123456"
match = re.search(r'__biz=([A-Za-z0-9=]+)', url)
if match:
    biz = match.group(1)
    print(f"BIZ: {biz}")
```

## ✅ 验证 BIZ 值

### 验证方法

1. **检查格式**: `Mz` 开头，`==` 结尾
2. **检查长度**: 20-24 个字符
3. **检查唯一性**: 不同公众号 BIZ 值应不同
4. **测试访问**: 将 BIZ 值代入以下链接测试：

```
https://mp.weixin.qq.com/mp/profile_ext?action=home&__biz={BIZ 值}
```

如果能正常打开公众号主页，说明 BIZ 值有效。

---

## 🚨 注意事项

1. **BIZ 值是公众号的唯一标识**，不会改变
2. **同一公众号的 BIZ 值在所有文章中相同**
3. **BIZ 值不需要保密**，可以公开
4. **不要混淆不同公众号的 BIZ 值**
5. **URL 编码的 BIZ 值需要解码**（`%3D` → `=`）
