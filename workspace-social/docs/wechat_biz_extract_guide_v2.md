## ✅ 正确方法一：通过文章链接提取（推荐）

### 步骤

#### 1. 进入公众号主页
```
微信搜索 → 输入公众号名称 → 点击进入
```

#### 2. 查看历史文章
```
公众号主页 → 向下滑动 → 查看"最近文章"
```

#### 3. 打开任意一篇文章
```
点击任意一篇已发布的文章
```

#### 4. 点击文章右上角"..."
```
文章页面 → 右上角"..."按钮
```

#### 5. 点击"复制链接"
```
弹出菜单 → 滑动到底部 → 点击"复制链接"
```

#### 6. 粘贴链接
```
粘贴到微信聊天框或记事本
```

#### 7. 提取 BIZ 值

**链接格式**:
```
https://mp.weixin.qq.com/s?__biz=MzIwNTY3ODkwMQ==&mid=2650123456&idx=1&sn=abc123...
                                      ↑ 这就是 BIZ 值
```

**提取方法**:
- 找到 `__biz=` 
- 复制后面的值（到下一个 `&` 之前）
- 示例：`MzIwNTY3ODkwMQ==`

## 🛠️ 提取工具（可选）

### Python 脚本快速提取

```python
import re

def extract_biz(url):
    """从 URL 中提取 BIZ 值"""
    match = re.search(r'__biz=([A-Za-z0-9=]+)', url)
    if match:
        return match.group(1)
    return None

# 使用示例
urls = [
    "https://mp.weixin.qq.com/s?__biz=MzIwNTY3ODkwMQ==&mid=...",
    "https://mp.weixin.qq.com/s?__biz=MzIwMTIzNDU2Nw==&mid=..."
]

for url in urls:
    biz = extract_biz(url)
    print(f"{url[:50]}... → {biz}")
```

## ⚠️ 常见问题

### Q1: 公众号没有历史文章怎么办？
**A**: 说明是新建公众号，尝试其他方法（如搜狗搜索）

### Q2: 复制链接后没有 `__biz` 参数怎么办？
**A**: 可能是短链接，需要在浏览器中打开后再复制

### Q3: BIZ 值包含 `%3D` 怎么办？
**A**: 这是 URL 编码，`%3D` = `=`，替换即可
```
MzIwNTY3ODkwMQ%3D%3D → MzIwNTY3ODkwMQ==
```

### Q4: 不同文章的 BIZ 值不同怎么办？
**A**: 不可能，同一公众号的 BIZ 值是固定的，检查是否复制错误
