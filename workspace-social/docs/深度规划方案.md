## 🤖 自动化检查系统

### 检查流程
```
内容创作完成
    ↓
自动检查（质量/合规/敏感词）
    ↓
检查通过？→ 是 → 进入发布队列
    ↓
  否
    ↓
列出问题清单 → 人工修改 → 重新检查
```

### 检查项目

| 检查项 | 标准 | 工具 |
|--------|------|------|
| 字数 | 800-3000 字 | article_quality_checker.py |
| 标题质量 | 含关键词/吸引力 | viral_title_generator.py |
| 敏感词检测 | 无违规词 | 真实性保障.py |
| 数据准确性 | 数据来源标注 | data_reviewer.py |
| 原创度 | >80% | article_quality_checker.py |
| 格式规范 | 标题/段落/配图 | auto_image.py |

### 执行方式
```bash
# 单篇文章检查
python scripts/article_quality_checker.py <文章路径>

# 批量检查
python scripts/check_all_assistants.py
```

## 📈 数据复盘系统

### 数据采集
| 数据源 | 频率 | 工具 |
|--------|------|------|
| 百家号后台 | 每日 | auto_monitor_system.py |
| 头条号后台 | 每日 | auto_monitor_system.py |
| 百度指数 | 每周 | baidu_index_collector.py |

### 复盘维度

**1. 内容表现**
- 阅读量 TOP10
- 互动率 TOP10
- 涨粉贡献 TOP10
- 完读率分析

**2. 选题分析**
- 各类型内容表现对比
- 热点话题跟进效果
- 季节性趋势

**3. 发布时间优化**
- 各时段阅读分布
- 最佳发布时间推荐

**4. 标题效果**
- 标题类型与阅读量关系
- 关键词效果分析

### 复盘报告

**日报**（每日 09:00）:
- 昨日数据概览
- 异常波动提醒
- 今日选题建议

**周报**（每周一 09:00）:
- 本周数据汇总
- TOP10 内容分析

**月报**（每月 1 日）:
- 月度数据趋势
- 粉丝增长分析
- 变现机会评估

## 📝 内容创作流程

### 标准流程
```
1. 选题（热点/系列/常青）
   ↓
2. 资料收集（数据/案例/政策）
   ↓
3. 大纲生成（outline_generator.py）
   ↓
4. 内容创作（ai_writer.py / 人工）
   ↓
5. 质量检查（article_quality_checker.py）
   ↓
6. 配图生成（auto_image.py / generate_article_images.py）
   ↓
7. 发布（auto_publish_baijiahao.py）
   ↓
8. 数据记录（memory/运营日志/）
```

### 快速流程（热点跟进）
```
1. 热点识别（hotspot_monitor.py）
   ↓
2. 快速创作（auto_writer_lite.py）
   ↓
3. 简化检查（标题 + 敏感词）
   ↓
4. 发布
```

## 🔐 合规与风控

### 内容红线
- ❌ 不发布虚假房价信息
- ❌ 不传播未经证实的政策
- ❌ 不恶意唱衰/炒作楼市
- ❌ 不泄露个人隐私
- ❌ 不侵犯版权

### 数据来源规范
- 房价数据：注明数据来源（安居客/链家/官方）
- 政策文件：引用官方原文
- 案例素材：脱敏处理

### 发布前检查清单
- [ ] 数据来源已标注
- [ ] 无敏感词
- [ ] 无虚假信息
- [ ] 图片已授权/AI 生成
- [ ] 联系方式已脱敏
