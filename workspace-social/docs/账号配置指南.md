### 步骤 2: 获取 Cookie

#### 百家号 Cookie 获取

1. **打开浏览器**
   - 推荐使用 Chrome 或 Edge
   - 访问 https://baijiahao.baidu.com

2. **登录账号**
   - 使用百度账号扫码或密码登录
   - 确保成功进入百家号后台

3. **打开开发者工具**
   - 按 F12（或右键 → 检查）
   - 切换到 **Network（网络）** 标签

4. **刷新页面**
   - 按 F5 刷新
   - 在左侧请求列表中选择第一个请求（通常是 `bpage` 或 `index`）

5. **复制 Cookie**
   - 在右侧找到 **Request Headers（请求头）**
   - 找到 `Cookie:` 字段
   - 复制完整内容（从 `BIDUPSID=` 开始到最后一个字段）

#### 头条号 Cookie 获取

1. **打开浏览器**
   - 访问 https://mp.toutiao.com

2. **登录账号**
   - 使用头条账号扫码或密码登录

3. **打开开发者工具**
   - 按 F12
   - 切换到 **Network（网络）** 标签

4. **复制 Cookie**
   - 刷新页面
   - 在 Request Headers 中找到 `Cookie:` 字段
   - 复制完整内容

## 🔧 常见问题

### Q1: Cookie 格式不对？
**A**: Cookie 应该是长字符串，类似：
```
BIDUPSID=xxx; PSTM=xxx; BAIDUID=xxx; ...
```
确保复制了完整内容，不要遗漏分号和空格。

### Q2: 测试失败 "浏览器启动失败"？
**A**: 运行以下命令安装浏览器：
```bash
playwright install
```

### Q3: Cookie 很快失效？
**A**: Cookie 有效期通常为 7-30 天，建议：
- 每周更新一次 Cookie
- 使用"记住登录状态"选项
- 避免频繁退出登录

### Q4: 多账号如何配置？
**A**: 在配置文件中添加多个账号：
```json
{
  "accounts": [
    {
      "name": "账号 1",
      "credentials": { "cookie": "xxx" },
      "status": "active"
    },
    {
      "name": "账号 2",
      "credentials": { "cookie": "yyy" },
      "status": "inactive"
    }
  ]
}
```
