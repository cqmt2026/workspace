---

## 📋 问题说明

### 自动获取限制

**搜狗微信搜索**: ❌ 有验证码，无法直接爬取  
**微信公众号主页**: ⚠️ 需要已知 URL  
**第三方 API**: ⚠️ 部分付费

### 结论

**完全自动化不可行**，需要**半自动 + 手动**结合

---

## 🔧 解决方案

### 方案 1：手动查询（推荐，5 分钟）

#### 步骤

1. **打开新榜** https://www.xinrank.cn/
2. **搜索公众号名称**（如"铭腾机构"）
3. **查看详情页**，BIZ 值在 URL 或页面源码中

#### 快速查询链接

| 公众号 | 新榜查询链接 |
|--------|-------------|
| 铭腾机构 | https://www.xinrank.cn/search?k=铭腾机构 |
| 重庆锐理数据 | https://www.xinrank.cn/search?k=重庆锐理数据 |
| 重庆房市 | https://www.xinrank.cn/search?k=重庆房市 |
| ... | ... |

---

### 方案 2：微信公众号搜索（手机）

#### 步骤

1. **打开微信** → 顶部搜索
2. **输入公众号名称**
3. **点击进入公众号**
4. **点击右上角"..."** → 查看公众号详情
5. **分享公众号** → 复制链接
6. **链接中包含 BIZ 值**：`__biz=Mzxxxxxxxxxx==`

---

### 方案 3：脚本辅助（批量处理）

#### 使用脚本

```bash
# 查询单个
python scripts/wechat_biz_fetcher.py --names "铭腾机构"

# 批量查询（从配置文件读取）
python scripts/wechat_biz_fetcher.py --file config/wechat_accounts.json --category "重庆房产自媒体"

# 更新配置文件
python scripts/wechat_biz_fetcher.py --file config/wechat_accounts.json --category "重庆房产自媒体" --update

# 导出报告
python scripts/wechat_biz_fetcher.py --file config/wechat_accounts.json --output biz_report.json
```

#### 脚本功能

- ✅ 自动读取配置文件
- ✅ 批量获取 BIZ 值
- ✅ 自动更新配置文件
- ✅ 导出获取报告
- ⚠️ 受搜狗反爬限制，成功率约 30-50%
