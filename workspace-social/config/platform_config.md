## ⚙️ 发布规则

### 通用规则
- ✅ 发布前必须主人确认
- ✅ 草稿状态通知主人审核
- ✅ 发布后记录数据

### 百家号
- **发布时间**: 20:00-22:00（晚高峰）
- **频率**: 日更 1-2 篇
- **类型**: 深度文章（楼市分析/楼盘测评/政策解读）
- **确认方式**: 发布前附预览链接

### 头条号
- **发布时间**: 12:00-14:00（午高峰）+ 20:00-22:00（晚高峰）
- **频率**: 日更 1-2 篇（可与百家号同步）
- **类型**: 深度文章 + 短图文
- **确认方式**: 发布前附预览链接

### 敏感内容特别规则
以下内容**必须人工确认**，禁止自动发布：
- ❌ 房价预测
- ❌ 政策解读（限购/贷款/税费）
- ❌ 楼盘负面新闻
- ❌ 政府规划传闻

## 🤖 自动化配置

### 质量检查（发布前必执行）
```bash
# 单篇文章检查
python scripts/article_quality_checker.py <文章路径>

# 检查项目
- 字数：800-3000 字
- 标题质量：含关键词/吸引力
- 敏感词检测：无违规词
- 数据准确性：数据来源标注
- 原创度：>80%
- 格式规范：标题/段落/配图
```

### 数据复盘
```bash
# 日报（每日 09:00）
python scripts/data_dashboard.py

# 周报（每周一 10:00）
python scripts/data_reviewer.py

# 数据采集（每日 09:00）
python scripts/auto_monitor_system.py
```

### Cron 任务
| 任务 | 频率 | 时间 | 脚本 |
|------|------|------|------|
| 热点采集 | 每日 | 09:30 | hotspot_monitor.py |
| 数据采集 | 每日 | 09:00 | auto_monitor_system.py |
| 日报生成 | 每日 | 09:30 | data_dashboard.py |
| 周报生成 | 每周一 | 10:00 | data_reviewer.py |

## 🚀 快速启动流程

### 第 1 篇内容发布
1. **选题**: 从四大方向选 1 个
2. **创作**: 使用 `ai_writer.py` 或人工创作
3. **检查**: 运行 `article_quality_checker.py`
4. **配图**: 运行 `auto_image.py` 或 `generate_article_images.py`
5. **审核**: 发送预览给主人确认
6. **发布**: 运行 `auto_publish_baijiahao.py`（或手动发布）
7. **记录**: 更新 `memory/运营日志/`
