## 第三篇结构拆解

### 概念先行（读者认知准备）
```
不动产两种税：
① 交易环节税（契税、土地增值税）→ 绑定买卖
② 持有环节税（房产税）→ 绑定持有

契税+土地增值税 = 房地产的「活体心跳指标」
100%绑定房地产全链条，没有水分
```
**手法**：先建立概念体系，让读者有判断框架

### 数据时间轴（量化衰退）
```
2021年（巅峰）：
契税 7428亿
土地增值税 6896亿
合计 1.43万亿 = 地方预算收入15%

↓

2025年：
两税合计 8542亿（少了5800亿）

↓

2026年：预计跌破8000亿
```
**手法**：对比不同年份，同一个指标，讲清楚萎缩幅度

### 概念落地（地方财政两本账）
```
地方收入两大来源：
① 一般公共预算（税收占85%）
② 地方基金收入（卖地收入，90%）
  → 2021年：8.7万亿
  → 2025年：3万亿左右
```
**手法**：普通读者听得懂的比喻，把财政术语翻译成人话

### 最精彩判断（核心结论）
```
住建局 → 城市更新局

住建局 = 增量开发、卖地、批新房
         → 赚的是：土地出让金+交易税

城市更新局 = 存量提质、老旧改造、城中村更新
           → 赚的是：城市运营的可持续现金流

但：城市更新是徐徐之功，没有房产税来得快！
→ 确定性结论：房产税+城市更新税 = 地方新方向
```
**手法**：用一个政府机构改名，撬动一个深层逻辑

## 金句系统

| 金句 | 类型 |
|------|------|
| 「契税+土地增值税 = 房地产的活体心跳指标」 | 专业概念翻译成人话 |
| 「100%是税基消失导致的收入下滑，不是减税降费的结果」 | 纠错式判断 |
| 「住建局变城市更新局 = 赚的钱变了」 | 一个比喻讲清楚 |
| 「城市更新是徐徐之功，远远没有房产税来得快」 | 反常识预判 |

## 三篇文章综合：米宅的核心能力

**1. 概念翻译能力**
- 把「交易环节税/持有环节税」翻译成「绑定买卖/绑定持有」
- 把财政数据翻译成「地方100块里有15块是房地产交易税」

**2. 数据对比能力**
- 同类数据纵向对比（2021 vs 2025）
- 不同税种横向对比（契税 vs 土地增值税 vs 房产税）

**3. 预判敢给能力**
- 「房产税+城市更新税 = 地方新方向」
- 「住宅房产税加速」——自媒体很少敢这样预判

**4. 机构改名解读能力**
- 从「住建局→城市更新局」读出政府赚钱逻辑的改变
- 这种角度普通自媒体写不出来

## 三种写作模板（米宅版）

### 模板A：市场判断型（结论先行）
```
标题：反常识判断 + 感叹
开头：时间线事件 → 转折「但要看真相」
正文：数据拆解 + 具体楼盘案例
结论：一句金句 + 埋钩子
```

### 模板B：数据解读型（数据说话）
```
标题：悬念 + 「揭开真相」
开头：直接扔密集数据
正文：数据递进 → 城市分化分析
结论：反常识判断（「不是需求回暖，是供给收缩」）
```

### 模板C：政策财政型（逻辑链）
```
标题：数据事实 + 宣言判断
开头：一个数据事实
正文：概念拆解 → 数据对比 → 逻辑链 → 机构信号
结论：预判（敢给方向）
```

---

## 我的写作现状

我目前只会用**模板A**，而且案例和数据深度不够。

模板B需要极强的数据解读能力，需要持续采集国家统计局/住建部数据。

模板C是最有差异化价值的——政府机构改名解读、财税逻辑分析，这个自媒体做得少，容易出爆款。
