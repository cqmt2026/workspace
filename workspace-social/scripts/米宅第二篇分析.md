## 标题分析

**原标题**：刚发布的5月份地产数据，把真相彻底揭开了！

- 「刚发布」= 时效性锚点
- 「把真相彻底揭开了」= 悬念+反常识，暗示数据会颠覆认知
- 情绪词：「揭开」

---

## 两种写作模式对比

米宅实际上有**两种套路**：

| | 第一篇（结论先行） | 第二篇（数据递进） |
|---|---|---|
| **标题** | 强结论+感叹 | 悬念式+「揭开真相」 |
| **开头** | 时间线密集事件 | 直接扔数据 |
| **逻辑** | 先给结论，再找证据 | 先展示数据，让数据自己说话 |
| **结尾** | 金句+钩子引下篇 | 反常识判断+互动引导 |
| **难度** | 中（结论容易，难在案例） | 高（需要极强数据解读能力） |

## 第二篇结构拆解

### Part 1：数据密集轰炸（开头）
直接扔5组数据，不解释，只呈现：
```
一线新房 -1.7%（上海+3.2%）
二线新房 -3.2%
三线新房 -4.2%
一线二手房 -5.8%
二线二手房 -5.7%
三线二手房 -6.2%
```
**写作手法**：数据就是悬念，不解释，读者自然会问「为什么一线这么差」

### Part 2：数据不是平铺，是对比
为什么要写同比不写环比？
```
环比 = 短期季节性波动（小阳春），不能说明趋势
同比 = 知道趋势
```
**写作手法**：主动回答读者内心疑问

### Part 3：全局判断（从数据到结论）
```
新房 > 二手房
一线 > 二线 > 三线
但最大变化：一线内部严重分化
```
**写作手法**：三段式递进（好→更好→但问题出现了）

### Part 4：核心分化（一线城市分析）
这是全文最硬核的部分：
```
上海：+3.2%（独立行情）
→ 原因1：城中村拆迁（静安区128街坊，450-730万补偿）
→ 原因2：高端新盘（10万+，量足）

北京：-2.1%（没有结构支撑）
→ 学区房拉胯+五环外库存大

广州：-3.3%（库存问题最严重）

深圳：-4.5%（下行幅度最大）
→ 2020年涨太多+供应太大
→ 但核心区已经供应荒（南山粤海10万楼面价）
```

### Part 5：前瞻性数据（领先指标）
用**未来供应**来说明问题：
```
2021年新开工：14.6亿㎡
2026年预测：5-6亿㎡
→ 供应萎缩2/3

深圳核心区已出现新房供应荒
→ 接下来很多核心城市也会出现
```

### Part 6：核心判断（反常识）
```
降幅收窄 ≠ 需求回暖
降幅收窄 = 供给严重收缩带来的被动止跌
```
**这是全文最硬的一句话**，颠覆读者认知

| 金句 | 类型 |

## 我的草稿 vs 米宅第二篇

| 问题 | 米宅 | 我 |
|------|------|-----|
| 数据来源 | 国家统计局+住建局+机构预测 | 仅有均价数字 |
| 数据深度 | 新开工/施工/竣工（先行指标） | 仅去化周期 |
| 分化分析 | 城市内部分化+结构性原因 | 单点论述 |
| 判断质量 | 「供给收缩是被动止跌」 | 「流动性回来了」（表面） |
| 结尾 | 反常识判断 | 干巴巴建议 |

## 总结：米宅的核心能力

1. **数据比读者知道得多**：国家统计局+住建部+机构综合，不是摘抄新闻
2. **数据比读者看得深**：新开工面积是领先指标，预判未来2年
3. **结论比读者敢给**：「降幅收窄是被动止跌」——这句话自媒体不敢说
4. **案例比读者具体**：具体到街坊门牌号、补偿价格
