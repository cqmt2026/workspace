## 一、微信公众号数据源（BrowserAct提取）

> **获取方法**：
> 1. browser-act --session ai-manju-research navigate \<url\>
> 2. browser-act --session ai-manju-research eval "document.getElementById('js_content').innerText"

### 铭腾机构
- **微信ID**: 铭腾机构
- **定期查阅**: 公众号内重庆市场周报/月报文章
- **文章存档**:
  - https://mp.weixin.qq.com/s/SBDR0Me9KZyFmQAHy-vBKw（2026年重庆中心城区新规好房项目将突破60个）
- **可获取**: 成交均价、新规好房数据、楼盘成交排行
- **引用格式**: 「铭腾数据显示」「据铭腾机构监测」

### 锐理数据
- **微信ID**: 重庆锐理数据
- **定期查阅**: 公众号内重庆土地/板块/产品力分析文章
- **文章存档**:
  - https://mp.weixin.qq.com/s/5Y5cCCJf9_KY0bPFJUgSAA（照母山北58亩好地出让/板块分析）
- **可获取**: 土地拍卖数据、板块分析、楼盘竞争格局、产品力排行
- **引用格式**: 「锐理数据显示」「据锐理数据监测」

## 二、其他可用渠道

### 重庆网上房地产（政府官网）
- **URL**: https://www.cq315house.com/
- **可获取**: 预售许可证信息、项目名称、开发商、楼栋、面积
- **特点**: 官方备案数据，真实可靠
- **注意**: 内页需要完整导航，URL直接访问返回404
- **引用格式**: 「据重庆网上房地产公示」

### 克而瑞（cric.com）
- **URL**: https://www.cric.com/
- **可获取**: 涉宅用地成交、商品住宅数据、城市市场月报
- **特点**: 部分详细数据需要订阅
- **引用格式**: 「克而瑞数据显示」

### 房天下
- **URL**: https://www.fang.com/
- **BrowserAct访问**: chrome模式可用
- **可获取**: 新房开盘、二手房源、小区信息

## 三、已验证不可用

| 平台 | 原因 |
|------|------|
| 链家/贝壳 | 严格反爬+JS混淆，需要登录 |
| 安居客 | 验证码拦截 |
| 诸葛找房 | 验证码拦截 |
| 搜狗微信搜索 | 需要微信登录态 |
| 锐理/铭腾官网 | DNS不通，但公众号文章可用 |

## 四、数据引用格式规范

```
A级（直接引用）:
  国家统计局 / 住建部 / 央行 / 财政部

B级（标注来源）:
  铭腾机构 / 克而瑞 / 锐理数据 / 中指研究院
  格式: 「XX数据显示」

C级（禁用具体数字）:
  自媒体 / 朋友圈中介
  → 只用定性描述
```
