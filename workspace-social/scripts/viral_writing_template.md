# 更新：2026-06-20

---

## 一、标题公式

### 黄金公式
**反常识/强数据 + 感叹词 + 悬念**
```
[感叹词] + [核心结论] + [悬念]
```

### 标题关键词权重（Top10）
1. 重磅（100%爆款率）
2. 揭秘（100%）
3. 新政/政策解读（100%）
4. 购房（100%）
5. 楼市（100%）
6. 突破/核心区（100%）
7. 怎么/如何（疑问式，100%）
8. 底价/溢价/挂牌/涉宅（数据式，100%）
9. 公积金/限购/税费（政策类，100%）
10. 成交/涨幅/跌幅（市场类，100%）

### 禁止词
- 普通陈述式（86%）
- 纯感慨无数据（感叹式需配合数据）

---

## 二、正文结构（五段式）

### 段1：开篇钩子（100-200字）
```
[强事实/强数据] + [普遍感受] + [一句话转折/反常识]
```
示例：
```
最近XX数据…（强事实）

但我发现了X个扎心真相：…（反常识）
同一座城市，两个市场。
```

### 段2：数据锚点（200-300字）
```
[权威数据] + [数据拆解] + [结构分化揭示]
```
注意：数据要有来源，拆解要让人看懂背后逻辑

### 段3：核心论点1（200-300字/论点）
```
[论点] + [具体案例/数字] + [判断逻辑]
```
每个论点配一个具体案例

### 段4：核心论点2（200-300字）
```
[论点] + [对比/反差] + [判断力]
```

### 段5：结论+行动指南
```
[一句话金句] + [分类建议] + [风险提示]
```

## 三、长度标准
| 类型 | 区间 | 说明 |
|------|------|------|
| 短篇 | 800-1200字 | 60%爆款率 |
| **中篇（推荐）** | **1200-1700字** | **100%爆款率** |
| 长篇 | 1700-2200字 | 100%爆款率 |
| 超长 | 2200+字 | 可用 |

---

## 四、最佳发布时间
- 周二/周四/周五（工作日）
- 避免周日发布
- 最佳时段：上午9-10点 / 晚20-21点

---

## 五、选题三要素（缺一不可）
1. **数据锚点**：具体数字（来源可靠）
2. **反常识判断**：颠覆读者认知
3. **实用建议**：看完有行动指引

---

## 六、避坑指南
- ❌ 不引用无法核实的数据
- ❌ 不做纯情绪发泄
- ❌ 标题不等于内容
- ✅ 数据是锚点，分化是主线，判断力是价值
