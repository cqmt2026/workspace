# 自媒体爆款写作模板 v3.0
# 基于：米宅三篇爆款深度拆解（市场判断型/数据解读型/政策财政型）
# 更新：2026-06-20

---

## 一、标题公式

### 通用公式
```
[数据词/悬念词/感叹词] + [核心判断/反常识结论] + [悬念]（可选）
```

### 三种标题类型

**A型（市场判断）**：
- 公式：反常识结论 + 感叹词
- 示例：「房价再次大幅度下调的可能性不存在了！」
- 要素：恐惧解除 + 强结论 + 时间感

**B型（数据解读）**：
- 公式：时效数据 + 悬念词
- 示例：「5月份地产数据，把真相彻底揭开了！」
- 要素：时间锚点 + 「揭开真相」

**C型（政策财政）**：
- 公式：数据事实 + 宣言判断
- 示例：「房产税成地方第一大税，改变来了！」
- 要素：核心数字 + 预判词

### 标题禁止词
- 纯陈述句（「重庆二手房均价上涨」）
- 无悬念（「二手房回暖的几个因素」）
- 无数据锚点（「关于重庆楼市的思考」）

---

## 二、开头公式

### A型开头（结论先行）
```
[密集事件/时间线] → [转折] → [核心判断]

示例结构：
4月第3周，53个城市松绑限购。
4月第4周，地方救市资金进场。
5月第1周，官方重磅会议定调。
但——要看数据蕴含的真相，不要看标题。
```

### B型开头（数据先行）
```
直接扔密集数据，不解释，让数据自己说话。

示例：
一线城市新房价格同比下降1.7%，降幅收窄0.4个百分点。
上海上涨3.2%，北京、广州和深圳分别下降2.1%、3.3%和4.5%。
...
降幅收窄，是不是个积极的信号呢？
```

### C型开头（概念先行）
```
一个数据事实 + 一个反常识问题

示例：
房产税收入5212亿，首次居地方税种首位。
这意味着什么？
```

## 三、正文结构

### 标准五段式

```
段1：开篇钩子（100-200字）
     → 情绪铺垫 + 核心判断预告

段2：数据锚点（200-300字）
     → 权威数据 + 拆解分析
     → 数据要有对比（同比/环比/城市间）

段3：核心论点1（200-300字）
     → 论点 + 具体案例（楼盘名/价格/事件）

段4：核心论点2（200-300字）
     → 论点 + 对比/反差/深层原因

段5：结论 + 行动建议（150-200字）
     → 一句金句收尾 + 分类建议/风险提示
```

## 四、数据使用标准（硬性）

### 数据来源分级
| 级别 | 来源 | 可用场景 |
|------|------|---------|
| A级 | 国家统计局/住建部/财政部/央行 | 所有场景 |
| B级 | 地方住建局/规划局/知名机构（中指/铭腾/克而瑞） | 所有场景 |
| C级 | 自媒体/朋友圈中介 | 禁止引用具体数字，只用定性描述 |

### 数据呈现方式
```
① 纵向对比（2021 vs 2025）
② 横向对比（一线 vs 二线 vs 三线）
③ 拆解对比（均价背后的结构：户型/区域/产品）
④ 领先指标（新开工面积 → 未来2年供应）
```

### 数据禁区
```
❌ 不引用无法核实的数据
❌ 不引用自媒体具体数字（用「业内人士透露」「市场机构数据显示」代替）
❌ 不用模糊词（「很多」「大幅」「略有」）
✅ 数字要具体（「减少5800亿」而非「大幅减少」）
```

## 五、案例使用标准

### 好案例要素
```
✅ 具体到楼盘名（XX玖序、XX悦府）
✅ 具体到数字（10.5万/㎡、42套、800组认筹）
✅ 具体到事件（触发拼社保、3人抢1套）
✅ 来源可追溯（拆迁公告、土拍结果、住建局备案）
```

### 案例引入方式
```
引出：「比如说」「举个例子」「具体看这个案例」
承接：数据 → 原因 → 结论
数量：每300字至少一个案例
```

## 六、金句系统

### 金句类型

| 类型 | 公式 | 示例 |
|------|------|------|
| 方法论句 | 「要XX，不要XX」 | 「要看数据蕴含的真相，不要看标题」 |
| 反常识句 | 「不是XX，是XX」 | 「不是需求回暖，是供给收缩」 |
| 判断句 | 「XX是XX的」 | 「二手房是另一个逻辑」 |
| 认知升级句 | 一个比喻讲清楚 | 「契税是房地产的活体心跳指标」 |
| 预判句 | 「XX是确定的」 | 「房产税+城市更新税是地方新方向」 |

### 金句分布
```
每300-400字一个金句
结尾必须有一个核心金句
金句要押韵或对仗（可选）
```

## 七、结尾公式

### A型结尾（埋钩子）
```
核心金句 + 「这个问题下次详细说」

示例：
「二手房选筹逻辑，是个系统性工程。
每个板块的选筹标准完全不同，这个话题下次展开讲。」
→ 引出系列文章
```

### B型结尾（反常识收尾）
```
核心反常识判断 + 互动引导

示例：
「降幅收窄 ≠ 需求回暖。
这个数据，值得你转发给身边要买房的朋友。」
→ 引发共鸣+转发动机
```

### C型结尾（预判方向）
```
核心预判 + 行动指引

示例：
「确定性房产税+未来预期的城市更新税，
大概率就是地方新的方向。
值得你持续关注。」
→ 给出方向+建立持续关注
```

## 八、写作自检清单

写完文章后，逐项检查：

```
□ 标题有反常识/数据/悬念三要素之一？
□ 开头在150字内给出核心判断？
□ 数据有A或B级来源？
□ 数据有纵向或横向对比？
□ 每个论点有具体案例（楼盘名+数字+事件）？
□ 每300字有一个金句？
□ 结尾有核心判断/预判/钩子？
□ 没有引用任何C级来源的具体数字？
□ 字数在1200-1800字之间？
□ 标题和正文核心观点一致？
□ 没有「大概」「可能」「也许」等模糊词？
□ 有明确告诉读者「该怎么做」的建议？
□ 文章角度和热点库其他文章有差异化？
□ 文章至少有一个「这个自媒体不敢说」的判断？
```

## 九、账号风格选择指南

### 四种风格适用场景

| 风格 | 适用话题 | 标题公式 | 开头公式 |
|------|---------|---------|---------|
| 米宅A型（宣言式） | 市场预测/房价判断 | 反常识结论+感叹 | 时间线事件→转折 |
| 米宅B型（数据式） | 数据解读/趋势分析 | 时效数据+悬念 | 直接扔密集数据 |
| 米宅C型（政策式） | 政策解读/财税分析 | 数据事实+宣言 | 概念拆解+逻辑链 |
| 楼市新观型（故事式） | 政策落地/争议话题 | 疑问式+悬念 | 身边故事→代入感 |

### 风格选择决策树

```
话题有具体楼盘要推广？
  → YES → 【掌楼牛市-软定型】（规划兑现+地段绑定+场景+CTA）
话题是具体楼盘跌价案例？
  → YES → 【掌楼牛市-案例型】（价格时间线+避雷指南+系列化）
话题是政策落地/争议性？
  → YES → 【楼市新观型】（争议挖掘+平衡结论）
话题有反常识判断空间？
  → YES → 【米宅A型】（案例+强结论）
话题是数据解读/趋势？
  → YES → 【米宅B型】（领先指标+递进）
话题是政策财税/制度？
  → YES → 【米宅C型】（概念翻译+预判）
```

### 掌楼牛市-软定型补充要素

**规划兑现式标题**：
```
[具体规划事件+日期] + [地段地位确立] + [感叹]
示例：「鱼珠湾隧道年底通车！XXX正式加入CBD核心圈！」
```

**地段绑定写法**：
```
「从[已有地标A]→[已有地标B]→[已有地标C]」
「X分钟从项目到XXX」
「不再是YYY，而是ZZZ的核心成员」
→ 绑定已有IP，让地段蹭势上位
```

**场景化生活方式**：
```
「晨起……一顿早餐的时间……」
「傍晚归来……推门即是……」
「从此，生活无须告别，亦无须妥协」
→ 用场景替代数据，让读者想象自己住在那里
```

**CTA**：
```
「欢迎加XXX微 XXXXX」
→ 私域沉淀（微信限制不能直接交易）
```

### 风格选择决策树

```
话题是政策落地/争议性？
  → YES → 楼市新观型（争议挖掘+平衡结论）
  → NO →
    有具体楼盘/区域跌价案例？
      → YES → 掌楼牛市型（价格时间线+避雷指南+系列化）
      → NO →
        话题有反常识判断空间？
          → YES → 米宅A型（案例+强结论）
          → NO →
            话题是数据解读？
              → YES → 米宅B型（领先指标+递进）
              → NO → 米宅C型（概念翻译+预判）
```

### 掌楼牛市型补充要素

**递进对比式标题**：
```
「比[已有事件]更可怕的，是[新同类事件]……」（系列化钩子）
示例：「比南沙跌更可怕的，是黄埔也跌了」
```

**系列化开头**：
```
「上周写了[前篇事件]，没想到[这次同类事件]上演！」
→ 勾起前篇记忆，读者追着看
```

**价格时间线写法**：
```
楼盘名：
XX年开盘：X万/㎡
XX年高点：X万/㎡
XX年现在：X万/㎡
→ 数字比文字更有冲击力
```

**「避雷式」结论**：
```
「临X盘 / 市/区交界盘，请注意避雷」
「这类盘的结局，从一开始就注定了」
→ 明确行动指引，读者转发因为「有用」
```

### 楼市新观型补充要素

**疑问式标题**：
```
[疑问词] + [具体政策/现象] + [？]
示例：「全款收旧房，真的能救老房子吗？」
```

**故事式开头**：
```
「我身边有个XX的朋友」
→ 具体场景（住哪/什么房/几年了）
→ 具体困境（想卖卖不掉/想买换不起）
→ 引出政策背景
```

**争议挖掘法**：
```
每个政策都有两面性：
争议一：「全款」≠「高价」≠「公平价」
争议二：收来的旧房处置方案A vs 方案B
→ 读者自己判断，比直接给结论更有传播力
```

**平衡结尾**：
```
「这是一次有意义的尝试，
但能不能真正解决问题，还需要时间。」
→ 不极端，各方都觉得有道理
```

## 十、差异化检查

在发布前，确认：
```
□ 这个角度热点库有吗？（没有=差异化）
□ 这个判断别家自媒体敢给吗？（不敢=价值）
□ 有具体到街道/楼盘/价格的案例吗？（有=深度）
□ 有一句话能让读者记住吗？（有=传播力）
```

## 十、知识库积累

每次写完文章，更新知识库：
```
1. 文章标题 → 记录阅读量/转发量
2. 文章核心判断 → 加入判断库
3. 文章数据来源 → 加入数据源清单
4. 文章金句 → 加入金句库
5. 文章案例 → 加入案例库（楼盘名+价格+城市）
```
