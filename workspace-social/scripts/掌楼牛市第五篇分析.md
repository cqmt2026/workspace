## 标题分析

**原标题**：比南沙卖8千更可怕的，是黄埔也卖8千了……

- 「比…更可怕的是…」= 递进式对比标题
- 引用前文：「南沙2万→8千」引发共鸣，再用「黄埔也一样」扩大焦虑
- 情绪词：「可怕」「跌成这个鬼样」
- 技巧：系列化运营（南沙篇→黄埔篇，读者会追着看）

---

## 风格定位

这是**事件驱动型案例分析**，跟米宅的「宏观判断型」和楼市新观的「政策解读型」完全不同。

| | 米宅 | 楼市新观 | 掌楼牛市 |
|---|---|---|---|
| **核心** | 我告诉你市场真相 | 这个政策有什么争议 | 这个楼盘跌得有多惨 |
| **视角** | 宏观 | 政策 | 单一案例 |
| **结论** | 方向性判断 | 两面分析 | 避开XX盘 |
| **适合** | 定期分析 | 政策解读 | 事件/个案 |

## 结构拆解

### Part 1：钩子（引用前篇，扩大焦虑）
```
「上周写了南沙2万→8千，评论区群情汹涌。
没想到，一模一样的剧情，居然在黄埔上演！」
```
**技巧**：系列化运营，南沙篇引流→黄埔篇追读

### Part 2：案例（具体到门牌号的价格线）
```
珠江嘉园

2014年开盘：1万/㎡
2018年：2万+/㎡（当时算便宜）
2021年高光：2.3-2.4万/㎡
2024年：9千-1万/㎡（跌破开盘价）

跌幅：超六成
```

### Part 3：原因分析（为什么跌）
```
① 价值底盘矮：学铁商配套有bug
② 临增盘（两头不靠岸）：
   - 喜欢黄埔配套的不会选这
   - 在意居住成本的选增城
③ 市/区交界盘都不行：临广盘/临佛盘/临清盘
```

### Part 4：市场数据（放大到广州大盘）
```
7月数据：网签8962套
环比 -9.39%
同比 -10.68%

刷新低价的案例：牛奶厂/华景新城/琶洲
「淡淡的死感，跟近期的雨天一样」
```

### Part 5：CTA结尾
```
「欢迎加掌牛哥微 zhanglouniushi，一起聊聊」
→ 私域引流
```

## 核心写作技巧

### 1. 系列化运营
```
南沙篇（引发关注）→ 黄埔篇（扩大焦虑）→ 下一个板块？
读者：追着看
```
**我的启发**：同一个现象可以写成系列（南沙/黄埔/增城/…）

### 2. 具体的价格时间线
```
开盘价 → 高点 → 现在
珠江嘉园：1万 → 2.3万 → 8千
→ 一目了然看出跌幅
```

### 3. 「避雷式」结论
```
「各位买家，请注意避雷啊」
→ 给读者一个明确行动指引
```

### 4. 情绪共鸣句
```
「跌成这个鬼样」
「淡淡的死感」
→ 读者转发不是因为「学到了」
  而是因为「说中了我的痛」
```

## 掌楼牛市型写作模板

### 标题公式
```
「比XX更可怕的，是XX也XX了……」
示例：
「比南沙跌更可怕的，是XX也跌了」
「比二手房更难卖的，是XX也撑不住了」
```

### 系列化开头
```
「上周写了[前篇]，没想到[这次同类事件]」
→ 勾起读者对前篇的记忆，引流
```

### 案例价格时间线
```
楼盘名：
XX年开盘：X万/㎡
XX年高点：X万/㎡
XX年现在：X万/㎡
跌幅：XX%
→ 数字比文字更有说服力
```

### 结论公式
```
「临X盘 / 临X交界盘，请注意避雷」
「这类楼盘的结局，从一开始就注定了」
```
