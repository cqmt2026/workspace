## 一、风格决策树（先选风格再动笔）

```
Q1：话题是具体楼盘/区域跌价？
  → YES → 【掌楼牛市型】
Q2：话题是政策落地/争议性？
  → YES → 【楼市新观型】
Q3：有反常识判断空间？
  → YES → 【米宅A型】
Q4：是数据解读/趋势？
  → YES → 【米宅B型】
Q5：是政策财税/制度？
  → YES → 【米宅C型】
```

---

## 二、五种风格核心要素

| 风格 | 标题公式 | 开头公式 | 结尾公式 | 最强能力 |
|------|---------|---------|---------|---------|
| **米宅A** | 反常识结论+感叹 | 时间线→转折 | 金句+埋钩子 | 案例+楼盘名 |
| **米宅B** | 时效数据+悬念 | 直接扔密集数据 | 反常识判断 | 领先指标 |
| **米宅C** | 数据事实+宣言 | 概念拆解 | 预判方向 | 财税逻辑 |
| **楼市新观** | 疑问句？ | 我朋友的故事 | 平衡结论 | 争议两面挖 |
| **掌楼牛市** | 比XX更可怕的… | 系列前篇引流 | 避雷指南 | 价格时间线 |

---

## 三、标题公式库

```
米宅A：「XX再次XX的可能性不存在了！」「XX的本质：不是XX，是XX」
米宅B：「XX月份XX数据，把真相揭开了！」
米宅C：「XX成XX，改变来了！」
楼市新观：「XX，真的能XX吗？」「XX出台了，XX吗？」
掌楼牛市：「比XX更可怕的，是XX也XX了……」
```

**禁止**：纯陈述句 / 无悬念 / 无数据词

---

## 四、数据红线（硬性）

| 级别 | 来源 | 可用 |
|------|------|------|
| A级 | 国家统计局/住建部/央行/财政部 | ✅ 直接引用 |
| B级 | 地方住建局/中指/铭腾/克而瑞 | ✅ 标注来源 |
| C级 | 自媒体/朋友圈中介 | ❌ 禁用，只用定性 |

```
呈现方式：纵向对比(2021 vs 2025) / 横向对比 / 拆解结构 / 领先指标
禁区：模糊词(大概/可能/也许) / 无法核实数字
```

---

## 五、案例标准（每300字至少一个）

```
✅ 楼盘名 + 具体价格 + 具体事件
  示例：万潮玖序42套/10.5万㎡、南山粤海街道楼面价破10万
❌ 「某个楼盘」「据说」「很多人」
```

---

## 六、金句公式（每300字一个，结尾必须有）

```
「要XX，不要XX」（方法论）
「不是XX，是XX」（反常识）
「XX是XX的」（判断）
「XX是确定的/XX是XX的开始」（预判）
一个比喻讲清楚一个专业概念
```

---

## 七、结尾公式

```
米宅A：金句 + 「这个问题下次展开」
楼市新观：「这是有意义的尝试，但…还需要时间」→ 平衡不极端
掌楼牛市：「临X盘，请注意避雷」→ 明确行动指引
米宅B/C：核心预判 + 行动指引
```

---

## 八、自检清单（写完必查）

```
□ 标题有反常识/数据/悬念之一？
□ 开头150字内给核心判断？
□ 数据有A或B级来源，标注了来源？
□ 数据有纵向或横向对比？
□ 每个论点有具体楼盘/价格/事件？
□ 每300字有一个金句？
□ 结尾有核心判断/预判/避雷指引？
□ 无C级来源的具体数字？
□ 无模糊词（大概/可能/也许）？
□ 字数1200-1800字？
□ 有一个「别家自媒体不敢说」的判断？
□ 读者看完知道「该怎么做」？
□ 和热点库已有文章角度有差异化？
```
