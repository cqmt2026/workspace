# Hot Topic Finder V2.0

> 更新: 2026-04-18

自动发现热点话题，智能去重，追踪使用历史。

## 核心功能

1. **热点发现**：从多平台获取热门话题
2. **话题去重**：检查话题是否已使用，避免重复
3. **历史追踪**：记录话题使用日期和次数
4. **智能推荐**：根据热度 + 新鲜度推荐话题
5. **多维度评分**：热度/争议性/时效性/可操作性/账号匹配

## 系统组成

| 脚本 | 功能 |
|------|------|
| `hotspot_monitor.py` | 热点采集（百度/微博/安居客/Bing） |
| `hotspot_recommender.py` | 选题推荐（5维度评分+Top3） |

## 评分维度

| 维度 | 权重 | 说明 |
|------|------|------|
| 热度 | 30% | 来源+标题关键词 |
| 争议性 | 25% | 问号/争议词 |
| 时效性 | 20% | 突发/新鲜度 |
| 可操作性 | 15% | 干货/实操性 |
| 账号匹配 | 10% | 山城房谈定位 |

## Cron自动化

| 时间 | 任务 |
|------|------|
| 08:00 | 热点分析-早间 |
| 12:00 | 热点分析-午间 |
| 18:00 | 热点分析-晚间 |

## 使用场景

✅ **适合：**
- "帮我找个热点话题写文章"
- "今天有什么热门事件"
- "这个话题我之前写过吗"
- "给我推荐3个最适合今天写的选题"

## 快速开始

```bash
# 采集热点
python workspace-social/scripts/hotspot_monitor.py

# 生成选题推荐
python workspace-social/scripts/hotspot_recommender.py
```

## 输出位置

- 采集报告: `memory/热点采集/hotspot_YYYY-MM-DD.md`
- 推荐报告: `memory/运营日志/热点分析/topic_recommendation_YYYY-MM-DD.md`
