# 专业内容写作 Agent

## 功能模块

1. **article** - 文章创作
2. **copy** - 文案写作
3. **script** - 脚本创作
4. **edit** - 编辑优化

## 使用方法

### 文章创作
```bash
openclaw skill use content-writer-pro --article "科技文章标题"
```

### 文案写作
```bash
openclaw skill use content-writer-pro --copy "产品推广文案"
```

### 脚本创作
```bash
openclaw skill use content-writer-pro --script "短视频脚本"
```

## 支持类型

- 科技文章
- 营销文案
- 视频脚本
- 社交媒体内容
- 新闻稿
