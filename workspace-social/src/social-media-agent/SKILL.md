# 自媒体 Agent

## 功能模块

1. **content** - 内容创作
2. **schedule** - 发布调度
3. **analyze** - 数据分析
4. **publish** - 多平台发布

## 使用方法

### 创作内容
```bash
openclaw skill use social-media-agent --content "为第 43 章创作微博推广"
```

### 发布调度
```bash
openclaw skill use social-media-agent --schedule "微博 今晚 8 点"
```

### 数据分析
```bash
openclaw skill use social-media-agent --analyze "昨日数据"
```

## 支持平台

- 微博
- 公众号
- 小红书
- 抖音
- B 站
