## 📋 灾难场景及恢复流程

### 场景 1：核心脚本损坏（P1）

**症状**:
- `topic_engine_v2.py` 等核心文件无法运行
- 系统功能失效

**恢复流程**:
```
1. 确认损坏文件
   ls realestate/*.py

2. 从备份恢复
   cp backup/auto/backup_YYYYMMDD_HHMMSS/realestate/*.py realestate/

3. 验证恢复
   python realestate/topic_engine_v2.py

4. 记录恢复操作
```

**预防措施**:
- ✅ 自动备份（24h 或 10KB）
- ✅ 保留 7 个历史备份

---

### 场景 2：项目文件丢失（P1）

**症状**:
- `projects/chongqing-real-estate/` 目录文件丢失
- 文章/素材无法访问

**恢复流程**:
```
1. 确认丢失范围
   ls projects/chongqing-real-estate/

2. 从备份恢复
   cp -r backup/auto/backup_YYYYMMDD_HHMMSS/projects/chongqing-real-estate/ projects/

3. 验证恢复
   ls projects/chongqing-real-estate/

4. 记录恢复操作
```

**预防措施**:
- ✅ 自动备份包含 projects/目录

---

### 场景 3：配置文件丢失（P2）

**症状**:
- 系统配置丢失
- 发布功能失效

**恢复流程**:
```
1. 从备份恢复配置
   cp backup/auto/backup_YYYYMMDD_HHMMSS/realestate/config.json realestate/

2. 验证配置
   cat realestate/config.json

3. 更新敏感信息（如需要）
```

**预防措施**:
- ✅ 配置文件纳入备份

---

### 场景 4：整个系统损坏（P0）

**症状**:
- `realestate/` 目录完全无法访问
- 所有文件丢失

**恢复流程**:
```
1. 确认备份可用性
   ls backup/auto/

2. 创建新目录
   mkdir realestate_new

3. 从备份恢复
   cp -r backup/auto/backup_YYYYMMDD_HHMMSS/realestate/* realestate_new/

4. 验证恢复
   python realestate_new/topic_engine_v2.py

5. 切换目录
   重命名 realestate_new 为 realestate
```

**预防措施**:
- ✅ 自动备份到独立目录
- ✅ 保留 7 个历史备份
