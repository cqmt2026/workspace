# 地段分析图解

**核心原则**：地段、地段、还是地段

---

## 一、城市能级决策树

```
                      选择城市
                         │
         ┌───────────────┼───────────────┐
         ↓               ↓               ↓
     一线城市        强二线城市       普通二线/三线
   (北上广深)      (杭州南京成都)    (其他城市)
         │               │               │
    ┌────┴────┐     ┌────┴────┐     ┌────┴────┐
    ↓         ↓     ↓         ↓     ↓         ↓
  核心区    成长区  核心区    成长区  核心区   谨慎
    │         │     │         │     │
    ✅        ✅     ✅        ✅     ⚠️
  保值      升值    保值      升值    自住
```

**建议**：
- 一线核心区：保值首选
- 一线/强二线成长区：升值首选
- 普通二线：自住为主
- 三线及以下：谨慎投资

---

## 二、区域选择矩阵

```
                    配套成熟度
                  低 ←───────→ 高
                ┌───────────────────┐
              低│  空白区   │  成长区  │
                │  ❌       │  ✅      │
     发展潜力   │  风险大   │  潜力大  │
                ├───────────┼─────────┤
              高│  新区     │  核心区  │
                │  ⚠️       │  ✅      │
                │  周期长   │  保值    │
                └───────────────────┘
```

**推荐**：
- ✅ 成长区：配套逐步完善 + 发展潜力大
- ✅ 核心区：配套成熟 + 保值性强
- ⚠️ 新区：配套空白 + 周期长
- ❌ 空白区：无配套 + 无发展

## 八、地段选择决策矩阵

```
                预算充足
                    │
        ┌───────────┴───────────┐
        ↓                       ↓
   追求保值              追求升值
        │                       │
        ↓                       ↓
  一线核心区            强二线成长区
  (北京/上海)           (杭州/成都)
        │                       │
        ↓                       ↓
  ✅ 保值性强            ✅ 升值空间大
  ✅ 流动性好            ✅ 发展潜力大
  ⚠️ 升值慢              ⚠️ 有不确定性


                预算有限
                    │
        ┌───────────┴───────────┐
        ↓                       ↓
   刚需自住              投资为主
        │                       │
        ↓                       ↓
  强二线郊区            强二线小户型
  (地铁沿线)            (核心区)
        │                       │
        ↓                       ↓
  ✅ 房价低              ✅ 总价低
  ✅ 通勤可接受          ✅ 容易出租
  ⚠️ 配套待完善          ⚠️ 升值慢
```
