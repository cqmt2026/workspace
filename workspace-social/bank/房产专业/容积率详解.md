**版本**：V1.0

## 核心概念

容积率是指项目用地范围内总建筑面积与项目总用地面积的比值，是衡量建设用地使用强度的重要指标。容积率越低，居住舒适度越高；容积率越高，土地利用率越高。

---

## 关键指标

### 1. 容积率计算公式
```
容积率 = 总建筑面积 ÷ 总用地面积
```

**说明**：
- 总建筑面积：地上建筑面积（不含地下）
- 总用地面积：净用地面积（不含代征地）

**示例**：
```
用地面积：10000㎡
总建筑面积：25000㎡
容积率 = 25000 ÷ 10000 = 2.5
```

### 2. 建筑密度
```
建筑密度 = 建筑基底面积 ÷ 用地面积 × 100%
```

**标准**：
- 低密度住宅：≤20%
- 高层住宅：≤25%
- 商业综合体：≤50%

### 3. 绿地率
```
绿地率 = 绿地面积 ÷ 用地面积 × 100%
```

**标准**：
- 新建住宅：≥30%
- 旧改住宅：≥25%
- 商业：≥20%

### 4. 容积率与产品类型
| 容积率 | 产品类型 | 建筑形态 |
|--------|----------|----------|
| 0.3-0.5 | 别墅 | 独栋/双拼 |
| 0.5-1.0 | 低密度住宅 | 联排/叠拼 |
| 1.0-1.5 | 多层住宅 | 6 层以下 |
| 1.5-2.0 | 小高层 | 7-11 层 |
| 2.0-3.0 | 高层住宅 | 12-33 层 |
| 3.0-4.0 | 超高层 | 34 层以上 |
| 4.0+ | 商业综合体 | 写字楼/公寓 |

## 容积率对居住体验的影响

### 1. 低容积率（<1.5）
**优点**：
- 楼间距大，采光好
- 人口密度低，安静
- 绿化率高，环境好
- 私密性强

**缺点**：
- 土地成本高
- 房价相对较高
- 配套可能不足

**适合人群**：改善型、养老

### 2. 中容积率（1.5-2.5）
**优点**：
- 舒适度适中
- 价格适中
- 配套较完善

**缺点**：
- 楼间距一般
- 人口密度中等

**适合人群**：刚需 + 改善

### 3. 高容积率（>2.5）
**优点**：
- 土地利用率高
- 房价相对较低
- 配套完善

**缺点**：
- 楼间距小
- 人口密度高
- 电梯等待时间长
- 停车难

**适合人群**：刚需

## 容积率与房价关系

### 1. 同区域内
```
容积率越低 → 舒适度越高 → 房价越高
```

**示例**（重庆北区）：
- 容积率 1.0 别墅：25000 元/㎡
- 容积率 2.0 高层：18000 元/㎡
- 容积率 3.0 超高层：15000 元/㎡

### 2. 不同区域
```
核心区：高容积率 + 高房价（地段价值）
拓展区：中容积率 + 中房价
远郊区：低容积率 + 低房价
```

### 3. 溢价分析
**容积率每降低 0.5，房价溢价约**：
- 别墅区：+10-15%
- 改善盘：+5-8%
- 刚需盘：+3-5%

## 使用示例

### 示例 1：楼盘对比文章
```markdown
## 同板块两楼盘对比：容积率差 1.5，房价差 3000 元/㎡值不值？

**楼盘信息**：
- A 楼盘：容积率 1.8，小高层，单价 18000 元/㎡
- B 楼盘：容积率 3.2，超高层，单价 15000 元/㎡

**容积率对比**：
| 指标 | A 楼盘 | B 楼盘 |
|------|--------|--------|
| 容积率 | 1.8 | 3.2 |
| 建筑密度 | 20% | 28% |
| 绿地率 | 35% | 30% |
| 楼间距 | 45 米 | 30 米 |
| 户数 | 500 户 | 1200 户 |

**居住体验差异**：
1. **采光**：A 楼盘楼间距 45 米，底层冬至日日照 4 小时；
   B 楼盘楼间距 30 米，底层日照仅 2 小时
2. **隐私**：A 楼盘每栋 2 梯 4 户，B 楼盘每栋 3 梯 8 户
3. **电梯**：A 楼盘等梯时间 30 秒，B 楼盘早高峰 2 分钟
4. **停车**：A 楼盘车位比 1:1.5，B 楼盘 1:1.2

**结论**：
容积率差异直接导致居住舒适度差异。A 楼盘单价高 3000 元/㎡，
但换来的是更低的密度、更好的采光、更少的住户。对于追求
居住品质的改善客户，A 楼盘更合适；对于预算有限的刚需客户，
B 楼盘性价比更高。
```

### 示例 2：产品定位分析
```markdown
## 容积率 2.5 的地块，做什么产品最赚钱？

**地块信息**：
- 位置：渝北区中央公园
- 面积：100 亩
- 容积率：2.5
- 用途：住宅

**方案一：纯高层**
- 产品：10 栋 33 层高层
- 户数：2000 户
- 预估售价：17000 元/㎡
- 货值：42.5 亿元

**方案二：高低配**
- 产品：3 栋别墅 +7 栋高层
- 户数：800 户
- 别墅售价：30000 元/㎡
- 高层售价：16000 元/㎡
- 货值：48 亿元

**方案三：纯洋房**
- 产品：15 栋 8 层洋房
- 户数：1000 户
- 预估售价：20000 元/㎡
- 货值：50 亿元

**结论**：
从货值最大化角度，纯洋房方案最优（50 亿），但开发周期长；
高低配方案次之（48 亿），但产品组合灵活；纯高层方案货值
最低（42.5 亿），但开发速度快。综合考虑，建议采用高低配方案。
```

## 注意事项

### 1. 容积率计算
- 不含地下建筑面积
- 不含架空层面积
- 包含阳台面积（计一半）
- 包含飘窗面积（符合条件）

### 2. 容积率调整
- 调整需规划部门审批
- 调整需公示
- 调整幅度一般≤10%

### 3. 容积率陷阱
- 警惕"综合容积率"（含商业）
- 注意分期开发的容积率
- 关注实际容积率 vs 规划容积率

## 常见误区

### 误区 1：容积率越低越好
**错误**：容积率越低越舒服

**正确**：容积率过低可能配套不足，生活不便

### 误区 2：容积率=建筑密度
**错误**：容积率高就是建筑密度高

**正确**：容积率是建筑面积与用地面积比，建筑密度是基底面积与用地面积比

### 误区 3：容积率不变就能做别墅
**错误**：容积率 1.0 就能做纯别墅

**正确**：还需考虑限高、日照、消防等要求
