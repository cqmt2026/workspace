# 前期物业管理

**版本**：V1.0  
**更新时间**：2026-03-26  
**适用场景**：物业科普、交房指南、物业分析

---

## 核心概念

前期物业管理是指业主大会选聘物业服务企业之前，由建设单位（开发商）选聘物业服务企业实施的物业管理。前期物业从项目交付开始，到业主大会成立并选聘新物业结束。

## 关键指标

### 1. 物业费标准（重庆 2026 年）
| 产品类型 | 物业费（元/㎡·月） |
|----------|------------------|
| 高层住宅 | 2.5-3.5 |
| 洋房 | 3.5-5.0 |
| 别墅 | 5.0-8.0 |
| 商业 | 8.0-15.0 |
| 写字楼 | 15.0-30.0 |

### 2. 物业承接查验
**查验内容**：
- 共用部位（外墙/屋顶/楼道）
- 共用设施（电梯/消防/监控）
- 共用设备（供水/供电/供气）
- 物业用房
- 资料档案

**时间**：交付前 30 天

### 3. 维修基金
**标准**（重庆 2026 年）：
| 产品类型 | 标准（元/㎡） |
|----------|-------------|
| 电梯住宅 | 80 |
| 非电梯住宅 | 50 |
| 独立住宅 | 60 |
| 商业 | 80 |

**用途**：
- 大修：屋顶防水、外墙维修
- 中修：电梯更换、消防改造
- 更新：设备更新、设施改造

## 前期物业流程

### 1. 物业选聘
**时间**：预售前
**方式**：
- 公开招标（3 家以上）
- 邀请招标（3 家）
- 协议选聘（1 家，需审批）

### 2. 合同签订
**签订方**：
- 建设单位（开发商）
- 物业服务企业

**合同期限**：
- 一般 2-3 年
- 到业主大会成立为止

### 3. 承接查验
**时间**：交付前 30 天
**参与方**：
- 建设单位
- 物业服务企业
- 监理单位

### 4. 物业交付
**流程**：
```
通知收房 → 资料审核 → 验房 → 问题整改 → 正式收房 → 物业入驻
```

### 5. 业主大会成立
**条件**：
- 交付面积达 50% 以上
- 或首套房屋交付满 2 年

**权利**：
- 选聘/解聘物业公司
- 决定物业费标准
- 决定维修基金使用

### 场景 1：交房指南
```markdown
"交房时，物业会收取以下费用：
- 物业费：预收 3-12 个月

- 垃圾清运费：500-1000 元
- 门禁卡/水电气卡：免费

注意：物业费从交房之日起算，未交房不收取..."
```

```markdown
"该楼盘前期物业为 XX 物业，物业费 3.2 元/㎡·月，
在同类楼盘中属于中等水平。XX 物业为上市公司，
服务品质有保障，业主满意度 85%..."
```

### 场景 3：物业更换
```markdown
"小区交付 3 年后，业主大会成立，决定更换物业。
流程如下：
1. 业主大会表决（2/3 以上同意）
2. 公开招标新物业
3. 签订新物业合同
4. 老物业退出交接
5. 新物业入驻..."
```

## 使用示例

### 示例：交房指南文章
```markdown
## 交房时，物业会收哪些钱？哪些可以不退？

**必须缴纳**：

1. **物业费**
   - 标准：高层 2.5-3.5 元/㎡·月
   - 预收：3-12 个月
   - 起算：从交房之日起

2. **维修基金**
   - 标准：电梯房 80 元/㎡
   - 用途：大修、中修、更新
   - 管理：住建委代管

3. **装修保证金**
   - 金额：2000-5000 元
   - 用途：保证不违规装修
   - 退还：装修验收合格后退还

4. **垃圾清运费**
   - 金额：500-1000 元
   - 用途：装修垃圾清运
   - 不退：已提供服务

**免费项目**：

- 门禁卡（首张免费，补办 20 元/张）
- 水电气卡
- 装修图纸审核
- 装修巡查

**注意事项**：

1. 物业费从交房之日起算，未交房不收取
2. 装修保证金必须退还，除非违规装修
3. 维修基金由住建委代管，物业无权动用
4. 物业无权收取"进场费"、"搬运费"等

**维权渠道**：

- 物业投诉电话：XXX
- 住建委投诉：XXX
- 物价投诉：12358
```

## 注意事项

### 1. 物业费调整
- 前期物业费由开发商与物业约定
- 业主大会成立后可重新定价
- 调整需 2/3 以上业主同意

### 2. 维修基金使用
- 需 2/3 以上业主同意
- 用于共用部位、共用设施
- 物业无权擅自使用

### 3. 物业更换
- 业主大会有权更换物业
- 需 2/3 以上业主同意
- 老物业必须配合交接

---

## 常见误区

### 误区 1：前期物业不能换
**错误**：前期物业合同签了就不能换

**正确**：业主大会成立后可以重新选聘

### 误区 2：物业费越低越好
**错误**：物业费越低越划算

**正确**：物业费要与服务质量匹配

### 误区 3：物业什么都能管
**错误**：物业负责小区所有事务

**正确**：物业只负责共用部位、共用设施
