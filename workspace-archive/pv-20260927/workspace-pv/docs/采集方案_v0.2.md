## 方案

### 数据流
```
collect_all():
  ├── baidu_hot() → s-data JSONP → hot_topics表
  ├── solarbe_news() → web_fetch → hot_topics表
  ├── bjx_news() → web_fetch → hot_topics表
  ├── nea_policy() → web_search搜索国能光伏政策 → policies表
  ├── cpia_data() → web_search搜索CPIA数据 → policies表
  └── (可选) mx_search() → API调用 → policies表
```

### 改动文件
| 文件 | 改动 |
|------|------|
| `scripts/core/config.py` | 更新SOURCES配置 |
| `scripts/core/hot_topic_collector.py` | 重写：baidu_hot(s-data)、solarbe、bjx |
| `scripts/core/policy_monitor.py` | 重写：nea + cpia + (可选mx-search) |

### 验收标准
运行 `python scripts/core/pipeline.py` 后：
- 百度热搜≥30条（含hotScore）
- 索比/北极星≥10条光伏新闻
- NEA政策≥5条
- CPIA数据≥3条
- hot_topics表有数据，policies表有数据
