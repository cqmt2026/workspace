## 概述

光伏获客系统负责热点采集、政策监控、内容生成、视频合成全流程。

## 六层架构

| 层级 | 模块 | 职责 |
|------|------|------|
| L1 | 数据采集层 | 头条/微博/抖音/36氪 |
| L2 | 数据处理层 | 清洗、评分、去重 |
| L3 | 内容生成层 | 脚本生成、视频合成 |
| L4 | 发布层 | 多平台发布 |
| L5 | 学习层 | 自我优化 |
| L6 | 知识库层 | Obsidian同步 |

## 行业插件层

| 插件 | 说明 |
|------|------|
| industry_config/solar/ | 光伏行业专用 |
| industry_config/storage/ | 储能行业专用 |
| industry_config/ev/ | 新能源车专用 |

## 核心脚本

| 脚本 | 功能 |
|------|------|
| pipeline.py | 一站式流水线 |
| hot_topic_collector.py | 四源热点采集 |
| policy_monitor.py | 政策监控 |
| content_generator.py | 视频脚本生成 |
| competitor_monitor.py | 竞品分析 |

## 数据流

```
头条/微博/抖音/36氪 → 清洗评分 → 脚本生成 → HyperFrames渲染 → 发布
                                      ↓
                              Obsidian知识库同步
```
