# 教育行业政策解读类内容模板

## 模板结构

```
【钩子】{title片段}出新政了！你家孩子受影响吗？

【正文】
最近教育部门发布了关于「{title全文}」的新规定。

很多家长可能还没注意到，但这条政策其实和每个孩子都有关：
1. {政策要点1：核心变化是什么}
2. {政策要点2：对孩子升学有什么影响}
3. {政策要点3：家长需要提前做什么准备}

【CTA】
关注我，政策解读不踩坑，孩子升学少走弯路。

参考来源：{source}
```

## 生成规则
- 钩子用问句制造焦虑感（但不夸大）
- 正文用"3点解读"结构，说人话
- CTA强调"不踩坑"和"不走弯路"
