# 收益计算类内容模板（光伏行业）

## 模板结构

```
【钩子】装一套{kw}光伏，一年到底能赚多少？算笔账给你看

【正文】
以常见的5kW-10kW屋顶光伏为例，结合当前组件价格和上网电价，真实算一笔账：

• 前期投入：每瓦约{price}元，5kW约{total}元
• 每年发电：约{days}小时 × {power}kW = {kwh}度
• 收益构成：自发自用省电费 + 余电上网卖钱
• 回本周期：约{years}年（25年寿命期）

【CTA】
你家屋顶能装几kW？每天发多少度？点关注私信我，免费帮你测算当地政策+收益方案。
```

## 生成规则
- 钩子必须含"算笔账"或数字量化词
- 数据要有时效标注（如"2026年8月参考价"）
- CTA引导用户提供"屋顶面积+所在城市"
