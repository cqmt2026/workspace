# 避坑指南类内容模板（光伏行业）

## 模板结构

```
【钩子】装光伏前必看！{title片段}，很多人踩过的{N}个坑

【正文】
这条信息值得所有想装光伏的人注意：{title全文}。

我们梳理了近期业主反馈最多的几个问题，帮你避开这些坑：
❌ 坑{N}：{具体坑点描述}
  → 正确做法：{解决方案}
❌ 坑{N}：{具体坑点描述}
  → 正确做法：{解决方案}
❌ 坑{N}：{具体坑点描述}
  → 正确做法：{解决方案}

【CTA】
装光伏前多看这条，少踩一个坑就省几万块。想找人帮你避坑？评论区留言你的城市和屋顶情况。
```

## 生成规则
- 钩子必须含"避坑""踩坑""注意"等警示词
- 每个坑点要有具体场景，不说大道理
- CTA引导"城市+屋顶情况"作为留资信号
