# 光伏行业价值主张

## 核心定位
让每一度绿电都算数 —— 从发电到储能，一站式交付

## 面向C端业主
- 省电费：自发自用，余电上网，每年稳定收益
- 省麻烦：勘测→设计→审批→安装→运维，全程托管
- 有保障：25年质保，AI预测性维护，减少停机风险

## 面向B端业主（工厂/园区）
- 降成本：峰谷套利+需量管理，电费直降20%-30%
- 合规：双碳目标下绿电占比硬性要求，提前布局
- 增值：屋顶变资产，增加厂房估值和绿色认证

## 差异化优势
- 全栈能力：EPC+EMS+运维一体化，不用找多家供应商
- 数据透明：实时发电收益可视化，每度电都看得见
- 本地服务：快速响应，故障24h上门
