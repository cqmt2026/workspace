## 一、核心原则

小程序性能问题的根源：**setData 数据量过大**

```
setData 单次数据量过大 → 通讯延迟高 → 卡顿
```

## 二、错题本实战优化：setData

### 1. 避免频繁 setData
**错误场景**: 输入时每次都 setData
```javascript
// ❌ 错误：每次按键都 setData
onInput(e) {
  this.setData({ value: e.detail.value })
}

// ✅ 正确：用防抖
let timer = null
onInput(e) {
  if (timer) clearTimeout(timer)
  timer = setTimeout(() => {
    this.setData({ value: e.detail.value })
    this.cloudMatch(e.detail.value)
  }, 300)
}
```

### 2. 分片写入大数组
```javascript
// ❌ 错误：一次性 setData 整个大数组
this.setData({ list: hugeArray })

// ✅ 正确：分批 setData
const chunkSize = 20
for (let i = 0; i < hugeArray.length; i += chunkSize) {
  const chunk = hugeArray.slice(i, i + chunkSize)
  this.setData({ 
    [`list_${i}`]: chunk,
    listLoaded: i + chunkSize
  })
}
```

### 3. 只 setData 变化的部分
```javascript
// ❌ 错误：把整个 data 都 setData
this.setData(this.data)  // 千万不要

// ✅ 正确：精确指定路径
this.setData({
  'list[0].name': '新名字',  // 只改一个字段
  'list.length': 100         // 只改长度
})
```

## 三、长列表优化方案

### 方案一：简单分页（适合错题本列表）
```javascript
// data
page: 1,
pageSize: 20,
list: [],
hasMore: true,
loading: false

// 加载更多
loadMore() {
  if (this.data.loading || !this.data.hasMore) return
  this.setData({ loading: true })
  
  wx.cloud.callFunction({
    name: 'getWrongQuestions',
    data: { 
      page: this.data.page,
      pageSize: this.data.pageSize 
    },
    success: res => {
      const newList = [...this.data.list, ...res.result.list]
      this.setData({
        list: newList,
        page: this.data.page + 1,
        hasMore: res.result.list.length >= this.data.pageSize,
        loading: false
      })
    }
  })
}
```

### 方案二：虚拟列表（适合超长列表）
**原理**: 只渲染可视区域内的元素

```javascript
// 核心思路
// 1. 计算可视区域能放多少个 item
// 2. 只渲染可视区域 + 少量缓冲区的 item
// 3. 滚动时动态更新渲染范围

const ITEM_HEIGHT = 80
const BUFFER_COUNT = 3

onPageScroll(e) {
  const scrollTop = e.scrollTop
  const screenHeight = wx.getSystemInfoSync().windowHeight
  
  const startIndex = Math.max(0, Math.floor(scrollTop / ITEM_HEIGHT) - BUFFER_COUNT)
  const endIndex = Math.min(
    this.data.allList.length,
    Math.ceil((scrollTop + screenHeight) / ITEM_HEIGHT) + BUFFER_COUNT
  )
  
  const visibleList = this.data.allList.slice(startIndex, endIndex)
  this.setData({
    visibleList,
    startIndex,
    offsetY: startIndex * ITEM_HEIGHT
  })
}
```

## 四、图片优化（错题本实战）

### 1. 先裁剪再上传
```javascript
// 场景：用户拍照上传错题
// ❌ 错误：直接上传原图（可能 3MB+）
wx.cloud.uploadFile({ filePath: originalPath, ... })

// ✅ 正确：Canvas 裁剪压缩后再上传
await this.cropWithCanvas(imagePath, ...)
const croppedPath = await this.cropWithCanvas(...)
wx.cloud.uploadFile({ filePath: croppedPath, ... })
```

## 五、渲染优化

### 1. 开启懒加载（关键！）
```json
// app.json
{
  "lazyCodeLoading": "requiredComponents"
}
```

### 2. 减少 WXML 节点数
**检查方法**: 微信开发者工具 → 性能 → 元素节点数

```xml
<!-- ❌ 错误：过多嵌套 -->
<view wx:for="{{list}}">
  <view wx:for="{{item.tags}}">
    <view wx:if="{{item.show}}">
      <text>{{item.name}}</text>
    </view>
  </view>
</view>

<!-- ✅ 正确：拍平结构 -->
<block wx:for="{{list}}" wx:for-item="item">
  <view data-id="{{item.id}}" class="item-row">
    <text>{{item.name}}</text>
  </view>
</block>
```

### 3. 避免频繁启动渲染
```javascript
// ❌ 错误：循环内频繁 setData
list.forEach(item => {
  this.setData({ [`item_${item.id}`]: process(item) })
})

// ✅ 正确：合并一次 setData
const updates = {}
list.forEach(item => {
  updates[`item_${item.id}`] = process(item)
})
this.setData(updates)
```

## 六、云函数优化

### 1. 限制返回字段
```javascript
// ❌ 错误：select *
const result = await db.collection('wrongbooks').get()

// ✅ 正确：只查需要的字段
const result = await db.collection('wrongbooks')
  .field({ question: true, answer: true, knowledge: true })
  .limit(20)
  .get()
```
