## 一、云存储踩坑

### 1.【踩坑】临时文件路径有时效
**问题**: 用 `wx.chooseImage` 拿到的临时路径，过段时间就失效
**解法**: 
```javascript
// ❌ 错误：存临时路径以后用
this.setData({ imagePath: res.tempFilePaths[0] })  // 之后可能失效

// ✅ 正确：立即上传云存储
const cloudPath = 'ocr/' + Date.now() + '.jpg'
wx.cloud.uploadFile({
  cloudPath,
  filePath: res.tempFilePaths[0]  // 立即上传
}).then(res => {
  this.setData({ cloudFileID: res.fileID })  // 存fileID
})
```

### 2.【踩坑】云存储链接有时效
**问题**: `getTempFileURL` 返回的链接有时效
**解法**: 
```javascript
// ✅ 正确：需要时实时获取
const urlRes = await cloud.getTempFileURL({ fileList: [fileID] })
const fileURL = urlRes.fileList[0].tempFileURL
```

## 二、云函数踩坑

### 3.【踩坑】云函数超时
**问题**: 复杂的 OCR 或 AI 解题超时
**解法**:
```javascript
// 1. 设置足够超时时间
// project.config.json 中
{
  "cloudfunctionTimeout": 300  // 300秒
}

// 2. 云函数内处理超时
exports.main = async function(event, context) {
  try {
    const result = await Promise.race([
      doHeavyWork(),
      new Promise((_, reject) => 
        setTimeout(() => reject(new Error('超时')), 25000)
      )
    ])
    return result
  } catch (err) {
    return { success: false, errMsg: err.message }
  }
}
```

### 4.【踩坑】云函数本地调试失败
**问题**: 微信开发者工具云函数本地调试失败
**解法**:
```javascript
// 确认 cloud.init 使用正确方式
const cloud = require('wx-server-sdk')
cloud.init({ 
  env: cloud.DYNAMIC_CURRENT_ENV  // 动态当前环境
})
```

### 5.【踩坑】云函数间调用失败
**问题**: 一个云函数里调另一个云函数报错
**解法**:
```javascript
// ✅ 正确：云函数互通
const cloud = require('wx-server-sdk')
cloud.init({ env: cloud.DYNAMIC_CURRENT_ENV })

exports.main = async function(event, context) {
  const result = await cloud.callFunction({
    name: 'getKnowledge',  // 目标云函数名
    data: { question: 'xxx', grade: 'grade3' }
  })
  return result.result
}
```

## 三、云数据库踩坑

### 6.【踩坑】云数据库查询无权限
**问题**: 小程序端直接查数据库报权限错误
**解法**:
```javascript
// ✅ 正确：通过云函数查询（云函数有admin权限）
wx.cloud.callFunction({
  name: 'getWrongQuestions',
  data: { grade: 3 },
  success: res => {
    // 云函数返回数据，不存在权限问题
  }
})
```

### 7.【踩坑】数据库索引导致查询慢
**解法**: 为常用查询字段添加索引
```
控制台 → 云开发 → 数据库 → wrongbooks → 索引管理
添加复合索引: grade ASC, nextReview ASC
```

### 8.【踩坑】分页查询 skip 大量数据慢
**问题**: skip(1000) 后数据很慢
**解法**: 使用游标分页，不用 skip
```javascript
// ❌ 错误：skip 大数据量
const res = await db.collection('wrongbooks')
  .skip(1000)
  .limit(20)
  .get()

// ✅ 正确：游标分页
const res = await db.collection('wrongbooks')
  .where({ _id: wx.cloud.Cloud.database().database.gt(lastId) })
  .limit(20)
  .get()
```
