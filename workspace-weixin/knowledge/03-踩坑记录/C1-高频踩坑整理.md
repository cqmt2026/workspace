## 一、云开发相关

### 1. 【踩坑】云函数收参数为 null
**问题**: 前端传坐标给云函数，云函数收到 null
**根因**: 微信云函数跨环境传参时，部分参数被序列化为 null
**错题本案例**: `cropBox` 参数从微信小程序传到云函数变成 null，导致云函数fallback到全图OCR
**解法**: 前端 Canvas 裁剪，不传坐标，只传裁剪后的 fileID

```javascript
// ❌ 错误：传坐标给云函数
wx.cloud.callFunction({
  name: 'ocr',
  data: { fileID, cropBox: { x, y, w, h } }
})

// ✅ 正确：前端裁剪后只传 fileID
// 前端 canvas 裁剪
const croppedPath = await cropWithCanvas(imagePath, ...)
const uploadRes = await wx.cloud.uploadFile({ cloudPath, filePath: croppedPath })
// 云函数只收 fileID
wx.cloud.callFunction({
  name: 'ocr',
  data: { fileID: uploadRes.fileID }
})
```

### 2. 【踩坑】token 无缓存导致重复申请
**问题**: 每次OCR都重新申请access_token，非常慢
**根因**: 没有缓存机制，token过期后重复申请
**解法**: 内存缓存 token，设置过期提前量

```javascript
let tokenCache = { token: null, expireAt: 0 }

async function getAccessToken() {
  const now = Date.now()
  // 过期前5分钟就重新申请
  if (tokenCache.token && tokenCache.expireAt > now + 300000) {
    return tokenCache.token
  }
  // ... 申请逻辑
  tokenCache = { token: result.access_token, expireAt: now + (result.expires_in - 300) * 1000 }
  return result.access_token
}
```

### 3. 【踩坑】云数据库权限不足
**问题**: 插入数据失败，权限被拒绝
**根因**: 云数据库权限设置不当
**解法**: 
- 控制台设置 `onlyCreatorReadWrite`
- 或者云函数内使用 `cloud.DYNAMIC_CURRENT_ENV`

## 二、Canvas 相关

### 4. 【踩坑】组件内 Canvas node() 返回 undefined
**问题**: 在组件中用 `createSelectorQuery()` 获取 canvas 节点失败
**根因**: 组件内要用 `.in(this)` 绑定组件实例
**解法**:
```javascript
// ✅ 正确
const query = wx.createSelectorQuery().in(this)
query.select('#cropCanvas').node(res => { ... })
```

### 5. 【踩坑】canvasToTempFilePath 报错
**问题**: canvasToTempFilePath 失败，提示"invalid canvas"
**根因**: 传的参数错误
**解法**:
```javascript
// ✅ 正确：传 canvas 对象，不是字符串id
wx.canvasToTempFilePath({
  canvas: res.node,  // Canvas 对象实例
  x: 0, y: 0, width: cropW, height: cropH,
  destWidth: cropW, destHeight: cropH,
  fileType: 'jpg',
  success: (r) => resolve(r.tempFilePath),
  fail: reject
})
```

### 6. 【踩坑】裁剪结果模糊
**问题**: 导出的图片很模糊
**根因**: destWidth/destHeight 设的太小
**解法**: destWidth/destHeight 要和 canvas 物理像素尺寸一致
```javascript
canvas.width = cropW   // 物理像素
canvas.height = cropH
wx.canvasToTempFilePath({
  // ...
  destWidth: cropW,  // 保持一致
  destHeight: cropH,
})
```

## 三、页面/组件生命周期

### 7. 【踩坑】onLoad 拿不到最新 data
**问题**: 在 onLoad 中 setData 后立即读取，拿到的是旧值
**根因**: setData 是异步的
**解法**: 
```javascript
// ❌ 错误
this.setData({ value: 123 })
console.log(this.data.value)  // 还是旧值

// ✅ 正确：用 callback 或 nextTick
this.setData({ value: 123 }, () => {
  console.log(this.data.value)  // 新值
})
// 或
wx.nextTick(() => {
  console.log(this.data.value)
})
```

### 8. 【踩坑】组件间事件触发时机不对
**问题**: 子组件触发事件，父组件收到时 data 还没更新
**根因**: 事件和 setData 时机问题
**解法**: 用 setData callback 或巧用 `wx.nextTick`

## 四、数据传输

### 9. 【踩坑】页面间传参 long 类型精度丢失
**问题**: 页面间通过 URL 传 ID（long类型），收到时精度丢失
**根因**: JavaScript number 精度问题
**解法**: 后端返回字符串ID，或者用数据库recordId

### 10. 【踩坑】formSubmit 获取不到 formId
**问题**: 模板消息需要的 formId 获取不到
**解法**: 
```xml
<form report-submit bindsubmit="formSubmit">
  <button form-type="submit">提交</button>
</form>
```

## 五、兼容性问题

### 11. 【踩坑】某些安卓机 canvas 模糊
**问题**: Android 部分机型 canvas 导出图片模糊
**根因**: 设备像素比问题
**解法**: 
```javascript
const dpr = wx.getSystemInfoSync().pixelRatio
canvas.width = cropW * dpr
canvas.height = cropH * dpr
ctx.scale(dpr, dpr)  // 按设备像素比缩放
```

### 12. 【踩坑】iOS 无法播放某些视频格式
**问题**: MP4 在 iOS 能播但 Android 不能播
**根因**: 视频编码格式不兼容
**解法**: 使用 H.264 编码，统一用 MP4 + H.264
