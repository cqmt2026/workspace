## 一、框架核心更新

### 1. 关键组件懒加载 `lazyCodeLoading`
```json
// app.json
{
  "lazyCodeLoading": "requiredComponents"
}
```
**作用**: 按需加载组件，减少首屏体积
**错题本应用**: ✅ 已在 app.json 使用

### 2. 分包异步化（2024重点）
```javascript
// 分包预加载
wx.loadPackage({
  packageRoot: 'pages/mine',
  success: () => { console.log('预加载成功') }
})
```
**适用场景**: TabBar页面首次访问前的预加载

### 3. 新增生命周期
```javascript
// onResize - 窗口尺寸变化（PC端小程序）
onResize(res) {
  console.log(res.size.windowWidth, res.size.windowHeight)
}

// onFontFace - 字体加载完成
onFontFace(font) {
  console.log('字体加载完成', font)
}
```

## 二、组件更新

### 1. Canvas 新API
```javascript
// node() 获取canvas实例（关键！）
const query = wx.createSelectorQuery().in(this)
query.select('#myCanvas').node(res => {
  const canvas = res.node  // 离屏Canvas
  const ctx = canvas.getContext('2d')
  // 支持2D离屏渲染
}).exec()
```
**错题本应用**: ✅ Canvas裁剪使用 node() API

### 2. `wx.createOffscreenCanvas`
```javascript
// 创建离屏Canvas（2024新增）
const offscreen = wx.createOffscreenCanvas({
  type: '2d',
  width: 300,
  height: 200
})
const ctx = offscreen.getContext('2d')
```

### 3. Video 小程序端增强
```javascript
// 倍速播放
<video src="..." playback-rate="{{2.0}}"></video>

// 清晰度切换
<video src="..." default-quality="360" />
```

## 三、API 更新（2024-2025）

| API | 说明 | 备注 |
|-----|------|------|
| `wx.getDeviceInfo()` | 获取设备信息（兼容新旧版本） | ✅ 错题本已用 |
| `wx.createIntersectionObserver` | 交叉观察者（替代旧版） | |
| `wx.nextTick` | 下一个渲染周期后执行 | 等同于 this.tick |
| `wx.getEnterOptionsSync` | 获取启动参数 | |
| `wx.getStorageInfoSync` | 同步获取存储信息 | 已存在但更稳定 |

### 1. `wx.getDeviceInfo()` 兼容写法
```javascript
let screenW = 375
try {
  const d = wx.getDeviceInfo()
  if (d && d.windowWidth) screenW = d.windowWidth
  else if (d && d.screenWidth) screenW = d.screenWidth
} catch(e) {}

// 备用方案
const sys = wx.getSystemInfoSync()
screenW = sys.windowWidth
```
