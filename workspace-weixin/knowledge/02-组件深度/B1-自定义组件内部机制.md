## 一、组件内选择节点（核心关键）

### 问题
组件内用 `wx.createSelectorQuery()` 无法选中自身模板内节点

### 解法
```javascript
// ❌ 错误 - 在组件内直接调用，选不到组件内节点
const query = wx.createSelectorQuery()
query.select('#cropCanvas')

// ✅ 正确 - 用 .in(this) 绑定组件实例
const query = wx.createSelectorQuery().in(this)
query.select('#cropCanvas').node(res => {
  // res.node 是离屏 Canvas 实例
})
```

### 错题本实战代码
```javascript
const query = wx.createSelectorQuery().in(this)
query.select('#cropCanvas').node(res => {
  if (!res || !res.node) { reject(new Error('canvas节点无效')); return }
  const canvas = res.node
  const ctx = canvas.getContext('2d')
  canvas.width = cropW
  canvas.height = cropH
  const img = canvas.createImage()
  img.onload = () => {
    ctx.drawImage(img, cropX, cropY, cropW, cropH, 0, 0, cropW, cropH)
    wx.canvasToTempFilePath({
      canvas,  // 注意：这里传的是 canvas 对象，不是字符串id
      x: 0, y: 0, width: cropW, height: cropH,
      destWidth: cropW, destHeight: cropH,
      fileType: 'jpg', quality: 0.9,
      success: (r) => resolve(r.tempFilePath),
      fail: reject
    })
  }
  img.src = imagePath
}).exec()
```

## 二、Canvas node() API

### 作用
获取离屏Canvas实例，支撑2D离屏渲染

### 两种Canvas写法对比

```javascript
// 方式1：老写法（推荐度下降）
<canvas canvas-id="myCanvas" style="width:300px;height:200px" />

// 方式2：新写法 node() API（2024主流）
<canvas type="2d" style="width:300px;height:200px" />
// 或者
<canvas type="webgl" />

// JS中获取
wx.createSelectorQuery().in(this)
  .select('#myCanvas')
  .node(res => {
    const canvas = res.node  // Canvas 实例
    const ctx = canvas.getContext('2d')  // 2D 渲染上下文
  }).exec()
```

### canvas-id vs type="2d"
| 特性 | canvas-id | type="2d" |
|------|-----------|------------|
| `getContext('2d')` | ❌ 不支持 | ✅ 支持 |
| 离屏渲染 | ❌ | ✅ |
| 性能 | 较好 | 更好 |
| 兼容性 | 广 | 需要基础库 2.7.0+ |

**结论**: 新项目用 `type="2d"`，老项目维护用 `canvas-id`

## 三、`getContext` 支持的渲染类型

const canvas = res.node

// 2D 渲染
const ctx2d = canvas.getContext('2d')

// WebGL 渲染（需要 type="webgl"）
const ctxgl = canvas.getContext('webgl')

## 四、图片裁剪流程（错题本实战）

```
用户框选坐标（屏幕坐标）
    ↓
换算成实际像素坐标（scale = imgW / screenW）
    ↓
前端 Canvas 裁剪（前端完成）
    ↓
上传裁剪后的小图到云存储
    ↓
云函数只收 fileID（不传坐标，避免跨环境丢参）
    ↓
云函数 OCR 识别
```

**关键经验**: 在哪操作就在哪里完成，不要跨环境传坐标

## 五、`wx.canvasToTempFilePath` 注意事项

### 1. 必须先设置 canvas 尺寸
```javascript
canvas.width = cropW
canvas.height = cropH
```

### 2. canvas 必须是离屏实例（node()获取的）
```javascript
// ❌ 错误：直接传字符串id
wx.canvasToTempFilePath({ canvas: 'cropCanvas', ... })

// ✅ 正确：传 canvas 实例对象
wx.canvasToTempFilePath({ canvas: res.node, ... })
```

### 3. 导出格式和质量问题
```javascript
wx.canvasToTempFilePath({
  canvas: res.node,
  x: 0, y: 0,
  width: cropW, height: cropH,
  destWidth: cropW, destHeight: cropH,  // 导出分辨率
  fileType: 'jpg',   // 或 'png'
  quality: 0.9,      // jpg 质量 0~1
  success: (r) => resolve(r.tempFilePath),
  fail: reject
})
```

## 六、createImage() 加载图片

```javascript
const img = canvas.createImage()  // 在离屏canvas上创建Image
img.onload = () => {
  // 图片加载完成，可以 drawImage
  ctx.drawImage(img, ...)
}
img.onerror = () => reject(new Error('图片加载失败'))
img.src = imagePath  // 本地路径或云存储URL
```

**注意**: 图片必须是本地临时路径或云存储URL，不支持网络图片直链

## 七、组件内数据规范

### 1. 组件实例数据要绑定好
```javascript
// 组件要显式 in(this)，否则找不到
const query = wx.createSelectorQuery().in(this)
query.select('#cropCanvas').node(...).exec()
```

### 2. 组件内触摸事件要 in(this)
```javascript
// 绑定组件内的 canvas
this.selectComponent('#cropCanvas')  // 也行
```

## 八、踩坑记录

| 问题 | 根因 | 解法 |
|------|------|------|
| 组件内 Canvas node() 返回 null | 未用 `.in(this)` | query.in(this) |
| canvasToTempFilePath 报错 | 传的canvas id而非实例 | 传 res.node |
| 裁剪结果模糊 | destWidth/destHeight 设太小 | 保持与 canvas 尺寸一致 |
| 图片 src 加载失败 | 用了网络图片直链 | 用本地路径或云存储URL |
