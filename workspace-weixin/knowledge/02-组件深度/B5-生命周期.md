## 一、页面生命周期

| 生命周期 | 时机 | 常用用途 |
|----------|------|---------|
| `onLoad` | 页面加载完成 | 接受参数、初始化数据 |
| `onShow` | 页面显示 | 刷新数据、检查登录 |
| `onReady` | 初次渲染完成 | 获取元素尺寸、启动动画 |
| `onHide` | 页面隐藏 | 暂停定时器、保存状态 |
| `onUnload` | 页面卸载 | 清理资源、取消请求 |
| `onResize` | 窗口尺寸变化 | PC端小程序适配 |
| `onPullDownRefresh` | 下拉刷新 | 触发业务刷新 |
| `onReachBottom` | 上拉触底 | 触底加载更多 |
| `onPageScroll` | 页面滚动 | 懒加载、显示回到顶部 |

### onLoad vs onShow
```javascript
// onLoad：只执行一次，适合一次性初始化
onLoad(options) {
  // 接受页面参数
  const id = options.id
  this.loadDetail(id)
}

// onShow：每次显示都执行，适合数据刷新
onShow() {
  // 检查是否需要刷新
  if (this.data.needRefresh) {
    this.loadList()
  }
}
```

### onReady vs onShow
```javascript
// onReady：DOM渲染完成后，可以获取节点信息
onReady() {
  // ✅ 可以获取节点尺寸
  const query = wx.createSelectorQuery()
  query.select('.content').boundingClientRect()
  query.exec(res => console.log(res[0]))
}
```

## 二、组件生命周期

| 生命周期 | 时机 | 说明 |
|----------|------|------|
| `created` | 组件实例创建 | 只能调用 setData，不适合操作 DOM |
| `attached` | 组件进入页面节点树 | 可以操作 DOM，适合初始化渲染 |
| `ready` | 组件布局完成 | 渲染完成，可以获取节点 |
| `moved` | 组件被移动 | 很少用 |
| `detached` | 组件离开页面节点树 | 清理定时器、取消请求 |

### 执行顺序（重要！）
```
组件实例创建
    ↓
组件进入页面节点树（attached）
    ↓
组件渲染完成（ready）
    ↓
...
    ↓
组件离开页面节点树（detached）
```

### created vs attached
```javascript
Component({
  created() {
    // ✅ 可以 setData
    this.setData({ initialized: true })
    // ❌ 不能获取 DOM（DOM 还没挂载）
    // wx.createSelectorQuery() 在这里拿不到节点
  },
  attached() {
    // ✅ 可以获取节点
    // ✅ 可以操作 canvas 等
  },
  ready() {
    // ✅ 布局完成，尺寸已定
  }
})
```

## 四、定时器处理

```javascript
Page({
  data: { timer: null },
  
  onLoad() {
    // ✅ 统一管理定时器
    this.data.timer = setInterval(() => {
      this.updateData()
    }, 3000)
  },
  
  onHide() {
    // ✅ 页面隐藏时暂停
    if (this.data.timer) {
      clearInterval(this.data.timer)
      this.data.timer = null
    }
  },
  
  onUnload() {
    // ✅ 页面卸载时必须清理
    if (this.data.timer) {
      clearInterval(this.data.timer)
    }
  }
})
```

## 五、错误示例

### 错误1：在 created 中获取节点
```javascript
// ❌ 错误
created() {
  const query = wx.createSelectorQuery()
  query.select('.my-element').boundingClientRect()
  query.exec(res => console.log(res))  // []
}

// ✅ 正确
attached() {
  const query = wx.createSelectorQuery()
  query.select('.my-element').boundingClientRect()
  query.exec(res => console.log(res))
}
```

### 错误2：定时器不清洗
```javascript
// ❌ 错误
onLoad() {
  setInterval(() => { this.update() }, 1000)
}
// 页面关闭后定时器继续跑 → 内存泄漏

// ✅ 正确
onLoad() {
  this.data.timer = setInterval(...)
},
onUnload() {
  clearInterval(this.data.timer)
}
```
