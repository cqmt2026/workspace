## 一、开发者工具调试技巧

### 1. 云函数本地调试
```
步骤：
1. 微信开发者工具 → 云开发 → 云函数 → 右键「本地调试」
2. 右键云函数 → 「启动本地调试」
3. 左侧面板会显示 localFunctionName
4. 前端调用时 name 仍用云函数名，会自动切到本地

注意：
- 本地调试时不要上传云函数，否则会覆盖
- 调试完后记得上传生产版本
```

### 2. 控制台日志
```javascript
// 云函数日志（云端也能看到）
console.log('[DEBUG] data:', data)
console.error('[ERROR]', err.message)

// 前端日志
console.log('变量:', value)
console.warn('警告:', msg)
console.error('错误:', err)

// Canvas 调试（标记关键步骤）
console.log('[Canvas裁剪] 开始')
console.log('[Canvas裁剪] 裁剪区域:', cropX, cropY, cropW, cropH)
console.log('[Canvas裁剪] 成功')
```

### 3. AppData 面板
- 实时查看 data 变化
- 修改 data 可直接双击编辑
- 适合验证 setData 是否生效

### 4. 编译模式切换
```
「详情」→「本地编译模式」
- 每次修改都重新编译（热更新）
- 不需要每次都重启工具
```

## 二、常见报错速查

### 1. 云函数报错

| 错误信息 | 原因 | 解决 |
|---------|------|------|
| `Cannot find module 'wx-server-sdk'` | 云函数没有 npm install | 云函数目录执行 `npm install` |
| `env parameter is required` | cloud.init 没写 env | cloud.init({ env: cloud.DYNAMIC_CURRENT_ENV }) |
| `权限不足` | 客户端直接查云数据库 | 改用云函数查询 |
| `function not exist` | 云函数没上传/没部署 | 上传云函数到云端 |
| `超时` | 云函数执行超30秒 | 增加超时时间或拆分逻辑 |

### 2. 云存储报错

| 错误信息 | 原因 | 解决 |
|---------|------|------|
| `tempFilePath not found` | 临时文件已过期 | 立即上传，不要存着以后用 |
| `file not exist` | cloudPath 错误 | 检查 cloudPath 格式 |
| `upload file too large` | 文件超 20MB | 压缩图片或分片上传 |
| `invalid file type` | 文件类型不支持 | 检查文件后缀 |

### 3. Canvas 相关报错

| 错误信息 | 原因 | 解决 |
|---------|------|------|
| `invalid canvas` | 传的 canvas id 而非实例 | 传 res.node，不传字符串 id |
| `canvas node is null` | 组件内未用 in(this) | query.in(this) |
| `image load failed` | 图片路径错误/失效 | 用本地路径或云存储 URL |
| `canvas has not been initialized` | canvas还没创建完成 | 放在 canvas 的 node callback 里 |

### 4. 云数据库报错

| 错误信息 | 原因 | 解决 |
|---------|------|------|
| `collection not exist` | 集合名拼写错误/没创建 | 检查集合名，确认已创建 |
| `permission denied` | 权限不足 | 走云函数查询，或修改权限规则 |
| `document not exist` | 删除了或_id错误 | 检查 _id 是否正确 |

### 5. OCR 报错

| 错误信息 | 原因 | 解决 |
|---------|------|------|
| `error_code: 110` | AK/SK 错误 | 检查百度云 API Key |
| `error_code: 1006` | 服务未开通 | 开通对应 OCR 服务 |
| `access_token expired` | token 过期 | 检查 token 缓存逻辑 |
| `无文字` | 图片太模糊/无文字 | 提高图片质量，或换角度拍摄 |

## 三、调试检查清单

### 1. OCR 识别失败排查
```
[ ] 检查 imagePath 是否有效
[ ] 检查 imagePath 是否本地临时路径（不是云存储URL）
[ ] 检查 cloudPath 格式是否正确
[ ] 检查 fileID 是否有效
[ ] 检查云函数日志，看具体报错
[ ] 检查 access_token 是否过期
```

### 2. Canvas 裁剪失败排查
```
[ ] canvas 是否用了 type="2d" + id
[ ] query 是否用了 .in(this)
[ ] canvas.width/height 是否设置了
[ ] img.onload 是否触发
[ ] 导出的 destWidth/destHeight 是否正确
```

### 3. setData 不生效排查
```
[ ] setData 在哪个生命周期调用（created阶段DOM还没挂载）
[ ] 是否用了 setData callback 确认
[ ] 检查路径是否正确（'list[0].name' vs 'list.0.name'）
```

## 四、真机调试

### 1. 开启真机调试
```
微信开发者工具 → 详情 → 本地设置 → 勾选「启用真机调试」
或点击工具栏「真机调试」按钮
```

### 2. 真机调试常见问题
```
问题：控制台连不上
解决：确保手机和电脑在同一局域网

问题：云函数调用失败
解决：检查云开发环境是否开通

问题：图片不显示
解决：真机可能不支持网络图片直链，用云存储 URL
```

### 3. 手机端查看日志
```javascript
// 手机端触发错误时打印
console.error('[ERROR]', err)
console.log('[DEBUG]', JSON.stringify(data))

// 真机调试面板会显示 console 输出
```

## 五、云函数调试

### 1. 云函数本地调试配置
```javascript
// index.js 入口
exports.main = async function(event, context) {
  console.log('接收参数:', JSON.stringify(event))
  
  try {
    // 业务逻辑
    const result = await doSomething(event)
    return { success: true, data: result }
  } catch (err) {
    console.error('错误:', err.message)
    return { success: false, errMsg: err.message }
  }
}
```

### 2. 云函数超时配置
```json
// project.config.json
{
  "cloudfunctionTimeout": 300  // 默认60秒，可调大
}
```

### 3. 云函数日志查看
```
微信开发者工具 → 云开发控制台 → 云函数 → 日志
可以按时间、调用来源筛选
```

## 六、常用调试代码片段

### 1. 打印完整对象
```javascript
console.log('obj:', JSON.stringify(obj, null, 2))
```

### 2. 检查函数参数
```javascript
function doOCR(fileID) {
  if (!fileID) {
    console.error('[OCR] fileID 为空！')
    return Promise.reject(new Error('fileID 不能为空'))
  }
  console.log('[OCR] 开始识别，fileID:', fileID)
  // ...
}
```

### 3. 检查 setData 前后对比
```javascript
console.log('setData 前:', JSON.stringify(this.data.form))
this.setData({ 'form.question': newQuestion })
console.log('setData 后（异步）:', JSON.stringify(this.data.form))
// 注意：setData后直接读可能还是旧值，用callback确认
this.setData({ 'form.question': newQuestion }, () => {
  console.log('setData 完成:', JSON.stringify(this.data.form))
})
```

## 七、快捷调试命令

```javascript

  onShow() {
    this.setData({ ...getApp().globalData.defaultForm })
  }
```

### 2. 模拟网络错误
```javascript
// 在控制台模拟错误
wx.cloud.callFunction = () => Promise.reject(new Error('模拟网络错误'))
```

### 3. 快速清空数据库测试数据
```javascript
// 云函数内慎用！
exports.main = async function() {
  const db = cloud.database()
  const res = await db.collection('wrongbooks').get()
  for (const item of res.data) {
    await db.collection('wrongbooks').doc(item._id).remove()
  }
  return { success: true, deleted: res.data.length }
}
```
