# 主系统 修复日志 - 2026-08-03 agnes-2.5-flash配置

## 问题描述
- 现象：主人想使用 agnes-2.5-flash 新模型，但配置中只有 agnes-2.0-flash
- 影响范围：无法使用最新模型能力
- 触发条件：主人询问

## 根因分析
- 直接原因：
  1. 配置中只有 agnes-2.0-flash，无 2.5
  2. 国际站 `apihub.agnes-ai.com` 国内无法连接
  3. 新 provider 未加入 OpenClaw 白名单
- 深层原因：模型升级后未及时同步配置

## 修复方案
1. 新增 provider `agnes-25`，baseUrl 指向国内站 `https://api.agnes-ai.cn/v1`
2. 添加模型 `agnes-2.5-flash`（512K上下文，65.5K最大输出）
3. 将新模型加入 `agents.defaults.models` 白名单
4. 重启 gateway 生效
5. API 直连验证：HTTP 200，响应正常

## 验证结果
- 验证方法：`session_status` 切换 + API curl 测试
- 结果：通过

## 经验教训
- 新增模型时必须同时检查白名单
- agnes-ai 国内站和国际站域名不同，需区分使用
- API Key 含 `…` 时直接写入配置文件即可，无需手动输入HTTP头
