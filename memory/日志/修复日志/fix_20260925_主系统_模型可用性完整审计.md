## 执行步骤

### 第一步：完整审计
- 运行 `audit_models_v3.py` 对所有 provider+model 组合进行 HTTP 连通性测试
- 结果：Nvidia provider 全部 410 Gone；sensenova 部分 404

### 第二步：配置修正
- **移除 Nvidia provider**：deepseek-ai、meta、mistralai 三个共享同一 key，全部不可用
- **修正 sensenova provider**：
  - 移除不存在的模型：sensenova-u1-fast、sensenova-6.7-flash-lite、deepseek-v4-pro
  - 添加缺失模型：glm-5.2、sensenova-6.8-flash-lite、kimi-k3
  - 修正版本号：6.7 → 6.8
- **保留 agnes-image/agnes-video**：可通过独立端点调用

### 第三步：Fallback 优化
- 按响应速度排序：glm-5.2 → sensenova-6.8-flash-lite → agnes-2.5-flash → deepseek-v4-flash → agnes-2.0-flash → GLM-5.1-FP8
- 最终验证：7 个对话模型全部可用

### 第四步：文档同步
