# 系统全面检查 + Cron故障修复 + C盘清理

## 背景
2026-08-10 主人发起系统全面检查，发现约20个Cron任务连续ERROR，C盘空间告急。

## 问题1：Cron isolated timeout（高严重度）
**症状**：约20个任务连续报 `cron: isolated agent setup timed out before runner start`
- Hot-Topic-Finder（14次）、INV-ML-Training（10次）、Daily-Morning-Report（7次）等
- 成功任务全是轻量短任务（Self-Heal 54s / System-Maintenance 13s / Memory-Recall 22s）
- 失败全是长任务（Hot-Topic 900s timeout / ML 2400s timeout）

**根因**：
1. `agents.defaults.maxConcurrent=4` 并发上限，长任务占满4个隔离会话槽位
2. 叠加C盘空间不足（仅6.7GB），会话创建临时文件失败

**修复**：
- `maxConcurrent: 4 → 8`（修改 openclaw.json）
- 重启 Gateway 使生效（pid 11648，运行正常）
- 清理C盘释放空间
