# 修复日志：语义搜索能力升级

## 问题描述
系统知识检索仅支持关键词匹配（LIKE查询），无法进行语义理解，导致相关但措辞不同的内容无法被检索到。

## 修复方案
1. 确认依赖包已安装
2. 创建semantic_search.py语义搜索引擎
3. 支持sentence-transformers向量搜索
4. 提供TF-IDF降级方案

## 执行步骤

### 1. 依赖验证
```bash
pip list | grep -E "scikit-learn|sentence-transformers"
```
结果：
- scikit-learn: 1.8.0 ✅
- sentence-transformers: 3.3.0 ✅

### 2. 创建语义搜索脚本
- 文件：`workspace/scripts/semantic_search.py`
- 大小：约8KB
- 功能：
  - 自动扫描所有知识库
  - 使用sentence-transformers生成向量
  - 支持LanceDB向量存储
  - 提供TF-IDF降级方案

### 3. 使用方式
```bash
# 构建索引
python semantic_search.py --build-index

# 执行搜索
python semantic_search.py --query "RPS选股策略" --top-k 5

# 指定模型
python semantic_search.py --query "低空经济" --model "shibing624/text2vec-base-chinese"
```

## 技术细节

### 向量模型
- 默认模型：`shibing624/text2vec-base-chinese`
- 维度：768维
- 首次使用需下载模型（约400MB）

### 降级策略
| 优先级 | 方案 | 适用场景 |
|--------|------|----------|
| 1 | LanceDB + sentence-transformers | 有GPU/大量数据 |
| 2 | JSON + numpy | 中等规模 |
| 3 | TF-IDF + sklearn | 小规模/无依赖 |
