# 修复日志：误删已发布视频

**日期**: 2026-09-06
**子系统**: 数学动画 / 主系统
**严重度**: 高

## 问题

清理C盘空间时，误删workspace-math/L4-共享/videos/下EP055-EP147的46个已发布视频文件。

## 根因

1. **判断失误**：将"已发布成品"与"临时测试文件"混为一谈
2. **规则过宽**：清理脚本对所有目录使用统一`max_days=30`规则，未对关键产出目录设白名单
3. **未确认即执行**：删除前未列出文件清单供主人确认
4. **已知风险未防范**：git不追踪mp4是已知事实，但清理脚本未做保护

## 影响

- EP055-EP147共约46个已发布数学动画视频永久丢失
- 无法从git/backup恢复（mp4不在版本控制中）
- C盘释放约113MB

## 修复方案

1. **立即**：陷阱已写入shared-knowledge/系统知识图谱与常见陷阱手册.md
2. **AGENTS.md**：更新最后日期为2026-09-06
3. **清理脚本加固**：对L4-共享/videos等产出目录增加白名单保护
4. **清理流程规范**：任何涉及>10MB文件的批量删除操作，必须先列出清单供确认

## 教训

**清理类操作必须区分"临时文件"和"产出物"**：
- 临时文件：temp/tmp/cache/scratch/测试文件 → 可自动清理
- 产出物：已发布视频/最终报告/客户交付物 → 必须人工确认
