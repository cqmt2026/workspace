## ✅ AS005 结尾页修复 + v9 完成（23:55）

### 问题
- AS005_v8 结尾页被截断（61s，原应 63s）
- 根因：`-shortest` 依赖 container 元数据，当 stream duration 元数据与实际不符，提前终止
- 教训：视频流 duration 元数据（69s）≠ container 报告时长（63s），`-shortest` 基于错误元数据截断

### 修复方案
- v9 = 原始视频（63.500s）+ 音频（63.488s）
- 使用 `-t 63.5` 精确控制，不用 `-shortest`
- 音画同步误差：仅 0.012s

### 核心经验：FFmpeg 合并标准流程
```
① ffprobe -select_streams v:0 -show_entries stream=duration -of csv=p=0 input.mp4
② 确认音频实际时长
③ 确定主参考（通常音频）
④ 用 -t 精确截取/补齐，不用 -shortest
⑤ 必查结尾帧（最后 3 秒）
```
