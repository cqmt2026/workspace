## 📋 模板分类

### 1. 创作类模板

#### 小说章节生成
```markdown
# 第 XX 章 [章节名]

> **本章概要**：一句话概括核心事件
> **本章爽点**：打脸/突破/获宝/逆转...
> **情绪曲线**：低开高走 / 层层递进 / 反转爆发

---

（开篇：承接上章 / 场景切入 / 对话开场）

（发展：矛盾升级 / 信息揭示 / 力量展示）

（高潮：本章爽点 / 冲突爆发 / 反转发生）

（收束：结果呈现 / 众人反应 / 章末钩子）

---

> **章末钩子**：[留下的悬念]
> **下章预告**：[下一章简要提示]
```

---

#### 自媒体文章生成
```markdown
# [标题]

> **核心观点**：一句话概括
> **目标读者**：[读者画像]
> **情绪基调**：激励/警示/科普/娱乐

---

（痛点引入：100 字）
- 描述读者痛点
- 引发共鸣

（方法/经验：500 字）
- 方法 1 + 案例
- 方法 2 + 案例
- 方法 3 + 案例

（总结 + 行动号召：100 字）
- 总结核心观点
- 引导行动
```

## 🔧 模板使用规范

### 必填字段

| 模板类型 | 必填字段 |
|---------|---------|
| 小说章节 | 章节名、概要、爽点、章末钩子 |
| 自媒体 | 标题、核心观点、目标读者 |
| 调研报告 | 调研时间、范围、核心发现 |
| 会话摘要 | 日期、完成事项、待办事项 |

---

### 可选字段

| 模板类型 | 可选字段 |
|---------|---------|
| 小说章节 | 情绪曲线、下章预告 |
| 自媒体 | 情绪基调、案例数量 |
| 调研报告 | 数据支撑、趋势分析 |
| 会话摘要 | 系统状态、中断记录 |

## 📝 模板使用示例

### 示例：生成小说章节

**输入**:
```
题材：都市男频
第 38 章：代价
大纲：陆鸣接到威胁电话，周志远提出年薪一百万收买
爽点：主角拒绝诱惑，坚持原则
```

**输出**:
```markdown
# 第 38 章 代价

> **本章概要**：陆鸣拒绝周志远收买
> **本章爽点**：主角坚持原则，拒绝诱惑
> **情绪曲线**：低开高走

---

（开篇：威胁电话）
...

（发展：年薪一百万收买）
...

（高潮：陆鸣拒绝）
...

（收束：继续调查）

---

> **章末钩子**：神秘人再次联系
> **下章预告**：新的线索浮现
```
