## 问题1：LOGO太小

**表现**: 结尾页LOGO完全看不清，极小

**根因分析**:
```python
# 原代码
logo.scale(0.4)           # scale(0.4) 相对于原图(2048×2048)太小
logo.to_edge(DOWN, buff=3.5)
```

Manim的 `scale()` 是相对于Mobject自身的维度：
- 原图 2048×2048 像素
- `scale(0.4)` → 819×819 像素
- 在竖屏 1080×1920 中只占约 42% 宽度
- LOGO高度 819px / 1920px 总高 ≈ 42.6%，看起来很小

**修复**: 改用 `height=2.5` 直接设置高度
```python
# 修复后
logo.height = 2.5  # scene单位，竖屏16单位高，2.5占15.6%，清晰可见
```

**教训**: Manim中设置图片大小优先用 `height`/`width` 而非 `scale()`

## 问题2：无音频

**表现**: 渲染出来的视频完全没有声音

**根因分析**:
```python
# 原代码
self.add_sound = lambda *args, **kwargs: None  # placeholder
```
这是一个空实现，根本没有加载音频文件。

**为什么会这样**: 之前的脚本用placeholder占位，但TTS生成失败后没有检查。实际音频 `audio_ep059_68.mp3`（1.2MB）存在，但代码没有调用它。

**修复**: 不用manim的add_sound，改用ffmpeg后处理嵌入音频
```bash
ffmpeg -y -i video.mp4 -i audio_ep059_speed.mp3 -c:v copy -c:a aac -shortest output.mp4
```

**教训**: 
1. TTS生成后要检查文件大小（68bytes明显是错误的）
2. 音频用ffmpeg后处理比manim内置更可靠

## 问题3：横屏渲染（最严重）

**表现**: 多次渲染都出来横屏1920×1080，而不是竖屏1080×1920

**根因分析**: Manim默认使用 16:9 横屏比例（frame_width=14.22, frame_height=8.0）

虽然脚本里设置了：
```python
config.frame_width = 9
config.frame_height = 16
```

但这只是在scene单位下的设置，不等于输出分辨率。

**错误尝试**:
1. 用 `--format=mp4 -qh` → 出来横屏（没指定分辨率）
2. 用 `-r 1920,1080` → 出来横屏（方向反了）
3. 用ffmpeg旋转 → 方向错误，画质损失

**正确做法**:
```bash
python -u -m manim scripts/ep059_scene.py EP059_Scene -r 1080,1920 --format=mp4 --disable_caching -ql
```
注意：`-r` 参数格式是 `宽,高`，所以 `1080,1920` = 宽1080高1920 = 竖屏

**另一个坑**: 渲染出来的目录名会骗人
- 用 `-ql` (480p) 时，目录名是 `1920p15` 但实际视频是 `1080,1920` 竖屏
- **必须用 ffprobe 验证实际分辨率**

**教训**:
1. Manim渲染必须显式指定 `-r 宽,高` 才能得到正确分辨率
2. 不要相信目录名，用 ffprobe 检查实际视频元数据
3. `-r` 参数格式是 `宽,高` 不是 `高,宽`

## 问题4：文字重叠

**表现**: 结尾页的CTA文字"学会了？转发给同学比比谁更快！"和LOGO重叠

**根因分析**:
```python
# 结尾页布局
teacher = Text("谢谢观看！", font_size=52)
teacher.move_to(UP * 3)        # Y ≈ 3

cta = Text("学会了？转发给同学比比谁更快！", font_size=32)
cta.move_to(DOWN * 2)          # Y ≈ -2

logo = ImageMobject(...)
logo.height = 2.5
logo.to_edge(DOWN, buff=3.5)    # LOGO底部 Y = -4 + 3.5 = -0.5
                                # LOGO顶部 Y = -0.5 + 2.5 = 2.0
```

计算得出：
- LOGO顶部 Y = 2.0
- teacher底部 Y ≈ 2.0（和LOGO重叠！）
- cta底部 Y = -2（也和LOGO重叠！）

**修复**:
```python
cta.move_to(DOWN * 5.5)  # Y = -5.5，完全在LOGO下方
```

**教训**: 结尾页布局要先计算所有元素的位置，用数学保证不重叠

## 问题5：缓存导致修改无效

**表现**: 修改了脚本代码，但渲染出来还是旧版本

**根因**: Manim有内置缓存机制，即使指定了 `--disable_caching`，某些情况下缓存仍然生效

**修复**: 
```bash
# 双重保险
Remove-Item -Path "L4-共享\frames\ep059_fruit" -Recurse -Force  # 手动删除缓存目录
python -u -m manim scripts/ep059_scene.py ... --disable_caching
```

**教训**: 修改代码后要手动删除缓存目录，不能只依赖 `--disable_caching`
