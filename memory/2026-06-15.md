### bullets_list
```python
def bullets_list(scene, items, start_pos, font_size=28, color="#FFFFFF",
                direction=DOWN, spacing=0.7, run_time=0.4):
    texts = []
    for i, item in enumerate(items):
        t = Text(str(item), font="Microsoft YaHei", font_size=font_size, color=color)
        t.move_to(start_pos + direction * i * spacing)
        texts.append(t)
    for t in texts:
        scene.play(Write(t), run_time=run_time)
        scene.wait(0.15)
    return texts
```

## EP107竖式修复（22:43补充）

### 问题描述
主人反馈EP107视频中竖式布局完全不对，不是标准手工对齐格式。

### 根因定位（3轮排查）
| 轮次 | 方法 | 结果 |
|------|------|------|
| 第1轮 | 修改坐标值 | 无效 |
| 第2轮 | 更新division_frame函数 | 文件被SESSION COMPACTION恢复旧内容 |
| 第3轮 | 修改EP107_pages.py | 无效 |

**最终根因**：`LEFT * 0.5` 是 numpy ndarray，不是 Mobject，`next_to()` 链式调用对 ndarray 完全失效 → 所有元素坐标变成 NaN → 竖式从根本上就画错了。

### 修复方案
**不用 next_to 链，全部改用显式绝对坐标**：
```python
d25.move_to(np.array([bar_x, 0.0, 0.0]))
D638.move_to(np.array([divd_x, 0.0, 0.0]))
q25.move_to(np.array([bar_x, 3.5, 0.0]))
p625.move_to(np.array([divd_x, -1.0, 0.0]))
r13.move_to(np.array([divd_x, -3.0, 0.0]))
```

### 标准竖式手工布局（最终版）
```
    商25(x=-1.5, y=3.5)     ← 竖线上方偏左
除数25(x=-1.5, y=0.0) | 被除数638(x=1.5, y=0.0)  ← 同一水平线
竖线x=-1.5           | 积625(x=1.5, y=-1.0)      ← 横线上方
                       ---(y=-0.5)                 ← 横线
                         余数13(x=1.5, y=-3.0)    ← 横线下方
```
**核心规则**：除数/被除数/积/余数全部右端对齐（对齐到被除数638的右端 x=1.5）
