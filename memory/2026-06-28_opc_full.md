## 一、easychen/opc-methodology (16k星)

**作者**: Easy（方糖07，Server酱作者）
**版本**: 2.0（2026年4月更新）
**协议**: CC BY-NC-SA 4.0

### 4大模块18章完整结构

**模块一：定义一人企业**
- 一人企业 = 个人驱动 + 可持续收入 + 智能杠杆 + 生活方式优先
- 不是自由职业/咨询，而是有系统性收入的商业模式
- 核心区别：用工具和自动化替代人力堆砌

**模块二：底层逻辑（4篇）**
1. **以小博大**：用杠杆而非人力，软件/内容/自动化是杠杆
2. **规模化**：从1到N不是加人，是加杠杆
3. **资产和被动收入**：三池模型（现金池/资产池/杠杆池）
   - 现金池：工资、项目收入（主动）
   - 资产池：数字产品、课程、版权（半被动）
   - 杠杆池：社区、品牌、工具链（被动放大）
4. **滚雪球和链式传播**：内容→流量→信任→转化→复购→推荐

**模块三：赛道选择与竞争策略**
- **不竞争策略**：找蓝海，不进入红海拼价格
- **结构化优势**：你的独特组合 = 你的护城河
  - 举例：会编程+懂投资+会写作 = 独特赛道
  - 与我们匹配度极高：主人 = 写作+投资+自媒体+AI

**模块四：构建一人业务**
- OPB画布（One Person Business Canvas）：9格规划工具
  - 价值主张 / 用户画像 / 渠道 / 收入模式 / 成本 / 关键活动 / 关键资源 / 关键伙伴 / 不做的事
- 月报制度：每月复盘，3个关键指标
- MVP设计：最小可行实验，1-2周出结果
- 用户池和触达能力：
  - 内容池：文章/视频/播客（产出一次，持续触达）
  - 社交池：粉丝/关注/邮件列表
  - 搜索池：SEO/关键词/长尾流量
  - 触达能力 = 池子大小 × 转化率 × 复购率

**模块五：基础设施搭建**
- 工具选择原则：免费优先、自动化优先、少即是多
- 9个AI技能集（为Claude Codex设计，与OpenClaw不兼容，已评估后删除）
- 推演沙箱：方糖真实创业模拟器（需Gemini 2.5 PRO）

### 三池四能力模型

| 池 | 内容 | 被动程度 |
|---|---|---|
| 现金池 | 工资、项目收入 | 主动 |
| 资产池 | 数字产品、课程、版权 | 半被动 |
| 杠杆池 | 社区、品牌、工具链 | 被动放大 |

| 能力 | 说明 |
|---|---|
| 产出能力 | 持续生产内容/产品 |
| 触达能力 | 让目标用户看到你 |
| 转化能力 | 把流量变成收入 |
| 复利能力 | 让资产自己增长 |

## 二、chen103226/awesome-one-person-company (158星)

**定位**: 一人公司高信号精选清单
**特色**: 只收录真实产品+真实收入+真实复盘

### 一人公司定义

| 特征 | 说明 | 反例 |
|---|---|---|
| 单人运营 | 1人或至多5人小团队 | 需要大规模团队 |
| 可持续收入 | 有稳定现金流(MRR/ARR) | 纯开源/hobby项目 |
| 杠杆效应 | 依赖软件/内容/自动化 | 咨询公司/劳动密集型 |
| 自主控制 | 追求自由与自主，非盲目扩张 | 风投驱动高速增长 |

核心理念：**Build a life, not just a company.**

### 30天启动清单

**Week 1: 验证想法**
- 确定目标用户痛点（至少访谈10人）
- 在Reddit/X/小红书寻找相关抱怨
- 制作简单落地页（Carrd/Framer）
- 预售测试（至少5个意向付费用户）
- 推荐：《The Mom Test》

**Week 2: MVP开发**
- 技术栈：Next.js + Supabase + Vercel
- 只做最小可行产品
- 集成支付（Stripe/Lemon Squeezy）
- 预算：$0-100

**Week 3: 内测与迭代**
- 邀请10-20个beta用户
- 收集反馈快速迭代
- 目标：Beta用户留存率 > 30%

**Week 4: 公开发布**
- Product Hunt发布
- 社区分享（Reddit/HN/V2EX）
- Build in Public博客
- 目标：获得第一个付费用户

### 创业Idea验证方法（The Mom Test原则）
1. 确定目标用户（越具体越好）
   - ❌ "想帮助创业者" → ✅ "帮助B站up主分析视频数据"
2. 发现真实痛点（避免假需求）
   - ❌ "你觉得这个功能有用吗？" → ✅ "上次你分析数据时遇到什么困难？"
3. 验证付费意愿（提前收钱）
   - ❌ "如果我做了你会用吗？" → ✅ "如果现在就有，你愿意支付多少？"
4. 快速MVP测试（1-2周）
   - 落地页 + Waitlist
   - 手动提供服务（伪装自动化）
   - 至少5个付费意向用户→开始开发
