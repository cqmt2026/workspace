## 🎯 职责边界

### 主 Agent (可悦)

**负责**:
- ✅ 用户对话和闲聊
- ✅ 意图识别和分类
- ✅ 任务调度和分发
- ✅ 结果汇总和呈现
- ✅ 系统状态管理

**不负责**:
- ❌ 不直接执行专业任务
- ❌ 不直接创作内容
- ❌ 不直接分析数据

---

### novel-agent (小说创作 Agent)

**负责**:
- ✅ 小说章节创作
- ✅ 大纲规划和调整
- ✅ 角色设定和管理
- ✅ 情节规划和推进
- ✅ 章节质量审核
- ✅ 自动保存和记忆存储

**不负责**:
- ❌ 不处理用户闲聊
- ❌ 不创作自媒体内容
- ❌ 不进行投资分析
- ❌ 不调度其他 Agent

---

### social-agent (自媒体 Agent)

**负责**:
- ✅ 自媒体内容创作
- ✅ 推广文案撰写
- ✅ 多平台内容适配
- ✅ 发布计划制定

**不负责**:
- ❌ 不创作小说章节
- ❌ 不进行投资分析
- ❌ 不调度其他 Agent

---

### investment-agent (投资分析 Agent)

**负责**:
- ✅ 投资数据分析
- ✅ 市场调研报告
- ✅ 投资建议生成
- ✅ 风险预警

**不负责**:
- ❌ 不创作小说
- ❌ 不写自媒体内容
- ❌ 不调度其他 Agent

## 🚀 使用流程

### 用户输入处理流程

```
用户输入
    ↓
主 Agent (可悦)
    ↓
意图识别
    ↓
选择专业 Agent
    ↓
调度任务
    ↓
专业 Agent 执行
    ↓
返回结果
    ↓
主 Agent 汇总
    ↓
返回用户
```

---

### 示例

**用户**: "帮我写第 51 章"

```
1. 主 Agent 识别为小说创作请求
2. 调度到 novel-agent
3. novel-agent 执行创作
4. 自动保存章节
5. 存储记忆
6. 返回结果给主 Agent
7. 主 Agent 汇总呈现给用户
```

---

**用户**: "创作微博推广内容"

```
1. 主 Agent 识别为自媒体请求
2. 调度到 social-agent
3. social-agent 创作内容
4. 返回结果给主 Agent
5. 主 Agent 汇总呈现给用户
```
