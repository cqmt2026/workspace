# 上下文压缩规则

**创建时间**: 2026-04-04  
**用途**: 长会话自动摘要，避免 Token 超限

---

## 🎯 触发条件

### 条件 1：Token 使用率

| 使用率 | 操作 | 通知 |
|--------|------|------|
| > 50% | 主动汇报 | ✅ |
| > 80% | 触发压缩 | ✅ |
| > 95% | 强制压缩 | ✅ |

---

### 条件 2：会话长度

| 消息数 | 操作 | 说明 |
|--------|------|------|
| > 50 条 | 建议压缩 | 提醒用户 |
| > 100 条 | 自动压缩 | 生成摘要 |
| > 200 条 | 强制压缩 | 分段摘要 |

---

### 条件 3：会话时长

| 时长 | 操作 | 说明 |
|------|------|------|
| > 2 小时 | 中期摘要 | 记录关键决策 |
| > 4 小时 | 完整摘要 | 生成会话总结 |
| > 8 小时 | 分段摘要 | 按主题分段 |

---

## 📋 压缩策略

### 策略 1：关键信息保留

**必须保留**:
- ✅ 用户明确指令
- ✅ 重要决策
- ✅ 待办事项
- ✅ 系统状态变更
- ✅ 文件操作记录

**可以删除**:
- ❌ 冗余对话
- ❌ 重复确认
- ❌ 中间思考过程
- ❌ 已完成的临时任务

---

### 策略 2：分层压缩

```
L0: 当前会话 (Context Window) - 不压缩
L1: 每日日志 (memory/YYYY-MM-DD.md) - 轻度压缩
L2: 核心记忆 (MEMORY.md) - 中度压缩
L3: 知识库 (bank/) - 不压缩
L4: 跨 Agent 共享 - 不压缩
L5: 人类知识层 - 不压缩
```

---

### 策略 3：主题分段

**按主题分段压缩**:
```
会话摘要 (2026-04-04)
├── 《鉴城师》优化
│   ├── 完成：41-50 章优化
│   └── 待办：Agent 搭建
├── 三 Agent 搭建
│   ├── 完成：计划制定
│   └── 待办：P0 实施
└── claw-code 调研
    ├── 完成：价值分析
    └── 结论：参考不照搬
```

## 🔄 压缩流程

### 自动压缩流程

```
1. 检测触发条件 (Token/长度/时长)
   ↓
2. 生成会话摘要
   ↓
3. 保存到 memory/YYYY-MM-DD.md
   ↓
4. 更新 MEMORY.md（如需要）
   ↓
5. 通知用户压缩完成
```

---

### 手动压缩命令

```
/compress - 立即压缩当前会话
/summary - 生成会话摘要
/status - 查看 Token 使用率
```

## ⚠️ 注意事项

### 不要压缩的内容

1. **用户明确指令** - "记住这个"、"保存到记忆"
2. **重要决策** - 项目方向、重大变更
3. **待办事项** - 未完成的任务
4. **系统配置** - 配置变更、规则更新
5. **情感表达** - 用户偏好、反馈

---

### 压缩失败处理

| 情况 | 处理方式 |
|------|---------|
| Token 超限 | 分段压缩，优先保留最近内容 |
| 保存失败 | 重试 3 次，失败则通知用户 |
| 摘要质量差 | 人工审核，手动修正 |
