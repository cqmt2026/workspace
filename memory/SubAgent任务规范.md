# Sub-Agent使用规范

**版本**: V1.0
**创建**: 2026-04-28
**来源**: corrections.md教训

---

## 核心原则

**Sub-Agent只做简单任务，复杂逻辑必须主会话**

---

## 适用任务（✅可用Sub-Agent）

### 简单批量操作
| 任务类型 | 示例 | 成功率 |
|----------|------|---------|
| 文本替换 | 批量替换关键词 | 80%+ |
| 文件复制 | 备份/批量复制 | 90%+ |
| 文件删除 | 清理临时文件 | 90%+ |
| 目录扫描 | 查找特定文件 | 85%+ |
| 内容统计 | 字数统计/行数统计 | 90%+ |

### 脚本执行
| 任务类型 | 示例 | 成功率 |
|----------|------|---------|
| 简单脚本 | 单一功能脚本 | 85%+ |
| 数据导出 | CSV/JSON导出 | 85%+ |
| 定时任务 | cron任务触发 | 90%+ |

---

## 不适用任务（❌禁用Sub-Agent）

### 复杂逻辑
| 任务类型 | 原因 |
|----------|------|
| 渲染测试 | Manim进程复杂，容易失败 |
| 音视频合并 | FFmpeg参数多，易出错 |
| 图像生成 | 需要预览确认 |
| 决策判断 | 需要主会话上下文 |

### 关键验收
| 任务类型 | 原因 |
|----------|------|
| 最终发布 | 必须主会话确认 |
| 对外发送 | 必须主会话确认 |
| 删除操作 | 不可逆，必须主会话 |

### 复杂编程
| 任务类型 | 原因 |
|----------|------|
| 多文件协同 | 依赖复杂 |
| 新功能开发 | 需要调试 |
| Bug修复 | 需要验证 |

---

## 任务拆分原则

### 复杂任务拆成简单任务

```
❌ 禁止：Sub-Agent生成10个Scene
✅ 正确：Sub-Agent生成单个Scene，主会话合并
```

```
❌ 禁止：Sub-Agent批量渲染+合并+发布
✅ 正确：Sub-Agent渲染，主会话合并，主会话发布
```

---

## 验收规则

### Sub-Agent完成后

1. **必须验证输出文件存在**
2. **主会话检查结果**
3. **失败立即回退，不积累**

### 验收检查点

```
Sub-Agent完成 →
  □ 输出文件存在？
  □ 文件大小合理？
  □ 内容格式正确？
  ↓
  失败 → 主会话重做或手动处理
  成功 → 继续下一步
```

---

## 配置建议

```python
# Sub-Agent超时设置
subagent(
    runtime="subagent",
    timeout=120,  # 复杂任务120s
    retry=2        # 最多重试2次
)
```
