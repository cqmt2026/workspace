## 一、重要说明

Pavo AI 是一个 SPA（单页应用），作品库通过 JavaScript 动态渲染，无法直接通过 URL 获取。本报告基于**逆向分析其前端 JS 代码**，提取 API 端点、数据模型和参数结构，推断路径生成高质量提示词。

## 三、数据模型逆向

### 3.1 作品/媒体数据结构

根据 JS 代码中的字段提取逻辑，一个作品（Work）包含以下核心字段：

```javascript
// 作品数据模型
{
  id: string,                      // 作品ID
  title: string,                   // 标题
  description: string,             // 描述文字
  prompt: string,                  // 用户输入原始prompt
  prompt_display: string,          // 展示用prompt（可能经过增强）
  video_prompt: string,            // 视频专用prompt（系统增强版）
  image_prompt: string,            // 图片专用prompt
  
  // 媒体信息
  mediaType: "image" | "video",    // 媒体类型
  media_info_json: {               // 媒体详细信息
    video_url: string,             // 视频URL
    image_url: string,             // 图片URL
    thumbnail_url: string,         // 缩略图
    ratio: string,                 // 宽高比 "16:9" | "9:16" | "1:1"
    duration: number,              // 时长（秒）
    width: number,                 // 分辨率宽
    height: number,                // 分辨率高
    fps: number,                   // 帧率
    file_size: number,             // 文件大小
  },
  
  // 生成参数
  model_code: string,              // 模型代码 (如 "Seedream")
  model_alias: string,             // 模型显示名
  ratio: string,                   // 宽高比
  resolution: string,              // 分辨率 (SD/HD/FHD)
  duration: number,                // 时长
  
  // 时间戳
  created_at: string,              // 创建时间
}
```

### 3.2 生成请求体结构

**基础图片/视频生成**:
```javascript
{
  model_code: "Seedream",          // 模型标识
  model_type: "video" | "image",   // 模型类型
  inputs: [                        // 输入数组
    {
      type: "text",
      content: "用户的prompt文本"
    },
    {
      type: "image",
      url: "参考图URL",
      role: "first_frame" | "last_frame" | "reference"
    }
  ],
  outputs: [                       // 期望输出
    {
      type: "video",
      format: "mp4"
    }
  ]
}
```

**特殊视频生成** (`special-video/generate`):
```javascript
{
  model_code: string,
  style_id: string,                // 风格ID
  keyframe_production_mode: "single_frame",
  upload_reference_image_url: string,  // 参考图URL
  custom_style_prompt: string,     // 自定义风格提示
  resolution: string,              // 分辨率
  // ... 其他参数
}
```

**短剧生成**:
```javascript
{
  segment_ids: ["seg_001"],        // 片段ID列表
  style_id: string,                // 风格ID
  model_code: string,              // 模型代码
  keyframe_production_mode: "single_frame",
  resolution: string,              // 分辨率
}
```

### 3.3 Canvas 对话模式

Pavo 的核心是 AI 对话式创作，通过 `conversation` 机制：
```javascript
// 对话消息结构
{
  conversationId: string,
  userMessage: "用户输入的创作指令",
  params: {
    baseMode: "generate_video",    // 基础模式
    type: "omni_to_video",         // 子类型
    model: "Seedream",             // 模型
    uploadedMaterials: [...],      // 上传素材
    firstFrame: {...},             // 首帧
    lastFrame: {...},              // 尾帧
  },
  prompt: "enhanced_prompt_text",  // 增强后的prompt
}
```

### 4.1 支持的模型模式

从代码中识别出的生成模式：

| 模式代码 | 中文含义 | 说明 |
|---------|---------|------|
| `generate_video` | 视频生成 | 从文本/图片生成视频 |
| `generate_image` | 图片生成 | 从文本生成图片 |
| `omni_to_video` | 综合→视频 | 多模态输入生成视频 |
| `frames_to_video` | 帧→视频 | 多图合成视频 |
| `1st_last_frame_to_video` | 首尾帧→视频 | 首尾帧驱动视频 |
| `image_edit` | 图片编辑 | 对已有图片编辑 |
| `visual-detail-image-edit` | 视觉细节编辑 | 精细图片编辑 |

### 4.2 支持的宽高比

从代码中提取的比例预设：
- `16:9` - 横版（主流）
- `9:16` - 竖版（短视频）
- `1:1` - 方形
- `4:3` - 标准
- `3:4` - 竖屏标准
- `2:3` - 电影感
- `21:9` - 超宽屏

### 4.3 支持的时长

- 短视频: 2s, 4s, 5s
- 标准: 10s, 15s
- 长视频: 30s, 60s

## 五、提示词结构模板

### 5.1 通用提示词公式

```
[场景描述] + [主体/人物] + [动作/事件] + [环境/氛围] + [镜头语言] + [光影描述] + [风格标签]
```

### 5.2 Pavo 风格的提示词结构

基于 API 参数和字段分析，Pavo 的提示词具有以下特点：

**结构层级**：
```
1. 场景时间/地点 (when/where)
   → "清晨的京都街头" / "未来都市的霓虹灯下"

2. 主体描述 (who/what)
   → "一位穿着和服的少女" / "赛博朋克风格的女性机器人"

3. 动作与互动 (action)
   → "缓缓转身，花瓣飘落" / "在雨中奔跑，水花四溅"

4. 镜头语言 (camera)
   → "远景→中景推近" / "慢镜头跟随" / "特写眼睛"

5. 光影氛围 (lighting)
   → "金色夕阳逆光" / "冷蓝色调霓虹灯光" / "柔和的自然光"

6. 风格质感 (style)
   → "电影级画质" / "吉卜力动画风格" / "赛博朋克写实"
```

**示例模板**：

```
// 模板A: 人物情感类
{prompt} = "{场景}，{人物}，{动作描述}，{镜头运动}，{光线描述}，{风格标签}"

// 模板B: 场景叙事类
{prompt} = "{地点}的{时间段}，{事件发生}，{人物反应}，{氛围渲染}，{电影感描述}"

// 模板C: 转场过渡类
{prompt} = "{起始场景}，{转场效果}，{目标场景}，{镜头衔接}"
```

**方案A: Pavo 作为视频生成替代**

# 替换当前的 HyperFrames 渲染流程
# 使用 Pavo 的 special-video/generate 或 canvas 对话模式
def generate_with_pavo(prompt: str, ratio: str = "16:9", duration: int = 10):
    """
    使用Pavo生成视频替代HyperFrames渲染
    prompt: 增强后的分镜提示词
    ratio: 视频比例
    duration: 视频时长

    # 调用Pavo API
    response = call_pavo_api(
        endpoint="/v1/pixa/special-video/generate",

## 九、技术分析总结

### 9.1 关键发现

1. **Pavo 是基于对话的 AI 创作平台**，不同于传统的"文本→视频"一次性生成，支持多轮对话迭代
2. **底层模型包括 Seedream**，支持多种生成模式（图生视频、帧间插值、风格化等）
3. **Prompt Enhance API** 可以自动将简短描述增强为详细生成提示
4. **短剧模式**支持分段生成，每个镜头独立控制
5. **作品库** 通过 `/v1/pixa/sd-feed/works` API 获取，但需要登录认证

### 9.2 局限性

- 无法直接访问作品库内容（需要登录 token）
- Playwright 连接不稳定（网络超时）
- 部分 API 需要 Bearer Token 认证

### 9.3 下一步行动建议

1. **获取 Pavo API Token**: 在浏览器中登录后获取 Cookie/Token
2. **实测 API**: 用真实 Token 调用 `/v1/pixa/sd-feed/works` 获取作品数据
3. **Prompt Enhance 测试**: 调用 `/v1/pixa/canvas/prompt/enhance` 验证增强效果
4. **小规模集成测试**: 选择一个地图热点选题，用 Pavo 生成对比测试
