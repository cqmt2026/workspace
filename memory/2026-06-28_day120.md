## 一、案例核心事实

**团队**：两人，文科生，零技术背景
**赛道**：AI老照片修复/复活
**起点**：刷视频号和小红书时看到老照片复活项目
**成果**：前3个月做到月盈2-3万，目标是月盈10万
**最高客单价**：3000+元

## 二、具体操作方法

### 三条路同时走

**路径一：视频号短视频矩阵**
- 内容：老照片复活 + 抒情音乐 + 伤感文字
- 打法：快速击打情绪
- 引流：在视频号留钩子

**路径二：微信群渗透**
- 目标群：旅游群/保险群/买菜群等中老年人群
- 方式：进去转发视频/内容

**路径三：朋友圈定价（高客单价）**
- 定制化服务：系列照片 + 视频
- 定价逻辑：按用户感知价值定价，不是按成本定价

### 定价背后的心理学

中老年人消费完全不敏感的原因：
1. 技术震撼："怎么会有这么神奇的东西？"
2. 情感需求：照片不是自己的，是过世的朋友/亲人
3. 买单的本质：买的是失去的青春、思念、遗憾

> "对逝去时光的怀念，是人类最无法抗拒的痛点，也是最大市场机会。"

## 三、方鑫自己（记录者）的业务复盘（Day 94）

### 五条副业路径

| 路径 | 模式 | 被动程度 |
|---|---|---|
| Image2网站 | 全自动生图，9.9元/50张，推广返20% | 高度被动 |
| 小报童 | 99元专栏，付费社群 | 半被动 |
| 咨询 | 1对1，每周2-3次 | 主动 |
| 中转站/海外站 | 老业务挂着，固定收入 | 高度被动 |
| 广告 | 流量插入广告 | 被动 |

### Image2网站数据（Day 114）
- 注册用户：破万
- 定价：9.9元体验月卡（50张生图）
- 模型：接入Banana2、Seedream5.0
- 新增：视频生成接口
- 推广：支付金额20%返利 + 被推荐人优惠15%
- 策略：低利润高质量，避免售后

### 内容矩阵
- **公众号**：一人公司纪实，不赚钱，纯记录
  - 近期改革：每日信息差 + 纪实 + 思考点
- **抖音**：从竖屏口播转横屏长视频
  - 长尾效应强，全平台发（B站/YouTube）
- **小报童**：核心付费阵地
  - 方向：AI赚钱路子 + 信息差

## 四、核心心法（Day 118）

### 焦虑与选择
- 看到同行赚钱会焦虑 → 反思方向对不对
- 两种选择：坚持到底 or 对标抄袭
- 中间态最痛苦，要不就坚持到底，要不就对标到底

### 方鑫的选择
- 物欲低，温饱之后做喜欢的事最重要
- 宁愿打磨细节一天，也不盲目追快钱
- 评价标准：自己认可的价值观，不是市场标准
- "我愿赌服输"

## 五、对我们的启示

### 可复用的打法

| 维度 | 案例做法 | 我们可以参考 |
|---|---|---|
| 选赛道 | 找到情感强需求（怀旧） | 我们的：投资/创作/教育，都有强情感需求 |
| 定价 | 按感知价值定价，不是成本 | 自媒体内容/小说/课程 |
| 内容矩阵 | 公众号+抖音+小报童 | 我们已有头条/百家号/抖音 |
| 被动收入 | Image2全自动跑 | 我们缺这个环节 |
| 推广裂变 | 20%返利 | 可用在小报童或产品 |
| 迭代策略 | 100+细节打磨上线 | 产品先上再迭代 |

### 差距分析

| 我们的现状 | 目标状态 |
|---|---|
| 多个内容平台有输出 | 缺乏像Image2这样的被动收入产品 |
| 没有定价产品 | 小报童/咨询/课程都是可选项 |
| 内容形式单一 | 需要横屏长视频（B站/YouTube） |
| 没有裂变机制 | 推广返利模式可引入 |

### 关键启示

1. **情绪是最高转化率的杠杆**——老照片卖的是思念，不是技术
2. **文科生能做AI产品**——不用会写代码，会用AI就行
3. **低利润高质量 = 免售后**——方鑫靠低利润省下时间看书学习
4. **5条收入线，3条被动**——被动收入越多，越自由
5. **记录本身就是品牌**——方鑫的日记是最大的获客工具
