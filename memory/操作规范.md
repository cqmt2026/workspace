# 操作规范

**版本**: V1.0
**更新**: 2026-06-07
**目的**: 防止路径错误、操作失误、重复踩坑

---

## 铁律（绝对不能违反）

1. **所有文件操作必须使用 path_config.py 中的路径常量**
2. **在workspace/目录外新建任何文件/目录前必须先确认**
3. **文件操作后必须验证文件确实在目标位置**
4. **每次会话开始时检查MEMORY.md中的待办**

---

## 文件操作流程

### 操作前（必须执行）

```
1. 确认目标路径在 workspace/ 下
2. 导入路径配置: from scripts.path_config import XXX
3. 检查目标目录是否存在
4. 如果不存在，停止操作并报告
```

### 操作中

```
1. 使用 path_config 中的路径变量
2. 不要硬编码任何路径
3. 操作完成后记录到日志
```

### 操作后（必须执行）

```
1. 验证文件存在于目标位置
2. 确认文件大小合理（非0字节）
3. 报告完成状态
```

## 常见错误及修复

| 错误 | 原因 | 修复 |
|------|------|------|
| market_data.db找不到 | 路径写成workspace-investment而非workspace/workspace-investment | 使用path_config.MARKET_DB |
| 文件放错位置 | 没确认路径就操作 | 始终使用path_config |
| 忘记检查路径 | 跳过了操作前检查 | 严格遵守操作前流程 |

## 验证命令

每次重要操作后运行：

```bash
python workspace/scripts/verify_paths.py
```

如果显示"所有关键路径正常"才能继续。
