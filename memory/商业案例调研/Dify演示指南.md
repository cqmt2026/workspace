# Dify演示版访问指南

## 访问地址
- **官方演示**: https://cloud.dify.ai
- **GitHub**: https://github.com/langgenius/dify
- **文档**: https://docs.dify.ai

## 核心功能体验清单

### 1. Chatbot应用
- 创建AI对话机器人
- 配置提示词模板
- 接入知识库问答
- 设置多轮对话逻辑

### 2. Agent智能体
- 工具调用（搜索/计算/代码执行）
- 多步骤任务规划
- 自主决策能力

### 3. Workflow工作流
- 可视化流程编排
- 条件分支逻辑
- 多模型串联

### 4. 知识库管理
- 文档上传（PDF/Word/Markdown）
- 自动分段与向量化
- RAG检索增强生成

### 5. API服务
- 一键生成API
- 多模型支持切换
- 调用量统计

## 演示建议流程

### 场景1：投资分析助手
```
步骤:
1. 上传你的投资研报PDF
2. 创建知识库
3. 构建Chatbot应用
4. 测试问答："分析茅台的投资价值"
```

### 场景2：自媒体内容助手
```
步骤:
1. 上传爆款文案作为参考
2. 创建工作流：热点采集→脚本生成→多平台适配
3. 测试内容生成
```

### 场景3：数据问答
```
步骤:
1. 上传CSV数据文件
2. 配置NL2SQL
3. 测试自然语言查询
```

## 账户注册
- 使用邮箱注册免费账户
- 获得免费额度（足够测试）
- 可导出配置迁移到私有部署

## 技术栈了解
- 后端：Python + FastAPI
- 前端：React + Next.js
- 数据库：PostgreSQL + Redis + Weaviate
- 部署：Docker Compose
