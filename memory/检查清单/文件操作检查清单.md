## ⚠️ 核心规则

### 【铁律 1】中文路径必须用 Python
**违反后果**: 编码错误 + 浪费时间

```python
# ✅ 正确
from pathlib import Path
path = Path(r'C:\Users\中文路径\文件.md')
content = path.read_text(encoding='utf-8')

# ❌ 错误
dir "C:\Users\中文路径\文件.md"
Get-ChildItem "C:\中文\路径"
```

## 📝 读文件前检查

### 【1. 路径检查】
- [ ] 路径是否包含中文？
  - 是 → 必须用 Python
  - 否 → 可用 PowerShell

- [ ] 路径是否存在？
  ```python
  if not path.exists():
      print(f"文件不存在：{path}")
      return
  ```

- [ ] 是否是文件（不是目录）？
  ```python
  if not path.is_file():
      print(f"不是文件：{path}")
      return
  ```

### 【2. 编码检查】
- [ ] 文件编码是什么？
  - `.md` / `.txt` → UTF-8
  - `.json` → UTF-8
  - `.csv` → 可能是 GBK，需要测试

- [ ] 是否指定 encoding='utf-8'？

### 【3. 权限检查】
- [ ] 文件是否被其他程序占用？
- [ ] 是否有读取权限？

## ✍️ 写文件前检查

### 【1. 路径检查】
- [ ] 路径是否包含中文？
  - 是 → 必须用 Python
  - 否 → 可用 PowerShell

- [ ] 目录是否存在？
  ```python
  path.parent.mkdir(parents=True, exist_ok=True)
  ```

- [ ] 文件是否已存在？
  ```python

- [ ] 是否需要备份原文件？

  if path.exists():

      shutil.copy2(path, backup)
  ```

### 【3. 内容验证】
- [ ] 内容是否为空？
- [ ] 内容编码是否正确？
- [ ] 是否需要追加而不是覆盖？

## 📋 标准操作流程

### 【读文件】
```python
from pathlib import Path

# 1. 创建路径对象
path = Path(r'C:\Users\中文路径\文件.md')

# 2. 检查文件存在
if not path.exists():
    print(f"❌ 文件不存在：{path}")
    return

# 3. 检查是文件
if not path.is_file():
    print(f"❌ 不是文件：{path}")
    return

# 4. 读取内容（指定编码）
content = path.read_text(encoding='utf-8')

# 5. 验证内容
if not content:
    print(f"❌ 文件为空：{path}")
    return

print(f"✅ 读取成功：{len(content)} 字")
```

### 【写文件】
```python
from pathlib import Path
from datetime import datetime

# 1. 创建路径对象
path = Path(r'C:\Users\中文路径\文件.md')

# 2. 创建目录（如不存在）
path.parent.mkdir(parents=True, exist_ok=True)

# 3. 备份（如已存在）
if path.exists():
    timestamp = datetime.now().strftime('%Y%m%d_%H%M%S')
    backup = path.with_suffix(f'.backup.{timestamp}')
    shutil.copy2(path, backup)
    print(f"✅ 已备份：{backup}")

# 4. 写入内容（指定编码）
path.write_text(content, encoding='utf-8')

# 5. 验证写入
written = path.read_text(encoding='utf-8')
if written == content:
    print(f"✅ 写入成功：{path}")
    print(f"   大小：{path.stat().st_size} bytes")
    print(f"   预览：{written[:50]}...")
else:
    print(f"❌ 写入内容不匹配")
```

## 🔧 工具函数

### 【cn_io.py】
```python
from pathlib import Path

def read_file(path_str):
    """安全读取文件（支持中文路径）"""
    path = Path(path_str)
    if not path.exists():
        return None, f"文件不存在：{path}"
    if not path.is_file():
        return None, f"不是文件：{path}"
    content = path.read_text(encoding='utf-8')
    return content, f"读取成功：{len(content)} 字"

def write_file(path_str, content):
    """安全写入文件（支持中文路径）"""
    path = Path(path_str)
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(content, encoding='utf-8')
    # 验证
    written = path.read_text(encoding='utf-8')
    if written == content:
        return True, f"写入成功：{path.stat().st_size} bytes"
    return False, "写入内容不匹配"
```

## 📊 常见错误及解决

| 错误 | 原因 | 解决 |
|------|------|------|
| `UnicodeEncodeError` | 用了 PowerShell | 改用 Python |
| `FileNotFoundError` | 路径不存在 | 检查路径 |
| `PermissionError` | 文件被占用 | 关闭占用程序 |
| 内容乱码 | 编码不对 | 指定 encoding='utf-8' |
| 写入后内容为空 | 未验证 | 添加验证步骤 |
