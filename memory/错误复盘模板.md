# 错误复盘模板 - 主系统

**版本**: V1.0
**生效**: 2026-04-28
**用途**: 每次出错后必须填写，形成检查点

---

## 错误复盘标准格式

```markdown
## 错误：[具体错误描述]

**发生时间**: YYYY-MM-DD
**涉及系统**: 数学动画/小说/自媒体/投资
**严重程度**: P0/P1/P2

### 1. 错误现象
[具体描述]

### 2. 错误原因
[为什么会出现这个错误？]

### 3. 触发条件
[下次遇到什么情况会触发这个错误？]

### 4. 检查点
[下次任务前必须检查什么？]

### 5. 固化规则
[更新到哪个清单？]
```
