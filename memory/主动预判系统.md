# 主动预判系统

**版本**: V2.0（细化版）
**创建**: 2026-04-28
**思路**: 不是等错了再救，是提前预判风险

---

## 核心方法：任务前3问

```
收到任务时必须回答：

❓ 问1：这个任务和之前哪个最像？
   → 那个任务踩过什么坑？
   → 教训库里有吗？

❓ 问2：上次同类任务的检查清单执行了吗？
   → 漏了哪项？

❓ 问3：本次有什么新风险点？
   → 这次可能会出什么错？
```

## 各子系统具体风险预判表

### 数学动画制作

| 新任务 | 预判风险 | 防范措施 |
|--------|----------|----------|
| 新题型（周期/几何） | 动画半径不一致 | 提取RADIUS常量 |
| 新EP首次制作 | 四维会审漏签字 | 逐项打勾 |
| 结尾页修改 | 文字重叠/Logo位置 | 预览检查 |
| 音频合并 | tpad忘了用/音频截断 | 用tpad补齐 |
| 新颜色 | HexColor格式错 | 用字符串格式 |
| 中文引号 | SyntaxError | 单引号包裹 |

### 小说创作

| 新任务 | 预判风险 | 防范措施 |
|--------|----------|----------|
| 新章节 | 节奏拖沓 | 每500字检查点 |
| 写完没爽点 | 爽点忘记植入 | 写前规划爽点 |
| 章尾太平 | 无hook | 必须加"然而/突然" |
| 替换操作 | replace重复 | 先检查是否存在 |
| 对话太多 | 内心独白缺失 | 必须有"因为这是他..." |

### 自媒体发布

| 新任务 | 预判风险 | 防范措施 |
|--------|----------|----------|
| 新平台 | 规则不熟 | 先查平台规范 |
| 新话题 | 敏感词踩坑 | 敏感词检查 |
| 黄金时间 | 错过最佳时段 | 12点/18点/21点 |
| 新封面 | 违规被删 | 先预览确认 |

### 投资分析

| 新任务 | 预判风险 | 防范措施 |
|--------|----------|----------|
| 新标的 | 数据来源不明 | 必须主人提供 |
| 新仓位 | 止损不明确 | 先问止损位 |
| 逆势操作 | 违背系统规则 | 先查趋势 |
| MACD零轴下方 | 买入信号错误 | 只看底分型 |

## 使用规则

1. **每次接任务**: 先回答3问，写入记录
2. **有风险**: 提前告知主人，不硬撑
3. **做完复盘**: 预判对错记入表格
