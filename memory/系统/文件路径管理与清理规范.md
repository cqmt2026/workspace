## 🗑️ 临时文件清理规范

### 临时文件定义

**需要清理的文件**:
- `temp_*.py` - 临时 Python 脚本
- `temp_*.txt` - 临时文本文件
- `temp_*.mp4` - 临时视频文件
- `tmp_*.txt` - 临时文本文件
- `*.tmp` - 临时文件

**需要保留的文件**:
- `temp_` 目录中的**内容文件**（如 `temp_chapters.txt` 如有实际内容）
- 正在使用中的临时文件

---

### 清理频率

| 类型 | 频率 | 负责人 |
|------|------|--------|
| **临时脚本** (`temp_*.py`) | 每次会话结束 | Agent 自动 |
| **临时文本** (`temp_*.txt`) | 每次会话结束 | Agent 自动 |
| **临时视频** (`temp_*.mp4`) | 每周一次 | Agent 提醒 |
| **扫描报告** | 每月一次 | Agent 提醒 |

## 🔧 自动化清理脚本

### 清理命令

```bash
# 清理临时脚本
python -c "import os; [os.remove(os.path.join(r,f)) for r,d,fs in os.walk('.') for f in fs if f.startswith('temp_') and f.endswith('.py')]"

# 清理临时文本
python -c "import os; [os.remove(os.path.join(r,f)) for r,d,fs in os.walk('.') for f in fs if f.startswith('temp_') and f.endswith('.txt')]"
```
