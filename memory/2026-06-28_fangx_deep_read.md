## 一、方鑫是谁？

- **背景**：大厂背景+名校标签（Day 94原文："脱离平台，我可能根本赚不到钱"）
- **定位**：一人公司创业者，OpenClaw深度用户
- **核心特质**：
  1. 极度自律（冷水澡、轻断食、每天14-16小时工作）
  2. 极度透明（所有收入、决策、困境全部公开）
  3. 极度务实（"解决自己的问题，大概率也能解决一群人的问题"）
  4. 物欲低（"温饱之后做喜欢的事最重要"）
  5. 长期主义者（受曾国藩影响，日拱一卒）

**关键洞察**：他不是"AI教程博主"，他是一个**在用AI创业的真实记录者**。他的日记本身就是最大的获客工具。

## 二、127天时间线：关键决策节点

### 第一阶段：产品验证期（Day 1-45）

**Day 1**：DeskFlow桌面待办清单
- 痛点：自己健忘，现有工具太重
- 决策：免费，无广告，无会员
- 结果：未提及收入，但验证了"解决自己的问题"的产品方法论

**Day 22**：深度研究OpenClaw
- 发现：OpenClaw潜力大但门槛高
- 决策：做OpenClaw教学网站 + 飞书文档
- **关键行为**：一天之内从头到尾摸透一个工具，然后输出教程

**Day 37**：战略调整
- 发现：内容不够垂直，口播视频B站/小红书推流差
- 决策：垂直OpenClaw领域，调整平台策略
- 工作量：抖音5条/天 + 公众号3篇/天 + 小红书5图文/天 + B站2长视频/周
- **关键行为**：用数据驱动决策，而不是凭感觉

**Day 39**：一篇吃透OpenClaw Skills
- 全神贯注写5-6小时
- 结论："帮助他人，就是帮助自己"

**Day 45**：飞书AI蜂群 + 个人网站上线
- 优化采集蜂和研究蜂协同
- 个人网站fxin.cc上线（先用Vercel免费域名）
- 第一条VibeCoding视频（从没学过剪辑到发布只花了一天）
- **关键洞察**：建个人网站是为了"留退路"——国内平台封禁尺度难把握

### 第二阶段：产品爆发期（Day 72-94）

**Day 72**：三条线并行
- 拍2条短视频（一条讲"文科生做AI赚钱"，一条开喷Anthropic）
- 写2篇小报童文章
- 个人网站fxin.cc正式上线
- **关键洞察**：真正赚到钱的是文科生——讲故事+感受美的能力

**Day 83**：Image2.fun正式上线
- 全流程：会员体系+画质档位+合规适配+生图模块重构
- 兼任站长+客服，一对一处理
- 核心认知："深度交给AI，广度留给自己"

**Day 87**：5天破2000用户
- 方法论："找到一个真实痛点，不断深入，直到彻底打爆"
- MVP策略：第一版只有Prompt列表+复制按钮，没有搜索/分类/用户系统
- 付费转化率超预期3倍
- **核心金句**："别从'我要做一个产品'开始，而是从'我能解决什么问题'开始"

**Day 90**：一人公司90天总结
- 极简主义：不浪费用户一秒心智带宽
- 为什么不卖课："有心者不用教，无心者教不会"
- 定投纳斯达克100，盈利超过炒股朋友
- **核心价值观**："做产品第一价值观是对你有用，第二才是赚钱"

**Day 94**：五人公司大总结
- 5条收入线：Image2网站 + 小报童 + 咨询 + 中转站/海外站 + 广告
- 公众号定位：记录和复盘，不为赚钱
- 抖音转型：竖屏口播→横屏长视频（长尾效应）
- 小报童定位：核心付费阵地
- **收入结构**：3条被动（Image2/中转站/广告）+ 2条主动（小报童/咨询）

### 第三阶段：认知升级期（Day 103-127）

**Day 103**：微信读书Skill + "系统学习AI是悖论"
- 核心观点：围绕真实问题学，不是系统学
- "先选一个你真的要解决的问题，然后为了这个问题去学1-2个最关键的工具"

**Day 106**："有些想法就应该死在脑子里"
- 核心警告：AI赋予的能力会让你误以为那是自己的能力
- "不是每个想法都值得被救活"
- **对我们的直接警示**：我们同时推进小说+自媒体+投资+数学动画+小程序，是不是也想太多了？

**Day 108**：复利 + 高精力
- 高精力是一人公司的底层资产
- 好习惯复利 vs 坏习惯复利
- "人一定要活在复利里"

**Day 114**：注册用户破万
- 完善了100+细节，修复了100+bug
- 新增视频生成接口
- 推广：20%返利 + 新用户优惠15%

**Day 116**：财富正在向AI集中
- 深度分析AI产业链的财富分配
- "AI首先奖励最靠近新生产资料的人"

**Day 118**：同行用AI赚钱的焦虑
- "要不就坚持到底，要不就对标到底，中间态最痛苦"
- "我愿赌服输"

**Day 120**：两人靠AI月盈十万
- 老照片复活案例
- 情绪杠杆：买的是失去的青春，不是技术
- 三条路：视频号矩阵 + 微信群渗透 + 朋友圈高客单价

**Day 127**：聊聊看书
- 输出过多，输入不足
- "感悟变少了"
- 意识到需要深度阅读来拓宽认知边界

## 三、方鑫的行为模式分析

### 1. 产品方法论（可复用）

| 原则 | 方鑫做法 | 我们的对照 |
|------|---------|-----------|
| **从自己的痛点出发** | DeskFlow是自己需要待办管理 | 投资分析是自己的刚需 |
| **MVP先行** | 第一版只有Prompt列表+复制按钮 | 我们先跑通投资分析流程，再做产品化 |
| **砍掉非必要功能** | "能删的功能全删了" | 不追求完美，先上线再迭代 |
| **低利润高质量** | 定价压到最低，避免售后 | 9.9元/50张，毛利很低但口碑好 |
| **利润分享** | 20%推广返利 | 用返利驱动裂变 |

### 2. 内容策略（可复用）

| 渠道 | 策略 | 频率 |
|------|------|------|
| 公众号 | 深度记录+复盘，不求流量 | 日更3篇 |
| 抖音 | 从竖屏口播→横屏长视频 | 日更5条→日更1条（质量优先） |
| 小报童 | 核心付费阵地，干货优先 | 日更 |
| B站 | 长视频教程，全平台分发 | 每周2条 |
| 个人网站 | 留退路，汇总所有内容 | fxin.cc |

### 3. 收入策略（可参考）

- **5条线并行**，但3条是被动收入
- **定价逻辑**：低利润高质量 → 免售后 → 省时间 → 做喜欢的事
- **推广逻辑**：让利20%返利 + 推荐人优惠15% → 裂变
- **内容即获客**：公开纪实本身就是最大的品牌

### 4. 认知升级（最值得学习）

- **Day 106**：警惕AI赋予的能力幻觉——"能调用AI≠有能力"
- **Day 103**：系统学习是悖论——围绕真实问题学
- **Day 127**：输出必须配输入——深度阅读拓宽认知边界
- **Day 118**：焦虑的解药是坚持到底或对标到底，不要卡在中间

## 五、对我们最直接的5条启示

### 1. 先跑通一条线，再做第二条

方鑫也是从DeskFlow开始，然后Image2，然后小报童。他不是一开始就5条线并行。

**我们的问题**：小说+自媒体+投资+数学动画+小程序，同时推进。

**建议**：先集中火力跑通**投资分析→付费内容**这条线。为什么？
- 我们已经有完整的技术栈
- 情绪杠杆最强
- 边际成本趋近于0

### 2. 公开纪实本身就是获客工具

方鑫的日记就是最大的品牌。他不需要投广告，因为"记录真实"本身就是内容。

**我们的机会**：把我们做OpenClaw系统、做投资分析、做小说创作的过程全部公开记录。这就是我们的"日记"。

### 3. 从自己的痛点出发做产品

方鑫的Image2是因为自己找Prompt烦。DeskFlow是因为自己健忘。

**我们的痛点**：
- 投资分析需要手动做 → 可以做成自动化看板
- 自媒体热点追踪需要手动 → 已经做了
- 小说创作需要去AI味 → 已经做了

**下一步**：把投资分析看板产品化（哪怕只是一个网页），解决"看盘+分析+推送"的痛点。

### 4. 低利润高质量 = 免售后

方鑫定价9.9元/50张，毛利很低，但"没有人说我质量差"。省下的时间用来看书、写作、学新东西。

**对我们的启示**：不要追求高价。先做一个99元的付费专栏，验证付费意愿。贵了没人买，便宜了才有量。

### 5. 警惕"想法太多"

Day 106的核心警告："有些想法就应该死在脑子里。"

**对我们的直接警示**：
- 错题本小程序 → 已否决 ✅
- 投资付费社群 → 还没跑通就谈变现 ❌
- 数学动画课程 → 还没产出过完整作品 ❌
- 小说有声书 → 小说还没爆 ❌

**应该聚焦的**：把投资分析流程跑通 → 产出稳定内容 → 验证付费意愿

## 六、行动清单

### 本周（立即执行）

1. **选定一个方向**：投资分析内容（小报童/公众号/头条付费专栏）

4. **公开记录**：把我们做投资分析的过程记录下来（这就是我们的"日记"）

6. **迭代产品**：根据反馈优化内容方向

### 长期（持续精进）

9. **维护高精力状态**：规律作息，持续学习
10. **日拱一卒**：不追求一夜爆红，追求长期复利
