# 失败模式库 - 创作问题

**版本**: V1.0
**创建**: 2026-04-28
**用途**: 每次小说创作时自动检查

---

## 模式1：爽点忘记植入

**错误现象**: 章写完了才发现没有爽点

**触发条件**: 写完再补爽点，节奏被打乱

**解决方案**: 
```
写初稿前先想好：
- 本章爽点是什么？
- 在哪个位置植入？
- 用哪个爽点关键词？
```

**检查点**: 
- [ ] 写前：确认本章爽点类型
- [ ] 写中：自然带出爽点
- [ ] 写后：检查是否有爽点关键词

**关键词**: 打脸/震惊/逆袭/碾压/翻盘/揭秘/反转

## 模式2：节奏拖沓

**错误现象**: 章读起来平铺直叙，没有起伏

**触发条件**: 每500字没有小高潮

**解决方案**: 
```
节奏公式：
每500字 = 1个小看点
每1000字 = 1个爽点
每章结尾 = 必须有hook
```

**检查点**: 
- [ ] 每500字是否有转折？
- [ ] 章尾是否有"然而/但是/突然"？

**关键词**: 然而/但是/突然/没想到/就在这时

---

## 模式3：内心独白缺失

**错误现象**: 章节检查时发现没有内心独白

**触发条件**: 写得太"客观"，没有主角视角

**解决方案**: 
```python
# 必须有"因为这是他..."格式
"因为这是他陆鸣做验房师十二年来第一次..."
"因为这是他必须揭穿的谎言..."
```

**检查点**: [ ] 章节中是否有"因为这是他..."

## 模式4：replace导致重复

**错误现象**: 同一段落被多次插入，变成重复

**触发条件**: 用str.replace()没有检查是否已存在

**解决方案**: 
```python
# 错误：每次运行都会插入
content.replace('**【本章完】**', add + '\n\n**【本章完】**')

# 正确：先检查
if add not in content:
    content = content.replace('**【本章完】**', add + '\n\n**【本章完】**')

# 验证重复
for line in content.split('\n'):
    if line.strip() in seen:
        print(f'DUP: {line[:50]}')
    seen[line.strip()] = 1
```

**检查点**: 每次批量替换前，先验证是否会产生重复

## 模式5：章尾无hook

**错误现象**: 章结尾太干，读者不想续读

**触发条件**: 最后一段是总结，没有悬念

**解决方案**: 
```python
# 章尾必须有hook关键词
"然而..."  # 意外转折
"但是..."  # 隐藏信息
"就在这时..."  # 关键时刻
"他没想到..."  # 悬念
```

**检查点**: [ ] 章尾最后一段是否含hook关键词

**关键词**: ?!/突然/然而/但是/查到/继续/没想到
