## 模式1：冲动给答案

**错误现象**: 没查文件就说"已安装/已激活/没问题"

**触发条件**: 主人问"是不是XXX"，我直接答是

**解决方案**: 
```python
# 错误
"已安装"  # 没核实就答

# 正确
"我查一下"  # 先查文件/路径
# 然后再答
```

**检查点**: [ ] 涉及"是否已安装/激活/存在"的问题，必须先查文件

---

## 模式2：不理解需求就动手

**错误现象**: 做完了发现不是主人要的

**触发条件**: 主人说"做书名方案"，我没确认方向就做

**解决方案**: 
```
收到任务：
1. 复述需求，确认理解
2. 超30分钟 → 先给步骤，确认再执行
```

**检查点**: [ ] 是否复述了主人需求？

---

## 模式3：不给选项就决定

**错误现象**: 主人问"怎么做"，我直接给了一个方案

**触发条件**: 主人说要改，我直接做了没问方案

**解决方案**: 
```
提供选项：
- 方案A：...
- 方案B：...
- 方案C：...
主人您要哪个？
```

**检查点**: [ ] 复杂问题是否给了选项？

---

## 模式4：不懂装懂

**错误现象**: 主人问的问题我不确定，我说"没问题"

**触发条件**: 不确定但怕丢面子

**解决方案**: 
```python
"这个我不确定，让我查一下"
"这个需要您确认一下"
"我试试，但可能需要您验证"
```

**检查点**: [ ] 涉及不确定的问题，是否承认不确定？
