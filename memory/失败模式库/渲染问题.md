## 模式1：HexColor不能用

**错误现象**: Manim CE报错 `HexColor not found`

**触发条件**: 使用 `from manim.utils.color import HexColor`

**解决方案**: 
```python
# 错误
color = HexColor("#FFD700")

# 正确
color = "#FFD700"  # 字符串格式
```

**检查点**: 每次写Manim代码前，先检查颜色用字符串格式

**涉及文件**: 所有Manim脚本

## 模式2：中文引号导致SyntaxError

**错误现象**: Python语法错误，中文引号被当作代码符号

**触发条件**: 代码中使用了 `""` 中文引号

**解决方案**: 
```python
# 错误
quote = txt("每人声明："左右两人..."", 26, WHITE)

# 正确
quote = txt('每人声明："左右两人..."', 26, WHITE)
```

**检查点**: 每次写字符串前，检查是否含中文引号，用单引号包裹

**涉及文件**: 所有Python脚本

## 模式3：动画半径与图形半径不一致

**错误现象**: 圆圈和动画中的点位置不匹配

**触发条件**: Circle半径和pos计算用的半径不同

**解决方案**: 
```python
# 统一常量
RADIUS = 1.6  # 所有地方用同一个值
circle = Circle(radius=RADIUS, ...)
pos = RADIUS * np.array([cos, sin, 0])  # 动画也用RADIUS
```

**检查点**: 每个Scene有圆形的，检查是否有RADIUS常量统一

**涉及文件**: EP052/EP053等圆形动画

## 模式4：文字与图形重叠

**错误现象**: 文字遮挡图形，或图形遮挡文字

**触发条件**: 圆桌半径太大，文字空间不足

**解决方案**: 
```python
# 缩小半径留空间
RADIUS = 1.6  # <=1.8
circle = Circle(radius=RADIUS, ...)
# 文字位置远离图形
note.move_to(DOWN * 2.8)  # 向下移动
```

**检查点**: 每次渲染后预览，检查文字与图形是否重叠

**涉及文件**: EP050/EP051/EP052结尾页

## 模式5：-shortest截断音频

**错误现象**: 音频被截断，声音不完整

**触发条件**: ffmpeg合并用 `-shortest` 参数

**解决方案**: 
```python
# 错误
cmd = ['ffmpeg', '-i', video, '-i', audio, '-shortest', output]

# 正确：用tpad补齐视频
pad = audio_dur - video_dur
cmd = ['ffmpeg', '-i', video, '-i', audio, 
       '-filter_complex', f'[0:v]tpad=stop_mode=clone:stop_duration={pad}[v]',
       '-map', '[v]', '-map', '1:a', ...]
```

**检查点**: 每次合并前，确认不用-shortest

**涉及文件**: 所有音视频合并脚本

## 模式6：Logo路径不完整

**错误现象**: `logo.png not found`

**触发条件**: 路径缺少`.openclaw`

**解决方案**: 
```python
# 错误
logo_path = r"C:\Users\Administrator\openclaw\..."  # 缺少.openclaw

# 正确
logo_path = r"C:\Users\Administrator\.openclaw\workspace\..."
if os.path.exists(logo_path):
    logo = ImageMobject(logo_path)
```

**检查点**: 每次用Logo前，验证路径存在

**涉及文件**: 所有结尾页脚本
