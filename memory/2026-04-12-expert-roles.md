## 📐 奥数老师：知识点分析

**题型**：年龄问题（差倍问题变种）

**核心知识点**：
1. 年龄差永远不变
2. 过去/未来的年龄 = 现在年龄 ± 年数差

**解题思路**：
| 时间点 | 爸爸年龄 | 儿子年龄 | 关系 |
|--------|---------|---------|------|
| 过去（爸爸=儿子现在） | y | 4 | 相差 (x-y) 年 |
| 现在 | x | y | 相差 (x-y) 年 |
| 未来（儿子=爸爸现在） | 79 | x | 相差 (x-y) 年 |

**关键**：年龄差 d = x - y 是定值

---

## 📝 解题步骤

**设**：爸爸现在 x 岁，儿子现在 y 岁，年龄差 d = x - y

**列方程**：
1. 过去：爸爸 y 岁时，儿子 4 岁
   - y - d = 4  →  y - (x-y) = 4  →  2y - x = 4

2. 未来：儿子 x 岁时，爸爸 79 岁
   - x + d = 79  →  x + (x-y) = 79  →  2x - y = 79

**解方程组**：
```
2y - x = 4      →  x = 2y - 4
2x - y = 79

代入：2(2y-4) - y = 79
      4y - 8 - y = 79
      3y = 87
      y = 29

x = 2y - 4 = 2×29 - 4 = 54
```

**答案**：爸爸 **54** 岁，儿子 **29** 岁

**验证**：
- 年龄差 = 54 - 29 = 25 岁
- 25 年前：爸爸 29 岁，儿子 4 岁 ✓
- 25 年后：儿子 54 岁，爸爸 79 岁 ✓

```python
# 年龄问题通用公式
def age_problem(past_child_age, future_parent_age):
    # 年龄差 d
    # 过去：parent - d = child_now, child_now - d = past_child_age
    # 未来：child_now + d = parent_now, parent_now + d = future_parent_age
    
    # 3 个时间点，2 个间隔，每个间隔 = d
    # past_child_age + 3d = future_parent_age
    d = (future_parent_age - past_child_age) / 3
    
    child_now = past_child_age + d
    parent_now = child_now + d
    
    return parent_now, child_now, d

# 本题：4 + 3d = 79 → d = 25
parent, child, diff = age_problem(4, 79)
print(f"爸爸{parent}岁，儿子{child}岁，年龄差{diff}岁")
# 输出：爸爸 54 岁，儿子 29 岁，年龄差 25 岁
```

**通用公式**：
> 年龄差 d = (未来年龄 - 过去年龄) ÷ 3
