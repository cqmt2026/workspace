# 地图热点脚本标准输出格式 schema

## JSON Schema

```json
{
  "title": "选题标题",
  "date": "YYYY-MM-DD",
  "category": "一张图 | 追热点 | 深一度",
  
  "metadata": {
    "source": "选题采集来源",
    "topic_score": 10,
    "word_count": 160,
    "estimated_duration_seconds": 45,
    "tts_speed": 1.0
  },

  "hook": {
    "type": "排名悬念 | 反常识 | 数字冲击 | 对比反差 | 身份代入",
    "text": "钩子文案（3秒内抓住注意力，口语化）"
  },

  "sections": [
    {
      "order": 1,
      "time_range": "0-5s",
      "visual": "画面描述（地图区域+标注内容）",
      "narration": "口播文案（口语化，一句话数据+一句话解读）",
      "data_point": "核心数据（用于大字标注）",
      "interpretation": "一句话解读（用于字幕或标注）"
    }
  ],

  "outro": {
    "type": "悬念 | 互动 | 情感",
    "text": "结尾文案（引导评论/收藏/关注，口语化）"
  },

  "full_text": "完整口播稿（连贯文本，用于TTS，按sections.narration顺序拼接）",
  "subtitle_lines": [
    "字幕第1行（不超过15字）",
    "字幕第2行"
  ]
}
```

## 各栏目参数对照

| 栏目 | 时长 | 字数 | 信息点数 | 每段时长 | 节奏 |
|------|------|------|---------|---------|------|
| 一张图（排名） | 30-60秒 | 100-200字 | 5-8个数据 | 每段5-8秒 | 快节奏，每项一图 |
| 追热点 | 45-90秒 | 150-250字 | 3-5个要点 | 每段8-15秒 | 中速，有故事线 |
| 深一度（城市） | 3-10分钟 | 600-2000字 | 按区域展开 | 每段15-30秒 | 慢速，深度讲解 |

## 字段说明

### hook.type 可选值
- `排名悬念`: "上半年XX出炉，前X名有哪些？"
- `反常识`: "你以为XX最强？其实..."
- `数字冲击`: "XX增长XX%，全国第一！"
- `对比反差`: "不靠海不沿江，却能..."
- `身份代入`: "所有XX人注意！"

### outro.type 可选值
- `悬念`: "还有更猛的，关注我下期继续"
- `互动`: "你最看好哪个？评论区聊聊"
- `情感`: "从XX到XX，每个地方都在努力"

### 口语化规则（生成时强制执行）
1. 长句拆短，每句不超过25字
2. 去除"首先""其次""综上所述"等书面连接词
3. 用"你""咱们"代替"用户""观众"
4. 数据+解读各一句，不要堆砌
5. 避免"据悉""据报道""据了解"等废话
6. 语速按220字/分钟估算
