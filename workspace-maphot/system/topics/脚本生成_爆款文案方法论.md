## 一、头部账号对标分析

### 核心对标（可复制度从高到低）

| 账号 | 粉丝 | 核心形式 | 可复制度 | 我们对应栏目 |
|------|------|---------|---------|-------------|
| **萧同学** | 活跃 | 经济数据+二维地图+数据标注+配音 | ★★★★★ | 一张图（30-90秒） |
| **小林地理** | 25万+ | 城市区县逐个介绍，二维地图+文字标注 | ★★★★★ | 深一度（5-15分钟） |
| **史图记忆簿** | 110万 | 手绘地图推演+历史事件 | ★★★★ | 追热点（3-8分钟） |
| **长安范儿** | 活跃 | 旅游线路+人文地理 | ★★★ | 深一度（5-10分钟） |
| **星球研究所** | 头部 | 精美地图+深度分析 | ★ | 暂不匹配（制作门槛高） |

### 萧同学逐条拆解（最高优先级对标）

**结构模板：**
```
[0-5s] 悬念钩子：中国地图全貌，5省高亮 → "上半年XX出炉，前X名有哪些？"
[5-55s] 逐项展示：每省5-10秒，数据格式统一 → "第X名，XX，XX数据"
[55-64s] 对比/反转/悬念结尾 → "台湾可能反超四川，你觉得呢？"
```

**关键特征：**
1. 每条只讲1个核心数据（GDP/增速/增量），不贪多
2. 数据格式统一，用户形成预期 → 提高完播率
3. 结尾必有悬念或互动 → 引导评论
4. 配色轻量，信息密度高 → 视觉冲击
5. 30-90秒短视频节奏 → 适合批量生产

### 小林地理逐条拆解

**结构模板：**
```
[0-10s] 开场：一个视频带你了解XX
[10s-8min] 每个区县：名字由来→面积→人口→产业→标签
[最后10s] 互动：你觉得哪个区最好？评论区聊聊
```

**关键特征：**
1. 模板化程度极高 → 批量生产容易
2. 每个区县信息格式统一 → 用户预期明确
3. 名字由来是亮点 → 增加趣味性
4. 收藏率极高（东莞32镇街：12.8k收藏/22k赞=58%）→ 知识型内容
5. 系列化运营 → 互相带动流量

## 二、抖音爆款文案通用公式

### 黄金公式：黄金3秒钩子 + 情绪递进主体 + 高互动结尾

#### 1. 黄金3秒钩子（前3秒定生死）

**5种实测有效的开头类型：**

| 类型 | 结构 | 示例 | 适用场景 |
|------|------|------|---------|
| 反常识 | 抛出与常识相反的结论 | "90%的人不知道！厨房油污清洁关键不是洗洁精" | 知识科普 |
| 数字冲击 | 用具体数字引发好奇 | "这个方法帮我3天涨了1万粉" | 经验分享 |
| 痛点直击 | 精准描述观众困扰 | "是不是每次开会都不知道说什么？" | 技能教学 |
| 结果前置 | 先展示惊人结果 | "最终的效果让我自己都吓了一跳" | 教程类 |
| 悬念提问 | 抛出一个有价值的问题 | "你知道为什么有些人怎么吃都不胖吗？" | 科普解释 |

**地图数据类专属钩子公式：**

| 钩子类型 | 模板 | 示例 |
|----------|------|------|
| 排名悬念 | "上半年XX出炉，前X名有哪些？" | "上半年外贸增速前五省份出炉" |
| 反常识 | "你以为XX最强？其实..." | "你以为广东外贸最强？其实西藏增速才是第一" |
| 数字冲击 | "XX增长XX%，全国第一！" | "西藏外贸增速132.4%，全国第一！" |
| 对比反差 | "不靠海不沿江，却能..." | "陕西不靠海不沿江，外贸增速全国第一" |
| 身份代入 | "所有XX人注意！" | "所有广东人注意！你的家乡外贸增速排第几？" |

#### 2. 情绪递进主体（中间段）

**核心原则：**
- 每5秒一个新信息点 → 防止划走
- 15秒内至少3个刺激点 → 画面+字幕+BGM同步输出
- 20-30秒处设置转折/反转 → 避免中途流失
- 数据格式统一 → 用户形成预期

**地图数据类主体结构：**

```
[项1] 第X名，XX → [核心数据] → [一句话解读]
[项2] 第X名，XX → [核心数据] → [一句话解读]
...
[转折] 但你知道吗？→ [意外发现/反转]
```

**具体写法：**
- 每项不超过10秒 → 保持节奏
- 数据+解读各一句 → 信息密度高
- 地图聚焦该区域 → 视觉跟随
- 大字标注关键数据 → 视觉冲击

#### 3. 高互动结尾（最后5-10秒）

**3种互动引导方式：**

| 类型 | 模板 | 示例 |
|------|------|------|
| 指令型 | "评论区扣X，送你XX" | "评论区说说你家乡排第几" |
| 悬念延续 | "明天揭秘XX，关注别错过" | "下期看看你的城市上榜没有" |
| 情感绑定 | "为所有XX点亮❤️" | "从沿边到中部，每个地方都在努力" |

**地图数据类专属结尾：**
- "你最看好哪个？评论区聊聊。"
- "你觉得你的家乡排第几？"
- "还有更猛的数据，关注我下期继续。"

## 三、口语化写作铁律

### 1. 极致口语化
- 像和朋友聊天一样写作
- 长句拆短，书面语改口头语
- 避免"首先""其次""综上所述"等书面连接词
- 用"你""咱们"代替"用户""观众"

### 2. 娱乐化表达
- 讲故事、造梗、场景演绎
- 软化专业内容 → 降低理解门槛
- 适当使用网络用语（不过度）
- 知识包裹在有趣表达中

### 3. 节奏感
- 简洁有力，重点突出，详略得当
- 长句讲解释，短句做结论
- 停顿制造强调
- 语速控制：正常语速约220字/分钟

### 4. 信息密度
- 金字塔表达：核心观点先行
- 分点阐述，每点一个数据+一句话解读
- 15秒内至少3个刺激点

## 四、脚本标准输出格式

### JSON结构规范

```json
{
  "title": "选题标题",
  "date": "YYYY-MM-DD",
  "category": "一张图|追热点|深一度",
  "estimated_duration_seconds": 45,
  "target_word_count": 160,
  "hook": {
    "type": "排名悬念|反常识|数字冲击|对比反差|身份代入",
    "text": "钩子文案（3秒内抓住注意力）"
  },
  "sections": [
    {
      "order": 1,
      "time_range": "0-5s",
      "visual": "画面描述（地图区域+标注内容）",
      "narration": "口播文案（口语化）",
      "data_point": "核心数据",
      "interpretation": "一句话解读"
    }
  ],
  "outro": {
    "type": "悬念|互动|情感",
    "text": "结尾文案（引导评论/收藏/关注）"
  },
  "full_text": "完整口播稿（连贯文本，用于TTS）",
  "subtitle_text": "字幕文本（分行，每行不超过15字）"
}
```

### 各栏目时长/字数对照

| 栏目 | 时长 | 字数 | 信息点数 |
|------|------|------|---------|
| 一张图（排名） | 30-60秒 | 100-200字 | 5-8个数据 |
| 追热点 | 45-90秒 | 150-250字 | 3-5个要点 |
| 深一度（城市介绍） | 3-10分钟 | 600-2000字 | 按区域逐一展开 |

## 五、AI脚本生成器设计思路

### 输入
- 选题标题 + 数据（来自选题采集）
- 栏目类型（一张图/追热点/深一度）

### 处理流程
1. 根据选题确定钩子类型（反常识/数字冲击/排名悬念等）
2. 根据栏目类型选择结构模板
3. 按数据项逐一生成"数据+解读"段落
4. 设计悬念/互动结尾
5. 全文口语化润色（去除书面语）
6. 估算时长，调整字数

### 质量检查清单
- [ ] 前3秒有钩子？
- [ ] 每5秒有新信息点？
- [ ] 数据格式统一？
- [ ] 结尾有互动引导？
- [ ] 全文口语化？
- [ ] 字数匹配目标时长？
- [ ] 无书面连接词？
