## 一、开场钩子技术（前3秒）

### 1.1 数字冲击型
**代表案例：** 小佛爷说《公积金缴存20强》
**表现手法：**
```
画面：深色背景 + 大号金色数字
文案："北京3340亿！全国第一！"
动画：数字从0滚动到3340（计数动画）
音效：重音"咚"
```
**技术实现：**
- GSAP `gsap.to("#number", {innerHTML: 3340, duration: 1, snap: {innerHTML: 1}})`
- 配合缩放脉冲效果

**适用场景：** 数据排名、经济数据、人口数据

---

### 1.2 悬念提问型
**代表案例：** 秒懂山河《29万亿GDP的江浙沪为何输给广东》
**表现手法：**
```
画面：地图高亮江浙沪 → 切到广东
文案："GDP总量领先，但人口抢人大战却输了？"
动画：地图区域闪烁 + 问号弹出
音效：悬疑BGM
```
**技术实现：**
- 地图区域SVG路径高亮（stroke-dasharray动画）
- 文字逐字出现（typewriter效果）

**适用场景：** 反常识选题、因果分析

### 1.3 反差对比型
**代表案例：** 小佛爷说《广州vs深圳》

文案："总额反超，但人均最低？"

- CSS flex布局 +GSAP stagger
- 颜色对比（红vs蓝）强化差异

**适用场景：** 两城PK、区域对比

## 二、中段叙事技术（核心内容）

### 2.1 榜单滚动型
**代表案例：** 小佛爷说《公积金缴存20强》
**表现手法：**
```
画面：城市列表逐条slide-in
排名 | 城市 | 缴存额 | 人均
--------------------------------
 1 | 北京 | 3340亿 | 3.5万
 2 | 上海 | 2660亿 | 2.8万
 ...
异常值：深圳第4名，人均1.78万（红色强调框弹出）
```
**技术实现：**
- GSAP timeline逐条动画
- 异常值红色边框 + scale脉冲
- 每行停留2-3秒

**适用场景：** 数据排名、城市对比

**关键参数：**
```javascript
// 榜单滚动速度
const rowDuration = 2.5; // 秒/行
const stagger = 0.1; // 行内元素延迟

// 异常值强调
gsap.to(".anomaly-row", {
  borderColor: "#ef4444",
  scale: 1.05,
  duration: 0.3,
  yoyo: true,
  repeat: 1
});
```

---

### 2.2 三层递进型
**代表案例：** 秒懂山河《江浙沪vs广东》
**表现手法：**
```
第一层（现象）：江浙沪GDP总量领先
  → 地图高亮 + 数据面板
  
第二层（数据）：但人口流入广东更多
  → 人口流动箭头动画
  
第三层（本质）：广东出生率103万，连续6年第一
  → 柱状图对比 + 金句："最敢生省份"
```
**技术实现：**
- 三层场景切换（scene1→scene2→scene3）
- 每层有独立动画序列
- 过渡效果：zoom-through转场

**适用场景：** 深度分析、因果解释

---

### 2.3 对比贯穿型
**代表案例：** 图说地理《计划单列市》
**表现手法：**
```
结构：5个城市逐个介绍，每段对比
大连（1984）→ 青岛（1986）→ 宁波（1987）→ 厦门（1988）→ 深圳（1988）
时间轴推进 + 共同点总结
```
**技术实现：**
- 时间轴导航（顶部进度条）
- 城市卡片切换（flip动画）
- 共同点用标签云展示

**适用场景：** 同类事物对比、历史梳理

---

### 2.4 悬念揭秘型
**代表案例：** 易懂地理《凉都六盘水》
**表现手法：**
```
开场：抛出问题"为什么六盘水能避暑？"
展开：地形、海拔、气候数据
揭秘："因为位于26度南，海拔1500米"
结尾：互动提问"你还知道哪些避暑胜地？"
```
**技术实现：**
- 问题-答案结构
- 数据可视化（温度计动画）
- 地形剖面图展示

**适用场景：** 科普类、冷知识

### 2.5 模板逐个型

### 3.2 数据可视化形式

| 类型 | 适用题材 | 技术实现 | 案例 |
|------|----------|----------|------|
| **圆环进度** | 覆盖率/完成率 | SVG stroke-dasharray | 公积金覆盖率 |

**圆环进度技术细节：**
```javascript
// SVG圆环动画
const circumference = 2 * Math.PI * 65; // r=65
gsap.to("#ring-fill", {
  strokeDashoffset: circumference - (circumference * value / 100),
  duration: 1.2,
  ease: "power2.out"
});

// 数字计数
gsap.to("#ring-value", {
  innerHTML: value,
  duration: 1.2,
  snap: { innerHTML: 1 },
  ease: "power1.out"
});
```

### 3.3 动画转场技术

| 类型 | 适用场景 | 技术实现 | 效果 |
|------|----------|----------|------|
| **zoom-through** | 场景切换 | scale 0.6→1 + blur清除 | 穿越感 |
| **push-slide** | 列表滚动 | x偏移 + opacity | 推入感 |
| **fade-blur** | 数据展示 | opacity + filter blur | 渐显感 |
| **split-screen** | 对比展示 | 左右分屏 stagger | 对比感 |
| **flip-card** | 信息切换 | rotateY 180deg | 翻转感 |

**zoom-through转场实现：**
```javascript
// 场景切换动画
gsap.to("#current-scene", {
  scale: 0.6,
  filter: "blur(10px)",
  duration: 0.4,
  ease: "power2.in",
  onComplete: () => {
    switchScene(); // 切换场景
    gsap.to("#new-scene", {
      scale: 1,
      filter: "blur(0px)",
      duration: 0.5,
      ease: "power3.out"
    });
  }
});
```

## 四、节奏控制技术

### 4.1 时长分配模型

**短平快（30-60秒）：**
```
开场钩子：3秒（10%）
核心内容：45秒（75%）
结尾互动：5秒（10%）
```

**标准版（60-90秒）：**
```
开场钩子：5秒（6%）
核心内容：70秒（78%）
结尾互动：10秒（11%）
```

**深度版（90-120秒）：**
```
开场钩子：8秒（7%）
核心内容：95秒（79%）
结尾互动：10秒（8%）
信息密度：每30秒一个数据点
```

---

### 4.2 动画节奏公式

**快节奏（数据排名）：**
- 每行停留：2秒
- 转场速度：0.3秒
- 总时长：N行 × 2秒 + 5秒（开场+结尾）

**中节奏（因果分析）：**
- 每层停留：10-15秒
- 转场速度：0.5秒
- 总时长：3层 × 12秒 + 10秒 = 46秒

**慢节奏（历史变迁）：**
- 每个节点停留：8秒
- 转场速度：1秒
- 总时长：N节点 × 8秒 + 10秒

---

### 4.3 信息密度控制

**高密度（数据排名）：**
- 每秒1个数据点
- 每行1行数据
- 观众需要快速阅读

**中密度（因果分析）：**
- 每秒0.5个数据点
- 每层2-3个关键点
- 观众有时间消化

**低密度（历史故事）：**
- 每秒0.3个数据点
- 每段1个核心观点
- 观众可以慢慢感受
