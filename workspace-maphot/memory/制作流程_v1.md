## 三、制作流程（6步）

### 第1步：选题采集
**输入**：城市名称
**输出**：选题数据（城市名+区县列表+数据）

**工具**：Python脚本
**数据来源**：百度百科/高德地图API/统计局
**产出文件**：`data/scripts/[城市]_选题.json`

**数据结构**：
```json
{
  "city": "深圳",
  "intro": "一个视频带你了解中国特色社会主义先行示范区广东省深圳市下辖10个区都有什么特点呢",
  "districts": [
    {
      "id": 1,
      "name": "福田",
      "name_origin": "原名福田，寓意"福田广种"",
      "area_km2": 78.66,
      "population": 155,
      "industry": "金融+总部经济",
      "tags": ["深圳CBD", "市民中心"]
    }
  ]
}
```

### 第2步：脚本生成
**输入**：选题数据JSON
**输出**：口播稿+字幕分段

**工具**：AI（主系统/子Agent）
**文案模板**（对标小林地理）：
```
[城市简介15秒]
一个视频带你了解[城市]下辖[数字]个[区/县]都有什么特点呢？

[每个区县15秒，共32个]
[序号] [区名]：[名字由来] → [面积X平方公里] → [常住人口约X万] → [特色产业/标签]

[结尾总结10秒]
这就是[城市]的[数字]个[区/县]，你最想去哪个呢？
```

**产出文件**：`data/scripts/[城市]_脚本.json`

### 第3步：地图制作 ⭐ 核心环节
**输入**：选题数据JSON
**输出**：竖屏地图视频片段（1080×1920）

**两种方案**：

#### 方案A：二维地图+标注（推荐首发）
- **工具**：Python + matplotlib + GeoJSON
- **流程**：
  1. 获取城市行政区划GeoJSON数据
  2. 绘制城市地图+区县边界
  3. 逐帧高亮当前区县
  4. 叠加文字标注（面积、人口、产业）
- **优势**：制作快，信息准确，对标小林地理
- **短板**：需要各城市GeoJSON数据

#### 方案B：三维地图动画（差异化）
- **工具**：Manim
- **流程**：
  1. 导入城市地图SVG/GeoJSON
  2. 三维地形+区县标注
  3. 镜头平移+缩放转场
- **优势**：视觉冲击力强，差异化
- **短板**：制作周期长

### 第4步：配音生成
**输入**：脚本JSON
**输出**：MP3配音

**工具**：Edge TTS（配音生成.py）
**配置**：
- 音色：zh-CN-YunyangNeural（沉稳男声）
- 语速：+0%（自然语速）
- 分句间隔：1秒

### 第5步：视频合成
**输入**：地图片段+配音+BGM
**输出**：完整MP4

**工具**：FFmpeg（视频合成.py）
**流程**：
1. 地图图片/视频片段按时间线排列
2. TTS配音对齐
3. BGM叠加（音量-20dB）
4. 字幕叠加（SRT/ASS）
5. 输出1080×1920 MP4

### 第6步：发布推送
**输入**：MP4文件
**输出**：发布记录

**平台**：抖音/头条/百家号/B站

## 四、当前需要解决的关键问题

### P0 必须解决（否则无法出片）

1. **城市级GeoJSON数据** — 地图可视化v3只有省级，需要城市级区县数据
   - 方案：从高德地图API/阿里云DataV获取
   - 路径：`data/cache/geojson/[城市].geojson`

2. **地图逐帧动画** — 当前只能生成静态地图，需要逐帧高亮+标注
   - 方案：扩展地图可视化v3，支持逐帧输出+FFmpeg合成
   - 或：用Manim做三维地图动画

3. **文案AI生成** — 脚本生成.py只有示例，需要接入AI
   - 方案：主系统/子Agent根据选题数据生成口播稿
   - 输出格式：JSON含full_text + 时间线

### P1 重要

4. **字幕同步** — 视频合成.py目前没有字幕功能
   - 方案：FFmpeg drawtext滤镜 或 Python生成SRT字幕

5. **BGM库** — 目前没有背景音乐文件
   - 方案：收集免费BGM放入`data/bgm/`

### P2 可后补

6. **发布API** — 各平台发布需要API Key
7. **自动化工作流** — 一键生成脚本

## 五、推荐路线（最小可行）

**第一期：深圳10区（二维地图版）**

```
第1步：选题采集 → 手动采集深圳10区数据（百度百科）
第2步：脚本生成 → AI生成口播稿（主系统）
第3步：地图制作 → 扩展地图可视化v3，增加城市级GeoJSON支持
第4步：配音生成 → Edge TTS（已有）
第5步：视频合成 → FFmpeg（已有，需加字幕）
第6步：发布 → 手动上传抖音验证
```

**制作周期预估**：
- 数据采集：1天
- 地图制作：2-3天（核心工作量）
- 脚本+配音+合成：1天
- 总计：**4-5天出第一期**
