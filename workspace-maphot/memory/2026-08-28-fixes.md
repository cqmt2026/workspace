# 短板修复记录 - 2026-08-28

## P0-A: 渲染模式自动选择 ✅
**文件**: `scripts/core/pipeline.py`
**改动**:
- 自动检测 index.html 中的 `<video>` 数量
- 视频数≤3 → drawElement 模式（快速）
- 视频数>3 → 自动切换 `--experimental-fast-capture=false`（截图模式，稳定）
- drawElement 失败时自动回退截图模式重试
- 超时从 600s 提升到 900s
- 使用 `npx hyperframes@0.8.17` 明确版本

**验证**: 6视频配置（中国贸易朋友圈）截图模式成功渲染 1650帧/3.3MB/4m20s

## P0-B: LLM 多模型 fallback ✅
