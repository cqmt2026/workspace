## 二、全流程验证结果

### 测试案例：鸡蛋价格地图

**选题来源：** 百度热搜#20 "鸡蛋售价9天上涨15.5%"

**流程执行：**
1. 选题分析 → 匹配决策（数据阈值+实景排名图）
2. 脚本撰写 → 口播稿约150字
3. 地图绘制 → 高德瓦片底图+31省着色+TOP20面板
4. 配音生成 → Edge TTS 60.5秒
5. 视频合成 → FFmpeg 1080×1920 25fps

**产出：**
- 地图：data/maps/20260822/egg_price_map.png（386KB）
- 配音：data/audio/egg_price_20260822.mp3（363KB）
- 视频：data/videos/egg_price_20260822.mp4（1.9MB）

**视频效果：**
- 底图：真实高德瓦片（道路/建筑纹理清晰）
- 数据层：31省按价格着色（蓝→黄→红渐变）
- 面板：TOP20排名+标题+副标题
- 配音：60秒口播，语速适中
- 时长：60.5秒，符合"一张图"栏目定位
