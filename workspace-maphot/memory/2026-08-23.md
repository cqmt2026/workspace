## 🚀 使用方法

### 快速开始
```python
# 采集选题
from scripts.modules.hot_topic_collector_v5 import HotTopicCollectorV5
collector = HotTopicCollectorV5()
topics = collector.run()

# 生成视频
from scripts.generate_videos import VideoGenerator
generator = VideoGenerator()
for script in topics[:5]:
    generator.generate(script)
```

### 单独调用
```python
# 题材分类
from core.match_maker_v2 import MatchMakerV2
topic_type, info = MatchMakerV2.classify_topic(title, subtitle, data)

# 视觉匹配
from core.visual_matcher import VisualMatcher
scheme = VisualMatcher.match_visual(topic_type, script, data)

# 地理角度匹配
from modules.hot_topic_collector_v5 import GEO_ANGLES
angle_info = GEO_ANGLES.get(keyword)
```
