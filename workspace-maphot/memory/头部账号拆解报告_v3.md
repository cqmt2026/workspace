## 一、新增案例：图说地理

### 1.1 账号信息
- **抖音号**：图说地理
- **粉丝量**：16.7万
- **内容定位**：地理知识科普 + 行政区划解析
- **风格特点**：简洁地图可视化 + 文字标注 + 旁白解说

### 1.2 爆款选题："计划单列市是怎么来的？"
- **视频链接**：https://v.douyin.com/W_hywzii1jM/
- **核心问题**：深圳、青岛、厦门、宁波、大连为什么能"单列"？
- **选题角度**：从行政概念切入，解释制度设计背后的地理逻辑

### 1.3 叙事结构拆解
```
开场（0-5秒）：
  → 抛出问题："你知道计划单列市吗？"
  → 引发好奇："为什么这5个城市这么特殊？"

展开（5-45秒）：
  → 历史背景：1980年代改革开放需要
  → 制度设计：省辖市但享有省级经济管理权限
  → 地理选择：为什么是这5个城市？

高潮（45-55秒）：
  → 深圳特例：唯一超越省会的计划单列市
  → 数据对比：GDP、人口、地位

结尾（55-60秒）：
  → 互动引导："你觉得下一个第六城会是谁？"
  → 标签：#深圳 #青岛 #厦门 #地理
```

### 1.4 视觉表现手法
- **地图形式**：中国地图高亮5个城市
- **动画类型**：点位逐个弹出 + 时间轴推进
- **数据展示**：表格对比GDP/人口/面积
- **风格特点**：简洁、信息密度高、不花哨

### 1.5 关键成功因素
1. **选题精准**：计划单列市是常见但大多数人不懂的概念
2. **痛点明确**：每个城市的人都会关心"我们为什么特殊"
3. **信息增量**：解释了制度背后的地理逻辑
4. **互动设计**：结尾提问引发评论区讨论

## 三、题材-表现手法匹配矩阵（更新版）

### 3.1 新增题材类型

| 题材类型 | 典型选题 | 用户核心需求 | 合适表现手法 | 我们的实现状态 |
|----------|----------|--------------|--------------|----------------|
| **制度起源** | 计划单列市怎么来的 | 理解概念和逻辑 | 时间轴+地图高亮 | ❌ 未实现 |

| **政策影响** | 公积金新规落地 | 影响范围和程度 | 热力图+分级色彩 | ❌ 未实现 |

### 3.2 选题角度分类

**高传播性选题特征：**
1. **概念澄清型**："计划单列市到底是什么？"——消除认知盲区
2. **利益相关型**："你的城市公积金排第几？"——与用户直接相关
3. **反常识型**："GDP最高的地方，人口却在流失"——打破认知惯性
4. **悬念揭秘型**："为什么只有深圳能超越省会？"——引发好奇心
5. **地域认同型**："山东不能失去青岛"——激发家乡自豪感

**低传播性选题特征：**
1. 纯数据罗列（没有故事线）
2. 过于专业化（术语太多）
3. 与用户距离太远（无关地域/行业）
4. 没有情绪触发点

## 六、关键方法论总结（更新）

### 6.1 选题决策树（更新）

```
选题 → 是否有强利益相关？ → 是 → 是否有数据支撑？ → 是 → 制作
                    ↓否                ↓否
              是否反常识？      是否有趣味性？
                    ↓是                ↓是
                  制作               放弃
                    ↓否
              是否解释概念？ → 是 → 制作
                    ↓否
                  放弃
```

### 6.2 表现手法选择流程（更新）

```
识别题材 → 匹配表现手法 → 生成配置 → 调用对应模板
     ↓            ↓            ↓
  关键词检测    手册查表      JSON配置
  + 人工确认
```

### 6.3 爆款公式（更新）

**爆款 = 好选题 × 强钩子 × 清晰叙事 × 数据支撑 × 互动引导**

- 好选题：利益相关/反常识/悬念感/概念澄清
- 强钩子：前3秒抓住注意力
- 清晰叙事：三层递进或对比贯穿
- 数据支撑：权威来源，可视化呈现
- 互动引导：结尾提问或投票
