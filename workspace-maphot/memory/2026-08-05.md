# 2026-08-05 工作记录

## 上午：流水线修复 + 视频产出

### 修复的问题

**1. sys.stdout 被关闭导致 ValueError**
- 根因：`topic_loader.py` 和 `pipeline_v2.py` 模块级 `sys.stdout` 重写，`main()` 内的 `print` 编译时绑定了旧的 stdout
- 修复：将 `sys.stdout` 重写移到 `main()` 之前执行

**2. FFmpeg 路径硬编码**
- 根因：`pipeline_v2.py` 中写死 `r'C:\Users\Administrator\AppData\Local\Microsoft\WinGet\Links\ffmpeg.exe'`，实际在 `C:\ffmpeg-bin\ffmpeg.exe`
- 修复：改用 `shutil.which('ffmpeg')` 自动查找，并添加 `import shutil`

**3. 模板脚本内容类型不匹配**
- 根因：`_build_yizhangtu` 不管 `content_type` 是什么，都走"排名型"模板
- 修复：新增 `_build_yizhangtu_mechanism`（机制型）和 `_build_yizhangtu_narrative`（叙事型）模板，根据 content_type 路由分发

**4. raw_data 为空时脚本循环不执行**
- 根因：`TemplateScriptGenerator._build_yizhangtu` 中 `for data in raw_data` 循环，但 raw_data 为空
- 修复：在 `_build_yizhangtu` 开头加 `_generate_placeholder_data()` 自动生成占位数据

**5. 视频输出路径不固定**
- 修复：统一到 `data/videos/`，不再按日期分目录
