### 8.1 音效触发
**技术：** AudioContext + 短音效
**实现：** 
```javascript
function playBeep() {
  const ctx = new AudioContext();
  const osc = ctx.createOscillator();
  osc.frequency.value = 880;
  osc.connect(ctx.destination);
  osc.start(); osc.stop(ctx.currentTime + 0.1);
}
```

### 8.2 数据声化
**技术：** 数据值映射到音高/音量
**实现：** `osc.frequency.value = 200 + dataValue * 10;`

### 8.3 BGM渐入渐出
**技术：** GainNode 渐变
**实现：** `gainNode.gain.linearRampToValueAtTime(0.3, ctx.currentTime + 2);`

### 8.4 音梗卡点
**技术：** 检测BGM节拍 + 同步动画
**实现：** `gsap.to(el, {scale: 1.2, duration: 0.1, yoyo: true}).delay(beatTime);`

### 8.5 环境音效
**技术：** Web Audio API + 噪声
**实现：** 白噪声模拟风声/雨声
