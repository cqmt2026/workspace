- 字幕系统：`tl.call()` 触发 `classList.add('active')`，`tl.call()` 触发 `classList.remove('active')`

## v4~v6 迭代成果

### 修复的问题
1. **场景切换时间错位**：原10s/20s/40s/60s → 改为13s/34s/52s/70s，对齐配音分段
2. **省份高亮不生效**：简称（"新疆"）vs GeoJSON全称（"新疆维吾尔自治区"）不匹配 → 全部改为全称
3. **配音只有38.9s**：视频100s空白 → 6段配音覆盖全程（100.2s）
4. **字幕同步**：时间点与配音精确对齐
5. **地图聚焦缩放**：新增 `#map-container` 包裹所有地图层，场景切换时整体缩放

### 地图聚焦缩放方案
- 开场全图：scale 1.05
- 场景2三条国道概览：scale 1.25
- 场景3 G219：scale 1.7 + 右移150px（聚焦西部新疆西藏）
- 场景4 G331：scale 1.5 + 左上移（聚焦北部东北内蒙古）
- 场景5 G228：scale 1.6 + 左移（聚焦东部沿海）
- 尾声：scale 1.15 全图
- 实现方式：`#map-container` 包裹 tile/province/flow/city 四层，GSAP `to()` 对容器做 transform

### 产出视频
- `data/videos/huangjin_daihuan_v4.mp4`（107.6MB，100s，~9000kbps，场景对齐配音）
- `data/videos/huangjin_daihuan_v5.mp4`（107.7MB，8941kbps，省份高亮修复）
- `data/videos/huangjin_daihuan_v6.mp4`（121.8MB，10220kbps，地图聚焦缩放）

### 脚本
- `scripts/fix_map_zoom.py`：添加 `#map-container` 容器 + 更新GSAP缩放动画
- `scripts/add_audio_v3.py`：6段配音生成+叠加+字幕时间输出

### 关键发现
- GSAP `to()` 对元素做 `transform: scale()` 时，`transform-origin` 默认是 `50% 50%`，但需要显式设置
- `#map-container` 包裹多层地图时，子元素需要 `position: absolute` 以保证定位一致
- HyperFrames 渲染时 `data-layout-allow-overflow` 需要加在容器上
- 音频叠加需要用 `-c copy` 取视频流，避免重编码
- 视频文件较大（~120MB）时，ffmpeg 叠加音频耗时约1分钟
