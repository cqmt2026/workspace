### 2. 字幕渲染失败 ✅
**问题**: ffmpeg ass滤镜无法处理Windows路径

**修复**: 使用相对路径
```python

ass_path = os.path.join(os.path.dirname(VIDEO_IN), "subs.ass")
cmd = ["ffmpeg", "-vf", "ass=subs.ass", ...]

```

