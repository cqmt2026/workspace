## 三、操作步骤

### 第1步：下载抖音视频

```bash
node "C:\Users\Administrator\.openclaw\workspace\skills\douyin-video\scripts\douyin.js" "https://v.douyin.com/分享链接/"
```

**输出**:
- 控制台打印：视频标题、作者、点赞/评论/分享/收藏数、时长、分辨率
- 视频文件：`C:\Users\Administrator\.openclaw\workspace\douyin-downloads\douyin_last.mp4`
- JSON结果：包含完整元数据

**注意**: 
- 链接必须是抖音短链格式 `https://v.douyin.com/xxx/`
- 每次新下载会覆盖旧文件，需要保留则先复制
- 视频分辨率通常是1920x1080（横屏）或1280x720（竖屏）

### 第2步：提取音频

```bash
cd C:\Users\Administrator\.openclaw\workspace\douyin-downloads
ffmpeg -y -i douyin_last.mp4 -vn -acodec pcm_s16le -ar 16000 -ac 1 douyin_last_whisper.wav
```

**输出**: `douyin_last_whisper.wav`（16kHz单声道PCM，Whisper专用格式）

### 第3步：Whisper转写

```bash
cd C:\Users\Administrator\.openclaw\workspace\douyin-downloads
whisper douyin_last_whisper.wav --model tiny --output_format txt --output_dir . --language zh
```

**参数说明**:
- `--model tiny`: 最快（约2-3分钟转写2分钟视频），精度够用
- `--model small`: 更准确（约5-8分钟），精度更高
- `--output_format txt`: 纯文本格式
- `--language zh`: 中文

**输出文件**:
| 文件 | 用途 |
|------|------|
| `douyin_last_whisper.txt` | 纯文本转录（用于分析文案结构） |
| `douyin_last_whisper.srt` | 带时间戳的SRT（用于逐帧对齐） |
| `douyin_last_whisper.json` | JSON格式（含每段的时间戳和置信度） |

### 第4步：提取帧图

```bash
cd C:\Users\Administrator\.openclaw\workspace\douyin-downloads
ffmpeg -y -i douyin_last.mp4 -vf "fps=1/8,scale=720:405" -frames:v 20 frame_%03d.jpg
```

**参数说明**:
- `fps=1/8`: 每8秒提取一帧（2分钟视频约15帧）
- `scale=720:405`: 缩放至720p宽，减少文件大小
- `-frames:v 20`: 最多提取20帧

### 第5步：分析帧图颜色

```python
from PIL import Image
import os

frames = sorted([f for f in os.listdir('.') if f.startswith('frame_') and f.endswith('.jpg')])
for f in frames:
    img = Image.open(f)
    w, h = img.size
    pixels = list(img.getdata())
    colors = {'blue': 0, 'green': 0, 'brown': 0, 'red': 0, 'other': 0}
    for p in pixels:
        r, g, b = p[0], p[1], p[2]
        if b > r and b > g and b > 100: colors['blue'] += 1
        elif g > r and g > b and g > 80: colors['green'] += 1
        elif r > 150 and g < 100 and b < 100: colors['red'] += 1
        elif r > 100 and g > 80 and b < 80: colors['brown'] += 1
        else: colors['other'] += 1
    total = sum(colors.values())
    print(f"{f}: 蓝{colors['blue']/total*100:.1f}% 绿{colors['green']/total*100:.1f}% 棕{colors['brown']/total*100:.1f}% 红{colors['red']/total*100:.1f}% 其他{colors['other']/total*100:.1f}%")
```

**颜色判断指南**:
| 颜色占主导 | 推测内容 |
|-----------|---------|
| 蓝色>50% | 水系/洪水/海洋图 |
| 绿色>50% | 地形/植被/地图 |
| 棕色>30% | 陆地/地形图 |
| 红色>10% | 数据高亮/热力图 |

### 第6步：深度拆解（分析维度）

按以下维度分析转录文本和帧图：

**A. 基本信息**
- 标题、作者、时长、分辨率、互动数据（点赞/评论/分享/收藏）
- 标签、音乐信息

**B. 结构拆解**
- 时间段划分（0-15秒钩子、正文分段、结尾）
- 每个时间段的内容和占比
- 文案技巧（钩子类型、递进逻辑、数据支撑、情感升华）

**C. 地图分析**
- 从帧图颜色判断地图类型
- 地图设计推断（开场全景、数据高亮、对比图、动画路径）
- 与系统现有能力对比

**D. 爆款要素总结**
- 选题公式、结构公式、数据支撑、情感升华
- 可复用的模板

**E. 生成可复用模板**
- 模板名、适用场景、结构框架
- 示例：可套用到哪些选题

## 四、常见问题

### 问题1：抖音短链解析失败
**现象**: `错误: 无法解析视频信息`
**原因**: 抖音页面结构变化，正则匹配失败
**解决**: 检查 `douyin.js` 中的正则表达式 `/"videoInfoRes":(\{.*?\}),"itemId"/` 是否需要更新

### 问题2：视频下载的是另一个视频
**现象**: 转录文本和标题不匹配
**原因**: 抖音短链跳转到了其他推荐视频
**解决**: 用 `video_id` 直接访问 `https://www.douyin.com/video/{video_id}` 重试

### 问题3：Whisper转录乱码
**现象**: 输出包含乱码字符
**原因**: 控制台编码问题
**解决**: 用 `python -c` 读取txt文件，设置 `encoding='utf-8'`

### 问题4：Windows GBK 编码报错
**现象**: `UnicodeEncodeError: 'gbk' codec can't encode character`
**原因**: PowerShell默认GBK编码，不支持某些Unicode字符
**解决**: 用Python脚本时设置 `sys.stdout.reconfigure(encoding='utf-8')`
