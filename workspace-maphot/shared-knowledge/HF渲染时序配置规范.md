# HF渲染时序配置规范

## 问题记录

2026-08-25: 使用HF模板渲染广州11区GDP视频时，出现严重时序不匹配：
- 脚本规划: 60秒
- 实际配音: 83秒
- 实际视频: 83秒（剪辑后60秒）

## 根因分析

1. **HF模板时间参数固定**
   - 当前模板硬编码了动画时长
   - 无法根据脚本内容动态调整

2. **TTS语速未校准**
   - 脚本估算: 24.5秒（368字）
   - 实际配音: 83秒
   - 语速偏差: 3.4倍

3. **时序不同步**
   - 脚本时间范围与HF动画时间不匹配
   - 缺少"脚本时长 → HF模板时长"的自动换算

## 解决方案

### 短期（已实施）
- 手动剪辑视频到目标时长
- 保留现有配音

### 中期（待实施）
1. **TTS语速校准**
   ```python
   # 测试不同语速
   rate = ["0.8", "1.0", "1.2", "1.5"]
   # 找到368字在X秒内完成的语速
   ```

2. **HF模板参数化**
   ```python
   # 将动画时长作为变量传入
   hf_template(config={
       "duration": script_duration,  # 从脚本计算
       "sections": script.sections   # 每段对应一个动画片段
   })
   ```

3. **时序对齐检查**
   - 渲染前: 验证脚本时长 vs 模板时长
   - 渲染后: 验证视频时长 vs 配音时长

## 教训

- ❌ 不要手动调试HF语法错误
- ✅ 应该用pipeline.py自动化
- ❌ 不要忽略时长匹配问题
- ✅ 应该在脚本生成时就计算准确时长
