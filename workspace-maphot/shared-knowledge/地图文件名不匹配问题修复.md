# 地图文件名不匹配问题修复

## 问题
流水线生成的地图文件名与HTML模板引用不匹配：
- 流水线生成：`map_天河区.png`
- HTML模板引用：`广州_天河区_map_v3.png`

## 影响
- 地图无法显示
- 视频内容缺失关键视觉元素

## 解决方案

### 方案A：重命名文件（临时）
```powershell
# 复制旧地图到新目录
Copy-Item "data/maps/20260731/广州_天河区_map_v3.png" "my-video/assets/maps/广州_天河区_map_v3.png"
```

### 方案B：修改流水线（根本解决）
在 `pipeline.py` 的地图复制步骤中，重命名文件：
```python
# 当前代码
shutil.copy2(os.path.join(maps_dir, f), os.path.join(hf_maps_dir, f))

# 修改为
new_name = f.replace("map_", "{city}_").replace(".png", "_map_v3.png")
shutil.copy2(os.path.join(maps_dir, f), os.path.join(hf_maps_dir, new_name))
```

## 教训
- 地图文件名规范：`{city}_{district}_map_v3.png`
- 流水线应与模板保持同步
- 测试时应检查文件引用是否正确
