# 字幕渲染问题解决记录

## 问题
ffmpeg ass滤镜无法正确处理Windows路径

## 错误信息
```
Unable to parse option value "UsersAdministrator.openclaw.../subs.ass" as image size
Error applying option 'original_size' to filter 'ass': Invalid argument
```

## 原因
1. PowerShell路径转义问题
2. ffmpeg ass滤镜对路径格式敏感

## 解决方案
1. 将ASS文件与视频放在同一目录
2. 使用相对路径而非绝对路径
3. 在视频目录执行ffmpeg命令

## 正确用法
```python
# 1. 创建ASS文件到视频同目录
ass_path = os.path.join(os.path.dirname(VIDEO_IN), "subs.ass")

# 2. 使用相对路径
cmd = [
    "ffmpeg", "-y",
    "-i", VIDEO_IN,
    "-vf", "ass=subs.ass",  # 相对路径
    "-c:v", "libx264", "-crf", "18",
    "-c:a", "copy",
    VIDEO_OUT
]

# 3. 在视频目录执行
result = subprocess.run(cmd, cwd=os.path.dirname(VIDEO_IN))
```

## 教训
- 不要在PowerShell中用反斜杠路径
- 用正斜杠或相对路径
- 复杂滤镜用Python脚本生成
