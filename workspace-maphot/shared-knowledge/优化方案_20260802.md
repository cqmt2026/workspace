## 二、分阶段优化方案

### 阶段一：P0 补齐（本周）

**目标：** 补齐基础能力，让流水线能覆盖更多选题类型

#### 1.1 信息密度提升（1天）

**改动：**
- `raw_data` 统一字段规范：`name/rank/value/area/tag/gdp_raw/population/density`
- 柱状图面板自动展示 `area` + `tag` + `reason`
- 数据来源：`data/` 目录下 JSON 统一格式

**文件：** `schemas.py`（字段规范）+ `province_map_drawer.py`（面板展示）+ 数据文件

#### 1.2 对比并排图集成（1天）

**改动：**
- `compare_drawer.py` 已继承 `BaseDrawer`，只需注册到 `MapMgr` 的 `DRAWER_REGISTRY`
- 对比型选题自动触发 `compare_drawer`
- 测试：对比型选题 → 并排图渲染

**文件：** `map_mgr.py`（注册表）+ `compare_drawer.py`（调试）

#### 1.3 钩子文案库扩充（0.5天）

**改动：**
- 每种手法 2-3 个文案变体
- `_build_yizhangtu` 随机选一个

**文件：** `script_mgr.py`

### 阶段二：P1 体验优化（本周-下周）

**目标：** 提升完播率和互动率

#### 2.1 互动率优化

**改动：**
- 根据 `emotion` 配置 CTA 强度
- 中段互动（每3-4段插入1句互动）
- 结尾强互动（点赞+关注+评论引导）

**文件：** `script_mgr.py`（分段生成逻辑）

#### 2.2 选题采集集成到流水线

**改动：**
- `topic_loader.py` 集成到 `pipeline_v2` 的 `run` 方法
- `--step 0` 自动采集
- 采集结果自动写入 `topic.recommend`

**文件：** `pipeline_v2.py` + `topic_loader.py`

#### 2.3 复盘自动化

**改动：**
- 每次流水线结束后自动生成复盘记录
- 评分模板：信息密度/完播潜力/互动率/视觉质量
- 写入 `MEMORY.md` 或知识手册

**文件：** `pipeline_v2.py`（新增 step 5）

## 三、优先级矩阵

```
高影响
  │
  │ 信息密度(P0)  对比并排图(P0)
  │  钩子文案(P1)  互动率(P1)
  │
  │  选题采集(P1)  复盘自动化(P2)
  │  剖面图(P2)    BGM库(P2)
  │
  └──────────────────────→ 低工作量
  多层叠加(P3)   3D飞行(P3)    高工作量
```

**建议顺序：** 信息密度 → 对比并排图 → 钩子文案 → 互动率 → 选题采集 → 复盘 → 剖面图 → BGM

## 四、风险与约束

### 约束
- 版本冻结：不做重大改动（柱状图坐标系已稳定）
- 单步验证：每次只改1个文件，改完编译验证
- 30分钟断点：超时回退

### 风险
- 对比并排图：`compare_drawer` 接口是否兼容 `BaseDrawer` 需要验证
- 信息密度：数据字段扩展后，旧数据文件需要统一格式
- 互动率：加了互动段后，视频时长会变长，需要注意完播率
