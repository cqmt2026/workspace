# coding-standards.md - 地图热点子系统编码规范

> 参考投资系统编码规范，适配地图+热点短视频场景

---

## 强制工作流（每次写代码必须执行）

### 开始前
1. `read` 目标文件 → 确认当前逻辑
2. `exec grep` 搜索调用点 → 确认影响范围
3. 确认 Python 版本、路径编码、依赖可用性

### 编写中
1. 遵循命名约定（snake_case/PascalCase/UPPER_SNAKE_CASE）
2. 边界情况同步处理（空输入/None/null/0/负数/极大值）
3. 遇到重复代码 → 立即提取函数
4. 错误处理用具体异常类型，不要裸 except

### 完成后
1. 运行验证测试（assert + print）
2. grep 确认没有遗漏的调用点
3. 错误信息完整可读

## 文件命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| Python脚本 | 中文名称（带.py后缀） | 选题采集.py、地图绘制.py |

## 日志规范

1. **分级记录**：INFO/WARNING/ERROR
2. **文件分离**：每个模块独立日志文件
3. **日期归档**：日志文件名包含日期
4. **关键操作**：发布、合成等关键操作记录详细参数

---

## 数据处理规范

1. **数据来源标注**：所有数据必须标注来源
2. **时间戳**：所有数据记录创建时间
3. **交叉核实**：关键经济数据需多源验证
4. **版本控制**：脚本JSON包含版本号

---

## 视频输出规范

| 参数 | 要求 |
|------|------|
| 分辨率 | 1080×1920（竖屏） |
| 格式 | MP4 (H.264) |
| 音频 | AAC 128kbps |
| 字幕 | SRT嵌入或硬烧 |
| BGM | 音量-20dB，淡入淡出2s |
| 时长 | 深一度3-5min / 追热点1-2min / 一张图30-60s |
