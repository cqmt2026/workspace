## 二、腾讯能解决什么问题？

### ✅ 能解决：

1. **POI数据补充**
   - 当高德/百度数据不足时，用腾讯补充
   - 覆盖不同地区的POI数据库差异

2. **电话信息获取**
   - 返回tel字段，可补充CRM电话覆盖率
   - 实测数据显示约30-50%电话覆盖率

3. **坐标数据获取**
   - 返回完整lat/lng，可用于地图可视化

4. **多边形精准搜索**
   - 支持自定义区域搜索（<30km²）
   - 适合高新区等特定区域精准抓取

5. **周边推荐**
   - /ws/place/v1/explore 接口
   - 无关键词，按热度推荐周边地点

### ❌ 不能解决（或有限制）：

1. **大数据量抓取**
   - 5千配额/天，单行业彻底抓取约需50-100次调用
   - 只能作为补充渠道，不能做主力

2. **电话号码完整性**
   - 腾讯电话覆盖率约30-50%
   - 低于高德（约78%）
   - 不能替代高德作为电话主要来源

3. **跨区域大规模搜索**
   - 多边形搜索限制面积<30km²
   - 不适合全城批量搜索

4. **历史数据追溯**
   - 无历史POI变化数据
   - 只能获取当前数据

## 四、结论：腾讯的定位

**腾讯地图API的正确定位：**

1. **应急备选渠道**
   - 高德/百度配额耗尽时启用
   - 补充特定行业数据

2. **多边形精准搜索**
   - 适合高新区等特定区域
   - 适合自定义范围搜索

3. **数据交叉验证**
   - 与其他平台数据对比
   - 验证数据准确性

4. **不适合做主力**
   - 配额太小（5千/天）
   - 电话覆盖率最低
   - 数据质量稍逊于高德
