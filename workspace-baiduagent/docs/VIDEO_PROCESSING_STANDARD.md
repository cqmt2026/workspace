# 抖音视频内容处理标准流程

> 版本：V1.0  
> 创建时间：2026-09-13  
> 适用范围：所有抖音视频内容获取任务

---

## 一、流程概览

```
输入抖音短链
    ↓
Step 1: 解析视频ID + 获取元数据
    ↓
Step 2: 下载视频 + 提取音频
    ↓
Step 3: Whisper 转写（tiny→base 降级）
    ↓
Step 4: ASR 规则修正
    ↓
Step 5: 人工精校（关键术语核对）
    ↓
Step 6: 生成报告 + 海报
    ↓
Step 7: 生成朋友圈文案
    ↓
输出到 assets/reports/
```

## 三、输出文件规范

### 3.1 报告文件

| 文件 | 命名规则 | 内容 |
|------|---------|------|
| 元数据 | `douyin_meta_{video_id}.json` | API 返回的原始数据 |
| 转写文本 | `douyin_transcript_{video_id}.txt` | 原始转写 |
| 修正文本 | `douyin_transcript_{video_id}_corrected.txt` | ASR 修正后 |
| 完整报告 | `douyin_report_{video_id}.md` | Markdown 格式报告 |
| 海报 | `GEO海报_视频{N}_精校版.png` | 视频内容海报 |
| 朋友圈文案 | `朋友圈文案_视频{N}_{标题关键词}.md` | 3 个版本文案 |

### 3.2 输出目录

```
assets/reports/
├── douyin_meta_{video_id}.json
├── douyin_report_{video_id}.md
├── douyin_transcript_{video_id}.txt
├── douyin_transcript_{video_id}_corrected.txt
├── GEO海报_视频{N}_精校版.png
└── 朋友圈文案_视频{N}_{标题关键词}.md
```

## 五、人工精校检查清单

每次生成海报后，必须核对以下内容：

- [ ] 平台名称是否正确（DeepSeek 而非 Doubao）
- [ ] GEO 术语是否统一
- [ ] 数据/数字是否准确
- [ ] 专业术语是否准确（如"包排名"而非"包牌名"）
- [ ] 语义是否通顺

## 六、海报生成规范

### 6.1 风格要求

| 视频 | 主题 | 配色 |
|------|------|------|
| 视频1 | 企业适配度分析 | 紫色渐变 (#667eea→#764ba2) |
| 视频2 | 中小商家入门指南 | 绿色渐变 (#11998e→#38ef7d) |

### 6.2 内容要素

必须包含：
1. 标题区（视频主题）
2. 核心判断标准
3. 主要内容框架（三类企业/三个优先级等）
4. 关键提醒/警示
5. 底部金句

禁止包含：
- 作者来源标注
- 视频ID等元数据

## 七、朋友圈文案规范

### 7.1 文案版本

每个视频生成 3 个版本：
1. **干货型**：结构清晰，突出要点
2. **故事型**：以故事切入，引发共鸣
3. **短文案**：简洁有力，快速传播

### 7.2 话题标签

固定标签：
```
#GEO #GEO优化 #AI营销 #企业获客 #中小商家
#本地生活 #AI搜索 #DeepSeek #通义千问 #Kimi
```

## 八、常见错误与处理

| 问题 | 原因 | 处理方案 |
|------|------|---------|
| ASR 识别错误 | 同音字/专有名词 | 扩展 `correct_asr.py` 词典 |
| 海报内容失真 | 自动摘要丢失细节 | 人工精校后重新生成 |
| 视频下载失败 | 链接失效/风控 | 使用浏览器兜底方案 |
| Whisper 卡死 | CPU 模式慢 | 改用 tiny 模型，等待超时后降级 |
