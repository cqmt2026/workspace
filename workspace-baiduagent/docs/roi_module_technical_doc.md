## 一、核心计算公式

### 1.1 基础公式

```
ROI = (营收 - 预算) / 预算 × 100%

其中：
营收 = 点击数 × 点击率 × 转化率 × 客单价
点击数 = 预算 / CPC（平均点击成本）
```

### 1.2 完整计算流程

```
输入参数：
├── budget: 月度预算（元）
├── cpc: 平均点击成本（元/点击）
├── click_rate: 点击率（%）
├── conversion_rate: 转化率（%）
└── avg_order_value: 平均订单金额（元）

计算过程：
1. 点击数 = budget / cpc
2. 线索数 = 点击数 × click_rate
3. 成交数 = 线索数 × conversion_rate
4. 营收 = 成交数 × avg_order_value
5. ROI = (营收 - budget) / budget × 100%
```

### 1.3 示例计算

**输入**：
- 预算：5,000元
- CPC：8元
- 点击率：3.5%
- 转化率：2.5%
- 客单价：50,000元

**计算**：
```
点击数 = 5000 / 8 = 625次
线索数 = 625 × 3.5% = 21.9个
成交数 = 21.9 × 2.5% = 0.55单
营收 = 0.55 × 50000 = 27,344元
ROI = (27344 - 5000) / 5000 × 100% = 446.9%
```

## 六、注意事项

### 6.1 保守原则
- 提案时使用**保守估计**（取区间下限）
- 避免过度承诺，宁可实际超出预期

### 6.2 行业差异
- 不同细分行业差异大（如医疗器械vs机械装备）
- 同一行业不同地域也有差异

### 6.3 数据时效
- 百度算法频繁更新
- 季度需重新验证基准值
