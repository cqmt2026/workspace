## 二、功能拆解

### 2.1 核心功能链

```
输入（线索列表）→ AI生成个性化邮件 → 发送 → 追踪响应 → 自动跟进
```

| 环节 | 功能 | 技术实现 |
|------|------|---------|
| **输入** | 导入leads列表（CSV/JSON） | 本地文件读取 |
| **生成** | AI生成个性化cold email | LLM调用 |
| **发送** | SMTP邮件发送 | 用户自有SMTP服务器 |
| **追踪** | 邮件状态追踪（已读/回复） | SQLite存储 |
| **跟进** | 自动排队follow-up | 本地队列调度 |

### 2.2 技术架构

```

```

**特点**：
- 仅2个文件，极度精简
- 依赖OpenClaw生态（`openclaw use`命令）
- 无复杂配置，零依赖部署

### 2.3 核心流程

1. **Lead Ingestion**
   - 输入：leads列表（name, email, company, industry等）
   - 存储：本地SQLite数据库

2. **Email Generation**
   - AI根据lead信息生成个性化邮件
   - 使用LLM（需配置API key）
   - 支持多轮对话优化

3. **Email Sending**
   - 使用用户自有SMTP服务器
   - 支持Gmail/Outlook/企业邮箱
   - 速率限制：避免被标记为垃圾邮件

4. **Response Tracking**
   - 追踪邮件状态（发送/已读/回复）
   - 存储到SQLite
   - 自动标记已回复leads

5. **Follow-up Queue**
   - 自动排队follow-up邮件
   - 支持延迟策略（如3天后跟进）
   - 最多N轮跟进后停止
