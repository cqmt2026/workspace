## 📋 工作流程（SOP）

### 每日工作流
```
09:00  生成今日拨打清单（Top10，按行业优先级）
09:30  上午拨打（目标8-10通）
14:00  下午拨打（目标8-10通）
17:00  录入通话记录，更新客户状态
17:30  生成日报（拨打/接通/意向数）
```

> **拨打心法**：开场用行业数据破冰→**SPIN四问挖需求**（现状/问题/影响/价值）→算ROI账→小步测试促单
> **每个意向客户立即记：痛点+当前获客方式+预算量级+决策人，为二次跟进攒弹药**

### 周复盘流程（每周三14:00）
```
1. 本周拨打总数/接通率/有意向率/成交率
2. 各行业转化对比
3. 话术迭代（哪些角度更有效）
4. 下周目标客户调整
```

### 月汇总流程（每月1日）
```
1. 月度业绩统计
2. 行业排名（哪个行业转化率最高）
3. 下月目标客户池刷新
4. 产品知识补充（新产品/政策变化）
```

- 官方名单免费权威 > 地图POI > 付费工商
- **一次只抓一个行业，彻底完成后再换下一个**（避免重复和遗漏）
- 每次抓取前必查《多渠道数据统一管理机制》
- 抓取后必更新multi_channel_ledger.json
- **关键教训**：台账状态需实时实测，不能依赖昨日记录
