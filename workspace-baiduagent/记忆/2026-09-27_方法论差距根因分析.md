## 分析框架

```
每个差距问三个问题：
1. 有规则吗？（AGENTS.md/MEMORY.md是否明确）
2. 有工具吗？（脚本/流程是否支持）
3. 执行了吗？（是否照做）

结论四象限：
□ 有规则+有工具+执行 = 应该做到
□ 有规则+无工具 = 需开发工具
□ 无规则+有工具 = 需制定规则
□ 无规则+无工具 = 需从零建设
```

## 差距逐项分析

### 差距1：日历日期错误

**现象：** 把09-28写成09-29

| 维度 | 判断 | 说明 |
|------|------|------|
| 有规则吗？ | ❌ 无 | AGENTS.md未规定"日期计算必须复核" |
| 有工具吗？ | ✅ 有 | Python datetime可自动计算 |
| 执行了吗？ | ❌ 否 | 手动写死日期，未用工具 |

**根因：** 无规则约束 + 有工具不用 + 手动操作出错

**纠正措施：**
```
□ 新增规则："所有日期计算必须用工具，禁止手写"
□ 执行：使用Python datetime模块计算
□ 验证：输出后人工核对一次
```
