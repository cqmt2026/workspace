```
GEO = 生成式引擎优化（Generative Engine Optimization）
→ 让企业在AI对话中被推荐
```

### 1.2 通俗解释
```
过去：客户搜"重庆机械厂家" → 看到百度搜索结果
```

## 六、常见问题

### Q1：GEO和SEO有什么区别？
```
SEO是让百度搜索引擎收录你的网页
GEO是让百度AI在回答问题时推荐你的企业

两者可以互补，但GEO面向的是AI搜索时代的新流量
```

### Q2：GEO需要多长时间见效？
```
- 内容发布后1-2周：百度收录
- 3-6个月：AI问答中出现品牌推荐
- 6-12个月：品牌搜索量显著提升

建议至少测试6个月，效果更稳定
```

### Q3：GEO适合所有行业吗？
```
不适合：
  ❌ B2C行业（口腔、装修、教培、母婴等）
  ❌ 软件IT行业（B2B属性弱）
  
适合：
  ✅ B2B制造业（机械、医疗、新材料等）
  ✅ 专精特新企业
  ✅ 有政府采购需求的企业
```

### Q4：GEO和SEM可以同时做吗？
```
可以，而且 recommended！

组合策略：
  - GEO：建立品牌信任，长期获客
  - SEM：快速获取线索，短期成交
  
两者互补，效果更佳
```
