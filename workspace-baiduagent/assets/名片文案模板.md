## 设计风格建议

| 元素 | 建议 |
|------|------|
| **主色调** | 百度蓝(#306AFF) + 白色 |
| **字体** | 黑体/微软雅黑，清晰易读 |
| **尺寸** | 标准名片85×54mm |
| **材质** | 350g铜版纸，哑光质感 |
| **数量** | 首批100张，预留加印空间 |

---

## 使用提示

1. **手写补充**：电话/微信/邮箱留空，现场手写更亲切
2. **双面印刷**：正面个人信息，背面公司业务
3. **二维码**：可加个人微信二维码，方便扫码添加
4. **备用版**：准备2-3版不同设计，应对不同客户群体
