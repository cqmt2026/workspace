## 🔍 30秒侦察标准流程

### 步骤1：企查查（30秒）
- 搜公司名
- 记录：经营范围、法人、注册资本、资质
- 输出：一句话业务描述

### 步骤2：百度（30秒）
- 搜"公司名"
- 记录：排名位置、是否有广告
- 输出：截图保存

### 步骤3：豆包（60秒）- 核心
- 搜"公司名"
- 搜"品类词+重庆"（如"不锈钢加工+重庆"）
- 记录：AI是否推荐、推荐前3名是谁
- 输出：截图保存

### 步骤4：竞品（30秒）
- 搜"行业词+重庆"
- 记录：前3名公司
- 输出：判断竞争格局

**总耗时：2-3分钟/家**

## ⚠️ 常见异议处理

### 异议1："GEO是什么？没听过"

```
"GEO是生成式引擎优化——简单说就是让AI在回答用户问题时，主动推荐你的品牌。

比如客户问豆包'重庆哪里有靠谱的XX厂家'，如果AI直接推荐你家，这就是GEO的效果。

豆包已经跟抖音生活服务打通了，AI推荐位置直接能成交，这是最新的获客入口。"
```

### 异议2："我们客户不会用AI搜"

```
"分行业看。你们是做B2B的还是B2C的？

如果是B2B，采购决策链长，客户一定会做信息搜集——AI搜索现在是他们找供应商的第一站。

你们同行有没有已经在布局的？如果没有，这就是机会窗口。"
```

### 异议3："太贵了吧"

```
"GEO分三个优先级：
- 第一级信息归一化，成本几乎为零，先把基础打好
- 第二级做诊断，看看AI认不认识你
- 第三级内容铺设，根据预算决定深度

建议先做诊断，免费的。我帮你搜一下你的品牌名和品类词，看看AI怎么答你。"
```
