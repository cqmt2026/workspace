## 一、GEO产品核心定位

### 1.1 一句话定位
```
"GEO = 让企业在AI对话中被推荐"
  → 客户问AI'重庆机械厂家推荐'，AI回答提到你的公司
```

### 1.2 与传统SEO/SEM区别

| 维度 | SEO | SEM | GEO |
|------|-----|-----|-----|
| 目标 | 搜索引擎排名 | 搜索广告位 | AI回复引用 |
| 载体 | 网页 | 广告位 | 知识库/内容 |
| 见效 | 3-6个月 | 即时 | 1-3个月 |
| 成本 | 低 | 高 | 中 |
| 竞争 | 红海 | 红海 | **蓝海** |

### 1.3 GEO价值主张（通用）
```
✓ 比传统广告便宜（年费5千-1万 vs SEM月耗5千+）
✓ 比SEO见效快（1-3个月 vs 3-6个月）
✓ 竞争少（蓝海市场，先发优势明显）
✓ 面向未来（AI搜索普及加速，提前卡位）
✓ 信任度高（AI推荐比广告更有说服力）
```

## 七、话术使用指南

### 7.1 展会陌拜流程（5分钟/客户）
```
第1分钟：破冰+观察
  → "您好，我看咱们产品是XX，在重庆做多久了？"

第2分钟：痛点挖掘
  → "现在主要靠什么渠道获客？效果怎么样？"

第3分钟：价值呈现
  → "我查了下，咱们行业百度上竞争很低，
     很多同行还没开始做..."

第4分钟：ROI算账（精简版）
  → "年费6,000-8,000元，预计3个线索，
     一个订单就能回本..."

第5分钟：促单+加微信
  → "这样，我加您微信，把方案和案例发您，
     您考虑下，有问题随时问我。"
```

### 7.2 关键提醒
```
✓ 先观察，再开口（看产品、看展位、看状态）
✓ 用问题引导（让他们自己说痛点）
✓ 给数据支撑（行业搜索量、竞品情况）
✓ 小步测试（年费6千-8千，降低门槛）
✓ 立即加微信（现场建联系，后续跟进）
```

### 7.3 禁止事项
```
✗ 不要一上来就推销产品
✗ 不要说"你们 need GEO"
✗ 不要纠缠没时间的人
✗ 不要承诺具体效果
✗ 不要一次性问太多问题
```
