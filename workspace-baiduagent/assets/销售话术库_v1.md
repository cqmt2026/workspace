## 一、百度搜索推广

### 通用开场白
```
"您好，请问是XX公司吗？我是百都科技的小度，做重庆中小企业获客增长的。

打电话前我先看了下贵公司的资料——你们做的是[一句话业务]，对吧？
我这边在做[行业]的获客调研，发现一个挺关键的现象：[一句行业洞察]。

想跟您简单确认下——你们现在主要靠什么渠道接客户/订单？大概耽误您2分钟，可以吗？"
```

### 分行业话术

#### 1.1 医疗器械/生物医药（高客单+B2B）
**侦察锚点**：医院/代理商采购决策链清晰
```
"我看到你们是做[体外诊断/手术器械/耗材]的，专精特新企业。
我注意到一个现象——重庆这边搜'重庆[产品]''[产品]厂家'，前几页基本都是外地公司和聚合平台，本地正规厂家几乎没有曝光。但医院采购、代理商找货源，第一件事就是百度搜供应商。

你们现在找客户主要靠什么？展会、代理商，还是老客户转介绍？"
```
**算账逻辑**：
- 单台设备产值：数万~数百万元
- 百度投放率：不足15%（蓝海）
- ROI：投1万换10万订单

**推荐产品**：搜索推广（主打）+ 爱采购B2B店铺（资质展示）+ 品牌专区

#### 1.2 机械装备/汽配（量大+供应链采购）
**侦察锚点**：技术参数词+企业资质
```
"我看到你们做[起重设备/模具/汽车零部件]的，是重庆专精特新企业。
我搜了下'重庆[产品]'，本地厂家曝光很少，反而是外地和B2B平台占前面。但下游客户找供应商，第一反应都是百度搜'[产品]+厂家'。

你们现在订单主要怎么来？老客户复购、展会，还是线上一块也有做？"
```
**算账逻辑**：
- 重庆专精特新机械企业：438家
- 百度投放率：中等，但细分品类空白
- 典型案例：月投5000，3个月接3单总额200万+

**推荐产品**：搜索推广（长尾关键词精准获客）+ 爱采购（工业品采购平台）

#### 1.3 新材料/化工（蓝海+政策风口）
**侦察锚点**：下游客群（汽车/电子/建筑）+ 技术优势
```
"我看到你们是做[复合材料/化工新材料]的，专精特新。
重庆新材料产值6200亿，但我发现你们这个细分[具体领域]，百度上几乎没人投广告，获客基本靠老客户和展会。问题是你们的潜在客户（主机厂/建筑商/电子厂）找供应商时，第一站是百度搜'[材料]+供应商'。

你们现在线上获客有在做吗？还是主要线下？"
```
**算账逻辑**：
- 2024年重庆先进材料产值：6200亿元
- 2027年目标：万亿级产业集群
- 百度投放率：几乎为零（绝对蓝海）

**推荐产品**：搜索推广 + 爱采购 + 信息流（触达潜在采购决策人）

#### 1.4 环保/检测（政府+国企项目）
**侦察锚点**：CMA资质+近中标记录
```
"我看到你们有[CMA/CNAS]资质，做[环境检测/水处理/环评]的。
环保检测这块有个特点——政府、国企招标前，甲方会先在百度上筛一轮供应商。你们现在百度上几乎没有品牌信息，等于甲方的第一手名单里没有你们。

你们主要是靠什么渠道拿下项目的？招投标信息、关系，还是有线上布局？"
```
**算账逻辑**：
- 政府招标必百度筛供应商
- CMA资质是硬门槛
- 百度曝光=进入甲方候选名单

**推荐产品**：搜索推广（行业词）+ 爱采购（资质长期展示）+ 品牌专区（信任背书）

## 二、美团医疗（商户通+推广通）

### 适用行业
- 口腔诊所
- 医美机构
- 眼科医院
- 男科医院
- 妇科医院
- 白癜风医院

### 通用开场白
```
"您好，请问是XX诊所/医院吗？我是百都科技的小度，专注医疗行业获客增长。

我看了下您在美团上的店铺，信息展示还不够完整。患者搜'重庆整牙''医美'时，看到的是您的基本信息、医生资质、项目案例，这些直接影响患者决策。

想跟您聊聊美团获客的优化方案，大概2分钟，可以吗？"
```

### 分产品话术

#### 2.1 商户通（年费产品展示）
**核心价值**：
- 完整展示机构信息、医生资质、项目案例
- 提升患者信任度
- 长期曝光，持续获客

**算账逻辑**：
- 年费投资：5000-20000元
- 预计每月新增患者：10-20名
- 单客价值：口腔8000-20000元，医美8000-25000元
- ROI：1个患者就能回本

**话术**：
```
"商户通是美团医疗的年费产品展示产品，可以完整展示您的机构信息、医生资质、项目案例。

患者搜'重庆整牙'时，看到的专业度和信任感，直接决定他们是否到店。

年费5000-20000元，预计每月新增10-20名患者，按口腔单客8000元算，1个患者就回本了。"
```

#### 2.2 推广通（按点击付费广告）
**核心价值**：
- 精准搜索获客
- 按点击付费，可控预算
- 效果可追踪

**算账逻辑**：
- 日预算：500-1000元
- 预计每月线索：50-100条
- 转化率：5-10%
- ROI：1单就能回本

**话术**：
```
"推广通是美团医疗的按点击付费广告产品，可以帮您提升店铺排名，获得精准流量。

日预算500-1000元，预计每月获得50-100条线索，按5%转化率算，1单就能回本。

您现在美团上的排名在第几位？我帮您做个竞品分析。"
```

### 分行业话术

#### 2.3.1 口腔诊所
**行业数据**：
- 重庆口腔诊所：1953家
- 百度投放率：低
- 美团是主要获客渠道

**话术**：
```
"重庆口腔诊所1953家，但百度几乎没人投广告，美团是主要获客渠道。

患者搜'重庆整牙''补牙'时，先看美团评价和案例。您的展示够专业吗？

商户通+推广通组合，年费5000-20000元+日预算500-1000元，预计每月新增10-20名患者。"
```

#### 2.3.2 医美机构
**行业数据**：
- 重庆医美机构：470家
- 决策周期长，需案例展示
- 小红书+美团组合效果好

**话术**：
```
"医美患者决策周期长，必搜美团看案例和评价，也会搜小红书种草。

您的美团店铺案例够多吗？评价够好吗？

商户通展示专业资质，推广通精准获客，小红书种草引流，组合拳效果最好。"
```

### 话术

现在布局等于抢占未来流量入口，竞争小、成本低。

投资5000-10000元，长期受益。我给您发个案例看看？"
```

## 七、异议处理

### "不需要"
```
"理解，很多客户一开始也这么说。但您有没有想过——您的客户找供应商时，第一站是百度/美团/小红书，如果搜不到您，就等于把客户拱手让人。

我们不逼您现在投，先给您做个免费的竞品分析，看看您和竞品的差距，您看如何？"
```

### "太贵了"
```
"我理解您的顾虑。但我们算笔账——

[行业]单客价值8000-20000元，投5000-10000元获客，转化1单就回本了。

而且我们可以先小预算测试，跑出效果再加大投入。您看如何？"
```

### "已经在投了"
```
"那太好了！说明您已经意识到线上获客的重要性。

您现在投的是哪个平台？效果怎么样？

我可以帮您做个免费的账户诊断，看看有没有优化空间，您看如何？"
```

### "再考虑考虑"
```
"没问题，理解您需要时间考虑。

我给您发份详细方案，您慢慢看。有任何疑问随时联系我。

另外，我每周会分享行业动态和竞品数据，对您做决策也有帮助，您看可以吗？"

## 八、SPIN提问法

### S（现状）
- "你们现在主要靠什么渠道获客？"
- "目前线上投入多少？"
- "主要客户从哪里来？"

### P（问题）
- "这个渠道有什么困扰吗？"
- "获客成本有上升趋势吗？"
- "客户转化率怎么样？"

### I（影响）
- "这个问题带来什么损失？"
- "如果不解决，会有什么后果？"
- "竞争对手怎么做？"

### N（价值）
- "如果解决这些问题，能带来多大收益？"
- "您期望的获客成本是多少？"
- "如果投1万换10万订单，您有兴趣吗？"
