## 二、分产品线话术

### 2.1 百度搜索推广（主打产品）

#### 通用开场白
```
"您好，请问是XX公司吗？我是百都科技的小度，做重庆中小企业获客增长的。

我调研了咱们机械行业，发现一个关键问题——下游客户找供应商，第一反应都是百度搜'[产品]+厂家'，但您在百度上几乎搜不到。

你们现在订单主要靠什么渠道？老客户复购、展会，还是线上一块也有在做？"
```

#### 分场景话术

**场景1：细分品类蓝海**
```
"我看到你们是做[起重设备/模具/数控机床]的，我搜了下'重庆[产品]'，前几页基本都是外地公司和B2B平台，本地厂家几乎没有曝光。

但下游客户（主机厂、建筑商、加工厂）找供应商时，第一站就是百度搜'[产品]+重庆'。

你们现在线上获客有在做吗？还是主要靠线下展会和老客户？"
```

**场景2：专精特新企业**
```
"我看到你们是重庆专精特新企业，技术实力很强。但有个现象——你们在百度上几乎搜不到，反而是外地企业和聚合平台排在前面。

这意味着什么？意味着你们的潜在客户（主机厂、国企、大型民企）找供应商时，根本看不到你们。

你们现在主要靠什么渠道拿订单？招投标、关系，还是有线上布局？"
```

**场景3：B2B采购习惯**
```
"我做机械行业获客调研时发现一个规律——下游客户找供应商，70%以上第一站是百度搜'[产品]+厂家'，其次是爱采购、阿里巴巴。

你们现在百度上有投放吗？还是主要靠老客户和展会？"
```

#### 痛点挖掘（SPIN提问法）

**S（现状）**
- "你们现在主要靠什么渠道获客？"
- "线上投入大概多少？"
- "主要客户从哪里来？"

**P（问题）**
- "这个渠道有什么困扰吗？"
- "获客成本有上升趋势吗？"
- "客户转化率怎么样？"
- "竞争对手有没有在线上布局？"

**I（影响）**
- "如果客户搜不到你们，会损失多少订单？"
- "每年展会投入多少？效果怎么样？"
- "老客户占比多少？新客从哪里来？"

**N（价值）**
- "如果百度能带来精准线索，你们能接受多少获客成本？"
- "投1万换10万订单，你们有兴趣吗？"
- "如果每月稳定带来5-10条精准线索，对你们帮助大吗？"

#### 算账逻辑
```
投入：月预算5000-20000元
产出：预计每月10-30条精准线索
转化：5-10%转化率 = 每月0.5-3单
单值：每台设备数万~数百万元
ROI：投1万换10万-100万订单

典型案例：
成都某起重设备企业，月投5000元，3个月接3单，总额200万+
```

#### 促单话术
```
"我们不逼您现在投，先给您做个免费的百度竞品分析，看看您和竞品的差距，您看如何？

另外，我们可以先小预算测试，月投3000-5000元，跑出效果再加大投入。您看下周有没有时间，我上门给您详细讲讲？"
```

### 2.2 爱采购（B2B平台）

#### 开场白
```
"您好，请问是XX公司吗？我是百都科技的小度。

我看到您是做[产品]的，工业品采购平台'爱采购'您可以了解一下。

下游客户找供应商时，会在爱采购上搜索'[关键词]'，您有展示吗？

爱采购年费制，长期展示企业资质和产品，持续获客，单次获客成本远低于搜索推广。"
```

#### 分品类话术

**起重设备/工程机械**
```
"起重设备B2B采购第一站是爱采购，您的产品在平台上吗？

1台设备产值数万~数百万元，1单就能回本年费。

典型客户：四川某起重设备企业，爱采购年费6800元，每月稳定带来2-3条线索，转化1单就回本。"
```

**数控机床/精密机械**
```
"数控机床采购商常用爱采购找供应商，您的产品展示够完整吗？

技术参数、资质认证、案例展示，爱采购都能长期展示。

年费6800-12800元，长期获客，单次获客成本远低于搜索推广。"
```

**汽摩配件**
```
"汽配配件采购商常用爱采购找供应商，您的产品上架了吗？

长期合作订单，年产值百万级。

爱采购年费6800元起，365天持续曝光。"
```

#### 爱采购 vs 百度搜索推广对比
| 维度 | 爱采购 | 百度搜索推广 |
|------|--------|-------------|
| **收费模式** | 年费制 | 按点击付费 |
| **展示周期** | 365天持续展示 | 付费期间展示 |
| **单次成本** | 低（年均摊） | 高（按点击） |
| **精准度** | 中等 | 高（可定向关键词） |
| **适合场景** | 长期展示、资质背书 | 精准获客、快速见效 |

**推荐组合**：爱采购（长期展示）+ 百度搜索推广（精准获客）

## 四、异议处理

```
"理解，很多机械企业主一开始也这么说。但您有没有想过——您的客户找供应商时，第一站是百度搜'[产品]+厂家'，如果搜不到您，就等于把客户拱手让人。

我们不逼您现在投，先给您做个免费的百度竞品分析，看看您和竞品的差距，您看如何？"
```

### "太贵了"
```
"我理解您的顾虑。但我们算笔账——

机械行业单客价值数万~数百万元，投5000-10000元获客，转化1单就回本了。

而且我们可以先小预算测试，月投3000-5000元，跑出效果再加大投入。您看如何？"
```

"那太好了！说明您已经意识到线上获客的重要性。

您现在投的是百度搜索还是爱采购？效果怎么样？

## 五、推荐产品组合

### 组合1：精准获客型（推荐）
- **百度搜索推广**（主打）+ **爱采购**（辅助）
- 适用：有明确目标客户、需要快速见效
- 预算：月10000-30000元

### 组合2：长期展示型
- **爱采购**（年费）+ **品牌专区**（年费）
- 适用：注重品牌曝光、长期获客
- 预算：年20000-50000元

### 组合3：全渠道布局型
- **百度搜索推广** + **爱采购** + **GEO** + **信息流**
- 适用：大型制造企业、品牌升级
- 预算：月30000-100000元
