# 展会陌拜检查清单

> 生成时间：2026-09-19
> 适用场景：展会现场陌拜
> 使用方式：打印随身携带，逐项打勾

---

## 一、展前准备（前一天晚上）

### 1.1 物料检查
```
□ 1. 名片（100张以上）
□ 2. 速查卡（已打印，A4双面）
□ 3. GEO产品白皮书（已打印，10份）
□ 4. ROI测算表（已打印，10份）
□ 5. 竞品格局图（已打印，5份）
□ 6. 笔记本+笔
□ 7. 手机充电宝（充满电）
□ 8. 手机电量（100%）
□ 9. 微信二维码（已准备好，可快速出示）
□ 10. PDF方案文件（已存入手机/平板）
```

### 1.2 话术准备
```
□ 1. 开场白背诵熟练（3种版本）
□ 2. 痛点问题背诵熟练（4个）
□ 3. 价值呈现背诵熟练（3句话）
□ 4. ROI算账背诵熟练（3个数字）
□ 5. 异议处理背诵熟练（4类场景）
□ 6. 促单话术背诵熟练（1句）
```

### 1.3 数据准备
```
□ 1. 目标行业A类客户名单（已导出）
□ 2. 目标企业百度现状（已查询）
□ 3. 竞品投放情况（已整理）
□ 4. 行业搜索量数据（已备份）
□ 5. ROI测算表格（已准备）
```

### 1.4 个人准备
```
□ 1. 着装整洁（商务休闲）
□ 2. 睡眠充足（7小时以上）
□ 3. 早餐吃好
□ 4. 心态调整（自信、不急躁）
□ 5. 目标设定（今日目标：加微信5-8个）
```

## 二、展会当天（早上）

### 2.1 出发前检查
```
□ 1. 再次检查物料（是否遗漏）
□ 2. 检查手机电量（是否充满）
□ 3. 检查充电宝（是否充满）
□ 4. 检查微信（是否可正常添加）
□ 5. 检查PDF文件（是否可正常打开）
□ 6. 检查速查卡（是否清晰可读）
```

### 2.2 到达展会后
```
□ 1. 熟悉展位分布（快速浏览全场）
□ 2. 筛选目标客户（按优先级排序）
□ 3. 确定拜访路线（从高意向到低意向）
□ 4. 调整心态（深呼吸，保持自信）
□ 5. 检查时间（确保有足够时间深度沟通）
```

## 三、陌拜执行（每客户5分钟）

### 3.1 第1分钟：破冰+观察
```
□ 1. 观察产品（看展位、看展品、看状态）
□ 2. 观察人员（看是否决策人、看是否有时间）
□ 3. 开场白（选1种版本）
   → 观察式："您好，我看咱们产品是XX..."
   → 数据式："您好，我刚查了下，搜'XX'..."
   → 问题式："您好，咱们平时怎么获客？..."
□ 4. 确认身份（"您是负责人吗？"）
□ 5. 确认时间（"现在方便聊5分钟吗？"）
```

### 3.2 第2分钟：痛点挖掘
```
□ 1. 提问1："现在主要靠什么渠道获客？"
□ 2. 提问2："效果怎么样？有没有困扰？"
□ 3. 提问3："有没有遇到过客户说'百度搜不到你们'？"
□ 4. 提问4："同行（如XX企业）已经在做百度推广，你们考虑过吗？"
□ 5. 记录关键点（痛点、预算、决策人）
```

### 3.3 第3分钟：价值呈现
```
□ 1. 行业数据（搜索量、竞争情况）
□ 2. 痛点关联（"您刚才说的问题，GEO可以解决"）
□ 3. 价值主张（"让AI在推荐时提到你们"）
□ 4. 案例支撑（"类似企业已经见效"）
□ 5. 差异化（"竞争对手还没布局，这是机会"）
```

### 3.4 第4分钟：ROI算账
```
□ 1. 投入说明（年费6,000-8,000元）
□ 2. 预期效果（3-6个月见效，线索成本30-50元）
□ 3. 对比优势（vs SEM便宜70-80%）
□ 4. 回本计算（一个订单就能回本）
□ 5. 降低门槛（"可以先测试3-6个月"）
```

### 3.5 第5分钟：促单+加微信
```
□ 1. 促单话术（"先做3个月测试，没线索再停"）
□ 2. 加微信（主动出示二维码）
□ 3. 发资料（现场发送PDF方案）
□ 4. 约定跟进（"我今晚把详细方案发您"）
□ 5. 感谢告别（"感谢您的时间，祝展会顺利"）
```

## 四、客户分类（现场记录）

### 4.1 A类客户（高意向）
```
特征：
  ✓ 有明显痛点（"百度搜不到我们"）
  ✓ 有预算意识（"多少钱？"）
  ✓ 有决策权（负责人/老板）
  ✓ 有时间深入沟通（>5分钟）

行动：
  → 立即加微信
  → 当晚发送详细方案
  → 3天内电话跟进
  → 1周内预约面谈
```

### 4.2 B类客户（中意向）
```
特征：
  ✓ 有兴趣但犹豫（"再看看"）
  ✓ 预算不明确（"多少钱？"但没表态）
  ✓ 需要内部讨论（"我和股东商量下"）

行动：
  → 立即加微信
  → 当晚发送基础方案
  → 3天后微信跟进
  → 1周后电话跟进
```

### 4.3 C类客户（低意向）
```
特征：
  ✓ 明确拒绝（"不需要"）
  ✓ 没时间（"很忙，下次吧"）
  ✓ 非决策人（"我做不了主"）

行动：
  → 加微信留后路
  → 发送行业数据参考
  → 不主动跟进
  → 等待客户主动联系
```

## 五、紧急应对

### 5.1 客户说"不需要"
```
应对：
  → "理解，我加您微信，发您行业数据参考"
  → "以后有采购方问起，您也能想到我们"
  → 不纠缠，微笑告别，找下一个目标
```

### 5.2 客户说"太贵了"
```
应对：
  → "一年6,000-8,000元，相当于每天16-22元"
  → "一个线索成本30-50元，比SEM便宜70-80%"
  → "而且可以先测试3个月，没线索再停"
```

### 5.3 客户说"再看看"
```
应对：
  → "没问题，我加您微信，发您方案和案例"
  → "您先看，有疑问随时问我"
  → 不催促，留后路
```

### 5.4 客户没兴趣，快步走
```
应对：
  → 微笑点头，不打扰
  → 记录"拒绝原因"（如：非决策人/没时间/明确拒绝）
  → 找下一个目标
```

### 5.5 客户问具体效果
```
应对：
  → "效果因人而异，但我可以给您看类似企业的案例"
  → "一般3-6个月见效，品牌搜索量提升30-50%"
  → "一个订单就能回本，您可以算算ROI"
  → 不承诺具体效果，只说行业平均水平
```
