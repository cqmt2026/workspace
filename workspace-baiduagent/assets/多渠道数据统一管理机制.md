## 四、渠道统一管理规则

### 1. 数据归属
```
master/ = 多渠道合并去重后的最终标准
source/<渠道>/ = 各渠道原始数据备份
├── amap/    (高德POI)
├── tencent/ (腾讯POI)
├── weijkw/  (卫健委)
├── gxq/     (高新区)
├── jiaow/   (教育局)
├── zjw/     (住建委)
└── qcc/     (企查查，待建立)
```

### 2. 每个渠道的台账
```
node_ledger.json 增加渠道维度：
- 平台/渠道
- 行业
- 关键词/筛选条件
- 新增数
- 去重数
- 抓取日期
```

### 3. 渠道去重
- 同一企业多平台来源 → 以**信息最全**的为准（如企查查>官方>地图）
- 电话：优先保留官方/工商渠道电话（更准确）
- 主键统一：企业名

### 4. 渠道覆盖检查
- 每月盘点：哪些行业缺哪个渠道
- 优先级：先补覆盖率最低的行业
- 记录到台账，避免重复
