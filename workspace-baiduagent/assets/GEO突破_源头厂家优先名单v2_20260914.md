## 八、源头厂家识别标准（v2）

### ✅ 源头厂家特征

| 特征 | 说明 |
|------|------|
| **有工厂/车间** | 企查查显示"生产制造"经营范围 |
| **有生产资质** | 专精特新、创新型中小企业、高新技术企业 |
| **有设备/产线** | 经营范围含"生产、制造、加工" |
| **B2B模式** | 客户是下游企业而非个人消费者 |
| **公司名称** | 含"制造"、"生产"、"有限"、"股份"、"技术"、"科技" |

### ❌ 非源头厂家特征（暂缓拨打）

| 特征 | 说明 |
|------|------|
| **名称含排除关键词** | 批发、超市、商行、经销、代理、贸易、供应站、零售、门店、经营部、加工部、加工厂、店、中心、服务部、工作室 |
| **无生产资质** | 企查查无生产制造相关经营范围 |
| **B2C模式** | 主要面对个人消费者 |
| **纯贸易公司** | 无生产设备，只做中间商 |

## 九、话术调整（源头厂家版）

### 开场白（机械类源头厂家）

```
"您好，请问是[公司名]吗？我是百都科技的小度，做重庆中小企业获客增长的。

打电话前我先在豆包上搜了一下——发现搜'[产品]+重庆'，AI回答里推荐的都是外地公司或者聚合平台，咱们本地厂家几乎没有曝光。

但你们下游客户找供应商时，第一件事就是搜这个。这意味着什么？你的潜在采购商正在被AI引导去别家。

冒昧问一下——你们现在主要靠什么渠道接客户？"
```

### 异议处理（源头厂家专属）

**异议："我们是工厂，客户都是老客户"**

```
"理解。但有个现象——你们下游客户（主机厂、工程方）找供应商时，第一步是不是先搜'XX厂家+重庆'？

如果AI推荐的都是外地公司，那你们的机会成本是多少？一个项目可能几十万起，错过一个就是一个。

我建议先做免费诊断，看看AI怎么答你们行业词，不花钱也能了解情况。"
```
