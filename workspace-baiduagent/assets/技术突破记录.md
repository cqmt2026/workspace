## ✅ 已验证有效的技术路径

### 1. PowerShell WebClient + 自定义Header

**代码示例：**
```powershell
$web = New-Object System.Net.WebClient
$web.Headers.Add("User-Agent", "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36")
$html = $web.DownloadString("https://cn.bing.com/search?q=你的搜索词")
```

**成功网站：**
- ✅ Bing搜索（cn.bing.com）
- ✅ 重庆市政府官网（www.cq.gov.cn）
- ✅ 网易新闻搜索（www.163.com）
- ✅ 今日头条搜索（so.toutiao.com）

**失败网站：**
- ❌ 百度（www.baidu.com）- 反爬机制
- ❌ 搜狗（www.sogou.com）- 验证码
- ❌ 活动行（huodongxing.com）- 重定向
- ❌ 美集会 - 域名失效

## 🔧 技术限制与解决方案

### 限制1：动态JS内容无法获取
**问题：** 很多网站的内容是通过JavaScript动态加载的，PowerShell只能获取HTML框架，无法获取实际内容。

**解决方案：**
```powershell
# 方案A：尝试使用IE COM对象
$ie = New-Object -ComObject InternetExplorer.Application
$ie.Visible = $false
$ie.Navigate("https://目标网站")
Start-Sleep -Seconds 5
$html = $ie.Document.Body.innerHTML
$ie.Quit()

# 方案B：使用Chromium Selenium（需要安装）
# 需要额外配置，今晚不推荐

# 方案C：接受限制，从静态HTML片段提取信息
```

### 限制2：搜索引擎反爬
**问题：** 百度、搜狗等有严格的反爬机制，触发验证码。

**解决方案：**
```powershell
# 方案A：使用必应代替百度
# 方案B：降低请求频率，添加随机延迟
Start-Sleep -Seconds (Get-Random -Minimum 2 -Maximum 5)
# 方案C：使用手机端User-Agent
$web.Headers.Add("User-Agent", "Mozilla/5.0 (iPhone; CPU iPhone OS 16_0 like Mac OS X)")
```

### 限制3：编码问题
**问题：** 部分网站返回GBK编码，PowerShell默认UTF-8。

**解决方案：**
```powershell
# 强制指定编码
$web.Encoding = [System.Text.Encoding]::GetEncoding("GBK")
$html = $web.DownloadString("https://目标网站")
```
