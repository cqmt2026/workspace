## 二、GEO知识核心要点（已提取自2个视频）

### 视频1：《所有企业都适合做豆包GEO吗？》

**三类适合企业的判断标准**：

| 层级 | 特征 | 行业示例 | 核心逻辑 |
|------|------|---------|---------|
| **第一类** | 高客单价 + 长决策周期 + 信息不对称 | 大型设备制造、跨境B2B、SaaS软件、律所、财税、留学、高端医疗 | 决策链上持续刷存在感，豆包推荐=信任背书 |
| **第二类** | 强监管 + 高信任门槛 | 金融理财、保险、医疗机构、正规教育 | 合规底子要硬，豆包引用偏好结构化、权威内容 |
| **第三类** | 本地生活服务 + 线下实体 | 餐厅、家政、美甲、汽修、口腔、摄影 | 基础信息治理先行，口碑一致才能发挥价值 |

**不适合的企业**：
- 客单价低、决策清晰的快消品类（纸巾、衣服、便利店）
- 获客完全依赖渠道分销或熟人关系

**核心判断公式**：
> "你的客户在购买决策前，会不会主动去搜'某某怎么选''A和B有什么区别'？"
> - 会 → 值得认真布局GEO
> - 不会 → 预算先放其他渠道

**案例数据**：
- 某教育企业系统化布局GEO后
- 官网主动咨询转化率：3% → 11%
- 月均转化数：60多单 → 250多单

---

### 视频2：《中小商家要不要跟着做GEO？》

**豆包最新动态**（关键武器）：
- 5月已完成抖音生活服务深度打通
- AI推荐位置 = 交易入口
- 酒店订单综合费率12%，比抖音主站高4个百分点
- **这是国内首个AI对话入口落地规模化交易抽佣案例**

**三个优先级落地路径**：
1. **信息归一化**（最重要！成本几乎为零）
   - 地图/点评/外卖/抖音/公众号信息统一
   - 店名、地址、电话、营业时间100%一致
   
2. **先做诊断再投入**
   - 在豆包/DeepSeek/Kimi/通义千问搜索品牌名+品类词
   - 看AI是否提到你、是否推荐
   
3. **内容铺设 + 持续监测**
   - 用免费Schema生成器给官网加结构化标记
   - 内容生命周期从90天缩短到45-60天，需持续维护

**三个警惕**：
- ❌ 别把大众点评/高德的预算多走
- ❌ 警惕"包排名保收录"服务商（SEO时代的老话术）
- ❌ GEO不是万能药，是持续运营

## 三、GEO话术融合（融入现有电话脚本）

### 开场白升级版（GEO切入）

```
"您好，我是百都科技的小度。打电话前我先在豆包上搜了一下你们公司——

发现一个现象：搜'[行业词]+重庆'，AI回答里推荐的都是外地公司或者聚合平台，咱们本地厂家几乎没有曝光。

但你们下游客户找供应商时，第一件事就是搜这个。这意味着什么？你的潜在采购商正在被AI引导去别家。

冒昧问一下——你们现在主要靠什么渠道接客户？"
```

### SPIN问题库（GEO版）

| 阶段 | 问题 |
|------|------|
| **S 现状** | "你们现在客户怎么来？百度、展会、老客户转介绍？" |
| **P 问题** | "有没有发现——搜你们行业词，AI回答里没你们？" |
| **I 影响** | "客户找供应商第一步是AI搜索，如果推荐的都是竞品，这个机会成本多大？" |
| **N 价值** | "如果能让AI在回答里推荐你们，相当于每次咨询都有人在帮你背书——这个价值你怎么看？" |

### 异议处理（GEO专属）

**异议："GEO是什么？没听过"**
```
"GEO是生成式引擎优化——简单说就是让AI在回答用户问题时，主动推荐你的品牌。

比如客户问豆包'重庆哪里有靠谱的XX厂家'，如果AI直接推荐你家，这就是GEO的效果。

豆包已经跟抖音生活服务打通了，AI推荐位置直接能成交，这是最新的获客入口。"
```

**异议："我们客户不会用AI搜"**
```
"分行业看。你们是做B2B的还是B2C的？

如果是B2B，采购决策链长，客户一定会做信息搜集——AI搜索现在是他们找供应商的第一站。

你们同行有没有已经在布局的？如果没有，这就是机会窗口。"
```

**异议："太贵了吧"**
```
"GEO分三个优先级：
- 第一级信息归一化，成本几乎为零，先把基础打好
- 第二级做诊断，看看AI认不认识你
- 第三级内容铺设，根据预算决定深度

建议先做诊断，免费的。我帮你搜一下你的品牌名和品类词，看看AI怎么答你。"
```

## 四、客户筛选标准（哪些优先推GEO）

### ✅ 高适配度客户（优先触达）

| 特征 | 说明 |
|------|------|
| **专精特新企业** | 政府资质背书，AI可信度高 |
| **机械/装备制造** | 高客单、长决策周期，B2B采购决策链清晰 |
| **医疗器械** | 强监管、高信任门槛，合规底子硬 |
| **新材料/化工** | 蓝海行业，百度几乎无投放，GEO竞争少 |
| **环保检测** | 政府/国企项目，招标前必搜供应商 |

### ⚠️ 需谨慎评估

| 特征 | 说明 |
|------|------|
| **本地生活服务** | 需先做基础信息治理，口碑一致才能发挥价值 |
| **教育/培训** | 需确认资质合规，豆包对这类内容审核严格 |
| **金融/保险** | 强监管，合规红线多，需评估资质完整性 |

### ❌ 不适合优先推GEO

| 特征 | 说明 |
|------|------|
| **客单价<500元的快消品** | 用户不会专门问AI"买什么纸巾" |
| **完全依赖熟人关系的行业** | 如部分传统手工业、社区小生意 |
| **渠道分销为主** | 客户不通过公开搜索找供应商 |
