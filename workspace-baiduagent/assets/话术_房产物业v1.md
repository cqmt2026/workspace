## 二、分业态话术

### 🏠 房产中介门店（推荐首推）

**侦察锚点**：门店位置+区域深耕+百度现状

```
"您好，请问是[门店名]吗？我是百都科技的小度，做重庆中小企业获客的。

我先看了下你们资料——你们是做[XX区]的中介对吧？
我这边在做房产中介行业的获客调研，发现一个挺关键的现象：现在客户找房子，第一反应都是百度搜'XX区二手房中介''重庆租房'，但搜出来的基本是链家贝壳这些大平台，像你们这样深耕本地的专业门店，反而几乎看不到。

冒昧问下——你们现在主要靠什么渠道接客户？线下门店自然客流、老客介绍，还是也有做线上？"
```

**SPIN深挖**：
- S（现状）："现在一个月能通过线上渠道接到几个客户？"
- P（问题）："如果客户想找房，直接在百度搜你们店名，能搜到吗？"
- I（影响）："等于客户主动找的时候，第一个看到的是竞争对手，不是你们"
- N（价值）："如果在百度上铺一层区域词，比如'XX区二手房''XX小区中介'，客户一搜就能看到你们本地专业门店，线索直接打过去"

**产品推荐**：
- 搜索推广（区域词+品牌词）——主推
- 百度地图标注——必做
- 信息流（人群包定向本区购房意向用户）——补充

**算账话术**：
```
"我不问你投多少，先帮你算笔账：你们成交一套二手房/租一套房，中介费大概多少？[等他答]
假设一单中介费3000，百度推广月投3000-5000，只要能带来1个有效客户就回本，2个就是赚。
关键是先小预算跑通——1000块先跑一周，看数据，效果好再谈长期合作。"
```

### 🏢 物业服务公司（B端蓝海）

**侦察锚点**：项目数量+服务能力+B端决策者

```
"您好，请问是[公司名]吗？我是百都科技的小度，做企业获客增长的。

我看到你们是做物业服务的，在[XX区]有项目在运营对吧？
我注意到一个现象——现在很多开发商和业委会在招标物业服务商的时候，第一件事就是百度搜'重庆物业管理公司''XX区物业服务'，验证供应商实力。但搜出来基本是品牌物业或者聚合平台，本地专业物业公司几乎没有品牌曝光。

冒昧问下——你们现在主要是靠什么渠道接项目？关系介绍、招投标，还是有做线上布局？"
```

**SPIN深挖**：
- S："你们现在主要负责多少个项目的物业管理？"
- P："甲方招标的时候，会先在百度上搜供应商名单对吧？你们在的话是不是更容易被看到？"
- I："等于甲方第一手筛选的时候，你们可能不在名单里，白白丢了机会"
- N："在百度上做一层品牌曝光，让甲方搜'重庆物业管理'就能看到你们，相当于多了一条获客渠道"

**产品推荐**：
- 搜索推广（行业词+地域词）——主打
- 品牌专区——B端信任背书（强烈推荐）
- 百家号——长期内容营销

**算账话术**：
```
"你们一个物业管理项目的年合同额大概多少？[等他答]
假设一个项目年合同50万，百度推广月投3000-5000，只要能带来一个招标机会就远超投入了。
而且物业是长期服务，一旦签下就是多年稳定收入，这个获客成本摊下来非常划算。"
```

## 三、异议处理（房产物业专属）

### 异议1："我们是中介，客户都是上门的，不需要百度"
```
"理解，门店客流确实很稳。但我想问个问题——如果客户想在百度上搜你们店的电话，能搜到吗？
很多门店的情况是：老客记得你、路过会来，但新客搜不到。等于每天都在等客上门，而没有主动获客的能力。
百度推广不是替代门店客流，是多一条路——让搜到你的人直接打你电话，比让他们去链家对比强。"
```

### 异议2："百度已经没流量了，都用抖音了"
```
"这要看客户群。抖音是刷到的，需求不强烈；百度是主动搜的，客户带着买房/租房目的来的，转化效率完全不同。
而且我们不只是百度——美团、抖音、小红书、GEO都能做。不同客户在不同平台触达，组合起来效果最好。你的客户可能既刷抖音也搜百度，两条线都占住才不漏掉。"
```

### 异议3："已经在投别的平台了，效果一般"
```
"那可能是平台选择问题。安居客、房天下收的是端口费，不管效果；抖音信息流是被动触达，转化率不稳定。
搜索是主动获客，客户自己搜到你了，说明有真实需求。你先免费做一次账户诊断，看看之前花的钱到底花在哪了、哪里漏了，然后决定要不要调整方向，不吃亏。"
```

### 异议4："太贵了，投不起"
```
"我先不问你预算，帮你算笔账：你们成交一套二手房/租一套房，中介费大概多少？
假设一单2000-3000，百度推广月投3000-5000，只要能带来1个有效客户就回本，2个就是赚。
而且不用一开始就大额——1000块先跑一周测试，看数据再说。这行不怕试，就怕不试还猜。"
```

### 异议5："我们只做本地，不需要大范围投放"
```
"这个观点对，但我建议反过来想——你们只做本地，更要在百度上把本区的搜索词占住。
比如在百度上搜'渝中区二手房''江北租房'，客户看到的应该是你们而不是别人。这个竞争没那么激烈，比去抢全国词划算得多。"
```

## 四、开场白30秒侦察清单（打电话前必看）

每通电话前，花30秒做以下侦察：

| 检查项 | 操作 | 目的 |
|--------|------|------|
| 公司是什么生意 | 搜公司名，看官网/简介 | 第一句话说出对方业务 |
| 老板是谁 | 企查查查法人/创始人 | 准备决策人称呼 |
| 百度现状 | 搜公司名，看排名/有没有广告 | 找到切入点 |
| 竞品有没有投 | 搜"行业词+重庆"，看前3 | 判断竞争烈度 |
| 一句话锚点 | 提炼客户最可能在意的1个点 | 制造好奇，不显得像推销 |
