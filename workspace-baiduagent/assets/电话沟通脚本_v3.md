# 百都科技·重庆中小企业增长顾问 电话脚本v3

> 用途：入职后直接使用
> 核心逻辑：先懂生意 → 挖痛点 → 算ROI账 → 全产品线匹配方案
> 更新：2026-08-26（扩展至重庆所有中小型企业 + 全产品线）

---

## 〇、打电话前必做侦察（30秒，决定成败）

每次拨打前，必须先查这5项：
- [ ] **公司是什么生意**（企查查：经营范围一句话看懂）
- [ ] **老板是谁/决策链**（企查查法人/创始人）
- [ ] **百度现状**（搜"公司名"看排第几、有没有广告）
- [ ] **竞品有没有投**（搜"行业词+重庆"看前3有没有同行）
- [ ] **一句话锚点**（找到客户最可能在意的1个点：新业务/竞品追着/老板露面/政策风口）

> **核心原则**：30秒侦察完，开口就有数据支撑，不像推销像顾问。

---

## 一、通用开场白（30秒内，先懂生意）

### 通用版
```
"您好，请问是XX公司吗？我是百都科技的小度，做重庆中小企业获客增长的。

打电话前我先看了下贵公司的资料——你们做的是[一句话业务]，对吧？
我这边在做[行业]的获客调研，发现一个挺关键的现象：[一句行业洞察，如'同行XX的百度曝光明显'/'最近搜这个行业的人变多了']。

想跟您简单确认下——你们现在主要靠什么渠道接客户/订单？大概耽误您2分钟，可以吗？"
```

**关键**：第一句一定先说出对方生意（证明做了功课），第二句抛行业洞察（制造好奇），第三句问获客方式（SPIN第1问），绝不直接报产品。

## 二、分行业脚本（覆盖重庆所有中小型企业）

### 🏥 1. 医疗器械/生物医药（高客单+B2B）
**侦察锚点**：医院/代理商采购决策链清晰
```
"我看到你们是做[体外诊断/手术器械/耗材]的，专精特新企业。
我注意到一个现象——重庆这边搜'重庆[产品]''[产品]厂家'，前几页基本都是外地公司和聚合平台，本地正规厂家几乎没有曝光。但医院采购、代理商找货源，第一件事就是百度搜供应商。

你们现在找客户主要靠什么？展会、代理商，还是老客户转介绍？"
```
**产品推荐**：搜索推广（主打）+ 爱采购B2B店铺（资质展示）+ 品牌专区

### 🏭 2. 机械装备/汽配（量大+供应链采购）
**侦察锚点**：技术参数词+企业资质
```
"我看到你们做[起重设备/模具/汽车零部件]的，是重庆专精特新企业。
我搜了下'重庆[产品]'，本地厂家曝光很少，反而是外地和B2B平台占前面。但下游客户找供应商，第一反应都是百度搜'[产品]+厂家'。

你们现在订单主要怎么来？老客户复购、展会，还是线上一块也有做？"
```
**产品推荐**：搜索推广（长尾关键词 精准获客）+ 爱采购（工业品采购平台）

### 🧪 3. 新材料/化工（蓝海+政策风口）
**侦察锚点**：下游客群（汽车/电子/建筑）+ 技术优势
```
"我看到你们是做[复合材料/化工新材料]的，专精特新。
重庆新材料产值6200亿，但我发现你们这个细分[具体领域]，百度上几乎没人投广告，获客基本靠老客户和展会。问题是你们的潜在客户（主机厂/建筑商/电子厂）找供应商时，第一站是百度搜'[材料]+供应商'。

你们现在线上获客有在做吗？还是主要线下？"
```
**产品推荐**：搜索推广+爱采购+信息流（触达潜在采购决策人）

### 🌿 4. 环保/检测（政府+国企项目）
**侦察锚点**：CMA资质+近中标记录
```
"我看到你们有[CMA/CNAS]资质，做[环境检测/水处理/环评]的。
环保检测这块有个特点——政府、国企招标前，甲方会先在百度上筛一轮供应商。你们现在百度上几乎没有品牌信息，等于甲方的第一手名单里没有你们。

你们主要是靠什么渠道拿下项目的？招投标信息、关系，还是有线上布局？"
```
**产品推荐**：搜索推广（行业词）+ 爱采购（资质长期展示）+ 品牌专区（信任背书）

### 🏠 5. 本地生活/到店服务（餐饮/装修/教育/医美家电等）
**侦察锚点**：客流依赖+区域关键词
```
"我看到你们做[同城装修/餐饮/教育]的，面向XX片区客户对吧？
我发现一个现象——现在用户找这类服务，很多直接在百度或百度地图搜'XX附近XX'。你们在[区域词]上的曝光怎么样？主要靠点评/地图/老客介绍，还是也想多一条获客路子？"
```
**产品推荐**：百度地图标注+搜索推广（区域词）+信息流（精准触达周边人群）

### 🏭 6. 建筑/建材/工程（项目制+B2B）
**侦察锚点**：资质+近期工程
```
"我看到你们做[建设工程/建材供应]的，有[资质]。
工程行业有个痛点——甲方找分包/供应商时，会先百度搜'XX工程公司''XX材料厂家'验证实力。你们现在百度上能搜到吗？项目主要靠关系还是也有市场化获客？"
```
**产品推荐**：搜索推广+品牌专区+爱采购

## 三、全产品线顾问式销售（不只会推搜索）

**先诊断客户需求 → 再推荐匹配产品组合**：

| 客户形态 | 主推产品 | 场景 |
|---------|---------|------|
| B2B制造/贸易 | 搜索推广+爱采购 | 客户主动搜供应商 |
| 品牌建设期 | 品牌专区+百家号 | 招投标前信任背书 |
| 本地服务/门店 | 百度地图+搜索（区域词） | 到店/到访客 |
| 大众消费 | 信息流+搜索 | 精准触达潜在人群 |
| 有官网/小程序 | 小程序+搜索联动 | 线上成交闭环 |

**产品矩阵对客户的提问**：
```
"你们现在的客户主要是主动找你们，还是被动等上门？
如果是主动找——百度搜索他们一定会用，这是'拦截式获客'。
如果是被动等——我们需要让客户'搜得到你、信任你、联系你'，这是'品牌+获客组合'。"
```

## 四、异议处理（覆盖全场景）

### 异议1："不需要百度推广"
```
"理解。冒昧问下——你们现在客户是靠什么来的？[等他答]
如果靠老客户/展会，那确实稳定。但有个问题：这套模式能保证下个月、下季度还有新客户吗？
我不是要你现在投，我想先帮你看看——在百度上搜你们行业，客户能看到几家本地供应商？如果连你们都不在上面，等客户主动找你的时候，发现竞品已经把位置占了。"
```

### 异议2："百度没人用了"
```
"分行业看。你们这个[制造业/本地服务]，客户要采购/消费时，第一步几乎都是搜索——搜'XX厂家''XX附近''XX哪家好'。抖音是刷到的，百度是搜的，需求强度完全不同。搜索来的客户，是带着明确需求的。
而且我们不只是百度——美团、抖音、小红书、GEO都能做。不同客户在不同平台触达，组合起来效果最好。"
```

### 异议3："已经在投了，效果不好"
```
"那可能是投放方式问题。你现在的账户——关键词是你们自己定的吗？落地页能承接咨询吗？有没有做数据回传？很多企业只开了户没做精细化运营，钱花出去了但没闭环。
这样，我免费帮你做一次账户诊断，看看钱到底花在哪、哪里漏了，你在决定要不要调整，不吃亏。"
```

### 异议4："太贵了"
```
"我不问你投多少，先帮你算笔账：你们现在一个客户/一单的毛利大概多少？[等他答]
如果一单毛利5万，一个月多签1单就多5万。百度推广月投3000-5000，只要能带来1个有效客户就回本，2个就是赚。
关键是先小预算跑通，数据出来了成本能控住再放大。你说呢？"
```

### 异议5："考虑一下"
```
"当然可以，这个事该慎重。我先把你们行业的百度投放数据和几个案例发您微信，您先看。
另外我建议——趁现在竞品还没把[关键词]的流量买走，先占个位置。等他们投了价格就上去了。这周我正好在附近，周三或周四下午，我过来当面给您算笔账？"
```

### 异议6："不信任你们这行"
```
"合理。我给两个东西让您验证：
1. 我们的营业执照和百度授权资质，随时可查。
2. 您可以先做个小测试——1000-3000元先跑一周，看数据，效果好再谈长期合作。这行不怕试，就怕不试还猜。"
```

## 五、行业数据卡（打电话时背）

### 医疗器械
- 重庆生物医药909家、医疗器械254家
- 单台设备产值数万~数百万，客单价高
- 医院/代理商采购前必百度搜供应商
- 中元汇吉/山外山/西山科技均为百度空白

### 新材料
- 2024产值6200亿，2027目标万亿
- 百度几乎无投放，获客成本行业最低
- 下游：汽车/电子/建筑/航天

### 机械装备
- 专精特新438家，重庆最大行业池
- B2B采购决策链清晰
- 百度搜"产品+厂家"是下游标准动作

### 环保检测
- 客户以政府/国企为主
- 招标前甲方先百度筛供应商
- CMA/CNAS资质是信任基础

### 本地生活
- 用户搜"XX附近XX"频率极高
- 百度地图+搜索是到店关键入口
- 区域词转化高、竞争相对可控

### 全渠道产品矩阵
- **美团**：本地生活/餐饮/到店服务，团购+搜索双引擎
- **抖音**：内容种草+本地生活+信息流广告，适合品牌+获客双目标
- **小红书**：种草营销+品牌曝光，适合消费品类（美妆/服饰/母婴/旅游等）
- **GEO**（生成式引擎优化）：让AI搜索（如ChatGPT/Claude等）推荐你的品牌，未来获客新赛道
