### 标准版（B2B制造业）

```
"您好，我是百都科技的小度。打电话前我先在豆包上搜了一下你们公司——

发现一个现象：搜'[产品]+重庆'，AI回答里推荐的都是外地公司或者聚合平台，咱们本地厂家几乎没有曝光。

但你们下游客户找供应商时，第一件事就是搜这个。这意味着什么？你的潜在采购商正在被AI引导去别家。

冒昧问一下——你们现在主要靠什么渠道接客户？"
```

### 简化版（本地生活服务）

"您好，我是百都科技的小度。最近我发现一个趋势——越来越多的客户在下单前会先问AI'哪家比较好''怎么选'。

我在豆包上搜了你们的行业词，发现AI推荐的前几名基本都是竞品。你们现在线上获客有在做吗？还是主要靠老客户？"

## 二、SPIN提问（GEO版）

| 阶段 | 问题 | 目的 |
|------|------|------|
| **S 现状** | "你们现在客户怎么来？百度、展会、老客户转介绍？" | 摸清当前获客方式 |

| **I 影响** | "客户找供应商第一步是AI搜索，如果推荐的都是竞品，这个机会成本多大？" | 放大痛点价值 |

## 三、异议处理速查

### 异议1："GEO是什么？没听过"

```
"GEO是生成式引擎优化——简单说就是让AI在回答用户问题时，主动推荐你的品牌。

比如客户问豆包'重庆哪里有靠谱的XX厂家'，如果AI直接推荐你家，这就是GEO的效果。

豆包已经跟抖音生活服务打通了，AI推荐位置直接能成交，这是最新的获客入口。"
```

### 异议2："我们客户不会用AI搜"

```
"分行业看。你们是做B2B的还是B2C的？

如果是B2B，采购决策链长，客户一定会做信息搜集——AI搜索现在是他们找供应商的第一站。

你们同行有没有已经在布局的？如果没有，这就是机会窗口。"
```

### 异议3："太贵了吧"

```
"GEO分三个优先级：
- 第一级信息归一化，成本几乎为零，先把基础打好
- 第二级做诊断，看看AI认不认识你
- 第三级内容铺设，根据预算决定深度

建议先做诊断，免费的。我帮你搜一下你的品牌名和品类词，看看AI怎么答你。"
```

### 异议4："我们先看看/考虑一下"

```
"当然可以，这个事该慎重。我先把你们行业的AI搜索数据发您微信，您先看。

另外我建议——趁现在竞品还没把[关键词]的流量买走，先占个位置。等他们投了价格就上去了。

这周我正好在附近，周三或周四下午，我过来当面给您算笔账？"
```

### 异议5："我们已经投了百度/抖音，还要GEO吗"

```
"三个平台不冲突，各自解决了不同的问题——

百度解决的是'知不知道'——用户搜你的品牌名能不能找到你；
抖音解决的是'感兴趣'——用户刷到你的内容会不会想了解；
GEO解决的是'选哪家'——用户问AI推荐时，AI答不答你。

这三个平台覆盖了用户决策的全链路。而且GEO目前竞争还小，现在进场正是窗口期。"
```

## 四、核心价值话术

### 一句话卖点

```
"GEO不是让你花钱买排名，而是让你的品牌在AI回答里被正面提及——相当于每次用户咨询时，都有AI在帮你做背书。"
```

### 案例数据（教育企业）

```
"我们上个月对接的一家教育企业，系统化布局GEO之后：
- 官网主动咨询转化率：3% → 11%
- 月均转化数：60多单 → 250多单

增幅不是靠加大投放，而是用户在反复向豆包提问的过程中，这家企业持续出现在推荐答案里。豆包每多推荐一次，用户离成交越近一步。"
```

### 窗口期话术

```
"GEO现在处于早期红利期，竞争还小。豆包5月才刚打通抖音生活服务，很多商家还不知道这个入口。

现在布局，相当于在AI时代的'百度搜索'红利期进场——越早占位，后期成本越低。"
```

## 五、判断客户是否适合GEO

### 核心问题（一问定生死）

```
"您的客户在购买决策前，会不会主动去搜'某某怎么选''A和B有什么区别'这些问题？"

✅ 会 → 值得认真布局GEO
❌ 不会 → 预算先放其他渠道
```

### 三类高适配度行业

| 层级 | 特征 | 行业 |
|------|------|------|
| 第一类 | 高客单价 + 长决策周期 | 机械制造、B2B软件、医疗器械、律所、留学移民 |
| 第二类 | 强监管 + 高信任门槛 | 金融理财、医疗机构、正规教育、保险经纪 |
| 第三类 | 本地生活服务 | 餐厅、家政、美甲、汽修、口腔、摄影 |

## 七、GEO三级落地路径（给客户讲清楚）

```
第一级：信息归一化（成本≈0）
├── 地图/点评/抖音/公众号信息统一
├── 店名、地址、电话、营业时间100%一致
└── 这是地基，不做这一步后面都是空的

第二级：做诊断再投入（成本=0）
├── 在豆包/DeepSeek/Kimi搜索品牌名+品类词
├── 看AI是否提到你、是否推荐
└── 了解自己在AI生态里的真实位置

第三级：内容铺设 + 持续监测（成本=根据预算）
├── 用Schema生成器给官网加结构化标记
├── 发布高质量专业内容
└── 每月监测AI推荐变化，持续优化
```
