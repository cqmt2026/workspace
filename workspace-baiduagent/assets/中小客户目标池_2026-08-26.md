# 百都科技·重庆中小客户目标池（2026年8月更新）

> 核心定位：**中小客户为主力战场**（预算3000~20000元/月，老板直接决策）
> 非核心：**低空经济暂不作为主线板块**（按主人指示调整）
> 数据来源：专精特新2275家 + 主城区创新型509家 + 行业细分名单

---

## 📊 一、客户分层标准（百度代理商体系）

### 分层逻辑

```
KA客户（一次性充值≥100万）→ 不是我们的主战场
  └── 百度直客或五星级代理商服务
  └── 我们绕开，除非客户主动询价

中小客户（充值<100万）→ 核心战场
  ├── A类（重点）：月耗≥5000，年框≥5万，有决策权，有转化预期
  ├── B类（中等）：月耗1000~5000，有预算需培养，决策快
  └── C类（长尾）：月耗<1000，试水心态，流失率高 → 不优先
```

### 中小企业识别画像

| 维度 | 理想特征 | 筛选动作 |
|------|---------|---------|
| 规模 | 专精特新/创新型中小企业 | 名单中直接锁定 |
| 决策人 | 老板/创始人/总经理直接拍板 | 优先找有公开联系电话的 |
| 百度现状 | 百度几乎无广告或排名靠后 | 搜索验证 |
| 行业 | B2B属性强、采购决策链清晰 | 机械/材料/医疗/环保优先 |
| 预算意识 | 有营销预算或可说服 | 专精特新企业普遍有政府补贴 |
| 地域 | 主城区优先（易拜访） | 按区县分布排序 |

## 🎯 二、行业优先级矩阵

### 评分标准
- **百度竞争度**：投放企业越少越好（蓝海=机会）
- **B2B转化效率**：采购决策越清晰越好
- **预算能力**：专精特新/创新型企业普遍有政府补贴，预算有保障
- **地域密度**：主城区企业优先（拜访方便）
