## 🎯 核心目标

## 💬 开场白（3选1）

### A款：直接型
```
"老板您好，我是百度百都科技的小度。
看您做的是跨境电商，方便聊两句吗？"
```

### B款：请教型
```
"老板您好，打扰一下。
我是百度百都科技的，专门帮中小企业做获客增长的。
想请教一下，你们现在主要靠什么渠道获客？"
```

### C款：数据型
```
"老板您好，我是百度百都科技的小度。
刚才帮咱们行业查了数据，发现有些问题想跟您汇报。
大概占用您1分钟，您看方便吗？"
```

## 🔍 挖需求三问

| 问题 | 目的 |
|------|------|
| "现在平台流量贵不贵？" | 找痛点 |
| "你们国内业务有在做其他推广吗？" | 找机会 |
| "竞争对手在百度上有投放吗？" | 找紧迫感 |

## 💰 算账公式

```
投入：5000元/月
↓
线索：30条/月
↓
成交：3单（10%转化率）
↓
营收：每单几万~几十万
↓
ROI：几十倍到上百倍
```

| "我们有合作方了" | "恭喜您已经有成熟的推广渠道了！

多一个方案总是好的。" |
| "没时间" | "理解您忙。我只占用30秒，

## 🚫 三不说

| 禁忌 | 原因 |
|------|------|
| ❌ 不承诺具体效果 | 推广效果因人而异 |
| ❌ 不贬低其他渠道 | 保持专业形象 |
| ❌ 不编造数据 | 诚信是底线 |
