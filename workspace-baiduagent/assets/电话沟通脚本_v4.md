## 〇、打电话前必做侦察（30秒，决定成败）

每次拨打前，必须先查这5项：
- [ ] **公司是什么生意**（企查查：经营范围一句话看懂）
- [ ] **老板是谁/决策链**（企查查法人/创始人）
- [ ] **百度现状**（搜“公司名”看排第几、有没有广告）
- [ ] **竞品有没有投**（搜“行业词+重庆”看前3有没有同行）
- [ ] **一句话锚点**（找到客户最可能在意的1个点：新业务/竞品追着/老板露面/政策风口）
- [ ] **行业洞察自动生成**（可选，借鉴OpenOutreach零名单外联理念）

> **核心原则**：30秒侦察完，开口就有数据支撑，不像推销像顾问。

## 一、通用开场白（30秒内，先懂生意）

### 通用版
```
"您好，请问是XX公司吗？我是百都科技的小度，做重庆中小企业获客增长的。

打电话前我先看了下贵公司的资料——你们做的是[一句话业务]，对吧？
我这边在做[行业]的获客调研，发现一个挺关键的现象：[一句行业洞察，如'同行XX的百度曝光明显'/'最近搜这个行业的人变多了']。

想跟您简单确认下——你们现在主要靠什么渠道接客户/订单？大概耽误您2分钟，可以吗？"
```

**关键**：第一句一定先说出对方生意（证明做了功课），第二句抛行业洞察（制造好奇），第三句问获客方式（SPIN第1问），绝不直接报产品。

## 二、SPIN+BANT双轮驱动（核心引擎）

### 第一轮：SPIN挖需求（先听再说）

| 阶段 | 问题 | 目的 |
|------|------|------|
| **S 现状** | "你们现在怎么获客？主要靠老客户/展会/网络？" | 摸清当前获客方式 |
| **P 问题** | "这种方式有什么困扰？比如客户来源不稳定？" | 找痛点 |
| **I 影响** | "这个困扰带来什么损失？比如错过一个客户亏多少？" | 放大痛点价值 |
| **N 价值** | "如果能解决，能带来多大收益？" | 让客户自己说出需求 |

### 第二轮：BANT量化评估（边聊边打分）

在对话过程中，同步评估BANT四维（每维0-3分，满分12分）：

| 维度 | 高分信号（2-3分） | 低分信号（0-1分） | 对应问法 |
|------|-------------------|-------------------|---------|
| **B 预算** | 明确说出预算范围/提到"可以考虑投入"/对比过价格 | 说"太贵了"/没提过钱/只关注免费方案 | "您目前获客这块大概什么预算？" |
| **A 权限** | 对方是老板/法人/可以直接拍板 | 对方说"要问老板"/"我们商量一下" | "这件事您能直接定吗？还是需要跟谁确认？" |
| **N 需求** | 主动承认有获客痛点/表达强烈改变意愿 | 说"还行"/"暂时没感觉"/"没考虑过" | 通过SPIN判断需求强度 |
| **T 时间表** | 说"最近就要"/"马上就需要"/"月底前" | 说"再看看"/"以后再说"/"不急" | "您计划什么时候开始？" |

### 打分决策树

```
总分 ≥ 9分（BANT≥3/4 且 综合≥8）→ 🔥 HOT LEAD
  → 当天约上门拜访，当面算账
  → 微信发完整方案，当天跟进

总分 6-8分 → 🟡 WARM LEAD
  → 加微信发资料，3天内二次跟进
  → 记录具体卡点，针对性突破

总分 ≤ 5分 → 🟢 COLD LEAD
  → 纳入培育池，每2周触达一次
  → 等待需求时机（行业变化/政策风口）
```

## 三、分行业脚本（覆盖重庆所有中小型企业）

### 🏥 1. 医疗器械/生物医药（高客单+B2B）
**侦察锚点**：医院/代理商采购决策链清晰
```
"我看到你们是做[体外诊断/手术器械/耗材]的，专精特新企业。
我注意到一个现象——重庆这边搜'重庆[产品]''[产品]厂家'，前几页基本都是外地公司和聚合平台，本地正规厂家几乎没有曝光。但医院采购、代理商找货源，第一件事就是百度搜供应商。

你们现在找客户主要靠什么？展会、代理商，还是老客户转介绍？"
```
**BANT追问**：
- "你们这次采购/找供应商，大概什么预算范围？"（B）
- "是您这边直接定，还是需要走审批？"（A）
- "现在找供应商最大的难点是什么？"（N）
- "计划什么时候确定供应商？"（T）

**产品推荐**：搜索推广（主打）+ 爱采购B2B店铺（资质展示）+ 品牌专区

### 🏭 2. 机械装备/汽配（量大+供应链采购）
**侦察锚点**：技术参数词+企业资质
```
"我看到你们做[起重设备/模具/汽车零部件]的，是重庆专精特新企业。
我搜了下'重庆[产品]'，本地厂家曝光很少，反而是外地和B2B平台占前面。但下游客户找供应商，第一反应都是百度搜'[产品]+厂家'。

你们现在订单主要怎么来？老客户复购、展会，还是线上一块也有做？"
```
**BANT追问**：
- "如果线上能带来新客户，您这边大概能接受什么预算范围？"（B）
- "推广这事是您自己定还是跟团队商量？"（A）
- "现在获客渠道里，您觉得最不满意的是哪块？"（N）
- "如果效果好，您打算什么时候开始试？"（T）

**产品推荐**：搜索推广（长尾关键词精准获客）+ 爱采购（工业品采购平台）

### 🧪 3. 新材料/化工（蓝海+政策风口）
**侦察锚点**：下游客群（汽车/电子/建筑）+ 技术优势
```
"我看到你们是做[复合材料/化工新材料]的，专精特新。
重庆新材料产值6200亿，但我发现你们这个细分[具体领域]，百度上几乎没人投广告，获客基本靠老客户和展会。问题是你们的潜在客户（主机厂/建筑商/电子厂）找供应商时，第一站是百度搜'[材料]+供应商'。

你们现在线上获客有在做吗？还是主要线下？"
```
**BANT追问**：
- "如果百度能帮您触达主机厂/建筑商，您这边预算大概在什么量级？"（B）
- "这个决策是您拍板还是需要跟股东/合伙人确认？"（A）
- "现在获客最头疼的是什么？新客户开发难？老客复购率下降？"（N）
- "想什么时候看到效果？"（T）

**产品推荐**：搜索推广+爱采购+信息流（触达潜在采购决策人）

### 🌿 4. 环保/检测（政府+国企项目）
**侦察锚点**：CMA资质+近中标记录
```
"我看到你们有[CMA/CNAS]资质，做[环境检测/水处理/环评]的。
环保检测这块有个特点——政府、国企招标前，甲方会先在百度上筛一轮供应商。你们现在百度上几乎没有品牌信息，等于甲方的第一手名单里没有你们。

你们主要是靠什么渠道拿下项目的？招投标信息、关系，还是有线上布局？"
```
**BANT追问**：
- "一个项目中标的话，金额大概什么量级？"（B）
- "投标前需要做品牌曝光，这事是您来决定还是公司统一规划？"（A）
- "现在丢标的主要原因是什么？没知名度？价格没优势？"（N）
- "下次招投标大概什么时候？需要提前多久布局？"（T）

**产品推荐**：搜索推广（行业词）+ 爱采购（资质长期展示）+ 品牌专区（信任背书）

### 🏠 5. 本地生活/到店服务（餐饮/装修/教育/医美家电等）
**侦察锚点**：客流依赖+区域关键词
```
"我看到你们做[同城装修/餐饮/教育]的，面向XX片区客户对吧？
我发现一个现象——现在用户找这类服务，很多直接在百度或百度地图搜'XX附近XX'。你们在[区域词]上的曝光怎么样？主要靠点评/地图/老客介绍，还是也想多一条获客路子？"
```
**BANT追问**：
- "一个到店客户的平均消费是多少？"（B）
- "推广预算这块您能直接定吗？"（A）
- "现在客流最大问题是什么？新客少？季节性明显？"（N）
- "想什么时候开始？"（T）

**产品推荐**：百度地图标注+搜索推广（区域词）+信息流（精准触达周边人群）

### 🏭 6. 建筑/建材/工程（项目制+B2B）
**侦察锚点**：资质+近期工程
```
"我看到你们做[建设工程/建材供应]的，有[资质]。
工程行业有个痛点——甲方找分包/供应商时，会先百度搜'XX工程公司''XX材料厂家'验证实力。你们现在百度上能搜到吗？项目主要靠关系还是也有市场化获客？"
```
**BANT追问**：
- "一个工程项目一般什么量级？"（B）
- "推广投放这事您能自己决定吗？"（A）
- "现在拿项目最大的瓶颈是什么？"（N）
- "接下来有没有新项目要投？"（T）

**产品推荐**：搜索推广+品牌专区+爱采购

### 🔥 7. 【美团医疗】民营医院 & 体检中心（重点突破口）

> ⚠️ **产品线隔离**：本章节仅适用于美团医疗产品线，与百度推广/抖音/小红书等产品线完全独立

#### 侦察准备（打电话前必做）

**查百度**：搜 `"[医院名]+重庆"` 和 `"重庆+口腔/医美/体检"`
- 你们的医院在不在？排第几？
- 同行都在不在？谁在前面？
- 有没有广告位（标"广告"的）？

**查美团**：打开美团APP或大众点评，搜对方医院名字
- ✅ 有没有上线？（没上线 = 空白市场，机会最大）
- ✅ 装修怎么样？（照片/视频/医生信息/品牌介绍）
- ✅ 团单有多少？价格怎么定？
- ✅ 有多少评价？星级多少？好评率多少？
- ✅ 有没有开通推广通？排名在哪？

#### 开场白（版本A：完全没上线）
```
"王院长您好，我是百都科技小度，专门帮重庆的民营医院做线上获客增长。

打电话前我先在美团上搜了一下你们医院——说实话有点意外，你们在美团上目前没有上线，但你们附近的XX医院、XX医院都已经上线了，而且经营评分都是金牌甚至英雄商家。

冒昧问一下——你们现在病人主要怎么来？老客户介绍、地推活动，还是线上平台也有在做？"
```

#### 开场白（版本B：已有上线但经营不好）
```
"李院长您好，我是百都科技小度。今天打电话是因为我注意到你们在美团上有店铺，但我看了一下——整体信息还不够完整：医生介绍少了几个，相册也没有上传，还缺几个核心项目。

我注意到你们附近3公里内，有X家同行的医院已经在美团上线了，而且经营评分都是金牌甚至英雄商家，评分比我查到的你们还高出不少。

想问一下——你们现在主要靠什么渠道获客？线上这块有专门负责的人吗？"
```

#### SPIN提问
**S — 现状**
```
"你们现在病人主要怎么来？线上平台占多少比例？"
"美团上有开店吗？大概多少团单在线？"
"现在有多少条评价？多少好评？"
```

**P — 问题**
```
"你们有没有发现——用户搜'XX科医院+重庆'，前几条里面好像没有你们？"
"现在病人到院之前一般要查什么？美团/点评/百度都会看对吧？如果他们在美团搜你的医院，能看到什么？"
"你们现在的评价管理有人专门盯着吗？"
```

**I — 影响**
```
"我查了一下，你们这片区有X家同行已经在美团上线了。这意味着每天搜'XX科+重庆'的患者，看到的都是他们，不是你们。

按你们门诊量估算——一个患者平均消费XXXX元，一个月如果因为线上曝光不足少来50个患者，这个损失大概是多少？"
```

**N — 价值**
```
"如果咱们能把美团上的信息补齐、团单设计好、评价管理起来，再配合推广通精准投放——一个月多10个到院患者，按您刚才说的客单价，这能带来多少增量收入？"

"而且美团有个特点——经营越好，广告越便宜，效果越好。这是一个正循环。"
```

#### 民营医院科室切入话术（以口腔科为例）

"我注意到你们医院的口腔科实力挺强的，有XX位专家，但美团上连口腔科的入口都没有。

现在患者看牙，尤其是洗牙、矫正、种植牙这些项目，第一步都是上美团搜'重庆洗牙''重庆口腔'，然后看评分、看价格、看评价再决定去哪家。

你们技术这么好，却在美团上找不到，相当于白白损失了大量主动找上门的患者。

我建议先从口腔科做起——先上商户通把基础信息、医生团队、团购项目配齐，再配合推广通精准投放。"
```

#### 美团医疗异议处理

**异议1："我们没有美团，不知道怎么弄"**
```
"完全理解，很多医院都这样。其实很简单——我们有个产品叫'商户通'，就是专门帮医院在美团上开店、装修、上架团单的。

一年就1499元（标准版），包含门店装修、医生团队展示、团单管理、预约功能，还有经营数据分析。等于给医院建了一个24小时线上前台。"
```

**异议2："太贵了"**
```
"商户通一年1499元，平均每天4块钱——不到一瓶水的钱。

但一年能给您的医院带来什么？
第一，在美团/点评上有一个完整的线上店铺，病人搜就能找到；
第二，能上架团购项目，比如体检套餐、专项检查，直接产生交易；
第三，有预约功能和在线咨询，病人可以先问再决定。

您算一下——来一个患者平均消费多少？只要一年内多带来两个通过美团来的患者，这就赚回来了。"
```

**异议3："百度/抖音我们已经投了，还要美团吗？"**
```
"三个平台不冲突，各自解决了不同的问题——

百度解决的是'知不知道'——用户搜你的医院名能不能找到你；
抖音解决的是'感兴趣'——用户刷到你的内容会不会想了解；
美团解决的是'去哪家'——用户已经决定要来医院了，在美团上选哪家。

这三个平台覆盖了用户决策的全链路。而且美团上用户是带着明确就医意图来的，搜索'重庆XX科医院'，需求强度非常高，转化率天然就高。"
```

**异议4："已经在投了，效果一般"**
```

## 五、异议处理（覆盖全场景）

### 异议1："不需要百度推广"
```
"理解。冒昧问下——你们现在客户是靠什么来的？[等他答]
如果靠老客户/展会，那确实稳定。但有个问题：这套模式能保证下个月、下季度还有新客户吗？
我不是要你现在投，我想先帮你看看——在百度上搜你们行业，客户能看到几家本地供应商？如果连你们都不在上面，等客户主动找你的时候，发现竞品已经把位置占了。"
```
**BANT辅助判断**：如果客户说"不需要"但没给出具体理由 → Cold Lead，记录原因后进入培育池。

### 异议2："百度没人用了"
```
"分行业看。你们这个[制造业/本地服务]，客户要采购/消费时，第一步几乎都是搜索——搜'XX厂家''XX附近''XX哪家好'。抖音是刷到的，百度是搜的，需求强度完全不同。搜索来的客户，是带着明确需求的。
而且我们不只是百度——美团、抖音、小红书、GEO都能做。不同客户在不同平台触达，组合起来效果最好。"
```

### 异议3："已经在投了，效果不好"
```
"那可能是投放方式问题。你现在的账户——关键词是你们自己定的吗？落地页能承接咨询吗？有没有做数据回传？很多企业只开了户没做精细化运营，钱花出去了但没闭环。
这样，我免费帮你做一次账户诊断，看看钱到底花在哪、哪里漏了，你在决定要不要调整，不吃亏。"
```
**BANT辅助**：客户已经在投 → B=高（有预算意识），N=已验证需求 → Warm/Hot Lead

### 异议4："太贵了"
```
"我不问你投多少，先帮你算笔账：你们现在一个客户/一单的毛利大概多少？[等他答]
如果一单毛利5万，一个月多签1单就多5万。百度推广月投3000-5000，只要能带来1个有效客户就回本，2个就是赚。
关键是先小预算跑通，数据出来了成本能控住再放大。你说呢？"
```
**BANT辅助**：说贵但没挂电话 → A=有意向，B=需确认量级 → 继续算账

### 异议5："考虑一下"
```
"当然可以，这个事该慎重。我先把你们行业的百度投放数据和几个案例发您微信，您先看。
另外我建议——趁现在竞品还没把[关键词]的流量买走，先占个位置。等他们投了价格就上去了。这周我正好在附近，周三或周四下午，我过来当面给您算笔账？"
```
**BANT辅助**："考虑一下"通常是A（权限）或T（时间）未确认 → 锁定具体决策人和时间

### 异议6："不信任你们这行"
```
"合理。我给两个东西让您验证：
1. 我们的营业执照和百度授权资质，随时可查。
2. 您可以先做个小测试——1000-3000元先跑一周，看数据，效果好再谈长期合作。这行不怕试，就怕不试还猜。"
```
