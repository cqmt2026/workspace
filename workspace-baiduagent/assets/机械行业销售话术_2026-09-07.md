## 一、机械行业特征分析

### 1.1 行业数据
| 指标 | 数值 | 来源 |
|------|------|------|
| 重庆机械企业 | 801家（百度POI+高德+专精特新） | 多渠道数据合并 |
| 百度投放竞争 | **几乎为零** | 实测验证 |
| 客户采购决策链 | 长（技术→采购→老板） | B2B特性 |
| 客单价 | 数万~数百万元 | 行业调研 |
| 决策周期 | 2-4周 | B2B特性 |

### 1.2 核心痛点
1. **获客渠道单一**：依赖老客户介绍+展会，新客户来源不稳定
2. **品牌曝光不足**：百度搜"重庆机械XX"，前3页看不到自家企业
3. **竞品已布局**：部分头部企业已投百度，抢占搜索流量
4. **采购决策链长**：技术/采购/老板多重决策，需要长期培育
5. **线上获客意识弱**：老板认为"老客户够用"，对百度认知不足

### 1.3 决策人画像
| 角色 | 关注点 | 话术重点 |
|------|--------|---------|
| **老板** | 投入产出、订单增长 | ROI算账、竞品对比 |
| **技术负责人** | 产品实力、技术方案 | 专业背书、案例展示 |
| **采购负责人** | 供应商信息、比价 | 资质认证、价格透明 |

## 二、机械行业通用话术

### 2.1 开场白（30秒）

**标准版**：
```
"您好，请问是XX公司吗？我是百都科技的小度，做重庆中小企业获客增长的。

打电话前我先看了下贵公司的资料——你们做的是[机械类型，如'数控机床/五金工具/包装设备']对吧？
我这边正在做重庆机械行业的获客调研，发现一个挺关键的现象：现在下游客户找供应商，第一站就是百度搜'重庆XX机械/重庆XX设备厂家'。

但我在百度上搜了几轮，像你们这种有技术实力的本地厂家，基本排不到前面。等于客户一搜，先看到的是外地竞品或者聚合平台。

想跟您简单确认下——你们现在主要靠什么渠道接订单？老客户介绍、展会，还是有在线上布局？大概耽误您2分钟，可以吗？"
```

**精简版**（时间紧时）：
```
"您好，我是百都科技小度。我们在做重庆机械企业的百度获客调研，
发现你们在'重庆XX机械'搜索上几乎没有品牌曝光，
等于把线上客户让给了外地竞品。
想了解一下你们现在的获客渠道，方便简单聊2分钟吗？"
```

### 2.2 SPIN提问（挖需求）

**S 现状**：
```
"你们现在主要靠什么渠道接订单？老客户介绍多还是新客多？"
"最近半年新客户的来源主要是哪些渠道？"
```

**P 问题**：
```
"老客户介绍虽然稳定，但新客来源是不是不太可控？"
"有没有遇到过这种情况——客户明明在百度搜过你们，但搜不到，直接找了竞品？"
```

**I 影响**：
```
"如果客户在百度搜不到你们，这个损失大概有多大？
比如一个设备订单，少则几万多则几百万，错过一个就多可惜。"
"现在下游客户越来越习惯线上找供应商，你们如果在线上不存在，等于主动放弃这块市场。"
```

**N 价值**：
```
"如果能在百度上建立品牌曝光，让下游客户一搜就能看到你们，
这对你们的订单增长会有多大帮助？"
"你们的产品技术实力很强，如果在百度上也能排前面，
是不是能接触到更多新客户？"
```

### 2.3 BANT评估（边聊边打分）

| 维度 | 问法 | 高分信号 |
|------|------|---------|
| **B 预算** | "你们目前获客这块大概什么预算？" | 明确说预算/对比价格/愿意测试 |
| **A 权限** | "这件事您能直接定吗？" | 老板/法人/直接拍板 |
| **N 需求** | 通过SPIN判断 | 承认痛点/表达改变意愿 |
| **T 时间表** | "您计划什么时候开始？" | 最近就启动/月底前 |

## 三、机械行业异议处理

### 3.1 常见异议及应对

| 异议 | 应对话术 |
|------|---------|
| **"我们主要靠老客户"** | "老客户稳定是好事，但新客户来源是否不太可控？百度可以帮您开拓新客户渠道，老客户维护+新客拓展双管齐下。" |
| **"太贵了"** | "一个设备订单少则几万，多则几百万。投3000元测试一个月，如果能带来一个客户就回本了。您算过这笔账吗？" |
| **"没效果/投过没用"** | "可能是投放方式或关键词选择的问题。我们提供免费账户诊断，帮您找出问题所在，优化后再投。" |
| **"考虑一下"** | "理解。我加您微信，把方案发您看看。下周我再来跟进，您有结果告诉我一声。" |
| **"已经在投了"** | "恭喜您，说明您已经认可百度的价值！我们可以帮您看看现有投放效果，优化关键词和出价，进一步提升ROI。" |
| **"不需要百度"** | "理解。不过我建议您至少做个官网认证（3000元/年），客户搜你们公司名时能看到官方认证，提升信任感。" |
| **"我们要汇报"** | "完全理解。我加您微信，把详细方案和技术资料发您，您内部沟通完告诉我结果，我随时配合答疑。" |

### 3.2 促单话术

**小步快跑版**：
```
"王总，我建议您先小预算测试一个月。
3000-5000元试水，看看实际效果和线索质量。
效果好再加大投入，效果好再谈长期合作。
这行不怕试，就怕不试还猜。"
```

**竞品倒逼版**：
```
"我注意到你们同行[竞品公司名]已经在百度投放了，
他们在'重庆XX机械'这个词上排前面。
如果你们不跟进，客户一搜就先到竞品那里去了。
先占位，再谈性价比。"
```

**ROI算账版**：
```
"王总，我帮您算笔账：
一个设备订单平均客单价[X]万，毛利率[Y]%，
毛利润就是[X×Y%]万。
百度推广一个月测试预算5000元，
如果能带来1个有效客户，就回本了。
如果能带来2-3个客户，ROI就是200%-600%。
您觉得这个账划算吗？"
```

## 五、机械行业案例参考

### 5.1 成功案例（虚构示例，用于话术演示）

**案例1：重庆XX机械设备有限公司**
- **背景**：做数控机床，老客户为主，新客户来源不稳定
- **方案**：百度搜索推广（搜索词：重庆数控机床、数控加工中心、重庆机床厂家）
- **效果**：3个月带来15个有效询盘，成交3台设备，回本3倍

**案例2：重庆XX五金工具有限公司**
- **背景**：做五金工具批发，线下渠道稳定但线上空白
- **方案**：爱采购B2B平台 + 百度搜索推广
- **效果**：年费9980元，带来40+条有效商机，成交8单，ROI 400%

**案例3：重庆XX包装设备有限公司**
- **背景**：做包装机设备，百度搜不到自己，竞品排前面
- **方案**：百度搜索推广 + 品牌专区
- **效果**：品牌词排名第一位，搜索曝光提升300%，询盘量翻倍
