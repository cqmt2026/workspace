## 二、分场景ROI测算

### 场景A：保守估计（测试期）
```
月预算：5000元
──────────────────────────────────────

营收：3 × 6000元 = 18000元
```

## 三、分培训方向ROI测算

### 3.1 退役军人定向培训
```
月预算：8000元
──────────────────────────────────────
CPC：5元（蓝海词）
点击量：8000 ÷ 5 = 1600次
咨询量：1600 × 5% = 80个
报名量：80 × 10% = 8人
营收：8 × 5000元 = 40000元
（政府补贴另计，学员实付低但政府买单）
获客成本：8000 ÷ 8 = 1000元/人
ROI：40000 ÷ 8000 = 5倍

政策加成：
- 政府补贴3000-5000元/人
- 如纳入承训机构，可获得稳定生源
- 长期价值：口碑+转介绍
```

### 3.2 央国企就业辅导
```
月预算：12000元
──────────────────────────────────────
CPC：12元（中等竞争）
点击量：12000 ÷ 12 = 1000次
咨询量：1000 × 5% = 50个
报名量：50 × 10% = 5人
营收：5 × 10000元 = 50000元
获客成本：12000 ÷ 5 = 2400元/人
ROI：50000 ÷ 12000 = 4.2倍

风险提示：
- 竞争激烈（中公/华图/高顿）
- 需差异化定位（如重庆本地化）
- 高客单价，转化周期长
```

### 3.3 辅警培训
```
月预算：6000元
──────────────────────────────────────
CPC：8元（中等竞争）
点击量：6000 ÷ 8 = 750次
咨询量：750 × 5% = 37个
报名量：37 × 10% = 4人
营收：4 × 3000元 = 12000元
获客成本：6000 ÷ 4 = 1500元/人
ROI：12000 ÷ 6000 = 2倍

机会点：
- 重庆年招聘80-100人（市级）+ 区县50-60人/次
- 竞争中等，可差异化切入
- 培训周期短，转化快
```

## 八、决策建议

### 8.1 建议方案
```
第一阶段（第1个月）：
- 预算：5000元/月
- 重点：退役军人培训（蓝海词）
- 目标：验证ROI，收集数据

第二阶段（第2-3个月）：
- 预算：10000元/月
- 重点：扩展辅警培训
- 目标：优化转化，提升ROI

第三阶段（第4-6个月）：
- 预算：20000元/月
- 重点：全面投放+GEO优化
- 目标：规模化获客，品牌建立
```

### 8.2 止损线
```
如连续2个月ROI < 2倍：
1. 暂停央国企培训投放
2. 优化关键词和创意
3. 如仍不达标，考虑退出

如ROI > 4倍且稳定：
1. 逐步增加预算
2. 扩展关键词覆盖
3. 考虑品牌广告
```
