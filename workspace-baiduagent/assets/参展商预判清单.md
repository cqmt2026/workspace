# 跨交会目标参展商预判清单

> 生成时间：2026-09-15
> 用途：现场陌拜参考

---

## 🎯 优先接触类型

### 第一梯队：跨境工厂（最高价值）

**特征：**
- ✅ 有自有品牌或工厂
- ✅ 展位面积≥12㎡
- ✅ 创始人/股东亲自参展
- ✅ 产品有差异化

**如何识别：**
```
□ 展位有"工厂直销"字样
□ 展位有产品认证证书展示
□ 讲解人员对产品细节熟悉
□ 主动展示生产线/研发实力
```

**话术重点：**
```
"老板您好，我是百度百都科技的小度。
看您做的是跨境工厂，想请教一下，
你们现在主要靠哪个平台？有没有觉得平台流量越来越贵？
我们有个客户，做类似的，通过百度直接获客，
效果还不错，加个微信我发您看看？"
```

---

### 第二梯队：跨境电商卖家

**特征：**
- ✅ 已在亚马逊/阿里国际站开店
- ✅ 有年营收1000万+规模
- ✅ 寻求多渠道布局

**如何识别：**
```
□ 展位展示多个平台Logo
□ 有"代运营""孵化"等服务
□ 提供数据分析工具
```

**话术重点：**
```
"老板您好，我是百度百都科技的小度。
看您在做跨境电商，想了解一下，
你们现在多平台布局了吗？
我们帮很多卖家通过百度搜索直接获客，
不用通过平台，客户是您的私域流量。
加个微信，我发几个案例给您参考？"
```

---

### 第三梯队：供应链服务商

**特征：**
- ✅ 物流/仓储/支付/ERP服务
- ✅ 希望拓展重庆本地客户
- ✅ 有预算做推广

**如何识别：**
```
□ 展位有"海外仓""物流"字样
□ 提供一站式解决方案
□ 有成功案例展示
```

**话术重点：**
```
"老板您好，我是百度百都科技的小度。
看您做的是跨境供应链服务，
想请教一下，你们主要服务哪些类型的客户？
我们有个资源，可以帮您在百度上建立曝光，
让有需求的工厂主动找到您。
加个微信，我发您看看我们的方案？"
```

## 📋 快速筛选标准

### 值得深入交流（标记⭐）

| 序号 | 特征 | 权重 |
|------|------|------|
| 1 | 创始人/老板亲自讲解 | ⭐⭐⭐ |
| 2 | 展位面积≥12㎡ | ⭐⭐ |
| 3 | 有产品认证/专利展示 | ⭐⭐ |
| 4 | 主动询问合作 | ⭐⭐⭐ |
| 5 | 年营收预估1000万+ | ⭐⭐ |

### 快速过滤（标记✗）

| 序号 | 特征 | 原因 |
|------|------|------|
| 1 | 纯贸易公司无产品 | 预算有限 |
| 2 | 展位<6㎡ | 规模小 |
| 3 | 个人兼职卖家 | 非目标客户 |
| 4 | 明显敷衍态度 | 浪费时间的 |

## ⚠️ 注意事项

### 形象管理
- [ ] 名片整洁，数量充足
- [ ] 着装得体（商务休闲即可）
- [ ] 手机充满电，带充电宝
- [ ] 舒适鞋子（全天站立）

### 沟通技巧
- ✅ 先问后说，了解需求再推荐
- ✅ 多听少说，让客户表达
- ✅ 不急于成交，先建关系
- ✅ 加微信是首要目标
- ❌ 不要强行推销
- ❌ 不要贬低竞争对手
- ❌ 不要承诺具体效果

### 风险控制
- 每天目标不要定太高（ realistic）
- 被拒绝是常态，不要纠结
- 保持微笑和专业
- 及时补水休息
