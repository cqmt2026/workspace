## 四、去重机制（防止重复入库）

### 去重键（三层）
1. **企业名**（主键）— 去除同名不同源
2. **电话**（次键）— 同一电话多平台
3. **地址+行业**（辅助）— 同名不同地址

### 入库流程
```
新抓取数据 → 比对CRM已有 name+phone
  ├─ 存在 → 跳过（避免重复）
  ├─ 电话缺失但name存在 → 补电话（update）
  └─ 都不存在 → 新增入库（insert）
```

### 唯一标准
- **master/ = 最终标准**（已去重合并）
- **source/ = 原始备份**（各源原始抓取）
- **temp/ = 临时处理中**
