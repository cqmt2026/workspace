## 二、30秒侦察清单

拨打前必须完成以下5项：

| 序号 | 动作 | 工具 | 输出 |
|------|------|------|------|
| 1 | 企查查看经营范围 | 企查查APP | 一句话业务描述 |
| 2 | 百度搜公司名 | 百度搜索 | 排名截图 |
| 3 | 豆包搜品牌+品类词 | 豆包APP | AI可见度判断 |
| 4 | 搜竞品是否投放 | 百度搜索 | 竞品清单 |
| 5 | 找锚点 | 综合判断 | 一句话切入点 |

**侦察示例**：

```
客户：重庆互久机械制造有限责任公司
行业：机械装备汽配
电话：13883458414

【企查查】
经营范围：机械设备制造、销售；汽车零部件生产...
一句话：做机械制造和汽车零部件的

【百度】
搜"重庆互久机械"
结果：第5页，无明显广告

【豆包】
搜"重庆机械制造厂家"
结果：AI推荐了3家公司，没有互久机械

【竞品】
搜"机械+重庆"
前3名：外地公司+聚合平台

【锚点】
"豆包搜你们行业词，AI推荐的都是外地公司，本地几乎没有曝光"
```

## 三、开场白（GEO版）

### P0类 - 机械/医疗/新材料/环保

```
"您好，我是百都科技的小度。打电话前我先在豆包上搜了一下你们公司——

发现一个现象：搜'[产品]+重庆'，AI回答里推荐的都是外地公司或者聚合平台，咱们本地厂家几乎没有曝光。

但你们下游客户找供应商时，第一件事就是搜这个。这意味着什么？你的潜在采购商正在被AI引导去别家。

冒昧问一下——你们现在主要靠什么渠道接客户？"
```

### P1类 - 口腔/医美/教培/宠物

```
"您好，我是百都科技的小度。最近我发现一个趋势——越来越多的客户在下单前会先问AI'哪家比较好''怎么选'。

我在豆包上搜了你们的行业词，发现AI推荐的前几名基本都是竞品。你们现在线上获客有在做吗？还是主要靠老客户？"
```

## 四、SPIN提问（GEO版）

| 阶段 | 问题 | 目的 |
|------|------|------|
| **S 现状** | "你们现在客户怎么来？百度、展会、老客户转介绍？" | 摸清当前获客方式 |
| **P 问题** | "有没有发现——搜你们行业词，AI回答里没你们？" | 制造焦虑感 |
| **I 影响** | "客户找供应商第一步是AI搜索，如果推荐的都是竞品，这个机会成本多大？" | 放大痛点价值 |
| **N 价值** | "如果能让AI在回答里推荐你们，相当于每次咨询时都有AI在帮你背书——这个价值你怎么看？" | 让客户自己说出需求 |

## 五、异议处理速查

### 异议1："GEO是什么？没听过"

```
"GEO是生成式引擎优化——简单说就是让AI在回答用户问题时，主动推荐你的品牌。

比如客户问豆包'重庆哪里有靠谱的XX厂家'，如果AI直接推荐你家，这就是GEO的效果。

豆包已经跟抖音生活服务打通了，AI推荐位置直接能成交，这是最新的获客入口。"
```

### 异议2："我们客户不会用AI搜"

```
"分行业看。你们是做B2B的还是B2C的？

如果是B2B，采购决策链长，客户一定会做信息搜集——AI搜索现在是他们找供应商的第一站。

你们同行有没有已经在布局的？如果没有，这就是机会窗口。"
```

### 异议3："太贵了吧"

```
"GEO分三个优先级：
- 第一级信息归一化，成本几乎为零，先把基础打好
- 第二级做诊断，看看AI认不认识你
- 第三级内容铺设，根据预算决定深度

建议先做诊断，免费的。我帮你搜一下你的品牌名和品类词，看看AI怎么答你。"
```

### 异议4："我们先看看/考虑一下"

```
"当然可以，这个事该慎重。我先把你们行业的AI搜索数据发您微信，您先看。

另外我建议——趁现在竞品还没把[关键词]的流量买走，先占个位置。等他们投了价格就上去了。

这周我正好在附近，周三或周四下午，我过来当面给您算笔账？"
```

### 异议5："我们已经投了百度/抖音，还要GEO吗"

```
"三个平台不冲突，各自解决了不同的问题——

百度解决的是'知不知道'——用户搜你的品牌名能不能找到你；
抖音解决的是'感兴趣'——用户刷到你的内容会不会想了解；
GEO解决的是'选哪家'——用户问AI推荐时，AI答不答你。

这三个平台覆盖了用户决策的全链路。而且GEO目前竞争还小，现在进场正是窗口期。"
```

## 六、BANT评分记录

每通电话同步评估：

| 维度 | 高分信号（2-3分） | 低分信号（0-1分） |
|------|-------------------|-------------------|
| **B 预算** | 明确说出预算范围 | 说"太贵了"/没提过钱 |
| **A 权限** | 对方是老板/法人 | 说"要问老板"/"商量一下" |
| **N 需求** | 主动承认有痛点 | 说"还行"/"没感觉" |
| **T 时间表** | 说"最近就要" | 说"以后再说"/"不急" |

**决策树**：
- 总分 ≥ 9分 → 🔥 HOT LEAD（当天约拜访）
- 总分 6-8分 → 🟡 WARM LEAD（3天内跟进）
- 总分 ≤ 5分 → 🟢 COLD LEAD（纳入培育池）
