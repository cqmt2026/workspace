# 百都科技·首月10家成交作战计划

> 目标：首月成交10家中小企业
> 时间：入职第1-4周
> 更新：2026-08-26

---

## 一、成交路径拆解

```
成交10家 = 需要触达约200家有效客户
         = 每天触达约7-8家
         = 每周触达约50家
```

### 转化漏斗（保守估计）

| 阶段 | 数量 | 转化率 | 说明 |
|------|------|--------|------|
| 触达（找到联系方式并联系） | 200家 | — | 含电话/微信/拜访 |
| 接通/回复 | 80家 | 40% | 电话接通+初步沟通 |
| 有意向（加微信/约拜访） | 30家 | 37% | 对方认可价值 |
| 上门拜访 | 20家 | 67% | 面谈+算账 |
| **签约成交** | **10家** | 50% | 完成开户+首月投放 |

## 二、每周作战计划

### Week 1：基建+首批触达（目标：5家签约）

| 天数 | 上午（9:00-12:00） | 下午（14:00-18:00） |
|------|---------------------|---------------------|
| Day 1 | 企查查批量筛选第一批（医疗器械+新材料各50家） | 电话触达15家（现有名单+企查查） |
| Day 2 | 企查查筛选第二批（机械装备50家） | 电话触达15家 + 加微信10人 |
| Day 3 | 百度搜索反向获客（搜"重庆医疗器械""重庆新材料"找空白） | 电话触达10家 + 预约拜访 |
| Day 4 | 拜访Day 1-2有意向的客户（目标2-3家上门） | 企查查筛选第三批 |
| Day 5 | 复盘本周数据 + 签约意向客户 | 准备Week 2 |

**Week 1 目标**：
- 触达：60家
- 接通：25家
- 有意向：12家
- **签约：3-5家**

### Week 2：拜访+转化（目标：累计5-7家）

| 天数 | 上午 | 下午 |
|------|------|------|
| Day 6-7 | 上门拜访Week 1预约客户（目标5-6家） | 电话跟进未成交客户 |
| Day 8-9 | 企查查筛选+百度搜索获客（新增80家线索） | 电话触达20家 |
| Day 10 | 复盘+签约Week 2客户 | 准备Week 3方案 |

**Week 2 目标**：
- 触达：100家
- 拜访：8-10家
- **新增签约：2-3家（累计5-8家）**

### Week 3：案例放大+批量转化（目标：累计8-9家）

| 策略 | 动作 |
|------|------|
| 案例放大 | 用Week 1-2已签约客户的实际效果（哪怕只是账户搭建完成+开始有咨询）作为说服材料 |
| 同行业复制 | 找已签约客户所在行业的其他企业，做定向攻单 |
| 转介绍启动 | 跟已签约客户沟通，请他们推荐同行朋友（可给老客户免半个月服务费） |
| 继续触达 | 每周新增80家线索，保持电话触达节奏 |

**Week 3 目标**：
- 新增签约：2-3家（累计7-10家）
- 转介绍激活：3-5个新线索

### Week 4：冲刺+收尾（目标：最终10家）

| 策略 | 动作 |
|------|------|
| 犹豫客户攻坚 | 对之前"再考虑考虑"的客户二次上门，用竞品动态逼单 |
| 月底政策利用 | 如有月度和季度政策优惠，主动提出 |
| 备选客户补位 | 从B类客户池里补充2-3个高意向客户 |
| 复盘总结 | 整理首月数据，为下月目标做准备 |

**Week 4 目标**：
- 新增签约：1-2家（最终10家）
- 持续跟进储备：15-20家（供下月使用）

## 四、获客渠道优先级

### 渠道1：企查查/天眼查（最核心，占60%工作量）

**每日产出目标**：30-50条有效线索

**筛选条件**：
- 地区：重庆主城区（优先两江/九龙坡/大渡口/渝北）
- 资质：专精特新 + 创新型中小企业
- 行业：医疗器械/新材料/机械装备/环保检测
- 规模：注册资本500万-5000万（中小规模，非国有大企）
- 电话：必须有公开联系电话

**操作SOP**：
1. 企查查筛选 → 导出Excel → 去重 → 电话逐一拨打
2. 每天新增线索50条，覆盖4个行业
3. 4周内累计触达800+条线索

### 渠道2：百度反向获客（零成本，占20%工作量）

**操作方式**：
1. 搜"重庆医疗器械""重庆新材料""重庆环保检测"等关键词
2. 找排名在10位以后、但企业资质好的公司
3. 记录公司名+地址+可能电话（官网/天眼查交叉验证）
4. 打电话时直接说："我在百度上搜'XX词'，看到贵公司排名在第X页..."

### 渠道3：园区/孵化器扫楼（占15%工作量）

**目标园区**（按距离和密度排序）：
| 园区 | 企业数 | 主攻行业 |
|------|--------|---------|
| 两江新区（鸳鸯/金山/互联网产业园） | 300+ | 医疗器械/软件/新能源 |
| 巴南软件园 | 150+ | 软件IT/医疗器械 |
| 九龙坡高新区 | 200+ | 机械制造/新材料 |
| 大渡口工业园区 | 100+ | 机械制造/环保 |
| 渝北空港工业园区 | 80+ | 新材料/生物医药 |

**操作方式**：
- 每周安排1天，去1-2个园区逐个拜访
- 带名片+一页纸资料+笔记本
- 目标每天拜访5-8家

### 渠道4：转介绍（占5%工作量）

- 每签约1家客户，请求推荐1-2家同行
- 推荐成功且签约的，给老客户减免半个月服务费

## 五、重点行业话术速查卡

### 医疗器械（最高优先级，28家可触达）

**开场**：
```
"您好，请问是XX公司吗？我是百都科技的。我在百度上搜'重庆医疗器械''重庆IVD'，前十页都没有你们。但百度每天有几千人在搜这些词找供应商。你们是重庆专精特新认定的企业，产品技术很强，为什么不在百度上做品牌曝光？"
```

### 新材料（15家可触达）

**开场**：
```
"您好，我是百都科技的。我看到你们是重庆专精特新认定的新材料企业。我在想一个问题——重庆新材料产业2024年产值6200亿，但百度上搜'重庆新材料'，几乎看不到你们的身影。你们的客户在百度上找供应商时，第一个看到的是谁？"
```

### 机械装备（量大海，优先选有明确产品类型的）

**开场**：
```
"您好，我是百都科技的。我看到你们是重庆做[具体产品，如起重设备/模具]的企业，专精特新资质。我在百度上搜'重庆XX设备'，搜索结果前几页基本都是外地企业。你们是重庆本地企业，产品实力强，但在百度上没有曝光，等于把客户让给了外地同行。"
```

### 环保检测

**开场**：
```
"您好，我是百都科技的。我看到贵公司是重庆环保检测领域的企业。政府项目招标的时候，甲方会不会先在百度上搜供应商名录？你们百度上没有投放，意味着甲方的第一手信息里没有你们。"
```

## 六、异议处理（升级版）

### "没预算" → 算账破局
```
"我理解。但您算笔账——你们现在获客成本是多少？如果是展会，一个展位几万块，来的客户也不一定精准。百度推广月投5000元，平均每天167元，按CPC 5元能带来33次点击，3%转化率=1个潜在客户。如果成交一个订单是10万，这个投入产出比是多少？"
```

### "不需要" → 竞品刺激
```
"理解。但您有没有发现，你们竞争对手[XX公司]已经在百度上投了？他们现在搜'重庆XX产品'排第1位，你们排第8页。这不只是丢了一个渠道的问题，是客户在找你们之前先找到了对手。"
```

### "考虑一下" → 限时逼单
```
"没问题。不过我想提醒您一下——百度竞价是实时竞价的，你现在不投，竞争对手投了，关键词价格会上涨。我建议先小预算测试一个月，效果好了再加，这样风险最小。您看要不我们先签个试用协议？"
```

## 九、风险预警

| 风险 | 应对 |
|------|------|
| 企查查线索质量差（空号/错号多） | 每天筛选100条只留30-50条有效的 |
| 电话被直接挂断 | 改发短信+加微信，先建立联系再打电话 |
| 老板不在/前台挡电话 | 尝试搜企业官网找邮箱或座机，换时间再打 |
| 客户说"已经在投了" | 主动提出免费账户诊断，对比效果 |
| 首周0成交心态崩 | 正常现象，第3-4周才是爆发期，坚持 |
