# 百都科技·机械行业高转化销售话术（实战版）

> 版本：v2.0 实战版
> 核心原则：不讲产品，先帮客户算账；不推销，先做顾问
> 目标：从"被挂电话"到"客户主动问报价"

---

## 一、拨通前必做的3件事（决定80%的成功率）

### 1. 查企业底细（1分钟）
- 企查查/天眼查看：成立时间、注册资本、参保人数、经营风险
- **关键判断**：参保人数>50人=有实力；成立>5年=稳定；有招投标记录=有采购预算
- **话术调整**：如果看到他们正在招销售/业务员 → 说明在扩张，有获客需求

### 2. 搜百度现状（2分钟）
- 搜"重庆+[产品]+厂家/供应商"
- 看前3页有没有他们？排第几？
- 看竞品是谁？外地品牌？B2B平台？
- **关键发现**：如果前3页全是外地企业和B2B平台 → 这是你的切入点

### 3. 找决策人（30秒）
- 企查查看法人/股东/高管
- 如果法人的名字在电话里能问到 → 直接找老板
- 如果问到前台 → "帮我转下负责销售的经理/老板"

## 二、开场白（15秒内抓住注意力）

### ❌ 错误开场（必死）
```
"您好，我是百都科技的，我们做百度推广的，您有需要吗？"
→ 客户：不需要（挂电话）
```

### ✅ 正确开场（3个版本）

#### 版本A：数据切入型（推荐）
```
"您好，是XX公司吗？我这边在做重庆机械行业的获客调研，
看到你们是做[具体产品，如：起重设备]的，对吧？

我搜了下'重庆起重设备厂家'，前3页全是外地企业和B2B平台，
你们这样的本地正规厂家几乎搜不到。

想跟您确认下——你们现在的订单，主要靠什么渠道来？
大概耽误您1分钟，可以吗？"
```
**为什么有效**：
- 第一句说出对方生意（证明做了功课）
- 第二句抛出现象（制造焦虑）
- 第三句问现状（让客户开口）

#### 版本B：痛点直击型
```
"您好，请问是XX公司吗？我是百都科技的小度。

打电话前我先搜了下你们公司，发现一个问题——
你们做[产品]做得不错，但在百度上几乎搜不到。

我现在手头有你们同行的数据，
他们通过百度每月稳定带来[具体数字]条精准线索。

想跟您聊聊这个事，大概2分钟，可以吗？"
```
**为什么有效**：
- 直接点出痛点（搜不到）
- 抛出同行案例（制造紧迫感）
- 给具体数字（增加可信度）

#### 版本C：利益诱导型
```
"您好，是XX公司吗？我这边服务过重庆[具体数字]家机械企业，
帮他们通过百度获客，平均每家每月带来[具体数字]条精准线索。

我看到你们是做[产品]的，技术实力很强，
但现在百度上几乎搜不到你们，客户都被竞品抢走了。

想给您发份同行案例看看，您微信是多少？"
```
**为什么有效**：
- 先给价值（服务过多少家）
- 再点出问题（搜不到）
- 直接要微信（降低防御）

## 三、挖需求（SPIN提问法实战版）

### S（现状）— 了解客户现在怎么做
```
"你们现在的订单，主要靠什么渠道？"
→ 客户：老客户转介绍/展会/百度/美团...

"线上渠道占比大概多少？"
→ 客户：不多/没有/刚起步...

"去年线上带来的订单大概多少？"
→ 客户：几乎没有/几万块...
```

### P（问题）— 让客户意识到问题
```
"那您有没有发现——现在下游客户找供应商，
第一反应都是百度搜'[产品]+厂家'？"

"我看过你们的数据，你们在百度上几乎搜不到，
这意味着什么？意味着您的潜在客户都在被竞品抢走。"

"您知道现在搜索'重庆[产品]'的前3页都是谁吗？
全是外地企业和B2B平台，本地正规厂家几乎没有。"
```

### I（影响）— 放大问题的严重性
```
"如果客户搜不到你们，会损失多少订单？
我帮您算一下——

假设您每月损失1个订单，
[产品]单值按10万算，一年就是120万。
10年呢？1200万。

这不是小数目。"
```

**关键技巧**：
- 用具体数字（10万、120万、1200万）
- 用时间维度（1年、10年）
- 让客户自己意识到损失

### N（价值）— 给出解决方案
```
"如果我们帮您解决这个问题，
您觉得每个月带来5-10条精准线索，
对你们有帮助吗？"

"投1万进去，换10万订单，
这个账您应该会算吧？"

"我们先小预算测试，
月投3000-5000元，跑出效果再加大，
您看如何？"
```

## 四、算账（让客户无法拒绝）

### 机械行业ROI算账模板

#### 场景1：单值高的设备（起重、数控机床）
```
投入：月预算8000元
产出：每月15-30条精准线索
转化：5%转化率 = 每月0.75-1.5单
单值：20万~100万/单
ROI：投1万换20万~100万订单

话术：
"您看，投8000元，
每月带来1-2单，
每单至少20万，
您说这个账划不划算？"
```

#### 场景2：单值中等的配件（液压、模具、汽摩配件）
```
投入：月预算5000元
产出：每月20-40条精准线索
转化：3%转化率 = 每月0.6-1.2单
单值：5万~20万/单
ROI：投1万换5万~20万订单

话术：
"虽然单值没有设备高，
但线索量大，转化稳定，
每个月稳定带来1单，
一年就是12单，
您算算多少产值？"
```

#### 场景3：长期合作的B2B订单
```
投入：年费6800元（爱采购）
产出：365天持续展示
转化：长期合作订单
单值：年合同5万~100万
ROI：年投6800换5万~100万订单

话术：
"爱采购是年费制，6800元用一年，
每天摊下来不到20块钱，
但您的产品全年365天展示在采购商面前，
只要能签1个长期合作订单，
就回本十几倍。"
```

## 五、异议处理（实战版）

### 异议1："不需要"
```
客户："不需要，我们不需要百度。"

错误回应："为什么不需要？"（被客户牵着走）

正确回应：
"理解，很多客户一开始也这么说。
但我好奇的是——
您现在的订单，主要来自什么渠道？"

→ 客户：老客户/展会/关系...

"那您有没有想过，
如果下游客户要找供应商，
第一站是百度搜，第二站是爱采购，
第三站才是展会和老客户转介绍。

您现在完全不在百度上，
等于把第一波客户拱手让人。

我们不逼您现在投，
先给您做个免费的竞品分析，
看看您和竞品的差距，
您看如何？"
```

### 异议2："太贵了"
```
客户："太贵了，我们投不起。"

错误回应："不贵啊，很便宜的。"（否定客户）

正确回应：
"我理解您的顾虑。
但咱们算笔账——

您一台[产品]卖多少？
假设10万，
您现在获客成本多少？
展会一届几万，老客户介绍也不一定稳定。

如果我们帮您通过百度获客，
投8000元，带来1单，
您说贵不贵？

而且我们可以先小预算测试，
月投3000-5000元，
跑出效果再加大，
风险可控。"
```

**关键技巧**：
- 不否认"贵"，而是重新定义"贵"
- 用客户的单值算账
- 强调"风险可控"

### 异议3："已经在投了"
```
客户："我们在投百度了。"

错误回应："那您效果怎么样？"（像审问）

正确回应：
"那太好了！说明您已经意识到线上获客的重要性，
这已经超过80%的机械企业主了。"

（先肯定，降低防御）

"您现在投的是哪个账户？
效果怎么样？
我帮您做个免费的账户诊断，
看看有没有优化空间，
您看如何？"

（给价值，不推销）

"很多客户投了百度但效果不好，
不是百度不行，
是关键词选择不当、落地页不专业、或者没有持续优化。
我可以帮您找找问题所在。"
```

### 异议4："效果不好"
```
客户："之前投过，没效果。"

错误回应："那是您没投对。"（指责客户）

正确回应：
"理解，我接触过很多机械企业，
确实有投了百度但效果不好的。

但我帮您分析下原因，
通常是这3个问题：

第一，关键词选得太泛，
比如投'机械设备'这种大词，
竞争激烈，点击贵，线索不精准。

第二，落地页不专业，
客户搜到您了，但网站打开慢、信息不全、没有资质展示，
客户信任度不够，转化率低。

第三，没有持续优化，
百度推广不是一劳永逸的，
需要每周分析数据、调整关键词、优化落地页。

我可以帮您做个免费的账户诊断，
找出具体问题，
您看如何？"
```

**关键技巧**：
- 不否定客户的经历
- 给出专业分析（显示专业度）
- 提供解决方案（免费诊断）

### 异议5："再考虑考虑"
```
客户："我再考虑考虑吧。"

错误回应："好的，那您考虑好了联系我。"（被动等待）

正确回应：
"没问题，理解您需要时间考虑。

但我好奇的是，
您主要在考虑什么？
是预算问题，还是对效果有顾虑？"

→ 客户：主要是预算/效果不确定...

"我理解。那这样，
我给您发份详细方案，
您慢慢看。

另外，我每周会分享机械行业获客数据和竞品动态，
对您做决策也有帮助。

您看这样行不行——
我们先小预算测试一个月，
月投3000-5000元，
跑出效果您再决定要不要加大，
如果没有效果，您也没有什么损失，
您看如何？"
```

**关键技巧**：
- 挖掘真实顾虑
- 给价值（每周分享数据）
- 降低门槛（小预算测试）

## 六、促单话术（临门一脚）

### 场景1：客户有意向，但犹豫
```
"王总，我理解您需要考虑。
但我想提醒您一点——

您现在不投百度，
您的竞争对手在投，
您的客户在搜，
您在看别人接单。

每个月损失的订单，
您算过吗？

我们先小预算测试一个月，
月投5000元，
如果没效果，您也没有什么损失，
但如果有效果，您每个月多接1-2单，
您说划不划算？"
```

### 场景2：客户问报价
```
"王总，我给您报个价——

百度搜索推广，月预算5000-20000元，
按点击付费，您可控。
爱采购年费6800元，365天展示。

但我建议您这样——
先投百度搜索推广，月预算5000元测试一个月，
跑出效果再加大，
同时开通爱采购，长期展示企业资质。

这样组合，效果最好，成本也可控。

您看如何？"
```

### 场景3：客户要对比
```
"王总，理解您要对比。
但我建议您这样对比——

不要只对比价格，
要对比效果。

我给您看几个同行案例：
成都某起重设备企业，月投8000元，3个月接3单，总额200万。
重庆某数控机床企业，月投5000元，每月稳定带来10-15条线索。

您看，同样的行业，
同样的投入，
效果差异很大。

关键是什么？
是关键词选择、落地页专业度、账户优化能力。

这些我们可以帮您做好，
您只需要决定要不要开始。"
```

## 八、话术核心原则

### 1. 不讲产品，先算账
- 不说"我们百度推广很好"
- 说"投1万换10万订单，您算算划不划算"

### 2. 不给压力，给价值
- 不说"您不投就亏了"
- 说"我先给您发案例，您看看"

### 3. 不否定客户，先认同
- 不说"您错了"
- 说"我理解，很多客户一开始也这么说"

### 4. 不逼单，给选择
- 不说"您今天就决定吧"
- 说"我们先小预算测试，效果不好也没损失"
