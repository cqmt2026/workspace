# GEO销售开场白多套方案

> 版本：V1.0  
> 创建时间：2026-09-13  
> 用途：针对不同客户类型、不同场景、不同反应，灵活切换开场白

---

## 一、开场白设计原则

| 原则 | 说明 |
|------|------|
| **30秒内说清价值** | 第一句话就要引起注意 |
| **数据支撑** | 用搜索结果证明问题存在 |
| **提问结尾** | 让客户回答问题，而不是直接推销 |
| **身份清晰** | 先说我是谁、做什么的 |
| **非推销感** | 像顾问一样说话，不像销售 |

## 二、5套核心开场白（按场景使用）

### 🎯 方案A：数据驱动型（通用推荐）

**适用场景**：首次接触、客户时间有限、需要快速建立信任

```
"您好，请问是[公司名]吗？我是百都科技的小度，做重庆中小企业获客增长的。

打电话前我先在豆包上搜了一下——发现搜'[行业词]+重庆'，AI回答里推荐的都是外地公司或者聚合平台，咱们本地厂家几乎没有曝光。

但你们下游客户找供应商时，第一件事就是搜这个。这意味着什么？你的潜在采购商正在被AI引导去别家。

冒昧问一下——你们现在主要靠什么渠道接客户？"
```

**优点**：
- ✅ 用数据说话，有说服力
- ✅ 制造紧迫感（客户正在流失）
- ✅ 结尾提问，引导对话

**适用客户**：所有B2B源头厂家

---

### 🎯 方案B：案例引用型（建立信任）

**适用场景**：客户 skeptical、需要第三方背书

```
"您好，请问是[公司名]吗？我是百都科技的小度。

我们上个月刚帮一家教育企业做了GEO优化，系统化布局之后：
- 官网主动咨询转化率从3%提升到11%
- 月均转化数从60多单增长到250多单

增幅不是靠加大投放，而是用户在反复向豆包提问的过程中，这家企业持续出现在推荐答案里。

我想问一下——你们现在主要靠什么渠道接客户？"
```

**优点**：
- ✅ 用真实案例说话，可信度高
- ✅ 量化效果，客户容易理解
- ✅ 结尾提问，引导对话

**适用客户**：对效果存疑的客户、需要数据支撑的决策者

---

### 🎯 方案C：痛点共鸣型（制造焦虑）

**适用场景**：客户表现出不感兴趣、需要激发需求

```
"您好，请问是[公司名]吗？我是百都科技的小度。

冒昧问一句——你们下游客户找供应商时，第一步是不是先搜'[行业词]+重庆'？

我刚在豆包上搜了，发现AI推荐的前几名都是外地公司，咱们本地厂家几乎没有曝光。

这意味着什么？你的潜在采购商正在被AI引导去别家，而你自己还不知道。

你们现在主要靠什么渠道接客户？"
```

**优点**：
- ✅ 直接戳痛点，制造危机感
- ✅ 提问开头，引发思考
- ✅ 结尾反问，引导对话

**适用客户**：表现冷淡、需要激发的客户

---

### 🎯 方案D：价值传递型（温和切入）

**适用场景**：客户时间充裕、愿意交流

```
"您好，请问是[公司名]吗？我是百都科技的小度，做重庆中小企业获客增长的。

我今天打电话是因为发现一个趋势——越来越多的客户在下单前会先问AI'哪家比较好''怎么选'。

豆包已经跟抖音生活服务打通了，AI推荐位置直接能成交。酒店订单综合费率12%，比抖音主站还高4个点。

这说明什么？AI推荐位置已经是真实的交易入口。

你们现在线上获客有在做吗？还是主要靠老客户？"
```

**优点**：
- ✅ 传递行业趋势，建立专业形象
- ✅ 用数据说明价值（费率对比）
- ✅ 结尾提问，引导对话

**适用客户**：对新技术接受度高的客户、愿意了解趋势的决策者

---

### 🎯 方案E：免费诊断型（低门槛切入）

**适用场景**：客户说"太贵了"、"考虑一下"、"不需要"

```
"我完全理解，这个事该慎重。

我建议先做免费诊断——我帮你搜一下你的品牌名和品类词，看看AI怎么答你，不花钱也能了解情况。

如果AI根本不认识你，那这就是机会；如果已经推荐你了，咱们再聊怎么优化。

您看这样行吗？我先帮你做个诊断，你评估一下值不值得做。"
```

**优点**：
- ✅ 零门槛，客户无压力
- ✅ 先诊断后报价，建立信任
- ✅ 结尾建议，引导下一步

**适用客户**：所有说"不需要"、"太贵了"、"考虑一下"的客户

## 四、按客户反应的应对话术

### 😐 客户说："不需要"

**应对方案E**：
```
"我完全理解，这个事该慎重。

我建议先做免费诊断——我帮你搜一下你的品牌名和品类词，看看AI怎么答你，不花钱也能了解情况。

如果AI根本不认识你，那这就是机会；如果已经推荐你了，咱们再聊怎么优化。"
```

---

### 💰 客户说："太贵了"

**应对方案E**：
```
"GEO分三个优先级：
- 第一级信息归一化，成本几乎为零，先把基础打好
- 第二级做诊断，看看AI认不认识你
- 第三级内容铺设，根据预算决定深度

建议先做诊断，免费的。我帮你搜一下你的品牌名和品类词，看看AI怎么答你。"
```

---

### 🤔 客户说："考虑一下"

**应对方案E**：
```
"当然可以，这个事该慎重。我先把你们行业的AI搜索数据发您微信，您先看。

另外我建议——趁现在竞品还没把[关键词]的流量买走，先占个位置。等他们投了价格就上去了。

这周我正好在附近，周三或周四下午，我过来当面给您算笔账？"
```

---

### ❓ 客户说："GEO是什么？没听过"

**应对方案D**：
```
"GEO是生成式引擎优化——简单说就是让AI在回答用户问题时，主动推荐你的品牌。

比如客户问豆包'重庆哪里有靠谱的XX厂家'，如果AI直接推荐你家，这就是GEO的效果。

豆包已经跟抖音生活服务打通了，AI推荐位置直接能成交，这是最新的获客入口。"
```

---

### 😏 客户说："我们客户不会用AI搜"

**应对方案A**：
```
"分行业看。你们是做B2B的还是B2C的？

如果是B2B，采购决策链长，客户一定会做信息搜集——AI搜索现在是他们找供应商的第一站。

你们同行有没有已经在布局的？如果没有，这就是机会窗口。"
```

---

### 📞 客户说："已经在投百度/抖音了"

**应对方案D**：
```
"三个平台不冲突，各自解决了不同的问题——

百度解决的是'知不知道'——用户搜你的品牌名能不能找到你；
抖音解决的是'感兴趣'——用户刷到你的内容会不会想了解；
GEO解决的是'选哪家'——用户问AI推荐时，AI答不答你。

这三个平台覆盖了用户决策的全链路。而且GEO目前竞争还小，现在进场正是窗口期。"
```
