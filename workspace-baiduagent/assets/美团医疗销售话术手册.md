# 美团医疗销售话术手册（正式版）

> 产品来源：美团医疗专科商户通 + 美团医疗推广通官方培训资料
> 目标客户优先级：
>   🔥 **第一优先级**：民营医院（重点突破口）
>   🔥 **第二优先级**：体检中心（重点突破口）
>   🟡 **第三优先级**：综合医院（含口腔科/医美科/中医科等强势科室）
> 核心策略：以医院整体美团线上化为切入点，顺势引出口腔/医美/中医等强势科室的推广需求
> 使用原则：先做经营基建再推广告，经营质量影响广告效果
> 更新：2026-09-06

## 一、医疗行业美团现状侦察（打电话前必做）

### 1.1 查百度——确认搜索需求

在百度搜 `"[医院名/科室名]+重庆"` 和 `"重庆+口腔科/妇科/医美"`，看：
- 你们的医院在不在？排第几？
- 同行都在不在？谁在前面？
- 有没有广告位（标"广告"的）？

**关键认知**：医疗决策链是——用户先搜 → 再看美团/点评 → 再到院。百度解决"知不知道"，美团解决"去哪家"。

### 1.2 查美团——摸清经营现状

打开美团APP或大众点评，搜对方医院名字，看：
- ✅ 有没有上线？（没上线 = 空白市场，机会最大）
- ✅ 装修怎么样？（照片/视频/医生信息/品牌介绍）
- ✅ 团单有多少？价格怎么定？
- ✅ 有多少评价？星级多少？好评率多少？
- ✅ 有没有开通预约/在线咨询？
- ✅ 有没有开通推广通？排名在哪？

**侦察结论决定话术角度**：
| 客户状态 | 话术切入点 |
|---------|-----------|
| **完全没上线** | "你们在美团上没有店铺，病人搜都搜不到，竞品全在上面挂着了" |
| **有上线但很烂** | "信息不全/照片模糊/没有医生介绍/没有团购，病人看了不会选你们" |
| **基础OK但没投广告** | "经营还凑合，但排名靠后，用户搜相关词你们根本看不到" |
| **已在投但效果不好** | "您现在ROI口径是怎样的？归因窗口期多长？非首单算不算？" |

## 二、开场白（30秒，建立顾问身份）

### 版本A：完全没上线的客户
```
"王院长您好，我是百都科技小度，我们这边专门帮重庆的医疗机构做线上获客增长。

打电话前我先在美团上搜了一下你们医院——说实话有点意外，你们在美团上目前没有上线，相当于重庆几百万搜'重庆XX医院'的用户，根本看不到你们。但你们附近的XX医院、XX医院都已经上线了，而且装修得挺专业。

冒昧问一下——你们现在病人主要怎么来？老客户介绍、义诊活动，还是线上平台也有在做？"
```

### 版本B：已有上线但经营不好的客户
```
"李院长您好，我是百都科技小度。今天打电话是因为我注意到你们在美团上有店铺，但我看了一下——整体信息还不够完整：医生介绍少了几个，相册也没有上传，还缺几个核心项目。

我注意到你们附近3公里内，有X家同行的医院已经在美团上线了，而且经营评分都是金牌甚至英雄商家，评分比我查到的你们还高出不少。

想问一下——你们现在主要靠什么渠道获客？线上这块有专门负责的人吗？"
```

### 版本C：已在投推广通的客户
```
"张院长您好，我是百都科技小度。我在研究咱们医疗行业的线上获客，发现你们已经在投美团的推广通了，做得挺早的。

我想了解下——你们现在推广通的ROI是按什么口径算的？归因窗口期是多久？首单之后如果复购还会计入吗？

另外您觉得现在的获客成本大概多少一条线索？"
```

## 三、SPIN提问（挖掘痛点+量化需求）

### S — 现状
```
"你们现在病人主要怎么来？线上平台占多少比例？"
"美团上有开店吗？大概多少团单在线？"
"现在有多少条评价？多少好评？"
```

### P — 问题
```
"你们有没有发现——用户搜'XX科医院+重庆'，前几条里面好像没有你们？"
"现在病人到院之前一般要查什么？美团/点评/百度都会看对吧？如果他们在美团搜你的医院，能看到什么？"
"你们现在的评价管理有人专门盯着吗？"
"有没有遇到过这种情况——病人来了说'我在美团上看到你们评分不高/差评'，影响了成交？"
```

### I — 影响（放大损失）
```
"我查了一下，你们这片区有X家同行已经在美团上线了。这意味着每天搜'XX科+重庆'的患者，看到的都是他们，不是你们。

按你们门诊量估算——一个患者平均消费XXXX元，一个月如果因为线上曝光不足少来50个患者，这个损失大概是多少？"

"美团和点评的星级，现在直接影响患者的选择决策。评分低的话，就算有患者搜到了你们，也可能直接划走选别家了。"
```

### N — 价值（让客户自己说）
```
"如果咱们能把美团上的信息补齐、团单设计好、评价管理起来，再配合推广通精准投放——一个月多10个到院患者，按您刚才说的客单价，这能带来多少增量收入？"

"而且美团有个特点——经营越好，广告越便宜，效果越好。这是一个正循环。你们现在投入一点把经营做起来，后面广告费用反而会降下来，您说是不是？"
```

## 四、BANT快速评估（边聊边打分）

| 维度 | 问法 | 高分信号 |
|------|------|---------|
| **B 预算** | "你们现在线上获客这块大概什么预算？美团推广通一个月投多少？" | 明确说出数字/表示可以考虑 |
| **A 权限** | "这件事是您拍板还是需要跟院长/市场部确认？" | 可直接决策 |
| **N 需求** | "现在线上获客对你们业务影响大吗？" | 主动承认问题/表达改变意愿 |
| **T 时间** | "如果方案合适，您打算什么时候开始？" | 近期就要/月底前 |

- 🔥 Hot：总分≥9分 → 当天约上门，当面算账
- 🟡 Warm：总分6-8分 → 加微信发方案，3天内跟进
- 🟢 Cold：总分≤5分 → 纳入培育池，两周后触达

## 五、异议处理（医疗行业高频场景）

### 异议1："我们没有美团，不知道怎么弄"
```
"完全理解，很多医院都这样。其实很简单——我们有个产品叫'商户通'，就是专门帮医院在美团上开店、装修、上架团单的。

一年就1499元（标准版），包含门店装修、医生团队展示、团单管理、预约功能，还有经营数据分析。等于给医院建了一个24小时线上前台。

您可以先在美团上搜一下同行业的医院看看，他们的线上展示就是您做了之后会变成什么样。要不要我先帮您规划一下，您看合不合适再决定？"
```

### 异议2："太贵了"
```
"商户通一年1499元，平均每天4块钱——不到一瓶水的钱。

但一年能给您的医院带来什么？
第一，在美团/点评上有一个完整的线上店铺，病人搜就能找到；
第二，能上架团购项目，比如体检套餐、专项检查，直接产生交易；
第三，有预约功能和在线咨询，病人可以先问再决定；
第四，每月有经营数据分析，知道流量从哪来、客户关心什么。

您算一下——来一个患者平均消费多少？只要一年内多带来两个通过美团来的患者，这就赚回来了。"
```

### 异议3："美团不适合我们这种专科/专科医院"
```
"我理解您的顾虑。但恰恰是专科/专科医院，美团的价值更大——

第一，患者有明确症状时，第一件事就是搜'重庆XX科哪家好'，这是主动需求，转化率高；
第二，美团现在医疗类客户大量涌入，但优质商家并不多，竞争远没白热化，现在进场正是窗口期；
第三，美团推广通是按点击付费的，成本可控——我们之前合作过的XX医院，平均一个到院患者的广告成本才XX元，远低于其他平台。

医疗行业在美团上的投放，现在正处于红利期，越早布局优势越大。"
```

### 异议4："已经在投了，效果一般"
```
"效果一般可能有几个原因——团单设计不够吸引？医生信息展示不充分？评价管理没跟上？还是关键词没定向准？

美团有个特点跟其他平台不一样：**您的线上经营质量，直接影响广告的性价比**。经营分越高、评价越多、团单卖得越好，广告竞价就越好，同样的钱能获得更多曝光。

我建议先做一次全面诊断——看看您的店铺经营评分是多少、哪些环节拖了后腿。然后我们可以针对性优化，把经营分和广告效果都提上来。"
```

### 异议5："需要跟领导/股东汇报"
```
"当然，医疗行业决策确实谨慎，该汇报就要汇报。

我给您准备一份简单的一页纸方案——包括：
1. 您在美团上的经营现状（截图）
2. 同行对比（几家竞品的线上展示）
3. 投放方案和预期效果
4. 投入产出测算（投多少→预计带来多少患者→带来多少收入）

我加您微信，先把这些发您，您看什么时候方便我们一起跟领导汇报？或者我先跟您领导简单介绍一下？"
```

### 异议6："百度/抖音我们已经投了，还要美团吗？"
```
"三个平台不冲突，各自解决了不同的问题——

百度解决的是'知不知道'——用户搜你的医院名能不能找到你；
抖音解决的是'感兴趣'——用户刷到你的内容会不会想了解；
美团解决的是'去哪家'——用户已经决定要来医院了，在美团上选哪家。

这三个平台覆盖了用户决策的全链路。而且美团上用户是带着明确就医意图来的，搜索'重庆XX科医院'，需求强度非常高，转化率天然就高。

很多客户同时用这三个平台，美团带来的患者，客单价和复购率反而比抖音高。"
```

## 六、成交推进（从意向到签约）

### 6.1 一页纸方案（上门必带）

包含4块内容：
1. **现状诊断**：截图显示对方美团店铺现状 vs 竞品现状
2. **经营评分对标**：行业标杆的经营评分（英雄/金牌）及差距
3. **投放方案**：商户通年费 + 推广通月预算建议
4. **投入产出测算**：
   - 投入：商户通1499元/年 + 推广通月预算XXX元
   - 预期：月曝光X万 → 点击率X% → 到院X人 → 收入XXX元
   - ROI：收入/总投入 = X倍

### 6.2 促单话术
```
"院长，您看——现在美团医疗行业正处于上升期，竞争没那么激烈，现在进场正好。

我建议先上商户通（1499元/年），把店铺基础建设做好——装修、团单、医生信息全部配齐。同时跑一个月推广通测试，预算可以先设3000元/月，看看实际效果和成本。

一个月后，根据数据我们再调整——效果好就放量，效果一般就优化关键词和素材。您看这样可以吗？"
```

### 6.3 签约确认（话术要点）
- 商户通版本：标准版 vs 品牌版（根据客户需求）
- 推广通预算：首月建议3000-5000元测试
- 经营目标：3个月内经营评分达到金牌（≥85分）
- 关键词方向：核心病种词（如洗牙/人流/妇科炎症等）

## 九、医疗行业特殊注意事项

### ⚠️ 合规红线
- 不承诺治疗效果（只说品牌展示、获客引流）
- 不保证具体ROI数字（强调点击成本可控，转化看经营）
- 医疗广告需符合平台审核规范（部分词汇受限）

### 💡 核心话术原则
1. **先帮客户把经营做起来，再谈投放**——这是美团与其他平台最大的区别
2. **强调经营质量的正向循环**——经营越好 → 广告越便宜 → 效果越好
3. **用数据说话**——截图对比、同行对标、数据测算
4. **ROI口径对齐**——先确认客户的归因逻辑，再谈效果

## 八、民营医院 & 体检中心突破话术（重点）

> 🔥 重点突破口：民营医院和体检中心决策链短、市场化程度高、线上获客意愿强

### 8.1 民营医院突破话术

#### 开场切入
```
"王院长您好，我是百都科技小度，专门帮重庆的民营医院做线上获客增长。

打电话前我先在美团上搜了一下你们医院——说实话有点意外，你们在美团上目前没有上线，但你们附近的XX医院、XX医院都已经上线了，而且经营评分都是金牌甚至英雄商家。

冒昧问一下——你们现在病人主要怎么来？老客户介绍、地推活动，还是线上平台也有在做？"
```

#### 痛点放大（民营医院特性）
```
"我知道民营医院和公立医院最大的区别就是——没有品牌背书，全靠口碑和市场获客。

但现在患者找医院的方式已经变了：
- 患者先搜'重庆XX医院哪家好' → 看美团评分和评价
- 再搜'XX科+价格' → 对比各家团单
- 最后决定去哪家

如果你们在这些渠道完全空白，就等于把主动找上门的患者拱手让给了同行。"
```

#### 科室切入（以口腔科为例）
```
"我注意到你们医院的口腔科实力挺强的，有XX位专家，但美团上连口腔科的入口都没有。

现在患者看牙，尤其是洗牙、矫正、种植牙这些项目，第一步都是上美团搜'重庆洗牙''重庆口腔'，然后看评分、看价格、看评价再决定去哪家。

你们技术这么好，却在美团上找不到，相当于白白损失了大量主动找上门的患者。

我建议先从口腔科做起——先上商户通把基础信息、医生团队、团购项目配齐，再配合推广通精准投放。一个季度下来，看看能不能给科室带来稳定增量。"
```

#### 促单闭环
```
"院长，民营医院的获客成本普遍比公立医院高3-5倍，因为你们没有品牌溢价。美团恰恰能帮你们解决这个问题——

第一，商户通（1499元/年）帮你们在美团上建一个完整的线上店铺，病人搜就能找到；
第二，推广通按点击付费，成本可控，一个月3000-5000元测试预算就能看到效果；
第三，经营越好广告越便宜，形成一个正循环。

你们周边3公里内有X家竞品已经在美团上了，再不动手就晚了。您看这周几方便，我上门给您详细汇报一下方案？"
```

### 8.2 体检中心突破话术

#### 开场切入
```
"张总您好，我是百都科技小度，专门帮医疗机构做线上获客增长。

我注意到你们体检中心在美团上还没有上线，但'重庆体检''单位体检''入职体检'这些都是高频搜索词，每个月搜索量非常大。

冒昧问一下——你们现在体检业务主要靠什么渠道获客？企业团检、医院转介，还是个人客户？"
```

#### 痛点放大（体检中心特性）

## 九、综合医院内科室切入话术

> 🟡 第三优先级：综合医院内科室（口腔/医美/中医/体检）
> 核心策略：以医院整体美团线上化为切入点，顺势引出口腔/医美/中医等强势科室的推广需求

### 9.1 科室机会识别（侦察阶段必做）

打电话前先在美团搜该医院，看：
- 有没有**口腔科/牙科/口腔门诊**的团单？
- 有没有**医美/整形/皮肤**的团单？
- 有没有**中医科/康复/体检**的团单？
- 如果有，排名和评价怎么样？
- 如果完全没有，这就是突破口！
