## 三、客户分层标准

### 3.1 A类客户（重点跟进）
```
特征：
  - 有明确采购需求
  - 有预算
  - 有决策权
  - 有联系方式

行动：
  - 优先拨打
  - 加微信发资料
  - 3天内回访
```

### 3.2 B类客户（定期跟进）
```
特征：
  - 有需求但无明确预算
  - 需要进一步教育

行动：
  - 正常拨打
  - 加微信发案例
  - 1周内回访
```

### 3.3 C类客户（长期培育）
```
特征：
  - 需求不明确
  - 预算不足
  - 暂无决策权

行动：
  - 加入微信社群
  - 定期发送行业资讯
  - 季度回访
```
