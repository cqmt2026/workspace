## 一、我的核心定位

```
我不是来卖百度广告的。
```

## 八、面试时可能被问的问题

### Q1：你为什么选择从中小客户切入？
```
"因为我发现2275家专精特新企业中，大部分还没有百度推广。
中小客户决策快、预算灵活、效果好说话。
而且我先从中小客户练手，做出案例后再拓展大客户，路径更稳。"
```

### Q2：如果企业说"不需要百度推广"怎么办？
```
"我会先问他们现在靠什么获客，然后指出他们的获客渠道有什么局限。
比如传统制造如果只靠展会，我会说展会一年就几次，百度365天在线获客。
而且我们不只是百度——美团、抖音、小红书、GEO都能做。不同客户在不同平台触达，组合起来效果最好。
如果对方坚持不需要，我会建议先小预算测试一个月，没有效果随时停。"
```

### Q3：你之前有什么销售经验？
```
"我之前研究过2275家专精特新企业，按行业做了分层，知道哪些有需求、哪些没投百度。
我懂企业的获客痛点，也懂百度的推广逻辑。
再加上我对医疗器械、新材料等行业的深入研究，我相信能快速上手。"
```

### Q4：你对中小客户的销售有什么经验？
```
"我的打法是先算账再卖产品，用行业案例建立信任，降低决策门槛。
中小企业老板最关心'投多少能带来多少线索'，我会帮他们算这笔账。
比如月投5000元，CPC 5元，1000次点击×3%转化=30个线索，
其中一个成交就是几万到几十万的产值，ROI非常高。"
```

### Q5：你对末位淘汰怎么看？
```
"我理解公司的考核机制。但末位淘汰也应该有缓冲期，
比如第一个月以学习为主，第二个月开始考核，给新人适应的时间。
我会用业绩证明自己，不会让自己落到末位。"
```
