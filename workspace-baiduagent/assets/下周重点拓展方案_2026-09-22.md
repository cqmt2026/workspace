## 五、风险与应对

### 5.1 风险1：电话打通率低

```
原因：
  - 电话覆盖率仅60%
  - 部分电话为空号/停机
  - 部分电话为非工作时间

应对：
  ✓ 筛选有公开电话的客户优先拨打
  ✓ 工作时间内拨打（9:00-12:00, 14:00-18:00）
  ✓ 预留50%时间用于企查查补漏
```

### 5.2 风险2：客户拒绝率高

```
原因：
  - GEO概念新颖，客户不理解
  - 预算有限，不愿尝试
  - 已有其他推广渠道

应对：
  ✓ 用通俗语言解释GEO（"让AI推荐你"）
  ✓ 强调ROI（"一个订单就回本"）
  ✓ 提供测试期（"先测试3个月，没线索再停"）
```

### 5.3 风险3：竞争对手抢先布局

```
原因：
  - Top 3行业市场空白率高（>90%）
  - 但已有少数竞品在投放

应对：
  ✓ 快速行动，抢占先机
  ✓ 强调"先发优势"（"现在布局=提前卡位"）
  ✓ 提供差异化价值（"AI推荐比广告更有信任感"）
```
