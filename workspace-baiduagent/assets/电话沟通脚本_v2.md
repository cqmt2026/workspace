# 百都科技·重庆中小客户销售电话脚本

> 用途：入职后直接使用
> 核心逻辑：先算账 → 指空白 → 给方案 → 促行动
> 更新：2026-08-26（移除低空经济板块）

---

## 一、通用开场白（30秒内）

```
"您好，请问是XX公司吗？我是百都科技的[你的名字]，专注做重庆中小企业百度推广的。

今天打电话是因为我们在做重庆制造业和医疗行业的市场调研时，发现很多专精特新企业百度上几乎没有投放，但他们的客户第一站都是百度搜供应商。

想跟您简单介绍一下，大概占用您2分钟时间，可以吗？"
```

**关键原则**：不要说"低空经济"或"新能源"，聚焦**制造业B2B + 医疗器械**两大核心板块。

## 二、分行业脚本

### 🏥 医疗器械/生物医药（最高价值蓝海）

**切入数据**：
- 重庆有909家生物医药企业、254家医疗器械企业
- 百度搜索"重庆医疗器械""重庆IVD"，前5页几乎没有制造企业在投广告
- 医疗企业单台设备产值数万~数百万，百度线索价值极高

**话术A（有电话的客户）**：
```
"您好，请问是[中元汇吉/山外山/西山科技]吗？我是百都科技的。

我在百度上搜'重庆医疗器械''重庆IVD体外诊断'，前十页都没有你们公司的独立推广页面。但百度每天有几千人搜这些词找供应商。

你们是重庆医疗器械领域的头部企业，专精特新认证，产品技术实力很强。如果在百度上建立品牌曝光，招投标前甲方搜供应商时，第一个看到的会是你们，而不是竞争对手或者聚合平台。

我们帮过一家重庆的骨科企业，投了3个月，月均带来8-12个有效询盘，转化率约30%。单条线索成本不到300元。

你们现在主要靠什么渠道获客？展会？代理商？还是老客户介绍？"
```

**话术B（无电话、需企查查找联系方式）**：
```
"您好，请问是[XX公司]吗？我是在企查查上看到贵公司的，你们是重庆专精特新认定的医疗器械企业，做的是[具体业务]。

我发现一个很有意思的现象——你们的产品技术在整个西南地区都是领先的，但在百度上搜'重庆[具体产品]'，根本找不到你们。这意味着什么？意味着你们的潜在客户在找供应商时，会看到竞争对手或者聚合平台。

我们是百度在重庆的授权代理商，专门做中小企业的百度推广。今天打电话不是要您马上投，而是想了解一下——你们公司目前有在做线上获客吗？还是主要靠线下？"
```

### 🏭 机械装备/汽配（量大海，筛选精准）

**切入数据**：
- 重庆机械装备汽配438家专精特新企业，是最大行业池
- B2B采购决策链清晰：技术部→采购部→老板
- 百度搜"重庆XX设备""重庆XX零部件"是采购方标准动作

**话术**：
```
"您好，请问是[XX公司]吗？我是百都科技的。

我看到你们是重庆专精特新认定的机械装备制造企业，做的是[具体产品，如起重设备/模具/汽车配件]。

我想跟您同步一个数据——我们在百度上搜'重庆起重设备''重庆精密模具'，搜索结果前几页基本都是外地企业或者大型平台，重庆本地制造企业的曝光很少。

你们是重庆本地的企业，产品实力强、有专精特新资质，但在百度上没有品牌曝光，等于把搜索流量让给了外地竞争对手。

我们有个客户在成都，做起重设备的，上个月通过百度推广接了3个订单，总金额超过200万。他们的月预算也就5000元左右。

我想问一下，你们现在主要靠什么渠道接订单？展会？老客户转介绍？还是线上平台？"
```

### 🧪 新材料化工（蓝海+政策风口）

**切入数据**：
- 重庆2024年先进材料产值6200亿，2027年目标万亿级
- 新材料行业百度几乎无投放，获客成本极低
- 专精特新企业普遍有政府补贴，营销预算有保障

**话术**：
```
"您好，请问是[再升科技/XX新材料]吗？我是百都科技的。

我看到你们是重庆专精特新认定的新材料企业，做的是[超细玻璃纤维/胶粘剂/镁合金]。我在想一个问题——你们的产品这么好，为什么百度上搜'重庆新材料''重庆XX材料'，几乎看不到你们的身影？

重庆新材料产业2024年产值6200亿，今年目标是万亿级。政府扶持力度很大，但大多数新材料企业还停留在'靠展会+人脉'的传统获客模式。

百度推广可以帮你们解决一个问题：当汽车零部件厂商、建筑工程方在百度上搜供应商时，第一个看到的应该是你们，而不是外地同行。

你们现在有在做线上获客吗？"
```

### 🌿 环保检测（稳定预算，政府采购驱动）

**切入数据**：
- 环保检测企业客户以政府/国企为主
- 招标前甲方必百度搜供应商名录
- 百度投放竞争极低

**话术**：
```
"您好，请问是[XX环保科技]吗？我是百都科技的。

我看到你们是重庆专精特新认定的环保检测企业。想跟您聊一个话题——政府项目招标的时候，甲方会不会先在百度上搜'重庆环保检测''重庆环境检测'来找供应商名单？

我们观察到一个现象：重庆大多数环保检测企业在百度上几乎没有投放。这意味着什么？意味着甲方的第一手信息里，没有你们。

百度推广对环保检测企业有一个特殊价值：你们可以通过百度爱采购建立B2B店铺，长期展示企业资质和项目案例，招投标前甲方搜到你们，信任度会大幅提升。

你们目前有在维护政府关系方面的线上形象吗？"
```

## 三、异议处理（通用版）

### Q1："我们不需要百度推广"
```
"理解，很多企业都有这个想法。但我想问一个问题——你们的客户在找供应商时，第一反应是什么？如果他们在百度上搜不到你们，就会搜到竞争对手。这不是要不要的问题，是迟早的事。建议先做个小测试，一个月3000-5000元，看看效果再说。"
```

### Q2："百度已经没人用了"
```
"B2B领域和C端不一样。采购方找供应商、工程方找分包商、医院找设备商——这些决策的第一步几乎都是百度。抖音适合品牌曝光，但百度适合精准获客。两个不冲突。"
```

### Q3："我们在投了，效果不好"
```
"那说明之前的投放方式有问题。很多公司只是开了个户，没有做关键词优化、落地页优化和数据分析，等于花钱买教训。我们可以免费帮你们做一次账户诊断，看看问题出在哪里，再决定要不要调整。"
```

### Q4："太贵了，投不起"
```
"我理解。但换个角度算笔账：如果你们月预算5000元，按行业平均CPC 5元算，能带来1000次点击；按3%转化率算，能带来30个线索。如果其中一个线索成交，产值可能几万到几十万，ROI是多少您自己算。关键是——你们现在获客的成本是多少？"
```

### Q5："我要考虑一下"
```
"没问题，这种事确实需要慎重考虑。我加您个微信，把方案和同行业案例发给您参考。另外，我这周正好在你们公司附近，方便的话我可以过来拜访一下，当面给您算算账。您看周三还是周四下午方便？"
```

### Q6："我们有专门的运营团队/已经有代理商了"
```
"那很好，说明你们对线上获客是有意识的。不过多一个渠道多一份机会——我们现在帮客户做百度推广，不是替代你们现有的运营，而是作为一个补充渠道，专门覆盖那些没被其他渠道触达到的采购方。而且我们提供免费账户诊断，对比一下现有投放效果和百度效果，您也不吃亏，您说呢？"
```

## 四、行业数据卡（打电话时备用）

### 医疗器械
- 重庆生物医药企业909家，医疗器械企业254家
- 中元汇吉：重庆最大IVD企业，百度无广告
- 山外山：科创板上市公司，血液净化设备，百度无广告
- 单台设备产值：数万元~数百万元
- 百度线索价值极高（高客单价+长决策链）

### 新材料
- 2024年重庆先进材料产值6200亿元
- 2027年目标：万亿级产业集群
- 百度投放极少，获客成本行业最低
- 再升科技：C919供应商，百度无广告

### 机械装备
- 重庆438家专精特新机械企业
- B2B采购决策链清晰（技术→采购→老板）
- 百度是供应商搜索第一入口
- 成都某起重设备客户：月投5000，3个月接3单，总额200万+

### 环保检测
- 客户以政府/国企为主
- 招标前必百度搜供应商
- 百度投放竞争极低
- 百度爱采购B2B店铺长期展示资质
