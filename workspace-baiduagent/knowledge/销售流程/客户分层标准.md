# 客户分层标准细化

> 用途：明确A/B/C级客户的界定标准，避免"把上市公司当中小客户"
> 更新：2026-08-26

---

## 一、百度代理商体系（官方标准）

根据界面新闻及百度官方资料：

| 层级 | 评定标准 | 服务方式 |
|------|---------|---------|
| **KA客户** | 年消耗 ≥ 100万 或 一次性充值大额 | 代理商客户经理一对一 |
| **中小客户(SMB)** | 年消耗 < 100万，几千~几万起步 | 电话销售/渠道商批量服务 |

**关键判定**：不是看企业规模，是看"营销预算承诺"。

## 二、中小客户的商业画像（多维度）

我们目标客户的**综合画像**（满足越多，匹配度越高）：

### 维度1：规模门槛（排除大客户）
| 指标 | 中小客户标准 | 判定方法 |
|------|------------|---------|
| 注册资本 | ≤ 5000万 | 企查查/天眼查 |
| 员工人数 | ≤ 200人 | 企查查 |
| 市值/上市 | 未上市 | 是否科创板/主板/新三板 |
| 年营收 | 500万~5000万（估算） | 工商数据+行业常识 |

**排除标准**：上市公司、国有控股、行业龙头、年框客户 → 不是我们的客户

### 维度2：预算门槛（真实可落地）
| 指标 | 中小客户标准 |
|------|------------|
| 首次投入 | 3000~10000元（试水意愿） |
| 月消耗意愿 | 3000~20000元 |
| 决策人 | 老板/创始人直接拍板 |
| 决策周期 | 1~4周内能定 |

### 维度3：获客需求（百度适配性）
| 特征 | 说明 |
|------|------|
| 缺稳定获客渠道 | 现有渠道有限/不稳定 |
| 客户有搜索行为 | B2B采购/本地服务/消费决策 |
| 百度上几乎无曝光 | 搜不到或排名靠后 |
| 产品/服务可线上展示 | 适合做落地页/推广 |

## 三、客户分级流程（实操SOP）

### Step 1：企查查初筛（30秒/家）
- 注册资本：≤5000万？
- 员工数：≤200人？
- 是否上市？（排除科创板/主板/新三板）
- 法人/股东：是否国企/央企？

### Step 2：百度现状验证（2分钟/家）
- 搜公司名：排名/有无广告？
- 搜行业词：竞品情况？
- 是否有官网/落地页？

### Step 3：电话试探预算（1分钟）
- "你们目前获客主要靠什么渠道？"
- "最近有做线上推广的计划吗？预算大概多少？"
- "这个问题您自己能决定还是需要上报？"

### Step 4：最终分级
| 结果 | 等级 |
|------|------|
| 3步全通过 | A级（重点） |
| 1-2步通过 | B级（培育） |
| 不符合规模或预算 | C级或跳过 |
