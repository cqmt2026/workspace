# 转介绍机制（MGM）

> 用途：已成交客户转介绍新客户的标准化流程
> 核心：让老客户成为你的"兼职销售"，用利益+人情驱动
> 更新：2026-08-26

---

## 一、转介绍时机（什么时候开口）

**最佳时机**：
- ✅ 客户效果数据好（出线索/成交）时
- ✅ 客户主动夸奖/感谢时
- ✅ 客户续费/加预算时
- ✅ 客户转介绍之前，先给足价值

**避免时机**：
- ❌ 客户刚签约还没看到效果
- ❌ 客户有不满/投诉时

---

## 二、转介绍话术（分层）

### 1. 效果好的老客户
```
"X总，感谢您对我们效果的认可。
您这个行业我知道还有几家跟您情况类似的（同行），
您要是觉得我们的服务还可以，方便帮我推荐一下吗？
我们也会给老客户返利（减免服务费/返点）。"
```

### 2. 一般关系的客户
```
"X总，您身边有没有同样在做推广或者有获客需求的朋友？
我现在帮企业做百度获客，如果您介绍朋友合作成功，
我给您申请减免半个月服务费，算是一点感谢。"
```

### 3. 加微信后的线上话术
```
"[X]总，感谢您这次合作！
如果您的同行/朋友也有获客需求，欢迎推荐给我。
介绍成功的话，我会给您准备一份答谢（服务费减免/赠品）。
您这边的效果数据我也会持续跟进，用得好了咱们再加码。"
```

---

## 三、转介绍激励方案

| 动作 | 激励 |
|------|------|
| 转介绍名单（给企业名） | 送行业报告/方案小样 |
| 转介绍+促成联系 | 减免半个月服务费 |
| 转介绍+成交 | 减免1个月服务费 / 返点 |

**返点/减免需经理确认，不超权限承诺！**

---

## 四、转介绍跟进SOP

```
1. 收到名单 → 当天验证+记录到CRM（来源=转介绍）
2. 24小时内触达 → 优先跟进（有人背书，成交率高）
3. 电话开场 → "XX总介绍我来找您的，说他那边效果不错..."
4. 过程反馈 → 关键节点同步给介绍人（让他有参与感）
5. 成交确认 → 兑现激励给介绍人（不及时兑现=断源头）
6. 循环 → 新客户效果好 → 再请他转介绍
```

---

## 五、重要原则

1. **先给价值再要转介绍** — 客户满意才愿意推
2. **及时兑现激励** — 口碑是转介绍源源不断的根本
3. **标注来源** — CRM记"来源=转介绍"，方便统计
4. **不勉强** — 客户没意愿就不提，别伤关系
