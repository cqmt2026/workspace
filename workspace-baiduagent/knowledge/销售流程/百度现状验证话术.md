# 百度现状验证话术脚本

> 用途：打电话前/中，快速验证客户百度现状的话术+动作指南
> 核心：用数据说话，让客户看到"机会"而不是听你说
> 更新：2026-08-26

---

## 一、验证三件事（必做）

### 1. 搜公司名
- 操作：百度搜"[公司全名]"
- 看什么：第几页？有没有广告位？官网排名？
- 话术："X总，我刚搜了贵司名字，第X页，排名靠后，说明您客户搜不到您"

### 2. 搜行业关键词
- 操作：百度搜"[行业]+重庆/厂家/供应商"
- 看什么：前3页有没有同行？谁在投广告？你的排名？
- 话术："搜'重庆XX'，前几页都是外地公司和平台，本地正规厂家没出现"

### 3. 搜竞品名
- 操作：百度搜"竞品名"或"竞品产品名"
- 看什么：竞品排第几？有没有投广告？
- 话术："我查到您同行XX已经在投百度了，他们排第一，您排第几？"

---

## 二、话术节奏（边搜边聊）

```
【打前准备】(3分钟)
1. 打开百度，准备搜3个词：公司名 / 行业词 / 竞品名
2. 记截图（用截图工具：Win+S截图）
3. 打开企查查，备查企业基本信息

【打电话时】(随聊随验证)
"X总，您方便吗？我现在就在百度上帮您搜一下，顺便看看您现在的曝光情况..."
→ 现场演示搜索过程（让对方有参与感）
→ "您看，这是搜'XX'的结果，您排第X页，同行XX排在第1位"
→ "这就是咱们要找的改进点：先把这几个词占住"
```

## 四、常见结果及应对

| 搜索结果 | 问题判断 | 应对策略 |
|---------|---------|---------|
| 公司名搜不到 | 官网未收录/没官网 | 先做官网或基木鱼页面，再推广 |
| 排第3页以后 | 有SEO但优化差 | 需要专业优化+广告加持 |
| 竞品在第1页 | 已被对手占位 | 竞争白热化，需差异化策略 |
| 前3页无广告 | 竞争对手少 | 蓝海，先发优势明显 |
| 竞品有广告但你没有 | 客户在帮竞品引流 | 立即行动，抢占位置 |
