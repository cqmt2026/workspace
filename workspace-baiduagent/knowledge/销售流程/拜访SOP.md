# 拜访流程SOP

> 每次上门拜访的标准流程
> 创建: 2026-08-26

---

## 一、拜访前（提前1-2天）

### 1.1 背景调研（必做）
- [ ] 企查查查询：注册资本、法人、经营范围、荣誉资质
- [ ] 百度搜索：公司名+行业关键词，看排名和竞品
- [ ] 官网分析：产品、案例、团队规模
- [ ] 准备3个针对性问题（基于调研结果）

### 1.2 资料准备
- [ ] 名片×3张
- [ ] 一页纸打印版
- [ ] 同行业案例截图（手机/平板）
- [ ] 笔记本+笔
- [ ] 预约确认（前1天发微信/电话确认）

---

## 二、拜访中（30-45分钟）

### 2.1 开场（5分钟）
```
"X总您好，我是百都科技的小度。感谢您抽出时间。
我们先不聊产品，我先了解一下您的情况——您现在主要靠什么渠道获客？最近有遇到什么获客上的困扰吗？"
```

### 2.2 需求挖掘（15分钟）
用SPIN四问：
- **S 现状**：你们现在怎么获客？预算多少？
- **P 问题**：这个方式有什么痛点？
- **I 影响**：这些问题带来什么损失？
- **N 价值**：如果能解决，能带来多大收益？

### 2.3 方案呈现（10分钟）
- 展示同行业案例（真实数据）
- 算ROI账：投入→线索→成交→利润
- 推荐产品组合（不是单一产品）

### 2.4 异议处理（5分钟）
根据客户反应，灵活应对：
- "不需要" → 问现状，找痛点
- "太贵了" → 算账，对比获客成本
- "考虑一下" → 约下次拜访，发资料

### 2.5 促单收尾（5分钟）
- 给限时优惠（本月政策）
- 低门槛测试（3000元试一个月）
- 约定下一步（加微信/发方案/约跟进时间）

---

## 三、拜访后（当天）

### 3.1 录入CRM
- [ ] 更新客户状态
- [ ] 记录沟通要点（痛点/预算/决策人/下一步）
- [ ] 设置跟进提醒

### 3.2 发送资料
- 微信发送方案和案例
- 确认下次联系时间

### 3.3 自我复盘
- 这次做得好的地方
- 这次可以改进的地方
- 下次拜访的改进点

---

## 四、拜访话术库

### 开场白
> "X总您好，我是百都科技的小度，专注帮重庆中小企业做百度获客的。上次跟您电话里聊过，今天专门过来给您把账算清楚。"

### 算账话术
> "我帮您算笔账：如果您月投3000元，按行业平均CPC 5元，能带来600次点击；按2%转化率，能带来12个线索；如果成交1个，毛利可能几万到几十万。这个账您看合理吗？"

### 逼单话术
> "X总，我建议先小预算测试一个月，3000-5000元，看看效果再决定。这样风险最小，您看这周就能启动？"
