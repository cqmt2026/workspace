# ROI算账模型

> 数据来源：data/baidu/ 销售话术+SEM策略文档 | 更新时间：2026-09-01

---

## 核心算账逻辑

```
投入 = 预存款 + 服务费
产出 = 线索数 × 转化率 × 客单价
ROI = 产出 / 投入 × 100%
```

---

## 一、搜索推广算账模板

### 输入参数
| 参数 | 说明 | 示例值 |
|------|------|--------|
| 日预算 | 每天愿意投多少钱 | 500元 |
| 点击成本(CPC) | 行业平均点击价格 | 8元/次 |
| 转化率 | 访问→咨询的比例 | 5% |
| 成交率 | 咨询→成交的比例 | 20% |
| 客单价 | 平均成交金额 | 5000元 |

### 计算过程
```
日点击量 = 500 ÷ 8 = 62.5次
周点击量 = 62.5 × 7 = 437.5次
月点击量 = 62.5 × 30 = 1875次

周咨询量 = 437.5 × 5% = 22个
月咨询量 = 1875 × 5% = 94个

周成交 = 22 × 20% = 4.4单
月成交 = 94 × 20% = 18.8单

月产出 = 18.8 × 5000 = 94,000元
月投入 = 500 × 30 + 100(均摊服务费) = 15,100元
ROI = 94,000 ÷ 15,100 = 6.2倍
```

### 一句话话术
> X总，您每天投500块，一个月大约带来18-19个成交客户，产出9万多，投入只要1.5万，ROI超过6倍。

## 二、爱采购算账模板

### 输入参数
| 参数 | 说明 | 示例值 |
|------|------|--------|
| 年费 | 基础会员6980/实力19800 | 6980元/年 |
| 日均商机 | 每天派单数量 | 2条/天 |
| 商机转化率 | 商机→成交比例 | 10% |
| 客单价 | 平均成交金额 | 10000元 |

### 计算过程
```
年商机总数 = 2 × 365 = 730条
年成交数 = 730 × 10% = 73单
年产出 = 73 × 10000 = 730,000元
年投入 = 6980元
ROI = 730,000 ÷ 6980 = 104倍
```

### 一句话话术
> X总，爱采购基础会员一年6980，每天送2条精准商机，一年730条商机，按10%成交率算能成交73单，每单1万就是73万，ROI超过100倍！

## 三、信息流算账模板

### 输入参数
| 参数 | 说明 | 示例值 |
|------|------|--------|
| 日预算 | 每天投放金额 | 1000元 |
| CPA目标 | 单个线索成本 | 50元 |
| 转化率 | 线索→成交 | 15% |
| 客单价 | 平均成交 | 8000元 |

### 计算过程
```
月线索数 = 1000 × 30 ÷ 50 = 600个
月成交数 = 600 × 15% = 90单
月产出 = 90 × 8000 = 720,000元
月投入 = 1000 × 30 = 30,000元
ROI = 720,000 ÷ 30,000 = 24倍
```

## 四、GEO算账模板

### 逻辑说明
GEO不直接产生线索，而是：
1. **品牌背书**：AI回答中引用企业信息 → 投标加分
2. **防御投资**：不让竞品在AI中占据推荐位
3. **长期资产**：一旦建成，持续获得免费流量

### 话术
> X总，GEO不是买流量，而是建品牌数字资产。就像买房和租房——投流是租房，每年涨价还随时可能被赶走；GEO是买地基建别墅，一次性投入，未来十年持续受益。更重要的是，您的竞争对手如果先做了，AI就会认为他们是权威答案，您再想做就来不及了。

## 五、异议对冲算账

### "太贵了"对冲
```
投入对比：
- 百度推广：1万预算 ≈ 1000+次曝光 ≈ 50+咨询 ≈ 10单
- 传统广告：1万预算 ≈ 报纸/横幅 ≈ 只能看不能点 ≈ 无数据追踪
- 线下地推：1万预算 ≈ 2人×1个月 ≈ 效果不可控
结论：百度ROI最高+可追踪+可优化
```

### "没效果"对冲
```
之前做没效果的原因分析：
1. 关键词选得不对 → 现在用智能拓词
2. 创意不够吸引 → 现在有AI生成优质创意
3. 落地页转化差 → 现在有基木鱼专业建站
4. 没有持续优化 → 现在有轻舸AI后台+专业优化师
结论：时代变了，产品也升级了
```

### "不需要"对冲
```
不做百度推广的隐性成本：
1. 客户搜索时看不到你 → 客户流失给同行
2. 品牌在网络上"隐身" → 影响企业形象
3. 竞争对手抢先占据关键词 → 后期成本更高
4. 错过AI搜索红利 → 未来获客成本更高
结论：不做的成本 > 做的成本
```
