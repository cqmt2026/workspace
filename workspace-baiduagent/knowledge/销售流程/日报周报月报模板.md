# 日报/周报/月报模板

> 用于每日/周/月销售数据汇总
> 与Python脚本配合使用（generate_daily_report()等）
> 更新：2026-08-26

---

## 一、日报模板（每日17:30生成）

```markdown
# 百都销售日报 - {date}

## 核心数据
- 今日拨打：{N}通
- 接通数：{N}通
- 有效通话：{N}通
- 有意向客户：{N}家
- 新增成交：{N}家

## 行业分布
| 行业 | 拨打 | 接通 | 意向 | 成交 |
|------|------|------|------|------|
| 医疗器械 | N | N | N | N |
| 新材料 | N | N | N | N |
| 机械装备 | N | N | N | N |
| 其他 | N | N | N | N |

## 今日亮点
- [记录今天最有价值的发现/话术/客户反馈]

## 明日计划
1. [具体行动]
2. [具体行动]
3. [具体行动]

## 问题/卡点
- [遇到的困难或需要支援的事项]
```

## 二、周报模板（每周三14:00自动生成）

```markdown
# 百都销售周报 - 第{week}周（{start_date} ~ {end_date}）

## 本周业绩
| 指标 | 数值 | 环比 |
|------|------|------|
| 拨打总数 | {N} | {+/-N%} |
| 接通数 | {N} | - |
| 有意向 | {N} | - |
| 新增成交 | {N} | - |
| 接通率 | {N}% | {+/-N%} |
| 转化率 | {N}% | {+/-N%} |

## 行业转化对比
| 行业 | 拨打 | 接通 | 意向 | 成交 | 转化率 |
|------|------|------|------|------|--------|
| 医疗器械 | N | N | N | N | N% |
| 新材料 | N | N | N | N | N% |
| 机械装备 | N | N | N | N | N% |
| 环保检测 | N | N | N | N | N% |

## 话术效果分析
- **最有效的开场白**：[记录]
- **最有效的异议处理**：[记录]
- **需要优化的环节**：[记录]

## 下周计划
1. [行动]
2. [行动]
3. [行动]

## 目标进度（vs 月目标10家）
- 已完成：{N}家
- 剩余：{N}家
- 预计完成时间：{date}
```

## 三、月报模板（每月1日09:00自动生成）

```markdown
| 成交客户 | {N} | {N} | {N}% |

## 行业排名
| 排名 | 行业 | 成交额 | 客户数 | 转化率 |
|------|------|--------|--------|--------|
| 1 | {industry} | {N}万 | {N} | {N}% |

## 问题诊断

- 改进措施：[方案]

## 下月目标
1. [目标1]
2. [目标2]
3. [目标3]

## 本月亮点
- [本月做得好的1-2件事]
```
