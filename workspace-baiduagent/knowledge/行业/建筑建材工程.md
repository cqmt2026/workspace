## 一、行业基本面

| 数据 | 说明 |
|------|------|
| 客户形态 | 建设工程、建材供应、装饰公司 |
| 决策人 | 老板/项目负责人 |
| 特征 | 项目制，中标为生，B2B采购 |

**关键特征**：
- 甲方找分包/供应商时，会先百度搜"XX工程公司""XX材料厂家"验证实力
- 项目制，决策链清晰但周期长
- 招投标前的线上信任形象很重要

## 二、百度投放现状（核心弹药）

| 观察 | 说明 |
|------|------|
| 行业词 | 竞争中等，细分词（XX钢结构/XX防水）可控 |
| 信任背书 | 品牌专区+官网对招投标加分 |
| 机会 | 本地工程/建材公司普遍没重视线上形象 |

| 类型 | 推荐产品 | 切入角度 |

## 四、话术弹药

### 一句破冰
```
"甲方/业主找你这种工程/材料商之前，会先百度搜一验证实力。
你们现在百度上能搜到吗？项目主要靠关系还是有市场化获客？"
```

```
一个工程项目价值几十万到千万级。
百度+品牌专区帮你建立信任，招标前甲方搜到你，多一次入围机会。"
```
