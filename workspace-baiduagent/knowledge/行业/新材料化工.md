## 二、百度投放现状（核心弹药）

| 观察 | 说明 |
|------|------|
| 百度竞争度 | **极低**，几乎无投放，蓝海 |
| 获客成本 | 行业最低 |
| 主攻方向 | 下游采购商搜索"[材料]+供应商/厂家" |

**抓头部空白**：
- 再升科技（C919供应商，超细玻璃纤维）→ 百度无广告
- 重庆镁业 / 重庆钛业 → 百度无广告
- 固特胶业 / 其他新材料 → 百度无广告
