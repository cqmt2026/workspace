# 本地生活服务行业销售知识库

> 用途：打电话/拜访重庆本地服务企业（餐饮/装修/教育/医美/家政等）
> 更新：2026-08-26

---

## 一、行业基本面

| 数据 | 说明 |
|------|------|
| 客户形态 | 到店/到家消费型，靠客流 |
| 决策人 | 老板/店长直接决策，决策快 |
| 特征 | 客单价中低，但量大、续费率看效果 |

**关键特征**：
- 用户找本地服务：搜"XX附近XX""XX哪家好"频率极高
- 百度地图+搜索是到店关键入口
- 区域词（如"XX区补牙""XX区装修"）转化高、竞争相对可控

---

## 二、百度投放现状（核心弹药）

| 观察 | 说明 |
|------|------|
| 区域词 | 竞争相对低，转化高 |
| 大词 | "装修""教育"等大词已被大品牌占据，绕开 |
| 机会 | 中小商家普遍没投，本地词是蓝海 |

---

## 三、目标客户分类

| 类型 | 客户特征 | 推荐产品 | 切入角度 |
|------|---------|---------|---------|
| 装修/家装 | 高客单，有区域 | 搜索（区域词）+地图 | "新区想装修的人搜'XX区装修'看到你吗？" |
| 餐饮/门店 | 到店客流 | 地图+信息流 | "附近客消费前先搜/看地图定位" |
| 教育/培训 | 招生 | 搜索+信息流 | "家长找机构搜'XX区X培训'，你在吗？" |
| 医美/齿科 | 高客单 | 搜索（区域词）+品牌 | "求美者搜'XX区整牙'，精准客流" |
| 家政/维修 | 到店/上门 | 搜索（区域词）+地图 | "小区业主搜附近服务，能找到你吗？" |

## 四、话术弹药

### 一句破冰
```
"现在用户找XX服务，动动手指就搜'附近XX'、'XX区XX哪家好'。
你们在[区域词]上的曝光怎么样？主要是点评、老客，还是也想多一条获客？"
```

### 算账示例
```
一个到店客户消费几百~几千元。
百度区域词带来精准到店客户，几十元一个线索，成交率高。"
```
