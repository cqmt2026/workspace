## 一、美团商业产品体系总览

美团点评商业产品分为三大收入模式：

```
美团点评 POI（门店载体）
│
├── 会员模式（商户通 MEM）
│     └── 收费：会员费（年费）
│
├── 佣金模式（交易佣金 CPS）
│     ├── 团购
│     ├── 次卡
│     ├── 预订
│     └── 预付
│
└── 广告模式
      ├── 推广通（CPC）按单次点击计费 ← 核心
      ├── 智选展位（CPM）按千次展现计费
      └── 智品牌秀（CPT）按时间计费
```

**美团商业产品核心特征**（区别于百度/抖音/腾讯）：
- **本地属性**：面向本地商户，兼顾用户体验
- **极简设计**：产品能力高度集中，操作/优化压力小
- **注重经营**：门店线上经营对广告权重影响非常大，经营动作贯穿始终
- **高度原生**：广告高度原生化，门店维度直接投放，转化链路完全复用门店设置

## 二、商户通（美团会员模式产品）

### 2.1 产品定位
**商户必经产品，开店、装修、运营一体化管理工具**
> 360度打造完美线上店铺，提高消费者关注度和认可度，提升到院转化

**用户想了解什么？**
- 商家是否有优惠？
- 商家医疗水平是否专业？
- 是否可以先咨询后到店？
- 是否可以提前预约？
- 商家服务质量如何？

### 2.2 核心功能（六大模块）

| 模块 | 功能详情 |
|------|---------|
| **门店装修** | 门店基础信息 / 商家视频 / 官方相册 / 门店头图 / 医生信息 |
| **货架运营** | 团购上线、修改及管理；商品数量多、覆盖广 |
| **用户运营** | 预约管理 / IM客户沟通 / 在线咨询 |
| **经营管理** | 经营参谋 / 经营评分 / 开店宝后台 |
| **评价管理** | 评价积累、差评响应机制 |
| **营销活动** | 自助立减 / 店内活动 / 活动报名 / 门店优惠码 / 预约到店礼 |

### 2.3 门店装修详情
- **门店头图**：精致头图脱颖而出
- **官方相册/视频**：品牌展示、门店活动
- **医生信息**：机构可上传医生团队信息，平台审核资质后展示职称、从业年份、执业经历、荣誉
- **品牌介绍**：凸显医院实力和特色项目，帮助用户选店
- **促销/活动**：报名留资
- **团单详情**：清晰展示服务权益
- **团购货架**：多重优惠，品类丰富

### 2.4 货架运营优秀案例（仁爱医院妇科）
- 商品在线：46个团单
- 品类覆盖：妇科检查、宫颈疾病、月经不调、不孕不育、人流、HPV疫苗、炎症检查治疗、妇科整形、肿瘤筛查等10类
- 高销品：早孕/验孕、胎儿排畸、妇科检查共9个团单
- 立减覆盖：超40%商品配置立减
- 引流品设计：40元以下早孕检查、500元以下宫颈癌筛查、100元以下炎症检查、350元月经不调检查，最低折扣至1.8折，新客特惠引新客下单

### 2.5 经营评分体系（美团平台）
**目的**：帮助商家熟悉线上运营规则、明确优化改进动作

| 等级 | 分数要求 | 权益 |
|------|---------|------|
| **英雄商家** | 本月分数 ≥90分 | 列表页、商户详情页牌级标识 |
| **金牌商家** | 本月分数 ≥85分 | 同上 |
| **银牌商家** | 本月分数 ≥80分 | 同上 |
| **铜牌商家** | 本月分数 ≥75分 | 同上 |

- 发放方式：牌级每月1日自动发放

### 2.6 星级评价算法（美团/点评）
- **数量**：因素相同时，评价数多的商户有机会获高星
- **质量**：评价包含更多真实有效信息影响越大
- **时间**：近期新提交的评价更重要
- **诚信度**：体验后真实评价纳入计算
- ⚠️ 独立性：美团APP与点评APP星级算法互不影响，同一门店在两个平台星级可能不一致，星级每日更新

### 2.7 评价运营优选机制
- **线下服务**：优化前台接待SOP，到店登记来源渠道，避免诱导消费及过度诊疗，对美团/点评渠道用户优先接待，离店设置惊喜点提升情绪体验
- **正常评价回复**：尽量皆有回复，避免格式模板，针对性体现机构特色
- **差评响应**：及时关注提醒，第一时间联动后线确认接诊/服务人员，与用户沟通解决诉求后回复差评表达诚意

### 2.8 商户通版本及价格
- 根据POI类目选择相应商户通版本
- 版本：**商户通**（标准版）、**品牌版商户通**
- S/A/B/C/D/E为美团城市等级分类，不同城市价格不同（西安A、太原B、兰州/乌鲁木齐/银川/西宁C），开通前找渠道经理前置确认
- 费用为1年，从方案生效日起

> 📌 价格刊例详见PDF第13-14页，需找渠道经理取最新刊例

### 2.9 适用行业（专科商户通）
综合医院、妇科医院、男科医院、皮肤病医院、肛肠医疗机构、精神卫生医疗机构

## 三、推广通（美团广告模式产品 - 效果广告）

### 3.1 产品定位
> 一款能够有效**提升门店排名与进店客流**的效果广告产品。平台提供关键词竞价、出价调配等功能，以适配门店经营为目标，提供自助化和简单化的投放能力。

### 3.2 广告位资源
通过推广通，商家可通过多广告位获得海量曝光：
- **搜索广告位**：搜索结果页、频道页（用户主动搜索，黄金广告位）
- **推荐广告位**：首页信息流、门店详情页、团购详情页

### 3.3 竞价逻辑（核心）
```
排序逻辑：ECPM = 出价 × 质量度
分数越高，排序越靠前，越容易被曝光展示
```

**广告召回条件**：
- 影响因素：关键词、商户POI信息（类目）、商户详情（名称、标签、位置、评价）、泛商品（团购、预定）、星级门槛、地址位置限制
- 过滤词：品牌词、门店名等不参与广告竞价

**出价规则**：
- 按点击出价，是商户愿为单次点击支付的推广费用
- 不同城市行业有底价，出价不得低于底价
- 若竞价胜出，最终扣费以**排名第二的出价 + 1分钱**为准（GSP第二价格拍卖）

**扣费规则（不计费情况）**：
- 广告曝光不计费
- 自然点击不计费（无"广告"标识）
- 直接搜索不计费（搜索商户/门店全称）
- 商户点自己不计费（登录商户后台账号）
- 员工点击不计费（美团员工含销售）
- 恶意点击不计费（系统识别并回退）

**质量度影响因素**：
- 广告质量-预估CTR（点击数据实时回传，预估准确）
- 门店维度影响因子：**经营质量**（团单销量、门店星级、用户评论）+ **用户行为**（地理位置、历史搜索/点击/购买/停留时长）

> ⚠️ 质量度 ≠ 质量分：质量分是门店经营效果，质量度是广告质量（含预估点击率、用户行为预估等）

### 3.4 美团CPC与其他平台的差异（核心卖点）
**经营动作至关重要**，门店经营结果会影响广告竞价能力及投后转化效果，经营贯穿线上营销始终。

| 维度 | 百度 | 抖音 | 微信 | 美团 |
|------|------|------|------|------|
| 优化核心 | 关键词+素材+人群+出价 | 素材+定向 | 素材+定向 | 关键词+素材+出价+**经营质量** |
| 转化链路 | 广告单独链路 | 广告单独链路 | 广告单独链路 | **高度原生，复用门店设置，只需优化头图** |
| 效果保障 | OCPC/OCPM | OCPM | OCPC | CPC/CPM，**后端效果受门店经营影响** |

**新店/老店策略**：
- 新店：先做好基础经营再投放，避免经营差导致广告无曝光优势、展示无吸引力浪费预算
- 老店：持续经营优化，提升广告预估竞争力、提高留资/到店转化及客单价

## 四、经营优化指南（投放前基建门槛）

### 4.1 投放前：完善基建（达到可投门槛）

| 维度 | 内容 | 指标建议 |
|------|------|---------|
| **门店质量-基础信息** | 电话/地址/营业时间 | 14天内综合信息填充≥1 |

### 4.2 投放中：持续优化
- **货品质量**：调整货架分类排序；根据关键词获量调整团单名称加入核心转化词；优化团单定价

## 五、为什么要投推广通（销售必背话术）

**商户灵魂拷问**：我在美团点评上做好店铺经营，有较高经营评分、团单销量，就有很多自然量了，还需要花钱投广告吗？

### 三大价值点
1. **精准获量**：利用广告模型和算法智能预估转化人群，推荐给潜在顾客，获得精准流量曝光及转化
2. **主动承接+抢占流量**：自主竞价提升搜索结果位次，广告流量与自然流量分开排序获额外增量；新店可提前获高位次，老店可通过关键词溢价获比较优势
3. **海量资源位**：整合站内外优质资源位（搜索、频道、信息流、商详页、站外媒体），覆盖更广

### 话术参考
> "自然获客与广告获客并不冲突。您在做好店铺经营的情况下可以获得一定自然客流，但若想进一步拓量，推广通广告投放可以突破自然流量的天花板，获得额外增量的抢量和拦截。
> 一方面，您通过广告竞价、关键词溢价，能提升门店在广告结果中的展示位次，用户一搜索，排在高位的是您的店铺，还能突破竞品抢量拦截。相比自然流量，广告获量更灵活可控。
> 另一方面，推广通资源位不只有搜索结果页，还有频道页、信息流、商详页、站外媒体等优质资源位，比自然流量覆盖范围更广，能获得更多曝光和转化，这些都是纯自然流量外的增量。"

## 六、投放操作指南（销售技术面）

### 6.1 投放流程
```
进入推广通 → 设置时段和预算 → 上传推广创意 → 设置门店出价 → 设置关键词及出价 → 设置其他曝光渠道及地区 → 审核通过 → 开始投放
```

### 6.2 产品功能
| 功能 | 说明 |
|------|------|
| **高峰日预算** | 平台流量高峰日（节假日/周末）设预算涨幅承接上涨流量 |
| **系统优选** | 千人千面展现给目标用户，提高点击率 |
| **智能调价** | 参考流量转化价值实时调价，转化成本稳定前提下提升转化量，节省成本 |
| **关键词出价** | 提升精准流量下的竞争力，提升曝光及点击率 |
| **外部平台展位投放** | 一键投放至微信、头条、QQ、抖音等优质流量媒体 |

### 6.3 提升曝光量（营销漏斗-曝光）
| 影响因素 | 建议操作 | 指标建议 |
|---------|---------|---------|
| **出现范围** | 增加计划数；关键词覆盖 | 计划≥3条（含1条通投），关键词包≥3个，关键词≥20个（高线≥60） |
| **出现时间** | 全天投放；高峰期加码 | 全月稳定在线，全天投放，医疗行业夜间也有搜索 |
| **出现位置** | 参考建议出价；关键词溢价；智能调价 | 关键词出价→精准流量竞争力；智能调价溢价上限30% |
| **素材覆盖** | 不同类型素材覆盖不同资源位 | 方图1:1≥5个、横图4:3≥8个、竖图3:4≥8个 |

**日预算建议**：初期少量测试，单计划300-500元，根据预算及接待能力调整。高峰日预算涨幅≥30%。

### 6.4 提升点击率
- 设置有吸引力素材，开启系统优选
- 关键词质量过硬 + 长期经营，展示项指标优异
- 第一屏位置对转化加成最高，后几屏递减

### 6.5 建议出价理解（常见疑问）
- **同商圈不同建议出价**：受门店广告质量分、经营情况影响
- **实际位次与建议位次不同**：建议出价仅参考，实际受竞价环境、用户喜好影响
- **建议出价常变化**：实时竞价，同类目商户调整出价

## 七、广告投放效果评估（ROI核心）

### 7.1 商户眼中的广告效果
```
ROI = 广告带来的订单金额 / 投放广告的消耗
```
**多数商户ROI口径**：
- 时间维度：只看当月，不做长周期归因
- 客户维度：只看当月点击的新客及首单

### 7.2 长周期归因案例
- 用户2月点击广告→3月到店消费→后续多次消费，只有**广告点击当月的首单**计入ROI分子
- 会造成平台用户质量/收益被低估

### 7.3 销售的启发
作为销售要了解清楚3要素：
1. 客户的ROI口径是什么（分子）
2. 归因窗口期是多久
3. 是否统计非首单

**拉齐口径后**对比各平台ROI才公平。当客户问"为什么你们ROI不如XX媒体"，先对齐口径。

### 7.4 ROI保障的边界（重要话术）
客户要求ROI≥2合理吗？——**不完全合理，不建议保障广告ROI**
1. 推广通保障的是**点击成本**，点击后的转化系统不能直接保障
2. 点击后效果受商户营销能力影响，不受广告算法控制
3. 广告模型优化ROI需获取转化数据，目前未打通回传，不具备学习预估优化能力

**话术参考**：
> "咱们推广通现在是点击出价模式，系统和模型直接保障的是点击成本。我们可以通过广告点击人群获取上的优化，尽可能提高后续成单率和消费金额，但用户到店消费受很多因素影响，比如线上店铺装修、网咨话术能力、线下营销服务能力。所以推广通投放主要是通过获取相对精准的点击人群，来提高后续付费转化的概率。"

### 7.5 关键指标公式
**预算去化角度**：收入 = 预算 × 预算消耗比（预算消耗比 = 消耗/可用预算）
**广告转化链路**：收入 = 曝光 × 点击率 × 点击均价(ACP)

**监控阈值**：
- 消耗波动20%以内、CTR波动0.5pp以内可忽略
- 超阈值与商户沟通调整
- 持续超3天提报TT排查

## 九、销售融合建议（对百都系统）

### 9.1 产品组合逻辑
1. **先商户通后推广通**：先帮客户做好线上经营基建（装修/商品/评分/口碑），再推推广通广告投放
2. **商广联动**：经营好→广告效果好→形成正循环
