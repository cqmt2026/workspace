## 一、抖音本地推

### 1.1 产品定位
抖音本地生活服务平台，覆盖餐饮、酒店、休闲娱乐、美容美发、教育培训等本地生活服务业态。

### 1.2 核心卖点
- **流量大**：日活7亿+，年轻人聚集
- **内容原生**：短视频+直播，用户接受度高
- **精准定向**：LBS定位+兴趣标签
- **转化闭环**：团购直接下单，到店核销

### 1.3 目标客户
- 餐饮店、火锅店、烧烤店
- 酒店、民宿
- 美容美发、医美机构
- 教育机构、培训班
- 健身房、瑜伽馆

### 1.4 销售话术

**开场白**：
```
"王总您好，我是百都科技小度。我们看到您在抖音上还没有开通本地推，但您周边的XX餐厅、XX酒店已经在抖音上投放了，效果还不错。

想跟您聊聊，你们现在主要靠什么渠道获客？老客户介绍多还是线上平台多？"
```

**痛点挖掘**：
```
"现在年轻人找餐厅、找玩法，第一步都是打开抖音搜'附近的美食'、'附近的好玩的'。如果他们在抖音上搜不到您，就等于把年轻客户让给了竞争对手。

而且抖音本地推是按效果付费的，曝光免费，只有用户点击或下单才收费，风险可控。"
```

**促单话术**：
```
"建议您先测试一个月，预算3000-5000元，看看实际效果。抖音本地推的转化链路很短——用户看到视频→点击团购→下单→到店核销，整个过程不到3分钟。

我们刚合作的一家火锅店，投放一个月带来了200多单团购，核销率60%以上，ROI能做到1:5。"
```

## 二、快手本地生活

### 2.1 产品定位
快手本地生活服务平台，覆盖下沉市场（三四线城市及县域），用户年龄偏偏低龄、消费能力强。

### 2.2 核心卖点
- **下沉市场王者**：三四线城市渗透率高
- **老铁文化**：用户信任度高，复购率高
- **性价比**：投放成本低于抖音30-50%
- **直播间转化**：直播带货+本地团购

### 2.3 目标客户
- 县域餐饮、农产品
- 三四线城市美容美发
- 本地生活服务商
- 农产品/特产商家

### 2.4 销售话术

**开场白**：
```
"李总您好，我是百都科技小度。我们发现您在快手上的曝光很少，但您周边的竞争对手已经在快手上做本地推广了。

快手在三四线城市的渗透率非常高，很多县城用户日常刷快手比刷抖音还多。您有没有考虑过在快手上做推广？"
```

**差异化话术**：
```
"快手和抖音最大的区别是——快手用户更信任主播，复购率更高。而且快手投放成本比抖音低30-50%，性价比更高。

如果您主要服务的是县城客户，快手可能是更好的选择。"
```

## 三、小红书种草

### 3.1 产品定位
小红书是年轻女性的生活方式平台，适合美妆、服饰、母婴、旅游、餐饮等消费品类。

### 3.2 核心卖点
- **女性用户为主**：18-35岁女性占比70%+
- **种草能力强**：用户主动搜索攻略、评测
- **搜索属性**：小红书已成为第二搜索引擎
- **长尾效应**：笔记发布后持续曝光

### 3.3 目标客户
- 美妆品牌、化妆品
- 服饰、鞋帽
- 母婴用品
- 旅游、酒店
- 餐饮、奶茶店
- 医美、口腔

### 3.4 销售话术

**开场白**：
```
"张总您好，我是百都科技小度。我注意到您在小红书上还没有布局，但您的目标客户（年轻女性）正在小红书上搜索'重庆美白'、'重庆牙齿矫正'等内容。

小红书现在已经是年轻人找攻略的第一站，很多用户在小红书看完笔记后才会去线下消费。"
```

**价值阐述**：
```
"小红书的种草逻辑是——用户看到真实测评→产生兴趣→搜索品牌→线下消费。这个链路比传统广告更自然，转化率也更高。

而且小红书的笔记有长尾效应，一篇优质笔记可以持续曝光几个月甚至几年。"
```

## 五、组合策略


## 六、异议处理

**异议1："我们没有预算做抖音"**
```
"抖音本地推最低3000元就能测试一个月，而且按效果付费，曝光免费。您可以先小规模测试，看到效果再加大投入。"
```

**异议2："我们不做C端，做B端"**
```
"即使是B端企业，决策人也是普通人，也会刷抖音、看小红书。而且您的竞争对手可能已经在上面布局了。"
```

**异议3："我们试过了，效果不好"**
```
"效果不好可能是因为内容不够吸引人，或者定向不准。我们可以帮您优化内容和定向策略，重新测试。"
```
