## 资料使用说明

### 电话销售场景
1. 先读 `knowledge/销售流程/异议处理库.md` — 开场白+异议处理
2. 再读 `knowledge/产品/产品速查表.md` — 快速查价格
3. 遇到ROI问题 → 读 `knowledge/销售流程/ROI算账模型.md`

### 拜访/面谈场景
1. 先看 `knowledge/产品/百度产品矩阵.md` — 了解全产品线
2. 结合行业数据做方案
3. GEO相关用 `knowledge/产品/GEO认知.md`

### 客户跟进
1. 异议类型 → 查异议处理库对应章节
2. 行业问题 → 查对应行业知识
3. 产品对比 → 查产品矩阵
