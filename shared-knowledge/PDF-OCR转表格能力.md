# PDF扫描件OCR转表格能力

> 创建日期：2026-10-11
> 状态：已验证可用 ✅
> 适用场景：扫描件PDF转结构化Excel

## 核心能力

将扫描件PDF（如政府公示名单、统计数据表等）转换为带完整字段的Excel表格。

---

## 标准流程（单脚本完成）

```python
# 脚本位置: scripts/ocr_enhanced.py
# 用法: python scripts/ocr_enhanced.py

# 流程:
# 1. PyMuPDF打开PDF，逐页转图片(dpi=150)
# 2. PIL增强：对比度×1.5 + 锐度×2.0
# 3. RapidOCR识别文字+坐标
# 4. 按y坐标分组为行，按x坐标分组为列
# 5. 正则匹配：信用代码/名称/地址/法人/类别/分数
# 6. 碎片拼接："司"等单独行与前一行合并
# 7. 相邻行补全缺失字段
# 8. 输出Excel+CSV
```

## 字段解析规则

| 字段 | 正则/规则 | 示例 |
|------|----------|------|
| 统一社会信用代码 | `^[0-9A-Z]{18}$` | 91500107060503830Y |
| 机构名称 | 含"公司/事务所/中心"，长度>4 | 重庆XX科技有限公司 |
| 地址 | 含"市/区/路/号"，不含"公司" | 重庆市九龙坡区... |
| 法定代表人 | `^[\u4e00-\u9fa5]{2,4}$` | 王勤 |
| 机构类别 | 含"代理记账/税务师/会计师" | 代理记账机构 |
| 信用分 | `^\d{2,3}\.\d{1,2}$`，范围100-500 | 446.45 |
