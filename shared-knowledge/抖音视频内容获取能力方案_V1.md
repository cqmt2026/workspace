# 抖音视频内容获取能力方案

> 版本：V1.0  
> 创建时间：2026-09-13  
> 适用子系统：主系统、百都代理、地图热点、自媒体、投资等

---

## 一、能力概述

本方案提供从抖音视频链接到结构化内容的完整获取能力，包括：
- 视频元数据提取（标题、作者、互动数据）
- 音频转写（Whisper本地/在线API）
- ASR错误修正（LLM辅助）
- 核心内容提炼
- 海报生成

---

## 二、技术架构

```
┌─────────────────────────────────────────────────────────────┐
│                    抖音视频内容获取管线                        │
├─────────────────────────────────────────────────────────────┤
│  输入：抖音短链（https://v.douyin.com/xxx/）                  │
│                       ↓                                     │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  Step 1: URL解析 → 提取video_id                     │   │
│  └─────────────────────────────────────────────────────┘   │
│                       ↓                                     │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  Step 2: API调用 → 获取视频元数据                    │   │
│  │         (需有效Cookies)                              │   │
│  └─────────────────────────────────────────────────────┘   │
│                       ↓                                     │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  Step 3: 视频下载 → FFmpeg音频提取                   │   │
│  └─────────────────────────────────────────────────────┘   │
│                       ↓                                     │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  Step 4: 语音转写 → Whisper Base/Medium             │   │
│  │         (本地CPU模式，或在线API)                       │   │
│  └─────────────────────────────────────────────────────┘   │
│                       ↓                                     │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  Step 5: ASR修正 → DeepSeek LLM修正同音字            │   │
│  │         (可选，需有效API Key)                          │   │
│  └─────────────────────────────────────────────────────┘   │
│                       ↓                                     │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  Step 6: 内容提炼 → 核心要点提取                      │   │
│  │         (LLM总结或规则提取)                            │   │
│  └─────────────────────────────────────────────────────┘   │
│                       ↓                                     │
│  输出：结构化JSON + Markdown报告 + 海报图片                 │
└─────────────────────────────────────────────────────────────┘
```

## 六、各子系统调用指南

### 6.1 百都代理子系统

**适用场景**：竞品分析、客户案例视频获取

```python

from douyin_pipeline import DouyinContentPipeline

pipeline = DouyinContentPipeline()
result = pipeline.run("https://v.douyin.com/xxx/")
```

## 七、错误处理

| 错误类型 | 原因 | 处理方案 |
|----------|------|----------|
| API 401 | Cookies过期 | 重新导出Cookies |
| API 403 | IP被封 | 等待或更换网络 |
| Whisper内存不足 | Medium模型 | 改用Base模型 |
| 下载失败 | 链接失效 | 检查URL格式 |
| 转写超时 | 音频过长 | 分段转写 |
