## 陷阱详情

### T001: 路径检查错误

**现象：** 检查小说系统时只看output目录，没看项目目录

**根因：** 路径检查不完整

**修复：**
```python
# 错误做法
if not os.path.exists(novel_output):
    print("无产出")

# 正确做法
project_dir = os.path.join(workspace, "项目一：鉴城师")
if os.path.exists(project_dir):
    files = os.listdir(project_dir)
    # 检查实际文件
```

---

### T002: 记录文件内容为空模板

**现象：** 看到usage_20260927.md就说是"今日使用"，但内容是空模板

**根因：** 只看文件名不看内容

**修复：**
```python
# 错误做法
if os.path.exists(usage_file):
    print("今日有使用记录")

# 正确做法
with open(usage_file, 'r', encoding='utf-8') as f:
    content = f.read()
if content.strip() and content != TEMPLATE:
    print("今日有实际使用记录")
else:
    print("记录为空模板")
```

---

### T003: data_api导入错误

**现象：** `from scripts.data_api import DataAPI` 报错

**根因：** data_api是目录（包），不是文件

**修复：**
```python
# 错误做法
from scripts.data_api import DataAPI

# 正确做法
from data_api import DataAPI
api = DataAPI()
```
