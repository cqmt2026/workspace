## 陷阱详情

### T001: 路径检查错误

**现象：** 检查小说系统时只看output目录，没看项目目录

**根因：** 路径检查不完整

**修复：**
```python
# 错误做法
if not os.path.exists(novel_output):
    print("无产出")

# 正确做法
project_dir = os.path.join(workspace, "项目一：鉴城师")
if os.path.exists(project_dir):
    files = os.listdir(project_dir)
    # 检查实际文件
```

---

### T002: 记录文件内容为空模板

**现象：** 看到usage_20260927.md就说是"今日使用"，但内容是空模板

**根因：** 只看文件名不看内容

**修复：**
```python
# 错误做法
if os.path.exists(usage_file):
    print("今日有使用记录")

# 正确做法
with open(usage_file, 'r', encoding='utf-8') as f:
    content = f.read()
if content.strip() and content != TEMPLATE:
    print("今日有实际使用记录")
else:
    print("记录为空模板")
```

### T003: data_api导入错误

**现象：** `from scripts.data_api import DataAPI` 报错

**根因：** data_api是目录（包），不是文件

**修复：**
```python
# 错误做法
from scripts.data_api import DataAPI

# 正确做法
from data_api import DataAPI
api = DataAPI()
```

## 检查清单（执行前必跑）

- [ ] 路径验证：所有路径用`os.path.exists()`确认
- [ ] 内容验证：读文件内容而非只看文件名
- [ ] 导入验证：包vs文件区分清楚
- [ ] 产出验证：检查实际产出文件内容
- [ ] 依赖验证：外部模块用`importlib`检查



### T015: 工具调用失败（2026-10-18）
**触发条件**：编写复杂Python/Shell命令时
**症状**：单行命令语法错误，执行失败
**修复方案**：
- 复杂操作（>3行）先写脚本文件，再执行
- 使用write工具创建.py文件，再用exec运行
- 避免在一行命令中嵌套过多逻辑

### T016: Windows路径处理错误（2026-10-18）
**触发条件**：处理文件路径时
**症状**：路径拼接错误，文件找不到
**修复方案**：
- Windows统一用`os.path.join()`，不用字符串拼接
- 路径分隔符用正斜杠`/`或双反斜杠`\\`
- 使用raw string：`r'C:\path\to\file'`

### T017: 删除操作风险（2026-10-18）
**触发条件**：执行rm/rmdir/shutil.rmtree操作前
**症状**：误删重要文件，数据丢失
**修复方案**：
- **任何删除操作前必须主人确认**
- 先备份再删除
- 使用`os.path.exists()`确认目标存在
- 删除后验证结果

### T018: 上下文管理混乱（2026-10-18）
**触发条件**：多任务并发执行时
**症状**：状态混乱，结果不确定
**修复方案**：
- 每步完成后主动汇报进度
- 避免同时启动多个后台任务
- 使用process/poll监控后台任务状态
- 单线程顺序执行更可靠
