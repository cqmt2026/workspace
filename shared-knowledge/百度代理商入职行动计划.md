# 百度代理商入职行动计划

> 生成时间：2026-08-21
> 用途：入职前准备 + 90天行动路线图
> 方法论：第一性原理拆解 → Ponytail收缩 → 可执行任务清单

---

## 一、第一性原理拆解

### 根因分析（5个为什么）

**问题**：入职百度代理商，如何应对挑战？

- Why 1：为什么要入职百度代理商？
  → 想进入ToB销售/互联网营销行业，积累企业客户资源

- Why 2：为什么选百度代理商而不是其他？
  → 门槛相对低、有培训体系、认为百度品牌还有市场

- Why 3：为什么百度代理商还有市场？
  → 百度搜索日均3亿次，B2B采购场景有真实需求，中小企业认知停留在"推广=百度"

- Why 4：为什么中小企业还在用百度？
  → 对他们来说，抖音/小红书运营门槛更高，百度最简单粗暴——给钱就上排名

- Why 5：为什么这个模式能持续？
  → **不能持续**。百度流量萎缩，用户习惯迁移，AI压缩广告位价值。吃存量，不做增量。

### 结论

入职的不是增长型行业，是**衰退型行业里的存量博弈**。

### 不可跨越的物理定律

- 百度搜索流量持续下降（日均3亿 vs 抖音53亿）
- 用户内容消费从"搜"转向"刷"和"问"
- AI直接回答问题，减少对搜索结果的点击
- 百度代理商（湖北世纪百捷/江苏青之峰）已经批量倒闭

### 可以打破的人为规定

- ❌ "销售就是打电话+拜访" → 可以做内容获客、行业垂直深耕
- ❌ "只能卖百度产品" → 可以研究竞品，帮客户做跨渠道决策
- ❌ "等公司分配客户" → 可以主动从源头获客（抖音、线下、行业社群）
- ❌ "提成主要靠新开户" → 可以把老客户续费+代运营做成主收入

## 二、重新定义角色

**不是**"百度推广销售"
**而是**"中小企业数字化获客顾问"

百度只是工具之一，真正卖的是：
- 获客能力
- 行业认知
- 可迁移的方法论

---

## 三、裂缝分析：理论最优 vs 行业现实

| 维度 | 理论最优 | 百度代理商现状 | 裂缝（发力点） |
|------|---------|--------------|-------------|
| 销售角色 | 获客顾问 | 广告位销售 | 做顾问而不是做推销 |
| 产品组合 | 全渠道方案 | 只卖百度产品 | 懂竞品，帮客户做组合决策 |
| 客户关系 | 长期伙伴 | 一锤子买卖 | 做代运营、做续费 |
| 行业深耕 | 懂行业懂客户 | 广撒网 | 选1-2个行业深耕（光伏等） |
| 收入模式 | 服务费+运营分成 | 开户提成 | 代运营复利 |

## 四、Ponytail最少可行方案

**最小可行动作**：
- 入职前准备：1周
- 产品吃透：爱采购 + 信誉认证（2个产品足够）
- 行业选择：光伏（已有积累，有优势）
- 止损线：3个月没开单就退出，不恋战

**能砍掉什么**：
- ❌ 不要学所有百度产品
- ❌ 不要一开始就想做全渠道代运营
- ❌ 不要贪多客户，先做透一个行业
- ❌ 不要等公司派任务，主动出击

## 五、详细行动路线图

### 阶段一：入职前准备（现在→入职第1天）

| 任务 | 具体动作 | 时间 | 产出 |
|------|---------|------|------|
| 信息收集 | 找2-3个在职百度代理商销售，问真实情况：提成比例、续费率、客户来源、最头疼的问题 | 1-2天 | 真实画像 |
| 产品自学 | 读百度爱采购官方文档（b2b.baidu.com/help），理解入驻流程、权益、收费标准 | 1天 | 产品知识卡片 |
| 行业研究 | 整理光伏行业关键词：政策热点、主要玩家、客户痛点、竞争对手打法 | 1天 | 光伏获客思维导图 |
| 竞品了解 | 搜抖音/头条上光伏获客的爆款内容，记录3个案例的结构和话术 | 0.5天 | 竞品参考库 |
| 话术准备 | 写一段30秒自我介绍+产品价值陈述，对着镜子练10遍 | 0.5天 | 自我介绍脚本 |

**止损点**：准备过程中发现完全不适合自己，及时止损。

### 阶段二：入职第1-30天（学习期）

#### 第1周：熟悉环境

| 任务 | 具体动作 | 检验标准 |
|------|---------|---------|
| 熟悉产品 | 把爱采购、信誉认证、百度推广三种产品弄懂：卖给谁、为什么买、怎么卖 | 能向陌生人讲清楚三种产品的区别 |
| 熟悉系统 | 学会用后台操作：开户流程、关键词添加、数据看板 | 能独立完成一次爱采购开户演示 |
| 熟悉客户 | 读公司给的现有客户名单，记录每个客户的行业、规模、历史沟通记录 | 能说出3个重点客户的画像和痛点 |
| 旁听电话 | 跟着老销售打10个电话，只观察不说话，记录开场白、应对异议的方式 | 写出"老销售的话术模板"笔记 |

#### 第2-4周：上手练习

| 任务 | 具体动作 | 检验标准 |
|------|---------|---------|
| 模拟演练 | 拿自己的光伏客户名单，模拟打电话/拜访，录下来自己复盘 | 能找到至少3个自己的表达问题 |
| 老客户维护 | 申请跟老销售一起维护几个老客户，记录客户关心的问题和决策流程 | 搞懂一个客户从了解到成交的完整路径 |
| 行业深耕 | 选1个细分行业（比如"分布式光伏"），吃透这个行业的搜索词、竞争格局、客户决策链 | 写出该行业的"获客作战地图" |
| 竞品对标 | 找一个抖音/头条上做光伏获客的同行，拆解他们的内容策略 | 能说出3个竞品打法和自己可以借鉴的点 |

#### 第30天复盘

- 开单了吗？开了多少？
- 老客户续费谈下来了几个？
- 自己最大的卡点是什么？
- 继续干还是止损？

---

### 阶段三：第31-60天（突破期）

**核心目标**：开第1单，跑通从接触到成交的闭环。

| 任务 | 具体动作 | 检验标准 |
|------|---------|---------|
| 主动获客 | 从源头找客户：光伏论坛/社群/展会现场，添加潜在客户微信，发有价值的内容而不是硬广 | 添加50个光伏行业潜在客户微信 |
| 案例打造 | 把前30天接触的某个潜在客户，用完整的获客思路说服他开户（哪怕是小单） | 签下第1个客户 |
| 内容输出 | 在朋友圈/社群分享光伏获客干货，建立专业人设 | 发10条有价值的行业内容 |
| 续费攻坚 | 主动联系3个即将到期的老客户，分析续或不续的原因，尝试挽回 | 争取到至少1个续费 |
| 方法沉淀 | 把整个开单过程写成案例笔记 | 输出1份完整的开单案例 |

#### 第60天复盘

- 开了几单？续费了几个？
- 哪类客户最容易成交？
- 自己的获客方式有没有跑通？
- 要不要调整行业或产品方向？

---

### 阶段四：第61-90天（验证期）

**核心目标**：验证自己是否适合这个方向，建立可持续的获客模式。

| 任务 | 具体动作 | 检验标准 |
|------|---------|---------|
| 规模化尝试 | 把第31-60天跑通的开单方法，复制到其他客户 | 月开单≥2个 |
| 跨渠道能力 | 主动研究抖音/视频号光伏获客打法，能和客户聊跨渠道方案 | 能输出1份"百度+短视频"组合获客方案 |
| 人设建立 | 在行业内建立"光伏获客专家"的认知，让客户愿意主动找你 | 有客户通过内容/转介绍主动联系你 |
| 复盘决策 | 90天整体复盘：收入、客户数、能力成长、行业认知 | 做出明确判断：继续干 or 换赛道 |

#### 90天复盘决策矩阵

| 条件 | 继续干 | 止损换赛道 |
|------|--------|-----------|
| 月均开单≥2个 | ✅ 继续深耕 | |
| 月均开单1个 | ⚠️ 看收入，如果勉强养活可以继续 | |
| 月均开单0个 | | ❌ 3个月止损，换方向 |
| 老客户续费率≥30% | ✅ 说明产品有真实价值 | |
| 老客户续费率<10% | | ❌ 产品本身有问题，换赛道 |
| 自己享受这个过程 | ✅ 坚持 | |
| 每天都很痛苦想逃 | | ❌ 性格不匹配，换方向 |

---

### 阶段五：第91天以后（两个方向）

#### 如果通过验证

1. **深耕行业**：把光伏获客做到行业内口碑，横向复制到新能源、储能等相邻行业
2. **扩展能力**：从"百度销售"升级为"企业数字化获客顾问"，加入抖音/视频号/小红书渠道
3. **跳板思维**：积累客户资源和行业认知后，跳到甲方做企业方的获客负责人，或者自己出来做获客服务商

#### 如果止损

1. **带着认知离开**：3个月你已经比99%的人更懂"企业获客是怎么回事"
2. **把经历写进简历**：ToB销售经验、客户运营、行业认知，都是可迁移的能力
3. **换赛道建议**：
   - 喜欢行业研究但不擅长销售 → 转到咨询/分析岗
   - 喜欢内容创作 → 转去做短视频获客

| 风险 | 概率 | 应对 |
|------|------|------|

## 八、核心信念

**这不是"找工作"，是"做一次商业实验"**

- 实验假设：我能否在百度代理商这个环境下，跑通ToB获客闭环？
- 检验标准：3个月开单数、续费率、客户满意度
- 止损线：3个月0单 → 退出，不恋战
- 无论结果如何，带得走的是：**行业认知 + 客户资源 + 获客方法论**

### 11.2 效果推广产品详解

#### ① 搜索推广（SEM）

**是什么**：用户搜索关键词时，在搜索结果页展示广告，按点击付费。

**计费方式**：CPC（按点击付费），最低50元/天可启动测试

**流量来源**：百度搜索首页结果页（前4条为广告位）

**核心优势**：
- 用户有明确搜索意图，转化率高
- 关键词精准定向，只触达目标人群
- AI智能出价（oCPC/oCPM），自动优化转化成本
- 实时数据可追踪，效果可控

**适合客户**：
- B2B制造企业（工业设备、原材料）
- 服务类企业（教育培训、法律咨询）
- 有明确产品关键词的企业

**竞价机制**：
- 实际扣费 = 下一名出价 × 下一名质量度 ÷ 你的质量度 + 0.01元
- 质量度越高，实际扣费越低
- 质量度取决于：创意相关性 + 落地页体验 + 账户历史表现

**开户成本**：
- 认证费：600元
- 预存推广费：最低5000元起
- 技术服务费：0元（2023年取消）
- 总开户成本：约5600元起

**关键数据**：
- 日均搜索量：超70亿次
- 月活用户：7.24亿
- 制造业平均CPC：约28.7元/次（2026年数据）
- 精准询盘转化率：约1.8%（制造业）

---

#### ② 信息流推广

**是什么**：在百度APP、贴吧、好看视频等平台的资讯流中穿插原生广告，"广告即内容"。

**计费方式**：OCPC（按转化出价）+ CPC（按点击付费）

**流量来源**：
- 百度APP信息流（月活7.24亿）
- 百度贴吧（全域DAU 8000万）
- 好看视频（人均使用时长80分钟）
- 百度联盟（外部合作媒体）

**核心优势**：

```
来的都是有采购意图的客户。我可以帮您看看之前的数据，
分析一下问题出在哪。"
```

#### 异议3："太贵了，6980不是小数目"
```
回应："我帮您算笔账：一个光伏项目订单几十上百万，
6980一年，如果能带来1-2个意向客户，投入产出比是1:100以上。
而且这不是纯广告，是入驻平台，有持续曝光。您算的是单次投入，
我算的是年度获客成本，平均到每个月不到600块。"
```

#### 异议4："我再考虑考虑"
```
回应："没问题，考虑是应该的。我加您微信，发一份光伏行业
的百度获客案例给您看看，您参考一下。另外想问您，
主要是考虑哪方面？是预算还是效果？我可以针对性解答。"
```
（目的：不挂断，获取更多信息，为跟进留口子）

#### 异议5："我们已经有抖音/头条在做了"
```
回应："那很好，说明您有数字化获客的意识。百度和爱采购是
 complementary的——抖音是做品牌认知，百度是做精准获客。
很多客户是抖音种草、百度搜索、然后成交。我可以帮您
 做个跨渠道的获客方案，让各个平台互相引流。"
```
（目的：不否定竞品，展示专业度）

### 11.5 面试反问清单（补充版）

**必问问题（决定去不去）：**
- [ ] 新人第一个月有培训吗？培训多久？谁带？
- [ ] 客户资源怎么分配？新人能拿到多少新客线索？
- [ ] 提成制度具体怎么算？新客和续费的分成比例？
- [ ] 有老销售带的mentorship吗？带多久？
- [ ] 公司目前光伏行业的客户有多少？转化情况如何？

**可选问题（了解公司）：**
- [ ] 公司今年的业绩目标是什么？
- [ ] 团队规模和分工是怎样的？
- [ ] 有没有代运营团队？销售需要配合做什么？
- [ ] 客户续费率的平均水平是多少？
- [ ] 优秀销售的月收入和他们的共同特点是什么？

**避坑问题（判断公司靠不靠谱）：**
- [ ] 试用期多久？试用期有底薪吗？
- [ ] 有没有业绩考核指标？不达标会怎样？
- [ ] 客户资源是保护期制的吗？保护期多长？
