# 百度投放快速判断能力

> 能力说明：当主人给一个客户名称后，我直接执行以下步骤，快速判断客户是否已投放百度
> 用途：不浪费主人时间，直接给结果

---

## 判断流程（4步，30秒内完成）

### Step 1: 搜索"客户名"看搜索结果
```python
# 我直接 web_search 客户名称：
# 搜"客户名" → 看前3条
# 如果有广告位出现竞品，说明客户没投或投得弱
# 如果客户品牌专区出现，说明已投品专
# 如果客户官网自然排名靠前，说明有SEO基础
```

### Step 2: 搜索"行业词+厂家/供应商"看爱采购
```python
# 搜"客户行业词 厂家" → 看前3页
# 如果有客户的爱采购店铺，说明已入驻
# 如果没有，说明未入驻
```

### Step 3: 搜索"客户名+百度/推广"验证
```python
# 搜"客户名 百度推广" → 看讨论区/投诉
# 如果有客户说"百度推广没效果"之类的讨论，说明投过
# 如果没有任何提及，说明大概率没投
```

### Step 4: 综合判断
```python
# 四种结果：
# 1. 已投放（搜索有广告/品牌专区/爱采购店铺）
# 2. 已投放但效果差（搜索排名靠后/没人提及）
# 3. 未投放但适合（B2B制造业/本地服务/教育等）
# 4. 不适用（纯C端快消品/垄断行业等）
```

---

## 使用示例

**主人说：** "看看XXX公司"
**我执行：**
1. web_search("XXX公司") → 检查前3条
2. web_search("XXX公司 厂家") → 检查爱采购
3. 综合判断 → 给出结论

**我回复格式：**
```
✅ [客户名] 投放判断结果
- 投放状态：未投放 / 已投放 / 效果差
- 最匹配产品：爱采购/搜索推广/信息流
- 推荐理由：一句话
- 销售话术：一句话
```

---

## 限制

- 如果客户名太常见（如"光明"），需要加场景词限定
- 如果客户是新注册公司，可能搜不到线上信息
- 如果客户是商标/品牌名，搜索推广结果可能不准确
