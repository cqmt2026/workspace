# 百度代理商电话销售话术手册

> 用途：电话开发客户的完整话术库
> 场景：ToB客户（光伏/制造业为主）
> 版本：v1.0 | 2026-08-22

---

## 核心原则

### 1. 通话时长控制
| 阶段 | 时间 | 目标 |
|------|------|------|
| 开场破冰 | 0-15秒 | 让对方不挂电话 |
| 需求挖掘 | 15-60秒 | 了解客户现状和痛点 |
| 方案推荐 | 60-120秒 | 匹配产品，算账 |
| 异议应对 | 按需 | 化解顾虑 |
| 收尾推进 | 最后15秒 | 约下次沟通或加微信 |
| **总时长** | **2-3分钟** | 完成一个闭环 |

### 2. 三个"绝对不能做"
- ❌ 绝对不能一上来就报价（会被直接挂断）
- ❌ 绝对不能只说"我是百度代理的"（像诈骗电话）
- ❌ 绝对不能推销感太重（像骚扰电话）

### 3. 正确的通话姿态
- ✅ 我是来帮您解决问题的，不是来卖东西的
- ✅ 专业顾问的角度，站在客户立场分析
- ✅ 语气自然，像朋友聊天，不像销售念稿

## 一、开场白话术库

### 版本A：直接型（适合制造业老板）
```
"王总您好，我是百度代理商的小刘。
这边看到咱们是做XX设备的，想跟您聊一下，
现在您这边新客户主要是通过什么渠道过来的？
是展会多还是线上搜索？"
```
**要点：**
- 先问问题，让对方开口
- 问题简单，不需要思考就能回答
- 一旦对方开口，电话就不会挂

### 版本B：调研型（适合不太确定要不要做推广的客户）
```
"陈总您好，我是百度那边的。
最近我们在做重庆制造业的线上获客调研，
想请教一下，咱们公司现在线上渠道做得怎么样？
大概每年在推广这块投入多少？"
```
**要点：**
- "请教"姿态，降低防备
- 调研名义，不是推销
- 顺势了解预算范围

### 版本C：案例型（适合已有竞对的行业）
```
"张总您好，我是百度代理商的小刘。
最近我们在服务一家做XX设备的厂家，
他们接入百度爱采购之后，询盘量增长了55%。
我搜了一下，发现同行业有几家已经在爱采购上了，
想跟您聊聊有没有兴趣了解一下。"
```
**要点：**
- 案例背书，建立信任
- 暗示竞品在做，制造紧迫感
- 不给压力，只是"聊聊"

### 版本D：痛点型（适合百度做过但没效果的）
```
"李总您好，我是百度代理商的小刘。
之前咱们公司试过百度推广对吧？
最近很多客户反馈说推广效果不如以前了，
 CPC从5块涨到快30块，转化率也掉了很多。
我这边想了解一下具体情况，看看能不能帮到您。"
```
**要点：**
- 知道客户做过，降低防备
- 说出真实痛点（CPC上涨），建立共鸣
- "帮到您"而不是"再卖你"

## 二、需求挖掘话术

### 追问1：了解客户现状
```
"您现在主要通过什么渠道获客？
是老客户介绍多，还是展会，还是线上？"
```
**根据回答继续追问：**
- 如果答"老客户介绍多" → "那新客户从哪来？有没有计划拓展新客户渠道？"
- 如果答"展会" → "展会效果怎么样？成本高吗？一年大概参加几个？"
- 如果答"线上有在做" → "主要在哪些平台？效果如何？"

### 追问2：了解客户痛点
```
"现在获客最大的困难是什么？
是线索不够，还是来了线索转化率低？
还是成本太高，不划算？"
```
**根据回答继续追问：**
- 如果答"线索不够" → "平均一个月能接到多少条有效线索？目标是多少？"
- 如果答"转化率低" → "来的线索质量怎么样？主要是价格敏感的多，还是有明确需求的？"
- 如果答"成本高" → "现在哪个渠道成本最高？平均一个线索多少钱？"

### 追问3：了解预算范围
```
"您这边每年在推广这块大概有多少预算？
是想先试试水，还是已经有计划要大力投入？"
```
**根据回答判断客户等级：**
- "先试试水" → 轻度客户，推爱采购6980起步
- "有计划" → 中度客户，推组合方案
- "想大力投入" → 重度客户，推全方案

### 追问4：了解决策流程
```
"这个推广的事，是您需要向谁汇报？
是老板直接定，还是需要走流程？"
```
**根据回答：**
- "老板直接定" → 直接跟决策人聊
- "需要汇报" → 了解汇报对象，准备材料
- "走流程" → 了解流程和周期，不要催促太紧

## 三、产品推荐话术

### 场景1：推荐爱采购（最适合制造业）
```
"王总，根据您的情况，我建议您可以先试试爱采购。
6980一年，在百度B2B平台上开店，
客户搜'XX设备厂家''XX供应商'，您的店铺就能出现在搜索结果里。
而且现在爱采购有AI客服，24小时自动接待客户询盘，
不用专门雇人坐那接电话。

我帮您搜了一下，同行业已经有几家在爱采购上了，
但您的品牌还没出现，正好是个机会。"
```
**关键词：**
- 具体数字（6980、24小时）
- 痛点匹配（AI客服解决人力问题）
- 机会暗示（竞品在做了，你没做）

### 场景2：推荐搜索推广（适合有明确搜索需求的）
```
"张总，您说客户都是主动来找你们的，这个需求很明确。
搜索推广就是捕捉这种主动需求的——
客户搜'XX厂家''XX价格'，您的广告就出现在前面。

最低5000块预存，按点击付费，
客户点一下才扣费，不点不花钱。
我先帮您测试两周，看关键词效果，
数据出来了再决定要不要加大投入，这样风险可控。"
```
**关键词：**
- 低风险（5000元起，按效果付费）
- 可控性（先测试两周，看数据）
- 数据驱动（用效果说话）

### 场景3：推荐组合方案（适合有一定预算的）
```
"李总，您的情况我建议做组合：
爱采购6980一年负责B2B采购入口，
搜索推广5000预存起负责关键词精准获客，
两个产品加起来，一年1万多，
一个光伏项目订单几十万，ROI是正向的。

我帮您算一下：假设爱采购一年带来3个意向客户，
其中1个成交，一个项目订单30万，投入产出比是30:1。
您觉得这个账合理吗？"
```
**关键词：**
- 具体算账（让客户自己算）
- 对比锚点（一个项目订单就够）
- 反问确认（你觉得合理吗？）

### 场景4：推荐信息流（适合教育/本地服务）
```
"刘总，您做的是职业技能培训，
客户不一定主动搜'焊工证培训'，
更多是在刷手机的时候被种草。

信息流就是在百度APP里推，
定向25-45岁、有职业需求的人群，
不用客户主动搜，系统自动找到目标客户。

我建议您先小预算测试，
每周投1000块，看转化率再调整。"
```
**关键词：**
- 场景描述（客户刷手机时）
- 精准定向（年龄+人群+需求）
- 小预算测试（降低决策门槛）

## 四、异议应对话术

### 异议1："我没兴趣/不需要"
```
"理解，可能现在时机还没到。
我加您个微信吧，发一些同行业的案例给您参考，
您有空的时候看看，万一以后有需要可以联系我。"
```
**策略：** 不纠结，加微信留后路，为下次跟进做准备。

### 异议2："百度已经没用过了/没效果"
```
"您之前做过百度推广是吧？具体是哪种？
搜索推广还是信息流？用了多久？
我帮您分析分析为什么效果不好。"
```
**策略：** 不反驳，先了解情况，找出问题根源。

**如果客户说"试过但效果差"：**
```
"我理解。很多客户反馈说百度效果差了，
主要原因是两方面的：
第一，CPC确实涨了，从以前的3块涨到现在的快30块；
第二，很多客户没做关键词筛选，来了很多无效流量。

但这是搜索推广的问题，不是百度平台的问题。
爱采购不一样——它是B2B专属平台，
来的都是有采购意图的，不是泛流量。
我建议您可以换个思路试试。"
```

### 异议3："太贵了，6980/5000不是小数目"
```
"我理解，一年几千块确实需要考虑。
但您算笔账：
一个光伏项目订单几十万，
如果能通过爱采购带来1个意向客户，
ROI是1:100以上。

而且这不是纯广告，是入驻平台，
有持续一年的曝光。平均到每天不到19块钱，
比一杯咖啡还便宜。
您觉得如果能带来一个客户，这个钱花得值吗？"
```
**策略：** 算账对比，把大数字拆成小数字，用ROI说服。

### 异议4："我再考虑考虑/研究研究"
```
"没问题，考虑是应该的。
您主要是考虑哪方面？
是预算、效果，还是觉得时机不对？
我可以针对性解答。"
```
**策略：** 不催，问具体顾虑，找到真正卡点。

**如果客户说"考虑效果"：**
```
"我理解您的担心。这样吧，
我先给您发几个同行业的案例数据，
您看看效果，再决定要不要试。
另外我可以安排一次免费的账户诊断，
帮您看看之前投放的数据，找出问题所在。"
```

### 异议5："我们有固定的合作代理商/服务商"
```
"那挺好的，说明您有数字化获客的意识。
我不竞争您现在的合作方，
只是想做个备份方案。
万一哪天需要换，或者想试试其他渠道，
您可以随时找我对比一下。
加个微信，以后有用得上的地方随时喊我。"
```
**策略：** 不争抢，做备胎，长期维护关系。

### 异议6："我们不需要线上获客/靠老客户就够了"
```
"老客户复购是好事，说明品质好。
但您有没有想过，新客户从哪来？
如果所有竞争对都在线上布局，
您不在，新客户就找不到您。

而且线上获客不是一次性的，
您入驻爱采购一年，
这一年里客户会持续搜到您的信息，
这是长期资产。"
```
**策略：** 不否定老客户价值，指出潜在风险，强调长期性。

### 异议7："你们百度不是快不行了吗？抖音不是更好？"
```
"您说得对，抖音确实流量大，
但抖音适合ToC，B2B采购决策链长，
需要信任背书。
百度的搜索场景是用户主动找供应商，意图更明确。

而且现在客户不光搜百度，还会问豆包、DeepSeek这些AI工具。
我们也在帮客户做AI搜索优化（GEO），
让客户的公司在AI推荐里也能被找到。
所以不是选百度还是抖音，
而是两个都做，覆盖面更广。"
```
**策略：** 不贬低竞品，承认对方优势，强调互补性，引出GEO新趋势。

### 异议8："我要跟老板/合伙人商量一下"
```
"完全理解，这种决策确实需要商量。
您看这样行不行，
我整理一份同行业的案例和数据给您，
您带回去给老板看。
另外我也可以跟您老板通个电话，
直接给他讲解一下方案，
省得您传话麻烦。"
```
**策略：** 提供支持材料，主动协助决策，降低内部沟通成本。

### 异议9："我现在没有预算/今年预算用完了"
```
"明白，那您看下半年有预算吗？
我可以先帮您做个方案，
等预算到位的时候直接能用。
另外您也可以先注册爱采购店铺，
6980一年的费用可以随时开通，
先用起来，效果好了再加大投入。"
```
**策略：** 寻找替代时间窗口，提供低门槛启动方案。

### 异议10："你们骗子吧？百度官方不会这样推销"
```
"哈哈我理解您的警惕，
现在骗子确实多。
我是百度授权代理商XX公司，
有正规的授权证书和营业执照。
您如果需要，我可以把授权书发您看看。
另外我们也可以先签正规合同，
款项打到百度官方账户，
不走我们个人账户，这样您放心。"
```
**策略：** 不生气，提供资质证明，强调官方渠道，建立信任。

## 五、收尾推进话术

### 推进1：加微信（最重要的一步）
```
"王总，今天跟您聊了这么多，
我怕电话里说不清楚。
我加您个微信吧，把案例和数据发给您，
您有空的时候看看，有问题随时问我。"
```
**微信通过话术：**
```
"王总您好，我是百度代理商的小刘，
刚才电话里跟您聊过。
这是我的微信，有任何问题随时找我。
我先发几个同行业的案例给您看看。"
```

### 推进2：约下次沟通
```
"王总，您看这周方便再通个电话吗？
我给您详细讲一下爱采购的入驻流程，
大概10分钟就好。"
```

### 推进3：约面谈/参观
```
"王总，电话里说不清楚，
您看这周方便的话，我过来拜访一下？
顺便把我们的方案材料带给您。
您公司具体地址是哪里？"
```

### 推进4：免费服务钩子
```
"王总，我这边可以提供一次免费的账户诊断服务，
帮您看看之前的投放数据，找出问题所在。
您觉得怎么样？"
```
**钩子设计：**
- 免费诊断 → 了解客户痛点
- 免费案例 → 建立信任
- 免费试用 → 降低决策门槛

## 六、电话销售心态建设

### 1. 心态调整
- **拒绝是常态**：10个电话里9个被挂，很正常
- **被挂断不是针对你**：客户可能在开会、在开车、心情不好
- **每次失败都是练习**：录音复盘，下次改进

### 2. 效率最大化
- **批量拨打**：一次打20-30个，不要间歇性工作
- **记录关键信息**：客户姓名、公司、行业、痛点、下一步动作
- **分类跟进**：A类（有兴趣）→ 当天跟进 | B类（需考虑）→ 一周后 | C类（无意向）→ 暂不联系

### 3. 复盘公式
```
今天通话 = 总量 - 挂断率 - 有效沟通率 × 转化率
目标：挂断率 < 60% | 有效沟通率 > 30% | 转化率 > 10%
```
