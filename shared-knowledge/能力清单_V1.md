## 六、能力调用规范

### 标准调用流程

```
1. 确认能力存在（查本清单）
2. 检查依赖条件（API Key/环境/权限）
3. 执行调用（主系统或子Agent）
4. 验证结果（成功/失败/边界情况）
5. 记录日志（写入修复日志或知识手册）
```

### 跨系统调用规则

| 场景 | 规则 |
|------|------|
| 主系统调用子系统 | 通过 sessions_spawn 派发 |
| 子系统调用主系统 | 通过 sessions_send 请求 |
| 子系统互相调用 | 禁止直接调用，经主系统调度 |
| 外部工具调用 | 优先用已有模块，不重复建设 |
