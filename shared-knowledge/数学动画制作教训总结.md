## 教训1：Manim渲染必须显式指定分辨率

**错误**: 不指定分辨率参数，默认出横屏1920×1080
**正确**: 必须加 `-r 1080,1920` 参数
```bash
python -u -m manim scripts/ep060_scene.py EP060_Scene -r 1080,1920 --format=mp4 --disable_caching -qm
```

**验证**: 渲染后用 ffprobe 检查实际分辨率，不要相信目录名
```bash
ffprobe -v error -select_streams v:0 -show_entries stream=width,height -of csv=p=0 output.mp4
```

---

## 教训2：渲染后必须用ffprobe验证实际元数据

**错误**: 相信目录名（如1920p15就是横屏）
**正确**: 目录名会骗人，必须 ffprobe 实际视频文件
**注意**: Manim 0.20.1 中 `-r 1080,1920` 渲染出来目录名可能是1920p15，但实际视频是竖屏

---

## 教训3：--disable_caching 不够，必须手动删除缓存

**错误**: 只加 --disable_caching，以为不会用缓存
**正确**: 修改代码后必须手动删除缓存目录
```bash
Remove-Item -Path "L4-共享\frames\ep060_lineup" -Recurse -Force
```

---

## 教训4：Manim图片大小用 height/width，不用 scale

**错误**: `logo.scale(0.4)` 对竖屏比例严重失调
**正确**: `logo.height = 2.5` 直接设置高度
**原因**: Manim中 scale 是相对自身维度，竖屏需要更大比例

---

## 教训5：结尾页布局用 next_to 链式排列，不用 move_to

**错误**: 用 move_to(DOWN*2) 等方式，和 LOGO 位置冲突
**正确**: 全部用 next_to 从上到下链式排列，避免中心定位重叠
**公式**:
```
标题(UP*5.5)
  ↓ next_to(DOWN, buff=0.5)
公式1(UP*3.8)
  ↓ next_to(DOWN, buff=0.5)
公式2
  ↓ next_to(DOWN, buff=0.5)
...
```

---

## 教训6：结尾页 LOGO 位置规范

**错误**: LOGO 放在顶部会遮挡标题
**正确**: LOGO 只放底部，`to_edge(DOWN, buff=2.5)` + `height=1.5`
**布局**: 文字区在上，LOGO 在底，完全独立

## 教训7：TTS API 超限后用免费替代方案

**错误**: Minimax API 超限后，每次生成68字节假文件（错误JSON）
**正确**: 立即切换到免费 TTS
```python
# pyttsx3（Windows自带，免费）
import pyttsx3
engine = pyttsx3.init()
engine.save_to_file(text, output_file)
engine.runAndWait()

# 或 edge-tts（微软，免费）
import edge_tts
communicate = edge_tts.Communicate(text, voice='zh-CN-XiaoxiaoNeural')
await communicate.save(output)
```

## 教训8：音频长度必须与视频精确匹配

**错误**: 视频41.9秒，音频52秒，音画不同步
**正确**: 渲染后检查音频长度，计算加速比例，用 ffmpeg 处理
```bash
# 1. 检查实际时长
ffprobe -v error -show_entries format=duration -of json video.mp4
ffprobe -v error -show_entries format=duration -of json audio.mp3

# 2. 计算加速比: audio_duration / video_duration
# 3. 加速并截断
ffmpeg -y -i video.mp4 -i audio.mp3 \
  -filter:a "atempo=1.28" -t 41.9 \
  -c:v copy -c:a aac output.mp4
```

## 核心教训一句话

> **每次渲染后必须立即用 ffprobe 验证分辨率和时长，不验证不出活。**
