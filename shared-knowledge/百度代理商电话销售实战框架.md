# 百度代理商电话销售实战框架

> ⚠️ **重要说明**：本文档是"可填充框架"而非"完整话术"。
> 框架部分（结构、流程、方法论）是经过验证的通用销售理论，可以直接用。
> 话术部分（具体的开场白、异议应对、产品推荐）标注了 **[待填充]** 的，需要你入职后旁听老销售、记录真实客户对话后，再补全为真实有效的话术。
> 版本：v1.0（框架版） | 2026-08-22

## 一、框架总览

### 1.1 一通完整电话的四个环节（已验证的销售方法论）

```
开场白 → 需求挖掘 → 价值传递 → 异议处理与收尾
```

**每个环节的目标：**
| 环节 | 目标 | 成功标准 |
|------|------|---------|
| 开场白 | 让客户在30秒内不挂断 | 客户愿意说第二句话 |
| 需求挖掘 | 了解客户现状和痛点 | 客户自己说出"我确实需要这个" |
| 价值传递 | 把产品翻译成客户收益 | 客户问"多少钱"或"怎么弄" |
| 异议处理与收尾 | 化解顾虑，推进下一步 | 约到微信/下次通话/面谈 |

### 1.2 通话时长控制（经验值，入职后需校准）

| 阶段 | 参考时间 | 目标 | 待校准 |
|------|---------|------|--------|
| 开场破冰 | 0-15秒 | 让对方不挂电话 | 老销售实际平均几秒开口？ |
| 需求挖掘 | 15-60秒 | 了解客户现状和痛点 | 客户平均愿意聊多久？ |
| 价值传递 | 60-120秒 | 匹配产品，算账 | 客户什么时候开始不耐烦？ |
| 异议处理 | 按需 | 化解顾虑 | 哪种异议最多？ |
| 收尾推进 | 最后15秒 | 约下次沟通或加微信 | 成功率最高的收尾方式？ |
| **总时长** | **2-3分钟** | 完成一个闭环 | 实际平均通话时长？ |

### 1.3 三个通用禁区（通用原则，所有销售适用）
- ❌ 一上来就报价（会被直接挂断）
- ❌ 只说"我是百度代理的"（像诈骗电话）
- ❌ 推销感太重（像骚扰电话）

## 二、环节一：开场白

### 2.1 开场白核心公式（通用销售理论）

```
✅ 自我介绍(1秒) + 来意说明(3秒) + 价值/问题(5秒) + 开放提问(3秒)
```

**话术结构：**
```
"您好，我是XX公司的XX。最近我们在做XX行业的调研，
发现XX问题。想请教您，您这边XX情况怎么样？"
```

### 2.2 开场白方向参考（待入职后填充真实版本）

| 方向 | 逻辑 | 话术示例 | 是否已验证 |
|------|------|---------|----------|
| 直接型 | 先问问题，让客户开口 | "现在新客户主要通过什么渠道？" | ❌ 待入职后验证 |
| 调研型 | 请教姿态，降低防备 | "最近在做XX行业调研，想请教一下" | ❌ 待入职后验证 |
| 案例型 | 案例背书+竞品压力 | "同行业XX家已经在做了" | ❌ 待入职后验证 |
| 痛点型 | 说出客户已知痛点 | "CPC从5块涨到快30块了" | ❌ 待入职后验证 |

## 三、环节二：需求挖掘

### 3.1 需求挖掘框架（通用销售方法论）

```
先问现状 → 再问影响 → 最后问期望
```

**话术结构：**
```
现状："您现在主要通过什么渠道获客？"
影响："现在获客最大的困难是什么？"
期望："如果有一个渠道能解决这个问题，您会考虑吗？"
```

### 3.2 追问话术参考（待填充）

| 客户回答 | 追问方向 | 追问话术示例 | 是否已验证 |
|---------|---------|-------------|----------|
| "老客户介绍多" | 新客户来源 | "那新客户从哪来？" | ❌ 待入职后验证 |
| "展会为主" | 展会效果 | "展会效果怎么样？成本高吗？" | ❌ 待入职后验证 |
| "线上有在做" | 具体平台 | "主要在哪些平台？效果如何？" | ❌ 待入职后验证 |
| "线索不够" | 线索数量 | "一个月能接到多少条有效线索？" | ❌ 待入职后验证 |
| "转化率低" | 线索质量 | "来的线索质量怎么样？" | ❌ 待入职后验证 |
| "成本高" | 具体成本 | "现在哪个渠道成本最高？" | ❌ 待入职后验证 |

## 四、环节三：价值传递

### 4.1 价值传递核心公式（通用销售方法论）

```
产品功能 → 翻译成客户收益 → 用具体数字说话
```

**话术结构：**
```
"根据您的情况，我建议您可以先试试XX。
XX一年XX元，帮您解决XX问题。
我帮您算一下：假设XX，ROI是XX:1。"
```

### 4.3 算账公式（通用逻辑，需用真实数据验证）

```
ROI = 客户平均客单价 × 预期增购客户数 ÷ 年费

示例（假设）：光伏订单50万，年增1单，爱采购6980/年
ROI = 500000 × 1 ÷ 6980 = 71:1
```

**待验证：**
- 客户听到"算账"后，是愿意听还是觉得烦？
- 老销售提"算账"时，客户什么反应？
- 什么情况下客户会主动问"多少钱"？

## 五、环节四：异议处理与收尾

### 5.1 异议处理通用框架（已验证的销售方法论）

```
认可 + 转折 + 举例 + 追问
```

**话术结构：**
```
认可："您说得对，XX确实存在XX问题。"
转折："但XX方面不一样。"
举例："比如XX客户，之前也XX，后来XX了。"
追问："您之前试过吗？效果怎么样？"
```

### 5.2 常见异议假设（入职后需验证是否真实存在）

| 异议 | 应对方向 | 话术示例（待验证） | 真实发生频率 |
|------|---------|-----------------|------------|
| "我没兴趣" | 加微信留后路 | "发些案例给您参考" | ❌ 待记录 |
| "百度没效果" | 帮分析原因 | "之前用的是什么产品？" | ❌ 待记录 |
| "太贵了" | 算账+拆分 | "每天不到XX元" | ❌ 待记录 |
| "考虑考虑" | 追问具体顾虑 | "主要是哪方面？" | ❌ 待记录 |
| "有合作代理" | 做备胎 | "做个备份方案" | ❌ 待记录 |
| "靠老客户够了" | 指出风险 | "新客户从哪来？" | ❌ 待记录 |
| "百度不行了" | 承认+转折 | "B2B搜索场景不一样" | ❌ 待记录 |
| "和老板商量" | 提供材料 | "我整理份资料给您" | ❌ 待记录 |
| "没预算" | 找替代窗口 | "下半年有预算吗？" | ❌ 待记录 |
| "骗子吧" | 提供资质证明 | "授权书发您看看" | ❌ 待记录 |

### 5.3 收尾推进公式（通用销售方法论）

```
加微信 → 约下次沟通 → 留钩子（免费服务/案例/数据）
```

**收尾话术结构：**
```
"王总，今天跟您聊了这么多，我加您个微信吧，
把XX发给您，您有空的时候看看。"
```
