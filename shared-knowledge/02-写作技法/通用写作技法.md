# 写作技法库

**跨项目共享**: 小说 + 自媒体

---

## 一、开篇技法

### 1. 场景切入法
```
不废话，直接上场景
例：「凌晨三点，城市早就睡了。
　　林默的出租屋里，电脑屏幕亮着，
　　他盯着后台那个数字——阅读量：0。」
```
作用：代入感强，读者秒入戏

### 2. 冲突前置法
```
先扔冲突，再解释背景
例：「老板娘指着林默的鼻子：
　　『滚！今天不交齐货款，别想出这个门！』」
```
作用：好奇心驱动阅读

### 3. 金句开篇法
```
先给一个观点，再展开
例：「这世上所有的逆袭，从来都不是偶然。」
```
作用：容易被转发/收藏

## 二、节奏控制

### 1. 三幕翻法（适用于短视频/自媒体）
- **第 1 翻**（0-20秒）：建立冲突
- **第 2 翻**（20-45秒）：高潮反转
- **第 3 翻**（45-60秒）：结局/悬念

### 2. 章内小高潮
```
每 500 字一个小高潮
大高潮 → 缓冲 → 更大高潮
```

### 3. 情绪递进公式
```
平静（200字）→ 隐患（300字）→ 
爆发（500字）→ 余波（300字）→ 悬念（结尾）
```

## 三、结尾技法

### 1. 悬念式结尾
```
「林默看着手机上的那条短信，
　手指悬在拨号键上方——
　打，还是不打？」
```
作用：强迫点下一章

### 2. 行动号召式结尾（自媒体）
```
「下期讲怎么用这个方法变现，
　关注我，明天见。」
```
作用：增加关注/互动

### 3. 金句总结式结尾
```
「这就是所谓的选择大于努力。
　你今天的选择，决定三年后的样子。」
```
作用：容易被转发

---

## 四、对白技法

### 1. 潜台词对白
```
表面：「这个项目啊，我们再看看。」
潜台词：「根本没戏，别想了。」
```
作用：制造张力

### 2. 短句对白
```
「谁让你来的？」
「我。」
「滚。」
```
作用：节奏快，阅读体验好
