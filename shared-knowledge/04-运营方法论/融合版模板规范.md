## 一、融合版定义

融合版 = 3秒痛点钩子 + 7步标准模板 + 互动结尾收尾

**目标**：完播率优化（抖音算法偏好）、信息密度高、无重复帧

---

## 二、融合版结构（8场景）

| 序号 | 场景 | 时长 | 内容要求 |
|------|------|------|----------|
| 0 | Hook | 2-3s | 痛点暴击 + 价值承诺 |
| 1 | Scene1_Problem | 3-5s | 题目展示（≤5s） |
| 2 | Scene2_Wrong | 4-6s | 两个错例同时展示（不切换） |
| 3 | Scene3_Demo | 5-7s | 动态演示（禁止静态摆拍） |
| 4 | Scene4_Formula | 8-10s | 公式推导 |
| 5 | Scene5_Calc | 6-8s | 计算过程 |
| 6 | Scene6_Verify | 7-9s | 验证答案 |
| 7 | Scene7_End | 6-8s | 互动结尾（EP048标准结构） |

**总时长标准**：40-50秒

---

## 三、Hook规范（3秒痛点）

### 3秒结构
1. **0-1s**：痛点词（震惊/挑战）
2. **1-2s**：价值承诺
3. **2-3s**：结果/效果

### 数字要准确
- ❌ "3分钟学会" → 太漫长
- ✅ "1分钟学会" → 有紧迫感

### 示例
```
"90%的人算圆面积，第一步就错了！"
"周长和面积，90%的人都搞混！"
"扇形面积，1分钟学会！"
```

## 四、Scene2错例展示规范

### 错误做法（禁止）
- 三个错例轮流切换 → 重复感强

### 正确做法（必须）
- 两个错例同时并排展示
- 不切换，不轮流

```python
# 同时展示（不切换）
wrong1 = txt("✗  错例1", font_size=36, color=ERROR_RED)
wrong1.move_to(UP * 1.8)
reason1 = txt("解释1", font_size=26, color=BRIGHT_WHITE)
reason1.next_to(wrong1, DOWN, buff=0.4)

wrong2 = txt("✗  错例2", font_size=36, color=ERROR_RED)
wrong2.move_to(DOWN * 0.5)
reason2 = txt("解释2", font_size=26, color=BRIGHT_WHITE)
reason2.next_to(wrong2, DOWN, buff=0.4)

self.play(Write(wrong1), Write(reason1), run_time=0.5)
self.wait(0.8)
self.play(Write(wrong2), Write(reason2), run_time=0.5)
```

## 五、Scene3动态规范（禁止静态）

### 静态禁止（超过3秒无变化）
- 直线画完后静止摆着8秒 → 重复感
- 圆展示后不动 → 重复感

### 必须有动态
- 直线画完后继续延伸/变化
- 标注逐个出现
- 有动画过渡

```python
# 好的做法：直线从左往右画 + 标注逐个出现
self.play(Create(straight), run_time=0.6)
self.wait(0.5)
self.play(Write(pi_t), run_time=0.5)
self.wait(0.5)
self.play(Write(d_t), run_time=0.5)
```

## 六、结尾页EP048标准结构

### 从下往上堆（4层）
```
[关注语]  ← 最上层
[口诀]    ← 第3层
[互动]    ← 第2层
[LOGO]    ← 底部（buff=3.5）
```

### 代码规范
```python
class Scene7_End(Scene):
    def construct(self):
        self.camera.background_color = BLACK

        # Logo贴底部
        logo_path = r"C:\Users\Administrator\.openclaw\workspace\workspace-math\assets\icons\logo.png"
        if os.path.exists(logo_path):
            logo = ImageMobject(logo_path)
            logo.scale(0.4)
            logo.to_edge(DOWN, buff=3.5)
            self.add(logo)
            self.play(FadeIn(logo), run_time=0.4)

        # 第1层（最下）：互动引导
        interact = txt("学会了的扣 1！", font_size=36, color=NEON_CYAN, stroke=BRIGHT_WHITE, stroke_width=0.3)
        interact.next_to(logo, UP, buff=0.7)

        # 第2层：口诀
        slogan = txt("口诀内容", font_size=36, color=NEON_YELLOW, stroke=ERROR_RED, stroke_width=0.3)
        slogan.next_to(interact, UP, buff=0.7)

        # 第3层（最上）：关注语
        follow = txt("关注我，每天学一道数学题！", font_size=26, color=BRIGHT_WHITE)
        follow.next_to(slogan, UP, buff=0.6)

        # 动画：逐层出现
        self.play(Write(interact), run_time=0.5); self.wait(0.5)
        self.play(Write(slogan), run_time=0.5); self.wait(0.5)
        self.play(Write(follow), run_time=0.5)
        self.play(Flash(follow, color=NEON_CYAN, flash_radius=0.8, num_lines=6, run_time=0.5))
        self.wait(2.0)
        self.play(Flash(slogan, color=NEON_YELLOW, flash_radius=1.0, num_lines=8, run_time=0.5))
        self.wait(4.0)
        self.clear()
```

## 七、音视频合并规范（tpad补齐）

### 禁止做法
```bash
# 会截断音频
ffmpeg -i video -i audio -shortest output.mp4
```

### 正确做法（tpad补齐）
```python
import subprocess, os

def merge_clip(video_path, audio_path, output_path, target_dur):
    v_dur = float(subprocess.run(
        ['ffprobe', '-v', 'error', '-show_entries', 'format=duration', '-of', 'csv=p=0', video_path],
        capture_output=True, text=True
    ).stdout.strip())

    a_dur = float(subprocess.run(
        ['ffprobe', '-v', 'error', '-show_entries', 'format=duration', '-of', 'csv=p=0', audio_path],
        capture_output=True, text=True
    ).stdout.strip())

    if v_dur < target_dur:
        pad_dur = target_dur - v_dur
        cmd = [
            'ffmpeg', '-y',
            '-i', video_path, '-i', audio_path,
            '-filter_complex', f'[0:v]tpad=stop_mode=clone:stop_duration={pad_dur}[v]',
            '-map', '[v]', '-map', '1:a',
            '-c:v', 'libx264', '-preset', 'fast', '-crf', '18',
            '-c:a', 'aac', '-t', str(target_dur), '-pix_fmt', 'yuv420p',
            output_path
        ]
    else:
        cmd = [
            'ffmpeg', '-y',
            '-i', video_path, '-i', audio_path,
            '-c:v', 'libx264', '-preset', 'fast', '-crf', '18',
            '-c:a', 'aac', '-t', str(target_dur), '-pix_fmt', 'yuv420p',
            output_path
        ]
    subprocess.run(cmd)
```

## 九、Manim CE兼容规范

### 颜色定义
```python
# ❌ 错误（Manim CE没有HexColor）
NEON_YELLOW = HexColor("#FFD700")

# ✅ 正确（直接用字符串）
NEON_YELLOW = "#FFD700"
```

### 文字描边
```python
# ❌ 错误
return Text(t, font_size=fs, color=c, stroke=stroke, stroke_width=sw)

# ✅ 正确
text = Text(str(t), font_size=fs, color=c)
if stroke:
    text.set_stroke(color=stroke, width=stroke_width)
return text
```
