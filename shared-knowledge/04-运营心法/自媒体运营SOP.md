# 自媒体运营 SOP

**版本**: v1.0
**更新**: 2026-04-11
**适用范围**: 房地产自媒体（百家号 + 头条号）

---

## 一、选题标准

### 选题评级（S/A/B/C）

| 等级 | 标准 | 时效 | 优先级 |
|------|------|------|--------|
| S | 政策重磅（限购/降息/土拍）| 12小时内发布 | P0 |
| A | 市场热点（楼盘爆火/维权）| 次日发布 | P1 |
| B | 实用干货（购房指南/贷款）| 3天内 | P2 |
| C | 日常内容（区域测评）| 1周内 | P3 |

### 选题来源
1. 热点采集（每日 09:30 cron）
2. 账号数据（每周一分析）
3. 评论区互动（粉丝问题）
4. 竞品监测（同行爆款）

---

## 二、内容生产流程

```
选题确定 → 资料搜集 → 脚本撰写 → 封面设计 → 标题优化 → 发布
```

### 2.1 脚本撰写
- 字数：800-1200 字
- 结构：痛点引入（20%）+ 干货（60%）+ 行动号召（20%）
- 必须含：本地化元素（重庆具体案例/数据）

### 2.2 封面设计
- 尺寸：3:4（900x1200px）
- 风格：统一模板，标题醒目
- 禁忌：模糊/过度P图/虚假数据

### 2.3 标题优化
- 长度：25-30 字
- 必须含：地域词（重庆）+ 痛点/利益点
- 公式：「城市+痛点+解决方案+数字」
- 例：「重庆买房最容易被坑的3个地方，懂行的人都在看」

## 三、发布流程

### 3.1 发布时间
| 类型 | 最佳时段 | 备用时段 |
|------|----------|----------|
| 政策解读 | 10:00-11:00 | 20:00-21:00 |
| 干货教程 | 14:00-15:00 | 19:00-20:00 |
| 热点蹭流 | 事件发生后 2 小时内 | - |

### 3.2 发布检查清单
- [ ] 政策类内容已核实来源
- [ ] 数据类内容已核实准确性
- [ ] 敏感词已过滤
- [ ] 封面符合规范
- [ ] 标题含地域词+痛点
- [ ] 已预约评论区互动话术

---

## 四、数据复盘

### 4.1 每日复盘（20:00 cron）
- 阅读量 TOP3 内容
- 异常数据波动（如有）
- 明日选题建议

### 4.2 每周复盘（周一 10:00 cron）
- 本周数据汇总
- 内容类型表现分析
- 标题效果分析
- 下周优化建议

### 4.3 数据预警
| 指标 | 预警值 | 处理 |
|------|--------|------|
| 阅读量 | < 500 | 检查标题/封面 |
| 互动率 | < 1% | 检查内容质量 |
| 负向评论 | > 10% | 检查敏感词/立场 |

---

## 五、爆款规律

### 5.1 高阅读量标题特征
- 数字型：「3 个」「5 个」
- 冲突型：「却被」「不懂」
- 利益型：「省钱」「赚钱」「避坑」
- 地域型：「重庆人」「重庆买房」

### 5.2 高互动内容特征
- 引发共鸣（「重庆刚需太难了」）
- 引发争议（「该不该在重庆买房」）
- 提供实用价值（「2024重庆购房指南」）
