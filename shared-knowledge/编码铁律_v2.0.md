## 一、命令选择规则

### 1.1 简单命令（1行）
```powershell
# 适用场景：单条命令，无复杂参数
git status
python script.py --help
netstat -ano | findstr "8080"
```

### 1.2 复杂脚本（多行）
```
适用场景：
- Python代码超过3行
- 含引号嵌套
- 含中文字符
- 含特殊字符

正确做法：
1. 使用write工具创建.py文件
2. 使用exec执行.py文件
3. 不要inline执行复杂Python代码
```

### 1.3 文件操作
```
读取小文件(<50KB): read工具
读取大文件: read工具(offset/limit)
写入新文件: write工具
修改现有文件: edit工具
批量文件操作: 写Python脚本
```

## 二、字符串处理铁律

### 2.1 引号使用
```python
# ❌ 错误：多层引号嵌套
cmd = 'python -c "print(\"hello\")"'

# ✅ 正确：使用原始字符串
cmd = r'python -c "print(' + "'" + 'hello' + "'" + ')"'

# ✅ 更好：写文件后执行
script = 'print("hello")'
write("script.py", script)
exec("python script.py")
```

### 2.2 路径处理
```python
# ❌ 错误：PowerShell路径
path = "C:\Users\Administrator\.openclaw"

# ✅ 正确：Python原始字符串
path = r"C:\Users\Administrator\.openclaw"

# ✅ 更好：使用Path对象
from pathlib import Path
path = Path(r"C:\Users\Administrator\.openclaw")
```

### 2.3 中文字符
```python
# ❌ 错误：在exec中直接写中文
python -c "print('中文内容')"

# ✅ 正确：写文件后执行
with open('script.py', 'w', encoding='utf-8') as f:
    f.write('print("中文内容")')
exec('python script.py')
```

## 三、工具选择决策树

```
收到任务
    ↓
需要执行命令？
├─ 简单单行命令 → exec
├─ 复杂脚本(>3行) → write + exec
├─ 需要交互 → exec(pty=true)
└─ 后台任务 → exec(background=true)

需要修改文件？
├─ 小改动(<5行) → edit
├─ 大改动/新建 → write
└─ 不确定内容 → read + edit/write

需要读取文件？
├─ 小文件(<50KB) → read
├─ 大文件 → read(offset/limit)
└─ 查找内容 → exec(grep/findstr)
```

## 五、常见错误模式

### 5.1 SyntaxError - 引号不匹配
```python
# 错误
print("Hello "world"")

# 正确
print('Hello "world"')
print("Hello 'world'")
print("Hello \"world\"")
```

### 5.2 SyntaxError - 括号不匹配
```python
# 错误
result = func(a, b, c

# 正确
result = func(a, b, c)
```

### 5.3 UnicodeEncodeError - 中文编码
```python
# 错误
python -c "print('中文')"  # PowerShell GBK编码问题

# 正确
# 方法1：写文件后执行
with open('script.py', 'w', encoding='utf-8') as f:
    f.write('print("中文")')
exec('python script.py')

# 方法2：设置环境变量
import os
os.environ['PYTHONIOENCODING'] = 'utf-8'
```

### 5.4 FileNotFoundError - 路径错误
```python
# 错误
open('C:\Users\name\file.txt')  # \n被解释为换行

# 正确
open(r'C:\Users\name\file.txt')  # 原始字符串
open('C:/Users/name/file.txt')   # 正斜杠
```

## 六、调试技巧

### 6.1 分步执行
```python
# 复杂任务分解为小步骤
step1 = "创建目录"
step2 = "写入文件"
step3 = "执行处理"

for step in [step1, step2, step3]:
    print(f"执行: {step}")
    # 执行并验证
```

### 6.2 输出验证
```python
# 每步输出关键信息
print(f"[DEBUG] 输入: {input_data}")
print(f"[DEBUG] 处理中...")
print(f"[DEBUG] 输出: {output_data}")
```

### 6.3 错误捕获
```python
try:
    # 执行代码
    result = do_something()
except FileNotFoundError as e:
    print(f"文件不存在: {e}")
except PermissionError as e:
    print(f"权限不足: {e}")
except Exception as e:
    print(f"未知错误: {e}")
```
