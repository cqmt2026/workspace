# 估值指标详解

## 一、PE（市盈率）= 市值 / 净利润

**定义**：PE是最常用的估值指标，表示投资者为每1元净利润支付的价格。

**三种PE**：
- **静态PE**：用去年全年净利润，优点是数据确定，缺点是滞后
- **动态PE**：用预期今年净利润随季度更新，适合趋势投资者
- **TTM PE**：用过去12个月净利润，兼顾时效性和确定性

**行业对比案例——贵州茅台**：
- 2024年净利润约750亿元
- 总市值约1.8万亿元
- PE = 18000 / 750 = 24倍

**行业横向对比**：
- 白酒行业平均PE：25-30倍（品牌溢价，现金流好）
- 银行行业平均PE：5-7倍（杠杆高，周期性强）
- 科技行业平均PE：40-60倍（高增长预期）

**判断标准**：
- PE < 10：可能是低估，也可能行业衰退
- PE 10-20：合理区间
- PE 20-30：偏高，需看增长
- PE > 30：成长股溢价，或泡沫风险

## 二、PB（市净率）= 市值 / 净资产

**定义**：PB是市值与账面净资产的比值，特别适合金融股和重资产公司。

**为什么适合金融股？**
银行的资产主要是贷款和金融资产，这些按账面价值记录，与市场价值差距较大，因此PB比PE更有参考价值。

**破净机会（PB<1）**：
- PB<1意味着市值低于净资产
- 可能被低估，也可能是"价值陷阱"（资产质量问题）
- 2014年中国银行业PB曾跌至0.6-0.7倍，之后大幅修复
- 2020年疫情后港股内银股PB一度跌破0.4倍

**判断标准**：
- PB < 1：破净，关注资产质量
- PB 1-2：正常区间
- PB > 4：轻资产或高ROE公司

## 三、PS（市销率）= 市值 / 营业收入

**适用场景**：
- 成长期互联网公司（京东、拼多多早年PS估值）
- 医药公司（研发费用高，短期可能亏损）
- 营收稳定但利润率波动大的公司

**判断标准**：
- PS < 1：可能低估
- PS 1-3：合理区间
- PS > 10：高成长预期，估值昂贵

## 四、PCF（现金流折算）= 经营现金流 / 市值

**公式**：PCF = 经营现金流 / 总市值

**优点**：不受会计政策影响，更难被操纵

**判断标准**：
- PCF倍数越低，相对越便宜
- PCF < 10：相对便宜
- PCF > 20：相对昂贵

## 五、PEG = PE / 净利润增长率

**定义**：PEG综合了估值（PE）和成长性（增长率），是判断成长股性价比的重要指标。

**公式**：PEG = PE / 净利润增长率（%）

**判断标准**：
- PEG < 1：相对低估，成长性被低估
- PEG = 1：估值合理，成长性与估值匹配
- PEG > 1：相对高估，成长性不足以支撑估值
- PEG > 2：严重高估

## 六、用Python拉取平安银行实时估值数据

```python
# -*- coding: utf-8 -*-
import requests
import json
from pathlib import Path

# 加载Cookie
cookie_file = Path(__file__).parent.parent.parent / 'config' / 'eastmoney_cookie.json'
with open(cookie_file, 'r', encoding='utf-8') as f:
    config = json.load(f)
    cookie = config['cookie']

session = requests.Session()
session.headers.update({
    'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64)',
    'Cookie': cookie,
    'Referer': 'https://www.eastmoney.com/'
})

# 平安银行 000001（深圳市场股票代码前加0.）
secid = '0.000001'
url = 'http://push2.eastmoney.com/api/qt/stock/get'

params = {
    'secid': secid,
    'fields': 'f43,f44,f45,f57,f58,f170,f171,f116,f117,f162,f163'
}

try:
    resp = session.get(url, params=params, timeout=10)
    data = resp.json().get('data', {})

    print('=' * 50)
    print(f"股票名称: {data.get('f58')} ({data.get('f57')})")
    print(f"最新价: {float(data.get('f43', 0)) / 100:.2f} 元")
    print('-' * 50)
    print('估值指标:')

    pe_ttm = float(data.get('f171', 0)) / 10000
    pe_dynamic = float(data.get('f170', 0)) / 10000
    pb = float(data.get('f116', 0)) / 10000
    ps = float(data.get('f117', 0)) / 10000
    pcf_dynamic = float(data.get('f162', 0)) / 10000
    pcf_ttm = float(data.get('f163', 0)) / 10000

    print(f"市盈率(TTM): {pe_ttm:.2f}" if pe_ttm > 0 else "市盈率(TTM): 亏损")
    print(f"市盈率(动): {pe_dynamic:.2f}" if pe_dynamic > 0 else "市盈率(动): 亏损")
    print(f"市净率(PB): {pb:.2f}")
    print(f"市销率(PS): {ps:.2f}")
    print(f"市现率(动): {pcf_dynamic:.2f}" if pcf_dynamic > 0 else "市现率(动): 负值")
    print(f"市现率(TTM): {pcf_ttm:.2f}" if pcf_ttm > 0 else "市现率(TTM): 负值")
    print('=' * 50)

except Exception as e:
    print(f"获取数据失败: {e}")
    print("提示：完整财务数据需使用财务专题API，商业使用需授权")
```

## 七、估值指标总结对比

| 指标 | 公式 | 适用场景 | 判断标准 |
|------|------|----------|----------|
| PE | 市值/净利润 | 成熟期、盈利稳定 | 5-20合理，>30需高增长 |
| PB | 市值/净资产 | 金融、重资产 | <1破净机会，>4轻资产 |
| PS | 市值/营业收入 | 成长期、亏损公司 | 1-10合理 |
| PCF | 经营现金流/市值 | 现金流好的公司 | 越低越便宜 |
| PEG | PE/增长率 | 成长股 | <1低估，>1高估 |

**核心原则**：没有完美的估值指标，只有适合当前场景的指标。银行股看PB+PE，科技股看PS+PEG，消费股看PE+PS，综合使用才能避免偏颇。
