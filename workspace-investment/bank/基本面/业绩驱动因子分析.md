# 业绩驱动因子分析

## 一、行业景气度：判断行业是否处于上升周期

行业景气度是影响公司业绩最重要的外部因素，同一家公司在行业上升期和下降期的表现可能天差地别。

**判断方法**：

1. **PMI（采购经理指数）**
   - PMI>50：制造业扩张
   - PMI<50：制造业收缩
   - 连续3个月>50说明行业处于上升周期

2. **行业营业收入增速**
   - 行业整体收入增速>GDP增速：朝阳行业
   - 行业整体收入增速<GDP增速：夕阳行业
   - 增速逐年提升：景气上行

3. **产品价格指数**
   - 大宗商品（原油、铜、钢铁）：关注期货价格走势
   - 消费类产品：关注零售价格指数

4. **产能利用率**
   - 产能利用率>80%：接近满产，有提价能力
   - 产能利用率<70%：产能过剩，激烈价格战

**案例**：2019-2021年光伏行业进入景气上升期，隆基绿能净利润从52亿增长到90亿，股价涨幅超过400%。而2022年后硅料产能大量释放，行业进入下行周期，即使强如隆基也出现业绩压力。这说明行业Beta（行业整体涨跌）往往比个股Alpha（个股相对涨跌）更重要。

## 二、产品竞争力：市场份额与毛利率变化

**市场份额分析**：
- 市场份额提升 = 产品竞争力增强 = 业绩增长有保障
- 市场份额萎缩 = 被竞争对手蚕食 = 业绩增长承压

**毛利率变化的深层含义**：
- 毛利率提升：可能是产品升级、规模效应或行业供需改善
- 毛利率稳定：竞争格局清晰
- 毛利率下降>5个百分点：需要警惕，可能是价格战前兆

**案例**：格力电器 vs 美的集团
- 2015年行业价格战，格力、美的毛利率均下滑
- 美的通过多元化（收购库卡机器人）提升收入结构
- 格力过度依赖空调，毛利率波动更大
- 最终美的市值和业绩稳定性均超过格力

## 三、政策驱动：哪些政策直接影响业绩

政策对A股业绩的影响远大于美股，投资者必须关注政策方向。

**直接利好政策**：
1. **补贴政策**：新能源车补贴、光伏补贴 → 直接提升利润
2. **税收优惠**：高新技术企业所得税15% → 节省大量税费
3. **产业规划**：十四五规划重点方向 → 行业确定性增强
4. **国产替代**：半导体、信创政策 → 打开国内市场空间

**直接利空政策**：
1. **集采政策**：药品、高值医用耗材集采 → 降价压力巨大
2. **环保限产**：钢铁、煤炭去产能 → 短期影响产量
3. **房地产调控**：限购、限贷 → 地产链业绩压力
4. **互联网监管**：平台经济反垄断 → 扩张受限

**案例：药品集采对医药行业的影响**：
- 2018年首批带量采购启动，心脏支架从1.3万降到700元
- 涉及集采的药企利润大幅缩水
- 未涉及集采的创新药企（恒瑞医药）相对受益
- 启示：政策免疫赛道（消费医疗、CXO）更值得关注

## 四、产能扩张：新建产能如何影响未来营收

产能扩张是双刃剑，成功的产能扩张带来业绩爆发，失败的产能扩张则可能拖垮公司。

**产能扩张的分析框架**：

1. **产能扩张的时机**
   - 行业上升期扩张：顺势而为，成功率较高
   - 行业下行期扩张：逆势抄底，风险较大

2. **产能利用率跟踪**
   - 新产能建成前：关注公司在建工程转固进度
   - 新产能建成后：关注产能利用率爬坡速度

3. **资金压力评估**
   - 产能扩张需要大量资本支出（CAPEX）
   - 自有资金充足：风险较低
   - 高负债扩张：一旦行业下滑可能资金链断裂

**案例：面板行业（京东方）**：
- 2017-2020年大举扩张LCD产能
- 产能建成后恰好赶上行业价格战
- 2021年净利润大幅下滑
- 教训：产能扩张需要与行业需求节奏匹配

## 五、季度财报环比分析：淡旺季规律

A股上市公司业绩有明显的季节性规律，季度环比分析需要考虑季节因素。

**主要行业淡旺季规律**：

| 行业 | 旺季 | 淡季 | 原因 |
|------|------|------|------|
| 零售/消费 | Q4（春节） | Q1淡季 | 春节消费旺季 |
| 白酒 | Q4、Q1 | Q2 | 中秋国庆+春节 |
| 房地产 | Q4 | Q1 | 结算周期 |
| 银行 | Q4 | Q1 | 季末考核 |
| 制造业 | Q2、Q3 | Q1 | 春节后开工 |
| 旅游 | Q2、Q3 | Q1、Q4 | 暑期旺季 |

**环比分析的正确方法**：
1. 不要直接用Q1和Q4比较，要考虑季节性
2. 正确方式：今年Q4 vs 去年Q4（同比）
3. 更准确方式：用4季度移动平均消除季节性

## 六、综合案例：银行业绩驱动因子分析

以平安银行（000001）为例展示完整分析框架：

```python
# -*- coding: utf-8 -*-
import requests
import json
from pathlib import Path

cookie_file = Path(__file__).parent.parent.parent / 'config' / 'eastmoney_cookie.json'
with open(cookie_file, 'r', encoding='utf-8') as f:
    config = json.load(f)
    cookie = config['cookie']

session = requests.Session()
session.headers.update({
    'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64)',
    'Cookie': cookie,
    'Referer': 'https://www.eastmoney.com/'
})

secid = '0.000001'
url = 'http://push2.eastmoney.com/api/qt/stock/get'
params = {
    'secid': secid,
    'fields': 'f43,f57,f58,f170,f171,f116,f47,f48'
}

try:
    resp = session.get(url, params=params, timeout=10)
    data = resp.json().get('data', {})
    print("【行情数据】")
    print(f"股票: {data.get('f58')} ({data.get('f57')})")
    print(f"最新价: {float(data.get('f43',0))/100:.2f}")
    print(f"市盈率(动): {float(data.get('f170',0))/10000:.2f}")
    print(f"市净率: {float(data.get('f116',0))/10000:.2f}")
except Exception as e:
    print(f"行情获取失败: {e}")

print("\n【业绩驱动因子分析框架】")
print("1. 行业景气度: 关注贷款需求指数、不良贷款率")
print("2. 产品竞争力: 净息差走势、手续费收入增速")
print("3. 政策驱动: LPR下调压缩净息差，降准释放流动性")
print("4. 产能扩张: 网点扩张速度、金融科技投入")
print("5. 季节性: Q4为银行旺季，业绩占比较高")
```

**银行股业绩驱动核心因子**：

1. **净息差（NIM）**：利息收入/生息资产，是银行最核心的盈利能力指标
   - 净息差扩大 → 业绩提升
   - 净息差收窄 → 业绩承压
   - 2023年银行净息差普遍收窄，压制业绩

2. **资产质量**：不良贷款率、拨备覆盖率
   - 不良率上升 → 需要增加拨备 → 侵蚀利润

3. **规模增长**：贷款余额增速
4. **中间业务收入**：手续费及佣金收入

## 七、总结：业绩驱动因子分析清单

**外部因素**：
- [ ] 行业景气度：PMI、价格指数、产能利用率
- [ ] 政策影响：补贴/税收/监管/集采
- [ ] 宏观经济：GDP增速、消费者信心指数

**内部因素**：
- [ ] 产品竞争力：市场份额、毛利率变化
- [ ] 产能扩张：在建工程、产能利用率
- [ ] 费用控制：三费占比（销售/管理/财务费用）

**信号验证**：
- [ ] 季度环比：是否考虑季节性
- [ ] 同环比结合：趋势判断更准确
- [ ] 先行指标：PMI、订单、库存等先于财务数据

**最终判断**：综合以上因子，给出业绩增长/下降的方向性判断，并估算可能的增速区间。
