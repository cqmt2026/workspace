# 财报基础三表解读

## 一、利润表：盈利能力

利润表反映企业在一定时期内的经营成果，是投资者最关注的核心报表。

**核心公式**：
- 净利润 = 收入 - 成本 - 费用
- 毛利 = 收入 - 成本，毛利率 = 毛利 / 收入
- EPS（每股收益）= 净利润 / 总股本

**案例**：贵州茅台2024年毛利率约92%，净利率约50%。这意味着每100元收入，扣除成本后剩92元，再扣除费用后约50元装进口袋。这样的利润率在家电、银行等竞争性行业几乎不可能出现，是高端白酒品牌护城河的直接体现。

**快速判断**：
- 毛利率>40%：有品牌溢价，护城河深
- 毛利率20%-40%：竞争较激烈，需要关注市场份额
- 毛利率<20%：红海市场，成本控制是关键

## 二、资产负债表：财务健康度

资产负债表反映企业在某一时刻的资产、负债和所有者权益状况。

**核心公式**：
- 总资产 = 负债 + 所有者权益
- 净资产（股东权益）= 总资产 - 负债

**案例**：某银行总资产10万亿，负债9.2万亿，则净资产8000亿。净资产就是"家底"，是吸收损失的安全垫。银行股分析中，巴菲特最看重的指标之一就是一级资本充足率，本质就是净资产质量。

**重点指标**：
- 资产负债率 = 负债 / 总资产（银行偏高是正常的）
- 流动比率 = 流动资产 / 流动负债（>1较好）
- 净资产收益率（ROE）= 净利润 / 净资产（核心盈利能力指标）

## 三、现金流量表：造血能力

现金流量表记录企业现金的流入和流出，分为三个部分：

**1. 经营活动现金流（造血能力）**
- 企业主营业务产生的现金流动
- 最好是"经营现金流>净利润"，说明利润有现金支撑
- **危险信号**：净利润为正但经营现金流持续为负

**2. 投资活动现金流（扩张/收缩）**
- 购买资产、对外投资等
- 大幅投资期可能是高速扩张，也可能是夕阳产业最后的挣扎
- 要结合行业周期判断

**3. 筹资活动现金流（融资/分红）**
- IPO、配股、发债、分红、还债等
- 频繁融资可能说明主业不赚钱
- 稳定分红是现金流健康的重要标志

## 四、重点：为什么"净利润好但经营现金流差"很危险？

这是财报分析中最需要警惕的情形，常见原因包括：

1. **应收账款堆积**：收入确认了但钱没收到，常见于toG项目（政府工程）
2. **存货积压**：产品卖不出去，收入没有现金支撑
3. **收入虚增**：通过关联交易等方式做高收入和利润
4. **会计政策调节**：延长折旧年限等手段虚增利润

**真实案例**：某环保公司早年大量承接PPP项目（政府与社会资本合作），收入确认激进，账面上利润好看，但政府回款周期长，导致经营现金流常年为负。2018年去杠杆政策一出，资金链断裂，股价暴跌90%。这个案例完美诠释了"有利润没现金"的危害。

**判断标准**：
- 经营现金流/净利润 连续3年>0.8 较好
- 该比值<0.5 且持续，需高度警惕

## 五、快速读财报技巧

**第一步：看现金流量表**（最重要）
- 经营现金流是否为正？是否持续为正？
- 净利润含金量如何？（经营现金流/净利润）

**第二步：看资产负债表**
- 资产负债率是否过高？（>80%需谨慎）
- 净资产增长情况如何？

**第三步：看利润表**
- 收入增长是否与利润增长匹配？
- 毛利率是否稳定？

**第四步：三表联读**
- 经营现金流好 + 利润好 = 优质公司
- 经营现金流差 + 利润好 = 警惕！重点查应收账款和存货

## 六、用东方财富API获取真实财报数据

以下代码展示如何用Python获取平安银行（000001）的财务数据：

```python
# -*- coding: utf-8 -*-
import requests
import json
from pathlib import Path

# 加载Cookie
cookie_file = Path(__file__).parent.parent.parent / 'config' / 'eastmoney_cookie.json'
with open(cookie_file, 'r', encoding='utf-8') as f:
    config = json.load(f)
    cookie = config['cookie']

session = requests.Session()
session.headers.update({
    'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64)',
    'Cookie': cookie,
    'Referer': 'https://www.eastmoney.com/'
})

# 获取平安银行（000001）实时行情
secid = '0.000001'  # 深圳主板0 + 股票代码
url = 'http://push2.eastmoney.com/api/qt/stock/get'
params = {
    'secid': secid,
    'fields': 'f43,f44,f45,f57,f58,f170'
}

try:
    resp = session.get(url, params=params, timeout=10)
    data = resp.json().get('data', {})
    print(f"股票名称: {data.get('f58')}")
    print(f"最新价: {data.get('f43')}")
    print(f"市盈率(动): {data.get('f170')}")
except Exception as e:
    print(f"获取失败: {e}")
```

**输出示例**：
```
股票名称: 平安银行
最新价: 12.35
市盈率(动): 5.42
```

## 七、总结

| 报表 | 核心问题 | 核心指标 |
|------|----------|----------|
| 利润表 | 赚钱吗？ | 净利润、毛利率、EPS |
| 资产负债表 | 家底厚吗？ | 总资产、净资产、ROE |
| 现金流量表 | 利润是真钱吗？ | 经营现金流、净利润含金量 |

**读财报的顺序**：现金流量表 → 资产负债表 → 利润表。记住：没有现金支撑的利润是"纸面富贵"，迟早出问题。
