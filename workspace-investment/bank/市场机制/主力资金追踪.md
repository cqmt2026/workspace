**更新时间**: 2026-04-21

## 一、市场资金结构

### 1.1 各类资金主体

| 资金类型 | 代表 | 特征 |
|----------|------|------|
| 公募基金 | 基金重仓股 | 价值投资，中长线 |
| 私募基金 | 私募概念股 | 灵活，题材驱动 |
| 券商自营 | 券商重仓股 | 跟政策走 |
| 保险资金 | 保险持仓 | 稳健，低估值 |
| 社保基金 | 社保重仓 | 价值投资，极保守 |
| 外资（北向）| 沪深股通 | 价值+趋势 |
| 游资（热钱）| 题材龙头 | 快进快出 |
| 散户 | 个人投资者 | 追涨杀跌 |

### 1.2 主力定义
通常指能影响个股短期走势的大额资金，包括：
- 机构席位（大单）
- 游资席位（龙虎榜常客）
- 庄家（控盘个股）

## 二、资金流向指标

### 2.1 超大单、大单、中单、小单

| 分类 | 单笔成交额 |
|------|-----------|
| 超大单 | 大于等于100万元 |
| 大单 | 大于等于20万元 |
| 中单 | 大于等于4万元 |
| 小单 | 小于4万元 |

**实战意义**：
- 超大单+大单净流入 → 主力资金主动买入
- 小单净流入 → 散户接盘（往往反向指标）

### 2.2 同花顺主力资金流向
- 统计超大单+大单净买入额
- 东方财富网用"主力净流入"指标

### 2.3 板块资金流向
- 每日统计各行业/概念板块的主力净流入
- 连续3日净流入板块 → 主力持续布局
- 单日大幅净流出板块 → 主力撤退

## 三、追踪方法

### 3.1 Level2数据（收费）
- 逐笔成交明细
- 委托队列（买一/卖一挂单量）
- 主力单识别算法

### 3.2 免费追踪方式

**1. 东方财富网 - 资金流向**
网址：https://data.eastmoney.com/zjlx/

**2. 同花顺 - 资金流向**
网址：https://data.10jqka.com.cn/funds/

**3. 上交所/深交所 - 交易公开信息**
每日公布异动个股席位

**4. 龙虎榜**
- 上榜条件：日涨跌幅偏离正负7%、日换手率20%、连续3日涨跌幅20%等
- 披露内容：买入/卖出门营业部名称和金额
- **游资席位识别**：温州帮、佛山系、成都系、杭州帮等

## 四、游资操盘风格

### 4.1 常见游资席位

| 席位 | 风格 |
|------|------|
| 佛山帮（光大佛山）| 一日游，次日砸盘 |
| 成都帮（华泰成都）| 题材挖掘，连续拉升 |
| 杭州帮（银河杭州）| 趋势跟随 |
| 温州帮（中信杭州）| 控盘拉抬 |
| 上海超短（国泰上海）| 极短线，次日必出 |

### 4.2 游资选股标准
1. **盘子小** - 流通市值20-100亿
2. **题材新** - 消息刺激、有想象空间
3. **位置低** - 调整充分，位置不高
4. **股性好** - 历史活跃，有涨停基因

### 4.3 游资拉升形态
- **点火** → 快速拉升3-5%吸引跟风
- **封板** → 拉至涨停并封死
- **溢价** → 次日高开出货

### 4.4 游资出货信号
- 涨停板反复打开
- 尾盘集合竞价大单砸盘
- 龙虎榜显示卖出远超买入

## 五、跟庄技巧

### 5.1 建仓识别
- 下跌末期缩量 → 主力吸筹
- 突然放量大涨 → 主力试盘
- 盘整期间窄幅震荡 → 主力控盘

### 5.2 洗盘识别
- 拉升前砸盘测试抛压
- 关键压力位反复震荡
- 缩量跌不破重要均线

### 5.3 出货识别
- 高位放量大阴线
- 利好兑现股价不涨（见光死）
- 连续高换手率
