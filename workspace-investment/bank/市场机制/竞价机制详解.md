# 竞价机制详解

**更新时间**: 2026-04-21

---

## 一、集合竞价

### 1.1 什么是集合竞价
集合竞价是在每个交易日上午9:15-9:25（深市还有14:57-15:00收盘集合竞价），将一段时间内收到的所有买卖委托集中撮合，形成开盘价和收盘价的竞价方式。

### 1.2 竞价规则

| 项目 | 上海 | 深圳 |
|------|------|------|
| 开盘集合竞价 | 9:15-9:25 | 9:15-9:25 |
| 收盘集合竞价 | - | 14:57-15:00 |
| 最大成交量价 | 即开盘价 | 即开盘价/收盘价 |

**成交价确定原则**：
1. **价格优先** - 买入时最高价优先，卖出时最低价优先
2. **时间优先** - 相同价格时，先委托的先成交
3. **最大成交量** - 满足以上条件时，以能成交最大数量的价格作为成交价

### 1.3 集合竞价阶段特征

#### 9:15-9:20（可撤单阶段）
- 可以挂单也可以撤单
- 成交量的参考意义不大
- **庄家常用手法**：在9:15用大单拉高或打压价格，9:19撤单，制造虚假意图

#### 9:20-9:25（不可撤单阶段）
- 只可挂单，不可撤单
- **真实性强**，是判断当日开盘方向的重要参考
- 若高开幅度大且成交量放大，往往代表主力意图明确

#### 9:25 开盘价确定
- 9:25整会产生当日开盘价
- 此时可以看到【虚拟成交价】和【匹配量】

### 1.4 实战应用

**弱转强模式**：
- 9:15-9:20大幅高开，9:20后快速回落
- 9:24出现承接，股价维持在高位
- 开盘后往往有拉升

**强转弱模式**：
- 9:15-9:20封板，9:20后涨停板被打开
- 代表封板资金撤单或抛压过重
- 需谨慎

## 二、连续竞价

### 2.1 交易时间
- **沪市**：9:30-11:30，13:00-15:00
- **深市**：9:30-11:30，13:00-14:57（14:57-15:00为收盘集合竞价）

### 2.2 撮合规则
遵循【**价格优先、时间优先**】原则：
- 买入委托：出价高者优先成交
- 卖出委托：出价低者优先成交

### 2.3 五档买卖盘
实时显示五个最优买卖价格：
- 卖盘（从低到高）：卖一、卖二、卖三、卖四、卖五
- 买盘（从高到低）：买一、买二、买三、买四、买五

**盘口语言**：
- 买一/卖一 挂单量突然变大 → 可能有护盘或出货意图
- 卖一持续大单压盘但价格不跌 → 主力吸筹
- 买一持续大单托盘但价格不涨 → 主力出货

## 三、价格形成机制

### 3.1 竞价价格形成
当日K线形成：
```
开盘价 = 9:25 集合竞价成交价
收盘价 = 沪市15:00成交均价，深市14:57-15:00集合竞价
最高价 = 全天最高成交价
最低价 = 全天最低成交价
```

### 3.2 涨跌停板机制
A股特殊制度，涨跌幅限制：

| 板块 | 涨跌幅 |
|------|--------|
| 主板（沪/深）| 10% |
| ST股 | 5% |
| 科创板/创业板 | 20% |
| 北交所 | 30% |
| 新股（上市首日）| 44%（沪）|

**涨停板封板逻辑**：
- 封板时间越早 → 主力越强，次日溢价概率越高
- 尾盘涨停 → 可能是主力借市场氛围偷袭
- 一字板（开盘即涨停）→ 最强，但次日容易高开低走

### 3.3 熔断机制（已取消）
- 2016年1月4日-1月7日曾试点
- 沪深300指数触发5%/7%熔断阈值时暂停交易
- 因效果不佳于2016年1月8日暂停

## 四、竞价量价关系实战

### 4.1 爆量高开
9:25集合竞价成交量是昨日均量3倍以上，且高开2%以上 → 主力异动

### 4.2 缩量高开
无量大涨 → 持股者惜售，但若无跟风盘则容易回落

### 4.3 地量竞价
成交稀少 → 市场冷清，可能是变盘前兆

### 4.4 竞价砸盘
9:20-9:25大单卖出压低开盘价 → 主力故意压低吸筹或出货前试盘
