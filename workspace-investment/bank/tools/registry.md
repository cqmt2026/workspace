## 🔧 工具接口规范

### 标准输入格式

```json
{
  "tool": "工具名称",
  "params": {
    "参数 1": "值 1",
    "参数 2": "值 2"
  },
  "options": {
    "选项 1": "值 1"
  }
}
```

### 标准输出格式

```json
{
  "status": "success|error",
  "data": {...},
  "error": "错误信息（如果有）",
  "metadata": {
    "执行时间": "...",
    "其他信息": "..."
  }
}
```

---

### 错误处理规范

| 错误类型 | 状态码 | 处理方式 |
|---------|--------|---------|
| 参数错误 | 400 | 检查必填参数 |
| 文件不存在 | 404 | 创建文件或报错 |
| 权限不足 | 403 | 请求授权 |
| 网络错误 | 503 | 重试或报错 |
| 未知错误 | 500 | 记录日志并报错 |

## 📝 工具使用示例

### 示例 1：读取文件

```json
{
  "tool": "read",
  "params": {
    "path": "memory/2026-04-04.md"
  }
}
```

**输出**:
```json
{
  "status": "success",
  "data": {
    "content": "文件内容...",
    "lines": 100
  }
}
```

---

### 示例 2：执行命令

```json
{
  "tool": "exec",
  "params": {
    "command": "python script.py"
  },
  "options": {
    "timeout": 30
  }
}
```

**输出**:
```json
{
  "status": "success",
  "data": {
    "stdout": "输出内容...",
    "stderr": "",
    "exit_code": 0
  }
}
```

---

### 示例 3：创建子 Agent

```json
{
  "tool": "sessions_spawn",
  "params": {
    "task": "分析市场数据",
    "mode": "run",
    "runtime": "subagent"
  }
}
```

**输出**:
```json
{
  "status": "success",
  "data": {
    "sessionKey": "agent:main:subagent:xxx",
    "runId": "xxx"
  }
}
```

## 🔄 工具发现机制

### 自动加载

1. **核心工具** - OpenClaw 启动时自动加载
2. **Skills 工具** - 扫描 `skills/` 目录，读取 `SKILL.md`
3. **自定义工具** - 读取 `tools/custom/` 目录

### 工具注册流程

```
1. 创建工具文件 (tools/custom/xxx.md)
2. 定义工具接口 (输入/输出/错误处理)
3. 添加到本注册表
4. 测试工具功能
5. 标记为 ✅ 可用
```
