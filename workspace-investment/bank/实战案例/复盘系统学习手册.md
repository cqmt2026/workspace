## 📖 复盘概述

### 什么是复盘？

复盘是**对过去的事情进行回顾、分析、总结、改进**的过程。

**核心公式**:
```
复盘 = 回顾 + 分析 + 总结 + 改进

目的：
✅ 找出成功原因（可复制）
✅ 找出失败原因（可避免）
✅ 形成经验（可积累）
✅ 持续进化（可成长）
```

### 复盘的价值

| 价值 | 说明 |
|------|------|
| **避免重复错误** | 同样的错误不犯第二次 |
| **复制成功经验** | 成功可以复制，失败可以避免 |
| **加速成长** | 复盘 1 次 = 经验×2 |
| **体系进化** | 从复盘中发现体系问题，持续优化 |

**一句话**: **不复盘=白干，复盘=经验×2**

## 📊 复盘的层次

### 四层复盘模型

```
第一层：交易复盘（每日）
  → 今日交易对错？

第二层：体系复盘（每周）
  → 体系有效吗？

第三层：学习复盘（每次学习后）
  → 学到了什么？

第四层：人生复盘（每月/每年）
  → 方向对吗？
```

---

#### 买卖点分析

**买入前**:
- ✅ 为什么买这只？（六维评分多少？）
- ✅ 符合体系吗？（哪个买点？）
- ✅ 仓位合理吗？（按体系应该多少？）
- ✅ 止损位设了吗？（设在哪里？）

**卖出后**:
- ✅ 为什么卖？（止盈/止损/体系信号？）
- ✅ 卖早了还是卖晚了？
- ✅ 下次如何改进？

---

#### 情绪分析

**买入时的心态**:
- 😐 冷静执行体系？
- 😰 害怕错过（FOMO）？
- 😎 过度自信？
- 😱 恐慌性买入？

**持有中的心态**:
- 😐 平静持有？
- 😰 频繁查看？
- 😎 盲目乐观？
- 😱 恐慌想卖？

**卖出后的心态**:
- 😐 平静接受结果？
- 😡 后悔卖早/卖晚？
- 😎 得意忘形？
- 😞 沮丧想翻本？

---

#### 纪律检查

| 纪律 | 标准 | 是否遵守 |
|------|------|----------|
| 仓位 | 按体系评分 | ✅/❌ |
| 止损 | -8% 无条件 | ✅/❌ |
| 止盈 | +15% 移动 | ✅/❌ |
| 持仓数 | 3-4 只 | ✅/❌ |
| 连亏休息 | 连亏 3 笔休息 | ✅/❌ |

## 四、高效复盘方法

### 4.1 KISS 复盘法

```
K - Keep（保持）
  → 哪些做得好，继续保持？

I - Improve（改进）
  → 哪些可以做得更好？

S - Start（开始）
  → 哪些新方法要开始尝试？

S - Stop（停止）
  → 哪些行为要停止？
```

---

### 4.2 AAR 复盘法（美军）

```
1. 原本打算做什么？（目标）
2. 实际发生了什么？（事实）
3. 为什么会有差距？（原因）
4. 下次如何改进？（行动）
```

---

### 4.3 PDCA 循环

```
P - Plan（计划）
  → 制定目标和计划

D - Do（执行）
  → 执行计划

C - Check（检查）
  → 检查结果，找出问题

A - Act（处理）
  → 改进问题，进入下一轮循环
```

---

### 4.4 5Why 分析法

```
问题：为什么亏损？

1Why: 因为止损没执行
2Why: 因为抱有侥幸心理
3Why: 因为之前有一次没止损反而盈利了
4Why: 因为那次是运气好
5Why: 因为缺乏系统性思维

根本原因：缺乏系统性思维，依赖运气

解决方案：建立系统，严格执行
```

## 五、复盘心理学

### 5.1 常见心理陷阱

#### 结果偏见

❌ "这笔赚了=我做对了"
✅ 赚可能是运气，亏可能是正常波动

**正确**: 看是否符合体系，不看盈亏

---

#### 后见之明

❌ "我早就知道会跌"
✅ 事后看都清楚，事前很难判断

**正确**: 看决策过程，不看结果

---

#### 确认偏见

❌ "只找支持自己观点的证据"
✅ 选择性失明

**正确**: 主动找反面证据

---

#### 过度自信

❌ "连续盈利=我很厉害"
✅ 可能是行情好

**正确**: 保持谦逊，敬畏市场

---

### 5.2 正确复盘心态

✅ **客观** - 对事不对人  
✅ **诚实** - 不欺骗自己  
✅ **开放** - 接受不同观点  
✅ **成长** - 错误是学习机会  
✅ **谦逊** - 市场永远是对的
