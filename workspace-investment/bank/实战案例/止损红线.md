# 止损红线

> 短线不止损，亏损无底洞。每次侥幸都是下一次爆仓的伏笔。

---

## 1. 硬止损规则（铁律，必须执行）

### ① 单笔最大亏损：-5% 必须割肉

- **触发条件**：任意持仓单笔浮亏达到 **-5%**
- **执行动作**：市价全仓卖出，不得拖延、不得补仓摊薄成本
- **禁止借口**："这只是回调""基本面没变"
- **九丰能源教训**：持有5天，亏损-5.9%（-1,385元）。根源是亏5%时没有止损，幻想反弹。

### ② 短线持仓上限：持有 5天 不论盈亏平仓

- **触发条件**：持仓天数达到 **5个交易日**（以买入当天为第1天）
- **执行动作**：
  - 有盈利 → 止盈离场
  - 亏损 ≤ 5% → 按硬止损执行
  - 亏损 > 5% → 按实际亏损无条件割肉
- **璞泰来教训**：买入即跌，2天-6.0%。短线持仓逻辑本身就是"短线"，超过5天性质已变。

### ③ 盈利保护：盈利达 +5% 后设保本价

- **触发条件**：持仓盈利从最高点回落超过 **-2%**，或盈利达到 **+5%** 时
- **执行动作**：
  - 盈利 +5% 时：将止损线上移至 **保本价（0%）**
  - 盈利从高位回落 -2%：触发预警，次日若未新高则止盈
- **目的**：让盈利奔跑，但绝不让盈利变成亏损

## 2. 软止损规则（情绪层面）

### ④ 买入后多久不涨需要警惕

| 时间节点 | 信号含义 |
|---|---|
| 买入后 **次日** 不涨 | 初步弱势，观察 |
| 买入后 **第3天** 仍不盈利 | 主力可能不及预期，减仓 |
| 买入后 **第5天** 不涨 | 必须平仓，不恋战 |

### ⑤ 连续亏损 3笔 后强制冷静期

- **触发条件**：连续 **3笔** 交易均为亏损
- **执行动作**：强制休息 **5个交易日**，期间禁止开新仓
- **冷静期任务**：
  1. 复盘近3笔亏损原因（是止损执行问题还是选股问题）
  2. 检查是否受情绪影响（急于翻本/频繁交易）
  3. 冷静期结束后，从小仓位开始试盘

## 3. 止损执行流程

### 触发 → 确认 → 执行

```
Step 1：触发预警
  条件满足 → 系统/人工发出止损预警信号

Step 2：确认信号
  5分钟内检查：
  [√] 是否是流动性问题（涨跌停无法卖出）
  [√] 当日大盘环境是否异常
  [√] 是否有突发重大利空

Step 3：执行动作
  ├─ 09:30-14:30 → 即时市价卖出
  ├─ 14:30-15:00 → 尾盘集合竞价卖出
  └─ 14:55前未执行 → 视为执行失败，记录原因
```

### 尾盘止损 vs 盘中止损

| | 优点 | 缺点 |
|---|---|---|
| **盘中止损** | 锁定价格，避免继续扩大亏损 | 可能卖在日内低点，事后后悔 |
| **尾盘止损（14:30后）** | 价格相对稳定，减少滑点 | 若已是跌停则无法出逃 |

**结论**：优先 **盘中止损**，不等到尾盘。尾盘止损仅限以下情况：
- 当日已是涨停/强势股，高位滞涨
- 预计次日有更好卖点

## 4. 真实案例对照

### 九丰能源 ✗ 典型不止损悲剧

| 项目 | 数据 |
|---|---|
| 持仓天数 | **5天** |
| 最终亏损 | **-5.9%（-1,385元）** |
| 问题所在 | 持有期间亏损从-2%扩大到-5.9%，始终不止损 |
| 正确做法 | 第2天亏损-2%时应设保本价；第3天亏损-3%应触发硬止损 |

### 璞泰来 ✗ 买入即跌，处理失当

| 项目 | 数据 |
|---|---|
| 持仓天数 | **2天** |
| 最终亏损 | **-6.0%** |
| 问题所在 | 买入前未设止损位，跌后不知如何处理，犹豫中亏损扩大 |
| 正确做法 | 买入即设 **-5%** 止损线；次日跌破-3%直接割肉，不幻想反弹 |

## 执行自检清单

每次止损操作前，逐项核对：

- [ ] **1. 是否触及硬止损红线（-5%）？**
  - 是 → 无条件执行，不犹豫

- [ ] **2. 是否超过持仓上限（5天）？**
  - 是 → 无论盈亏，当天平仓

- [ ] **3. 盈利是否从高位回落超过-2%？**
  - 是 → 止盈或上移止损

- [ ] **4. 是否连续亏损3笔？**
  - 是 → 强制进入5日冷静期

- [ ] **5. 执行时间是否在14:55前？**
  - 否 → 立即操作，拒绝拖延

> **核心原则**：止损的核心不是"卖对"，而是"不让自己死在一次侥幸里"。规则定下来，就当法律执行，不讲感情。
