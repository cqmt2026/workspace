# 龙头股战法

## 一、什么是龙头股
龙头股是指在某个板块或题材中，涨幅最大、流动性最好、最能带动板块节奏的那只股票。它是市场资金聚焦的核心，也是短线交易者最追求的目标。龙头股不是人为规定的，而是在市场博弈中自然形成的。

## 二、龙头股的四大特征
| 特征 | 说明 |
|------|------|
| 市值适中 | 太大拉不动（>1000亿），太小流动性差；50-500亿最优 |
| 题材正宗 | 业务与热点题材高度契合，不是蹭概念 |
| 股性活跃 | 日成交金额>5亿，换手率高 |
| 先于板块动 | 行情启动时，龙头总是率先拉升 |

## 三、如何识别龙头
1. **先于板块启动**：龙头股不会等板块涨起来了才动，而是在板块行情酝酿时就率先拉升。
2. **涨幅超越板块平均**：同一板块中，龙头股涨幅通常是板块平均涨幅的2-3倍。
3. **缩量回调时抗跌**：连板后回调，成交量萎缩，但股价不跌破关键均线（MA5/MA10）。
4. **板块回调时逆势**：整个板块回调时，龙头股往往在尾盘拉升。

## 四、龙头股买卖点
| 买点 | 条件 | 优点 | 缺点 |
|------|------|------|------|
| 首板涨停 | 题材重大利好，午后涨停，<14:30封板 | 位置低，风险小 | 难以识别 |
| 打二板 | 首板后次日高开>5%，缩量回调企稳 | 经过市场验证 | 成本提升 |
| 三板定龙 | 连续三个涨停，缩量板 | 趋势明确，惯性强大 | 风险累积 |

**卖点：阴线首刀**
- 标志：放量大阴线（换手>20%），涨停打开尾盘大幅回落
- 操作：次日开盘30分钟不能反包，果断离场
- 跌破MA5/MA10时也可离场

## 五、实战案例复盘
| 日期 | 事件 | 股价 |
|------|------|------|
| 2月1日 | 政策催化，板块首次异动 | 18.5元 |
| 2月5日 | 首板涨停，题材正宗确认 | 20.3元 |
| 2月6日 | 缩量回调，强势整理 | 21.1元 |
| 2月7日 | 打二板，成交量放大 | 23.2元 |
| 2月8日 | 三板定龙，市场公认 | 25.5元 |
| 2月9日 | 四连板，获利盘锁定 | 28.1元 |
| 2月19日 | 放量大阴线首刀 | 30.5元 |
| 2月20日 | 低开低走，龙头陨落 | 27.3元 |

**复盘总结**：
- 首板后缩量回调是最佳介入时机
- 三板后进入博傻阶段，仓位要降
- 阴线首刀是最明确的离场信号
- 龙头陨落后不要抄底——补跌杀伤力极大

## 六、风险提示
1. **补跌风险**：龙头见顶后连续跌停，跌幅往往是行情启动前的水平
2. **流动性风险**：极端行情下可能开板直接天地板，追板当天亏损20%
3. **虚假龙头**：蹭热点封板但无实质行情，往往一日游第二天低开

def find_leader(stock_list):

## 八、总结

| 识别方法 | 先于板块动、涨幅超越平均、缩量回调抗跌 |
