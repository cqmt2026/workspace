# 止损方法论

## 一、为什么止损是生存的第一法则

止损的目的是**在市场中活得足够久**。统计数据：
- 亏10%需要涨11%回本
- 亏20%需要涨25%回本
- 亏50%需要涨100%回本
- 亏80%需要涨400%回本

**亏损的速度永远快于回本的速度**，所以止损是保护本金的第一道防线。

## 二、五种止损方法

### 1. 固定比例止损
- **方法**：买入后下跌10%机械止损
- **适用**：短线交易、止损纪律强的人
- **优点**：简单粗暴，执行容易
- **缺点**：不适合大波动股票，容易被震出
- **代码**：
```python
def fixed_stop_loss(entry_price, current_price, threshold=0.10):
    if (entry_price - current_price) / entry_price >= threshold:
        return True  # 触发止损
    return False
```

### 2. 均线止损
- **方法**：跌破MA20止损（收盘价确认）
- **适用**：趋势交易、中线持仓
- **优点**：跟随趋势，不被正常回调洗出
- **缺点**：滞后性，趋势反转时要等均线确认
- **操作**：跌破MA20收盘，次日开盘离场

### 3. 形态止损
- **方法**：股价跌破关键支撑位（前期低点、趋势线、前箱体底）
- **适用**：有明确支撑位的股票
- **优点**：止损位明确，逻辑清晰
- **缺点**：需要识别支撑位，新手难
- **案例**：股价在50元形成支撑，若跌破48元（支撑下方5%）止损

### 4. 时间止损
- **方法**：持有X天（短线3-5天，中线10天）不涨则出
- **适用**：短线炒作、题材股
- **优点**：控制时间成本，避免无量横盘消耗机会成本
- **缺点**：可能卖在启动前夜
- **代码**：
```python
def time_stop_loss(hold_days, max_days=5):
    if hold_days >= max_days:
        return True
    return False
```

### 5. 鳄鱼组线止损（Bill Williams）
- **原理**：使用三条均线（蓝、红、绿）判断市场状态
- **操作**：绿色（最短）在红色下方时，进入下降趋势，全线止损
- **适用**：有技术基础，能接受复杂策略的人

## 三、散户最常见的止损错误

### 错误一：跌了死扛
- **表现**：亏了不止损，认为只是回调，最终深套
- **心理**：不甘心认错，期待反弹回来
- **后果**：从短线炒成了长线，从轻仓持成了重仓
- **数据**：2024年某股票从30元跌到5元，中间任何一次止损都是对的

### 错误二：补仓摊平成本
- **表现**：跌了加仓，想降低平均成本
- **逻辑**：看起来平均成本低了，但实际上是在逆势加仓
- **后果**：如果趋势是向下的，补仓只会亏得更多
- **正确做法**：在止损线止损后，等股价企稳再决定是否重新买入

### 错误三：止损幅度太大
- **表现**：设20%止损，认为拿得住
- **后果**：亏20%需要25%才能回本，仓位管理失控
- **建议**：单笔交易止损不超过总资金的2-5%

## 四、止损vs不止损的真实数据对比

假设初始资金100万，买入一只10元股票1万股：

| 场景 | 止损（-10%） | 不止损（跌80%） |
|------|------|------|
| 亏损 | 1万元 | 8万元 |
| 回本需要 | 涨11% | 涨400% |
| 剩余资金 | 99万 | 20万 |
| 再买股票 | 可买900股@11元 | 只够买200股@4元 |

**结论**：不止损看起来"不亏"，实际上亏得更多，而且回本难度指数级上升。

## 五、止损的三个层次

| 层次 | 内容 |
|------|------|
| 第一层 | 亏了就卖，不关心价格 |
| 第二层 | 按固定比例止损，机械执行 |
| 第三层 | 根据股票特性和市场环境动态调整止损 |

大多数人在第一层和第二层之间，能做到第三层的人少之又少。

## 六、Python计算止损点
```python
def calculate_stop_loss(entry_price, method='fixed', ma20=None, atr=None, threshold=0.10):
    if method == 'fixed':
        return entry_price * (1 - threshold)
    elif method == 'ma20' and ma20:
        return ma20
    elif method == 'atr' and atr:
        return entry_price - 2 * atr
    return entry_price * 0.9  # 默认亏10%
```

## 七、总结
| 方法 | 适用场景 | 优点 | 缺点 |
|------|------|------|------|
| 固定比例 | 短线 | 简单 | 被震出 |
| 均线止损 | 趋势交易 | 跟随趋势 | 滞后 |
| 形态止损 | 有支撑位 | 逻辑清晰 | 难识别 |
| 时间止损 | 题材炒作 | 控制时间 | 卖飞 |
| 鳄鱼组线 | 高级交易 | 综合判断 | 复杂 |

**核心理念**：止损的艺术在于平衡——太紧容易被震出，太松亏损会扩大。找到适合自己的止损节奏。
