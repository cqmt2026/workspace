# 趋势跟踪策略

## 一、什么是趋势
趋势是市场运动的方向，分为三种：
- **上升趋势**：高点不断抬高（Higher High）+ 低点不断抬高（Higher Low）
- **下降趋势**：高点不断降低（Lower High）+ 低点不断降低（Lower Low）
- **横盘整理**：高点相近 + 低点相近

只有上升趋势才适合趋势跟踪策略，下降趋势和横盘市是趋势跟踪策略的敌人。

## 二、移动平均线系统

### 常用均线
| 均线 | 周期 | 用途 |
|------|------|------|
| MA5 | 5日 | 超短线，灵敏但假信号多 |
| MA10 | 10日 | 短线 |
| MA20 | 20日 | 中线，趋势交易核心 |
| MA60 | 60日 | 长线，判断牛熊分界 |

### 多头排列
均线多头排列：MA5 > MA10 > MA20 > MA60，是上升趋势的确认信号。多头排列下，每次回调到均线附近是买点。

### 空头排列
均线空头排列：MA5 < MA10 < MA20 < MA60，是下降趋势的确认信号。空头排列下不要抄底。

## 三、趋势线画法与应用

### 画法
上升趋势线：连接两个相邻的低点，即成上升趋势线。第二个低点必须高于第一个低点。

### 实战应用
- **趋势线支撑**：回调到趋势线附近是买入机会
- **趋势线突破**：收盘价跌破趋势线+3日确认，是离场信号
- **趋势线角度**：角度越陡，回调幅度越大；角度越缓，趋势越持久

## 四、趋势跟踪止损方法

### 1. 趋势线止损
- 条件：收盘价跌破上升趋势线
- 确认：连续3日收盘价在趋势线下方
- 优点：能捕捉大段趋势，假信号少
- 缺点：需要等待确认，止损幅度较大

### 2. 均线止损
- 条件：股价跌破MA20
- 操作：跌破MA20收盘，次日开盘离场
- 优点：明确量化，执行简单
- 缺点：震荡市中频繁被洗出局

### 3. ATR止损（真实波幅止损）
- 计算：取最近14日的最高价与最低价之差
- 操作：买入价 - 2×ATR 作为止损价
- 优点：适应性强，不受波动率影响
- 缺点：需要计算

## 五、Python回测均线策略
```python
import numpy as np

def simple_ma_backtest(prices, short_ma=5, long_ma=20):
    """
    简单双均线策略回测
    金叉买入，死叉卖出
    """
    signals = []
    position = 0  # 0=空仓, 1=持仓
    
    for i in range(long_ma, len(prices)):
        short = np.mean(prices[i-short_ma:i])
        long = np.mean(prices[i-long_ma:i])
        
        if short > long and position == 0:
            # 金叉，买入
            position = 1
            signals.append(('BUY', i, prices[i]))
        elif short < long and position == 1:
            # 死叉，卖出
            position = 0
            signals.append(('SELL', i, prices[i]))
    
    return signals

# 示例数据回测
prices = [10, 11, 12, 11.5, 13, 14, 15, 14.5, 16, 17, 16.5, 18]
result = simple_ma_backtest(prices)
for action, idx, price in result:
    print(f'{action} at index {idx}, price={price}')
```

## 六、注意事项
1. **假信号**：震荡市中，均线会频繁交叉，产生大量假信号
2. **滞后性**：均线天生滞后，趋势反转时反应慢
3. **参数选择**：不同标的需要不同参数，不能一套策略打天下
4. **仓位管理**：趋势明确时重仓，趋势模糊时空仓
