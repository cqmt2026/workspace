# 舆情分析模块

**标签**: 舆情 | 新闻情绪 | NLP
**文件**: `scripts/sentiment_analysis.py`
**状态**: ✅ 已完成

---

## 核心功能

| 功能 | 说明 |
|------|------|
| 个股舆情 | 分析单只股票新闻情绪 |
| 市场情绪 | 统计市场整体情绪偏向 |
| 情绪评分 | -10(极悲) ~ +10(极乐观) |

---

## 情绪判断

| 分数 | 市场情绪 |
|------|----------|
| >3 | 偏正面 |
| -3~3 | 中性 |
| <-3 | 偏负面 |

---

## 使用方法

```python
from sentiment_analysis import analyze_stock_sentiment, analyze_market_sentiment

# 市场情绪
print(analyze_market_sentiment())

# 个股舆情
print(analyze_stock_sentiment('600519'))
```
