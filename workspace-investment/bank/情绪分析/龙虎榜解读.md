# 龙虎榜解读

## 一、什么是龙虎榜

龙虎榜是沪深交易所每日公布的**异常波动股票公开信息**，揭示特定席位（营业部/机构）的买卖数据。

### 1.1 上榜条件

| 条件类型 | 具体标准 |
|---------|---------|
| **日涨跌幅偏离** | 日涨跌幅偏离值 ±7%（ST股 ±5%） |
| **日振幅** | 日振幅达到 15% |
| **日换手率** | 日换手率达到 20% |
| **异常波动** | 连续3个交易日累计偏离值 ±20% |
| **无价格涨跌幅限制** | 新股、恢复上市等 |

### 1.2 信息披露内容

```
股票名称/代码 | 异动日期
==============================
席位名称          买入额(万) | 卖出额(万) | 净额(万)
------------------------------
光大证券佛山绿景路   12,345    |   5,678    |  +6,667
华鑫证券上海茅台路    8,901    |   3,456    |  +5,445
机构专用            5,678    |   1,234    |  +4,444
...
```

## 二、席位类型详解

### 2.1 散户集中营（常规席位）

| 特征 | 说明 |
|------|------|
| **名称** | 通常以券商营业部命名 |
| **资金量** | 单次买入额1000万-5000万 |
| **行为特征** | 快进快出，短线为主 |
| **信号含义** | 散户追涨，反向指标？ |

⚠️ **注意**：并非所有营业部席位都是散户，可能是游资伪装

### 2.2 游资席位

游资（热钱）是指利用资金优势短期内炒作题材股的机构化资金。

| 特征 | 说明 |
|------|------|
| **名称** | 特定券商营业部，久而久之形成口碑 |
| **资金量** | 单次买入可达数亿 |
| **行为特征** | 题材炒作、连板接力 |
| **操作周期** | 1-10个交易日 |
| **席位风格** | 敢死队型、价值投机型 |

### 2.3 机构专用

| 特征 | 说明 |
|------|------|
| **名称** | "机构专用" |
| **资金量** | 通常较大，1000万-数亿 |
| **行为特征** | 价值投资、中长期持有 |
| **操作周期** | 数周至数月 |
| **信号含义** | 正面信号，但需结合估值 |

## 三、著名游资营业部一览

### 3.1 顶级游资席位

| 席位名称 | 风格特点 |
|---------|---------|
| **光大证券佛山绿景路** | 龙头挖掘者，擅长首板 |
| **华鑫证券上海茅台路** | 题材炒作，连板接力王 |
| **中信证券上海分公司** | 资金实力强，影响力大 |
| **华泰证券浙江分公司** | 短线高频，题材敏感 |
| **国泰君安南京太平南路** | 价值投机并重 |
| **招商证券深圳蛇口工业七路** | 敢死队风格 |

### 3.2 游资操盘模式

| 模式 | 说明 |
|------|------|
| **首板** | 挖掘低位股，次日溢价卖出 |
| **连板** | 连续拉升，击鼓传花 |
| **反包** | 调整后二次拉升 |
| **卡位** | 抢先封板，堵死对手 |
| **砸盘** | 出货时大单砸盘 |

## 四、机构 vs 游资

### 4.1 核心区别

| 对比项 | 机构 | 游资 |
|-------|------|------|
| **投资理念** | 价值投资 | 趋势/题材炒作 |
| **持股周期** | 中长期 | 短线 |
| **买入信号** | 估值合理/偏低 | 题材催化 |
| **卖出信号** | 估值偏高/基本面恶化 | 短线利润兑现 |
| **龙虎榜频率** | 偶尔出现 | 频繁出现 |

### 4.2 识别技巧

```
机构买入特征：
  - 出现在"机构专用"席位
  - 买入金额通常较大
  - 多出现在调整后的低位
  - 配合基本面利好

游资买入特征：
  - 出现在券商营业部席位
  - 常配合题材/消息炒作
  - 多出现在高位或涨停
  - 换手率高，席位快速更替
```

### 4.3 实战意义

| 情况 | 市场含义 |
|------|---------|
| **机构大幅买入 + 股价低位** | 积极信号，中线看好 |
| **机构大幅卖出 + 股价高位** | 警惕见顶风险 |
| **游资接力 + 题材持续** | 短期行情延续 |
| **游资砸盘 + 高位放量** | 短期顶部预警 |

## 五、如何从龙虎榜判断主力意图

### 5.1 核心分析框架

```
Step 1: 看席位性质
  └─ 机构 > 游资 > 散户

Step 2: 看买卖净额
  └─ 净买入大 → 主力看多
  └─ 净卖出大 → 主力看空

Step 3: 看买卖集中度
  └─ 买入集中 → 合力拉升
  └─ 卖出集中 → 主力出货

Step 4: 看股价位置
  └─ 低位机构买入 → 建仓
  └─ 高位游资接力 → 赶顶

Step 5: 看题材配合
  └─ 有实质利好 → 延续性强
  └─ 无实质利好 → 一日游
```

### 5.2 常见市场含义

| 龙虎榜特征 | 市场信号 |
|----------|---------|
| **机构 + 游资同时买入** | 强强联合，看涨信号强 |
| **游资对倒** | 制造活跃假象，实际净卖出 |
| **机构卖出 + 游资接盘** | 机构出货完毕，风险大 |
| **散户集中营买入** | 可能是主力诱多 |
| **多家游资接力** | 题材持续，行情未完 |

### 5.3 注意事项

⚠️ **局限性与风险**：
- 龙虎榜数据T+1公布，存在滞后
- 大资金可能分拆账户规避披露
- 游资手法多变，不可机械套用
- 追涨龙虎榜个股风险极大

## 六、Python拉取近期龙虎榜数据

```python
# -*- coding: utf-8 -*-
"""
获取近期龙虎榜数据（东方财富）
"""
import requests
import json
from pathlib import Path
from datetime import datetime, timedelta
import sys

sys.stdout.reconfigure(encoding='utf-8')

# 加载Cookie
cookie_file = Path(__file__).parent.parent / 'config' / 'eastmoney_cookie.json'
with open(cookie_file, 'r', encoding='utf-8') as f:
    config = json.load(f)
    cookie = config['cookie']

session = requests.Session()
session.headers.update({
    'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64)',
    'Cookie': cookie,
    'Referer': 'https://www.eastmoney.com/'
})

def get_longhu_bang(date=None, page=1, page_size=20):
    """
    获取龙虎榜数据
    
    Args:
        date: 日期，格式 YYYYMMDD，默认获取最近交易日
        page: 页码
        page_size: 每页条数
    """
    if date is None:
        # 默认获取最近交易日（简单处理：今天）
        date = datetime.now().strftime('%Y%m%d')
    
    url = 'https://datacenter-web.eastmoney.com/api/data/v1/get'
    params = {
        'reportName': 'RPTA_WEB_LHB_MRTJ',
        'columns': 'ALL',
        'pageNumber': str(page),
        'pageSize': str(page_size),
        'sortTypes': '-1',
        'sortColumns': 'trade_date',
        'source': 'WEB',
        'client': 'WEB',
        'filter': f'(trade_date>{date[-8:]})',  # 最近数据
    }
    
    try:
        resp = session.get(url, params=params, timeout=15)
        if resp.status_code == 200:
            data = resp.json()
            if data.get('result'):
                records = data['result'].get('data', [])
                if records:
                    print(f"=== 龙虎榜数据 ===")
                    for r in records[:5]:  # 只展示前5条
                        code = r.get('stock_code', '')
                        name = r.get('stock_name', '')
                        reason = r.get('reason', '')[:20]
                        date_val = r.get('trade_date', '')
                        print(f"{date_val} {code} {name} | {reason}")
                    return records
                else:
                    print("当日无龙虎榜数据")
            else:
                print("数据获取失败")
    except Exception as e:
        print(f"获取失败: {e}")
    return None

def get_longhu_detail(secid):
    """
    获取特定股票的龙虎榜详情
    
    Args:
        secid: 股票代码，如 '1.600519'
    """
    url = 'https://datacenter-web.eastmoney.com/api/data/v1/get'
    params = {
        'reportName': 'RPTA_WEB_LHB_DETAIL',
        'columns': 'ALL',
        'pageNumber': '1',
        'pageSize': '10',
        'sortTypes': '-1',
        'sortColumns': 'trade_date',
        'source': 'WEB',
        'client': 'WEB',
        'filter': f'(scode={secid})',
    }
    
    try:
        resp = session.get(url, params=params, timeout=15)
        if resp.status_code == 200:
            data = resp.json()
            if data.get('result'):
                records = data['result'].get('data', [])
                if records:
                    latest = records[0]
                    print(f"\n=== {latest.get('sname', 'N/A')} 龙虎榜详情 ===")
                    print(f"股票代码: {latest.get('scode', 'N/A')}")
                    print(f"上榜原因: {latest.get('reason', 'N/A')}")
                    print(f"日期: {latest.get('trade_date', 'N/A')}")
                    
                    # 席位数据（买入）
                    buy_seats = latest.get('buySeats', [])
                    if buy_seats:
                        print(f"\n买入席位 Top 5:")
                        for i, seat in enumerate(buy_seats[:5], 1):
                            seat_name = seat.get('seatName', 'N/A')
                            buy_amt = seat.get('buyAmt', 0) / 1e4  # 万元
                            print(f"  {i}. {seat_name}: {buy_amt:.0f} 万")
                    
                    # 席位数据（卖出）
                    sell_seats = latest.get('sellSeats', [])
                    if sell_seats:
                        print(f"\n卖出席位 Top 5:")
                        for i, seat in enumerate(sell_seats[:5], 1):
                            seat_name = seat.get('seatName', 'N/A')
                            sell_amt = seat.get('sellAmt', 0) / 1e4  # 万元
                            print(f"  {i}. {seat_name}: {sell_amt:.0f} 万")
    except Exception as e:
        print(f"获取详情失败: {e}")

if __name__ == '__main__':
    # 获取近期龙虎榜
    get_longhu_bang()
    
    # 获取具体股票龙虎榜详情（示例：贵州茅台）

    print("\n--- 示例：获取贵州茅台龙虎榜 ---")
    get_longhu_detail('1.600519')
```

## 七、实战案例

### 案例：2024年某题材股龙虎榜分析

假设某AI概念股XYZ（虚构），连续3个涨停后登上龙虎榜：

| 席位 | 买入额(万) | 卖出额(万) | 净额(万) | 类型 |
|------|-----------|-----------|---------|------|
| 华鑫上海茅台路 | 5,000 | 1,000 | +4,000 | 游资 |
| 光大佛山绿景路 | 4,500 | 500 | +4,000 | 游资 |
| 机构专用 | 3,000 | 500 | +2,500 | 机构 |
| 某券商北京营业部 | 2,000 | 3,000 | -1,000 | 散户集中营 |

**分析**：
1. 游资+机构同时大额买入 → **强信号，看多**
2. 游资席位接力 → 题材炒作延续概率大
3. 机构出现在高位涨停 → **需警惕，可能是接盘**
4. 某营业部净卖出 → **主力出货迹象**

**结论**：高位游资接力+机构买入，需结合题材实质性和市场情绪判断。若无实质利好，可能是**最后的疯狂**。
