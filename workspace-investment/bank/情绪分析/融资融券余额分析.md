# 融资融券余额分析

## 一、核心概念

### 1.1 融资余额（Margin Debt）

**融资余额** = 投资者向券商借入资金买入股票后，尚未归还的总额

| 指标 | 含义 |
|------|------|
| **融资余额增加** | 投资者看多，借钱加仓，市场做多力量增强 |
| **融资余额减少** | 投资者看空或止盈，主动还款，做多力量减弱 |

### 1.2 融券余额（Short Selling Balance）

**融券余额** = 投资者向券商借入股票卖出后，尚未买回还券的总额

| 指标 | 含义 |
|------|------|
| **融券余额增加** | 投资者看空，借股票卖出，市场做空力量增强 |
| **融券余额减少** | 投资者看多或止损，买入股票还券，做空力量减弱 |

---

## 二、融资融券比

### 2.1 计算公式

```
融资融券比 = 融资余额 / 融券余额
```

### 2.2 解读

| 比值区间 | 市场含义 |
|---------|---------|
| **> 2** | 多方极度强势，看涨情绪浓厚 |
| **1.5 - 2** | 多方较强 |
| **> 1** | 多方占优（最常见） |
| **< 1** | 空方占优，市场偏弱 |
| **< 0.5** | 空方极度强势 |

> **注意**：A股融资余额远大于融券余额，融资融券比通常>1

### 2.3 实战用法

```
融资融券比持续上升 → 确认上涨趋势，持有
融资融券比高位拐头向下 → 预警见顶，减仓
融资余额大幅下降 + 指数下跌 → 确认下降趋势
```

## 三、融资净买入额变化趋势

### 3.1 指标说明

```
融资净买入额 = 当日融资买入额 - 当日融资偿还额
```

| 趋势 | 市场信号 |
|------|---------|
| **持续净流入** | 杠杆资金持续加码，看多后市 |
| **持续净流出** | 杠杆资金持续减仓，看空后市 |
| **高位净流入减少** | 做多动能衰减，警惕回调 |
| **低位净流入增加** | 资金逆势抄底，关注机会 |

### 3.2 观察窗口

| 时间维度 | 意义 |
|---------|------|
| **单日** | 短期情绪波动 |
| **周度** | 中期趋势判断 |
| **月度** | 长期趋势确认 |

## 四、警戒线与平仓线

### 4.1 维持担保比例

投资者融资融券账户的核心风险指标：

```
维持担保比例 = 担保物价值 / 负债总额
            = (现金 + 证券市值) / (融资欠款 + 融券市值)
```

### 4.2 关键比例

| 比例 | 名称 | 含义 |
|------|------|------|
| **≥ 300%** | 提取线 | 可提取超过300%的担保证券 |
| **≥ 150%** | 警戒线 | 收到券商预警，需关注 |
| **≥ 130%** | 平仓线 | 券商通知追保，追加担保物 |
| **< 130%** | 强制平仓线 | 券商有权强制卖出还债 |

### 4.3 风险提示

⚠️ **强制平仓风险**：
- 市场快速下跌时，融资客面临双重损失
- 2024年多轮调整中，融资盘爆仓加剧下跌
- 观察融资余额快速下降期，往往对应市场加速赶底

## 五、融资客集中板块追踪

### 5.1 追踪方法

1. **东方财富数据中心** → 融资融券 → 板块融资余额排行
2. **同花顺iFinD** → 融资融券 → 行业杠杆资金流向
3. **乌龟量化** → 情绪数据 → 融资板块热力图

### 5.2 板块集中度分析

```
某板块融资余额占全市场比例 = 该板块融资余额 / 全市场融资余额
```

| 集中度 | 含义 |
|-------|------|
| **> 15%** | 极度集中，关注该板块风险 |
| **10%-15%** | 偏高，跟踪异动 |
| **5%-10%** | 正常范围 |
| **< 5%** | 偏低，资金关注度低 |

### 5.3 融资客加仓信号

```
融资净买入额 Top 3 板块连续出现 → 资金集中布局
融资净买入额 Top 板块 vs 指数背离 → 预警先行信号
```

## 六、Python获取融资融券数据

```python
# -*- coding: utf-8 -*-
"""
获取A股融资融券数据
数据来源：东方财富
"""
import requests
import json
from pathlib import Path
import sys

sys.stdout.reconfigure(encoding='utf-8')

# 加载Cookie
cookie_file = Path(__file__).parent.parent / 'config' / 'eastmoney_cookie.json'
with open(cookie_file, 'r', encoding='utf-8') as f:
    config = json.load(f)
    cookie = config['cookie']

session = requests.Session()
session.headers.update({
    'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64)',
    'Cookie': cookie,
    'Referer': 'https://www.eastmoney.com/'
})

def get_margin_data():
    """
    获取全市场融资融券汇总数据
    """
    url = 'https://datacenter-web.eastmoney.com/api/data/v1/get'
    params = {
        'reportName': 'RPTA_WEB_RZRQ_MRTJ',
        'columns': 'ALL',
        'pageNumber': '1',
        'pageSize': '1',
        'sortTypes': '-1',
        'sortColumns': 'trade_date',
        'source': 'WEB',
        'client': 'WEB',
    }
    
    try:
        resp = session.get(url, params=params, timeout=10)
        if resp.status_code == 200:
            data = resp.json()
            if data.get('result'):
                records = data['result'].get('data', [])
                if records:
                    latest = records[0]
                    rzye = latest.get('rzye', 0) / 1e8  # 融资余额（亿元）
                    rqye = latest.get('rqye', 0) / 1e8  # 融券余额（亿元）
                    rzrqye = latest.get('rzrqye', 0) / 1e8  # 融资融券余额
                    ratio = rzye / rqye if rqye > 0 else 0  # 融资融券比
                    
                    print(f"=== 融资融券数据 ===")
                    print(f"日期: {latest.get('trade_date', 'N/A')}")
                    print(f"融资余额: {rzye:.2f} 亿元")
                    print(f"融券余额: {rqye:.2f} 亿元")
                    print(f"融资融券比: {ratio:.2f}")
                    print(f"融资融券余额: {rzrqye:.2f} 亿元")
                    return latest
    except Exception as e:
        print(f"获取失败: {e}")
    return None

def get_margin_by_industry():
    """
    获取行业板块融资余额排行
    """
    url = 'https://datacenter-web.eastmoney.com/api/data/v1/get'
    params = {
        'reportName': 'RPTA_WEB_RZRQ_HY',
        'columns': 'ALL',
        'pageNumber': '1',
        'pageSize': '10',
        'sortTypes': '-1',
        'sortColumns': 'rzye',
        'source': 'WEB',
        'client': 'WEB',
    }
    
    try:
        resp = session.get(url, params=params, timeout=10)
        if resp.status_code == 200:
            data = resp.json()
            if data.get('result'):
                records = data['result'].get('data', [])
                print(f"\n=== 融资余额 Top 10 行业 ===")
                for i, r in enumerate(records, 1):
                    name = r.get('hy_name', 'N/A')
                    rzye = r.get('rzye', 0) / 1e8
                    print(f"{i}. {name}: {rzye:.2f} 亿元")
    except Exception as e:
        print(f"获取行业数据失败: {e}")

if __name__ == '__main__':
    get_margin_data()
    get_margin_by_industry()
```

## 七、实战案例

### 案例：2024年9月行情反转

| 时间 | 融资余额变化 | 市场表现 |
|------|------------|---------|
| 2024年9月初 | 融资余额约1.4万亿，持续低迷 | 指数底部震荡 |
| 2024年9月24日 | 政策利好，融资客大幅净买入 | 指数单日暴涨 |
| 2024年9月底 | 融资余额突破1.5万亿 | 趋势确认上涨 |

**启示**：融资余额是行情的**滞后确认指标**，而非领先指标。但融资余额大幅变化可作为趋势强化的确认信号。

## 八、注意事项

⚠️ **核心要点**：

| 风险点 | 说明 |
|-------|------|
| **杠杆放大效应** | 融资放大收益的同时也放大亏损 |
| **强制平仓风险** | 维持担保比例<130%面临强平 |
| **滞后性** | 融资数据T+1公布，不宜作为短线指标 |
| **庄家诱多** | 有时主力通过融资数据制造假信号 |
| **政策影响** | 监管层调整保证金比例会显著影响融资规模 |

## 九、总结

| 指标 | 含义 | 实战用法 |
|------|------|---------|
| **融资余额** | 做多力量 | 增加=看多，减少=看空 |
| **融券余额** | 做空力量 | 增加=看空，减少=看多 |
| **融资融券比** | 多空力量对比 | >1多方强势，<1空方强势 |
| **警戒线150%** | 风险预警 | 关注追保通知 |
| **平仓线130%** | 强制卖出风险 | 避免触及 |
