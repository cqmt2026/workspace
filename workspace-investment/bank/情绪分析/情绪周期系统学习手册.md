## 📖 情绪周期概述

### 什么是情绪周期？

情绪周期是指**市场参与者群体情绪**从悲观到乐观再到悲观的循环过程。

**核心逻辑**:
- 市场走势 = 资金推动
- 资金流向 = 情绪驱动
- 情绪变化 = 可预测的周期性

**一句话**: **走势是情绪的外化，情绪是走势的本质**

---

## 🔄 情绪周期六阶段模型

### 完整周期

```
冰点期 → 启动期 → 发酵期 → 高潮期 → 退潮期 → 衰退期 → (回到冰点)
```

---

### 1️⃣ 冰点期（绝望）

**特征**:
| 指标 | 表现 |
|------|------|
| 涨停家数 | <20 家 |
| 跌停家数 | >50 家 |
| 连板高度 | 2-3 板 |
| 成交量 | 极度萎缩 |
| 赚钱效应 | 极差（<10%） |
| 市场言论 | 一片悲观 |

**操作策略**:
- ✅ 空仓/轻仓（<10%）
- ✅ 观察龙头股
- ✅ 等待拐点信号
- ❌ 不抄底、不追涨

**心理状态**: "这市场没法玩了"

---

### 2️⃣ 启动期（希望）

**特征**:
| 指标 | 表现 |
|------|------|
| 涨停家数 | 30-50 家 |
| 跌停家数 | <10 家 |
| 连板高度 | 4-5 板 |
| 成交量 | 温和放量 |
| 赚钱效应 | 好转（30-40%） |
| 市场言论 | 谨慎乐观 |

**关键信号**:
- ✅ 新龙头出现（突破空间限制）
- ✅ 主线板块雏形
- ✅ 冰点后首阳

**操作策略**:
- ✅ 试错建仓（20-30%）
- ✅ 跟随龙头
- ✅ 主线龙头首阴

**心理状态**: "好像有点机会？"

---

### 3️⃣ 发酵期（乐观）

**特征**:
| 指标 | 表现 |
|------|------|
| 涨停家数 | 50-80 家 |
| 跌停家数 | <5 家 |
| 连板高度 | 6-8 板 |
| 成交量 | 持续放量 |
| 赚钱效应 | 良好（50-60%） |
| 市场言论 | 普遍乐观 |

**关键信号**:
- ✅ 板块扩散（龙头→龙二→龙三）
- ✅ 补涨股出现
- ✅ 踏空资金入场

**操作策略**:
- ✅ 加仓主升（50-70%）
- ✅ 主线龙头/补涨龙
- ✅ 持股待涨

**心理状态**: "这波行情来了！"

---

### 4️⃣ 高潮期（狂热）

**特征**:
| 指标 | 表现 |
|------|------|
| 涨停家数 | >100 家 |
| 跌停家数 | 0-3 家 |
| 连板高度 | 9 板 + |
| 成交量 | 天量 |
| 赚钱效应 | 极好（>80%） |
| 市场言论 | 极度乐观 |

**关键信号**:
- ⚠️ 百股涨停
- ⚠️ 新股民入场
- ⚠️ 媒体疯狂报道
- ⚠️ 垃圾股补涨

**操作策略**:
- ⚠️ 持股/分批止盈（50%）
- ⚠️ 不追高
- ⚠️ 准备撤退
- ❌ 不开新仓

**心理状态**: "牛市来了！冲啊！"

---

### 5️⃣ 退潮期（焦虑）

**特征**:
| 指标 | 表现 |
|------|------|
| 涨停家数 | 30-50 家 |
| 跌停家数 | 10-30 家 |
| 连板高度 | 高度股跳水 |
| 成交量 | 开始萎缩 |
| 赚钱效应 | 恶化（30-40%） |
| 市场言论 | 分歧加大 |

**关键信号**:
- ⚠️ 龙头股高位跌停
- ⚠️ 连板股批量炸板
- ⚠️ 亏钱效应出现

**操作策略**:
- ⚠️ 减仓（30-50%）
- ⚠️ 止盈保护
- ⚠️ 切换防御板块
- ❌ 不接力高位股

**心理状态**: "好像不太对劲？"

---

### 6️⃣ 衰退期（恐慌）

**特征**:
| 指标 | 表现 |
|------|------|
| 涨停家数 | <20 家 |
| 跌停家数 | >50 家 |
| 连板高度 | 2 板都难 |
| 成交量 | 快速萎缩 |
| 赚钱效应 | 极差（<10%） |
| 市场言论 | 一片恐慌 |

**关键信号**:
- ⚠️ 千股跌停
- ⚠️ 流动性危机
- ⚠️ 融资盘爆仓

**操作策略**:
- ❌ 空仓（0%）
- ❌ 不抄底
- ❌ 不接飞刀
- ✅ 等待冰点

**心理状态**: "快跑！要崩盘了！"

## 📊 情绪量化指标

### 核心指标

| 指标 | 计算方法 | 阈值 |
|------|----------|------|
| **涨停家数** | 当日涨停股票数量 | >100 高潮，<20 冰点 |
| **跌停家数** | 当日跌停股票数量 | >50 危险，<5 安全 |
| **连板高度** | 最高连板数 | >9 高潮，<3 冰点 |
| **炸板率** | 炸板数/涨停尝试数 | >40% 危险 |
| **赚钱效应** | 上涨家数/总家数 | >80% 高潮，<20% 冰点 |
| **成交量** | 两市成交额 | 天量高潮，地量冰点 |
| **北向资金** | 净流入/流出 | 大幅流入/流出 |

---

### 情绪指数公式

```
情绪指数 = (涨停家数×0.3 + 连板高度×10×0.2 + 赚钱效应×0.3 - 跌停家数×0.2)

>80: 高潮期
60-80: 发酵期
40-60: 启动期/退潮期
20-40: 衰退期
<20: 冰点期
```

## 🎯 情绪拐点识别

### 冰点→启动（最佳买点）

**信号组合**:
1. ✅ 连续 3 天冰点（涨停<20，跌停>50）
2. ✅ 出现新龙头（突破 5 板空间）
3. ✅ 成交量温和放大
4. ✅ 跌停家数锐减

**操作**: 重仓出击龙头

---

### 启动→发酵（加仓点）

**信号组合**:
1. ✅ 涨停家数突破 50
2. ✅ 板块效应明显
3. ✅ 连板高度突破 6 板

**操作**: 加仓主线

---

### 高潮→退潮（撤退信号）

**信号组合**:
1. ⚠️ 龙头股高位跌停
2. ⚠️ 炸板率>40%
3. ⚠️ 跌停家数开始增加

**操作**: 减仓/清仓

---

### 衰退→冰点（观察）

**信号组合**:
1. ✅ 跌停家数开始减少
2. ✅ 成交量极度萎缩
3. ✅ 市场言论极度悲观

**操作**: 准备抄底

## 📈 情绪周期嵌套

### 大周期套小周期

```
月线情绪周期（数年）
  └─ 周线情绪周期（数月）
      └─ 日线情绪周期（数周）
          └─ 盘中情绪波动（数小时）
```

### 操作策略

- **大周期向上 + 小周期冰点** = 黄金买点
- **大周期向下 + 小周期高潮** = 逃命机会

---

## ⚠️ 情绪周期常见误区

### 误区 1: 刻舟求剑

❌ "上次冰点后涨了 50%，这次也会"
✅ 每次周期都不同，需结合当下

---

### 误区 2: 过早抄底

❌ "已经跌了这么多了，应该是冰点"
✅ 冰点可以更低，等拐点信号

---

### 误区 3: 贪婪不止盈

❌ "还能涨，再等等"
✅ 高潮期分批止盈，不赚最后一块钱

---

### 误区 4: 情绪化交易

❌ "市场这么差，肯定还要跌"（衰退期割肉）
✅ 逆向思维，衰退期准备，冰点期出击

## 🎯 仓位管理

| 情绪阶段 | 仓位 | 操作 |
|----------|------|------|
| 冰点期 | 0-10% | 空仓等待 |
| 启动期 | 30-50% | 试错建仓 |
| 发酵期 | 60-80% | 加仓主升 |
| 高潮期 | 50-80% | 持股/止盈 |
| 退潮期 | 20-40% | 减仓保护 |
| 衰退期 | 0% | 空仓等待 |

## 🔄 情绪周期 vs 缠论融合

| 维度 | 缠论 | 情绪周期 | 融合方案 |
|------|------|----------|----------|
| **分析对象** | K 线走势 | 投资者情绪 | 走势是情绪外化 |
| **买点** | 一二三买 | 冰点转启动 | 情绪拐点=缠论一买 |
| **卖点** | 背驰/一二三卖 | 高潮转退潮 | 情绪拐点=缠论一卖 |
| **周期** | 月/周/日/15 分钟 | 数天至数周 | 对应日线级别 |
| **优势** | 精确 | 前瞻 | 互补增强 |

### 融合公式

```
v5.0 = 缠论多周期 + 情绪周期

买点 = 缠论一买 + 情绪冰点转启动
卖点 = 缠论一卖 + 情绪高潮转退潮
仓位 = 缠论信号 × 情绪阶段系数
```

## 🎯 核心精髓

1. **情绪驱动资金** - 资金驱动走势
2. **周期循环** - 冰点→启动→发酵→高潮→退潮→衰退
3. **拐点为王** - 冰点转启动是最佳买点
4. **逆向思维** - 别人恐惧我贪婪，别人贪婪我恐惧
5. **仓位匹配** - 不同情绪阶段，仓位不同
