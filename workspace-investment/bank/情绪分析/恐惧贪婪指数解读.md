# 恐惧贪婪指数解读

## 一、原理：CNN Fear & Greed Index 的7个指标

CNN Fear & Greed Index（恐惧贪婪指数）是衡量美股市场情绪的经典指标，数值范围0-100。指数综合以下**7个维度**：

| 指标 | 含义 | 极端值含义 |
|------|------|-----------|
| **股价动量** | 标普500距52周高点的距离 | 距高点越近→贪婪 |
| **垃圾债券利差** | 垃圾债与国债收益率利差 | 利差收窄→贪婪 |
| **看跌/看涨比** | 期权市场情绪 | 看跌增加→恐惧 |
| **市场波动率(VIX)** | VIX恐慌指数 | VIX升高→恐惧 |
| **看跌期权需求** | 标普500看跌/看涨期权量 | 需求高→恐惧 |
| **股价 breadth** | 上涨vs下跌家数比 | 上涨多→贪婪 |
| **债券市场动能** | 股债相对强弱 | 债券强→恐惧 |

> **核心逻辑**：当所有指标同时指向同一方向时，市场情绪处于极端状态。

## 二、区间划分与含义

```
0 ────── 25 ────── 45 ────── 55 ────── 75 ────── 100
极度恐惧      恐惧      中性      贪婪     极度贪婪
```

| 区间 | 含义 | 市场特征 |
|------|------|---------|
| **0-25** | 极度恐惧 | 恐慌性抛售，人人自危，估值极度压缩 |
| **25-45** | 恐惧 | 负面情绪主导，但非恐慌 |
| **45-55** | 中性 | 多空平衡，无明确方向 |
| **55-75** | 贪婪 | 乐观情绪蔓延，追涨明显 |
| **75-100** | 极度贪婪 | 泡沫迹象，高位追涨普遍 |

### 3.2 A股特色考量

- A股散户占比高，情绪波动更大
- 杠杆资金（融资融券）是重要情绪锚点
- 国家队动向会显著影响情绪
- 韭菜情绪指标需结合政策面判断

## 四、历史极值回顾

### 2020年新冠疫情（极度恐惧）

- **时间**：2020年3月
- **美股**：Fear & Greed Index 跌破10，创历史极值
- **A股**：上证指数跌至2646点
- **背景**：全球疫情爆发，熔断频发
- **教训**：极度恐惧是逆向买入的绝佳时机

### 2024年行情回顾

- **2024年初**：市场情绪低迷，指数持续调整
- **2024年9月**：政策利好刺激，情绪快速由恐惧转贪婪
- **极值参考**：当沪深300 PE<10倍时，往往对应情绪底部

## 五、实战用法

### 5.1 逆向投资策略

```
极度恐惧区 (0-25) → 分批建仓，布局优质资产
极度贪婪区 (75-100) → 分批减仓，锁定利润
```

### 5.2 仓位管理参考

| 情绪区间 | 参考仓位 | 操作原则 |
|---------|---------|---------|
| 0-25 | 80%-100% | 大胆加仓，越跌越买 |
| 25-45 | 60%-80% | 逐步建仓，精选标的 |
| 45-55 | 40%-60% | 均衡配置 |
| 55-75 | 20%-40% | 逢高减仓，不追涨 |
| 75-100 | 0%-20% | 清仓或对冲，规避风险 |

### 5.3 注意事项

⚠️ **局限性**：
- 恐惧贪婪指数是**逆向指标**，不是预测工具
- 极端值可能持续很长时间（如2018年贸易战）
- 需结合估值、基本面综合判断

## 六、Python获取当前恐惧贪婪数据

```python
# -*- coding: utf-8 -*-
"""
获取CNN Fear & Greed Index数据
"""
import requests
import json

def get_cnn_fear_greed():
    """
    获取CNN Fear & Greed Index
    """
    url = "https://production.datavix.cnn.com/v2/fear-and-greed/latest"
    headers = {
        'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64)',
        'Referer': 'https://www.cnn.com/',
    }
    
    try:
        resp = requests.get(url, headers=headers, timeout=10)
        if resp.status_code == 200:
            data = resp.json()
            score = data.get('fearAndGreed', {})
            current = score.get('score', 'N/A')
            rating = score.get('rating', 'N/A')
            previous = score.get('previousClose', 'N/A')
            
            print(f"当前恐惧贪婪指数: {current}")
            print(f"评级: {rating}")
            print(f"前一交易日: {previous}")
            return current
    except Exception as e:
        print(f"获取失败: {e}")
    
    return None

if __name__ == '__main__':
    get_cnn_fear_greed()
```
