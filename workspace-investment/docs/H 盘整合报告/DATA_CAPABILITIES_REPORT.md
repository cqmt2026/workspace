## 🎯 当前可用数据

### 【1. 大盘指数】✅

```python
# 获取方式
url = 'http://push2.eastmoney.com/api/qt/stock/get'
params = {'secid': '1.000001', 'fields': 'f43'}  # 上证指数
```

**可获取**: 当前价、开盘、最高、最低、成交量

---

### 【2. 个股行情】✅

```python
# 获取方式
url = 'http://push2.eastmoney.com/api/qt/stock/get'
params = {'secid': '1.600519', 'fields': 'f43,f44,f45,f46,f47'}
```

**可获取**: 实时行情、涨跌数据、成交量、市值、市盈率

---

### 【3. 板块数据】✅

```python
# 获取方式
url = 'http://push2.eastmoney.com/api/qt/clist/get'
params = {'fs': 'm:90 t:3', 'fields': 'f12,f14,f3,f104,f105'}  # 概念板块
```

**可获取**: 板块涨幅、领涨股、上涨/下跌家数

---

### 【4. 资金流向】✅

```python
# 获取方式
url = 'http://push2.eastmoney.com/api/qt/stock/get'
params = {'secid': '1.600519', 'fields': 'f113,f114,f115'}  # 个股资金流
```

**可获取**: 主力净流入、超大单、大单、中单、小单

---
