## 四、量价背离图解

### 顶背离（卖出信号）

```
价格
  ↑
  │          B 高点（更高）
  │         /╲
  │        /  ╲
  │       /    ╲      D 跌破
  │  A 高点      ╲    /
  │   /╲          ╲  /
  │  /  ╲          ╲/
  │ /    ╲
  └──────────────────→ 时间

成交量
  ↑
  │  ████████ ← A 点量大
  │  ██████
  │      ████ ← B 点量小（背离）
  │      ██
  │        █
  └──────────────────→ 时间
        ↑
      卖出信号
```

**含义**：价格创新高，成交量不创新高 → 上涨动力不足  
**操作**：减仓或清仓

---
