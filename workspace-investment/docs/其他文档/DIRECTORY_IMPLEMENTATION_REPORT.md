## 📋 使用说明

### strategy/ - 战略方向

**用途**：
- 存储战略方向文档
- 存储重大决策文档
- 由老板直接管理

**示例**：
```markdown
# 2026 年 Q2 股票系统发展战略

**日期**：2026-03-24  
**决策人**：老板

## 战略目标

## 实施路径

## 预期效果
```

---

### insights/ - 洞察总结

**用途**：
- 市场洞察分析
- 交易规律总结
- 系统优化建议

**生成方式**：
- Agent 自动生成
- 人工审核确认

**示例**：
```markdown
# 早盘尾盘规律分析

**日期**：2026-03-24  
**来源**：数据分析  
**置信度**：高

## 现象描述

## 数据分析

## 规律总结

## 应用建议
```

---

### decisions/ - 决策记录

**用途**：
- 架构决策记录（ADR）
- 业务决策记录
- 技术决策记录

**ADR 格式**：
```markdown
# ADR-XXX：决策标题

**日期**：YYYY-MM-DD  
**状态**：提议/已采纳/已废弃  
**决策人**：CEO Agent + 人工

## 背景

## 决策

## 后果

## 合规性

## 备注
```

---

### agents/ - Agent 状态

**用途**：
- 各 Agent 配置文件
- Agent 状态文档
- Agent 知识库

**示例**：
```markdown
# V14 主系统 Agent

**状态**：✅ 运行中  
**职责**：推送 + 交易 + 报告  
**配置文件**：agents/v14_system_config.json

## 配置

## 知识库

## 运行日志
```

---

### review/ - 待审核内容

**用途**：
- Agent 提交审核内容
- 人工审阅记录
- 审核结果记录

**审核流程**：
```
Agent 提交 → 放入 review/ → 人工审阅 → 通过/拒绝
```

---

### shared-knowledge/ - 共享规范

**用途**：
- 技术规范
- 操作规范
- 业务规范

**示例**：
```markdown
# V14 系统架构规范

**版本**：V1.0  
**生效日期**：2026-03-24  
**适用范围**：V14 系统

## 目的

## 规范内容

## 执行要求

## 违规处理
```
