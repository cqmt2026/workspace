# 均线系统详解

**核心目标**：利用均线判断趋势和买卖点

---

## 一、均线基础

### 1. 什么是均线
- 移动平均线（Moving Average）
- 一段时间内收盘价的平均值
- 平滑价格波动
- 显示趋势方向

### 2. 常用均线

**短期均线**：
- 5 日均线（MA5）：周线
- 10 日均线（MA10）：半月线
- 20 日均线（MA20）：月线

**中期均线**：
- 30 日均线（MA30）
- 60 日均线（MA60）：季线

**长期均线**：
- 120 日均线（MA120）：半年线
- 250 日均线（MA250）：年线

### 3. 均线计算

**简单均线（SMA）**：
```
MA(N) = (C1 + C2 + ... + CN) / N
```
- C1-Cn：最近 N 日收盘价
- N：周期数

**指数均线（EMA）**：
- 更重视近期价格
- 反应更灵敏
- 适合短线

## 二、单均线用法

### 1. 5 日均线
**特点**：
- 最灵敏
- 紧贴股价
- 适合短线

**用法**：
- 股价在 MA5 上：短线强势
- 股价在 MA5 下：短线弱势
- MA5 向上：短线上涨
- MA5 向下：短线下跌

**操作**：
- 短线：MA5 上持股
- 跌破 MA5：减仓
- 跌破 MA10：清仓

### 2. 10 日均线
**特点**：
- 短线重要支撑
- 波段操作参考
- 反应较快

**用法**：
- 股价在 MA10 上：波段强势
- 股价在 MA10 下：波段弱势

**操作**：
- 波段：MA10 上持股
- 跌破 MA10：减仓或清仓

### 3. 20 日均线
**特点**：
- 月线
- 中线重要参考
- 主力成本线

**用法**：
- 股价在 MA20 上：中线强势
- 股价在 MA20 下：中线弱势

**操作**：
- 中线：MA20 上持股
- 跌破 MA20：减仓

### 4. 60 日均线
**特点**：
- 季线
- 生命线
- 牛熊分界线

**用法**：
- 股价在 MA60 上：牛市
- 股价在 MA60 下：熊市

**操作**：
- MA60 上：积极操作
- MA60 下：空仓或轻仓

### 5. 250 日均线
**特点**：
- 年线
- 长期趋势
- 牛熊分界

**用法**：
- 股价在 MA250 上：长期牛市
- 股价在 MA250 下：长期熊市

**操作**：
- MA250 上：长期持有
- MA250 下：谨慎操作

## 三、多均线系统

### 1. 均线排列

**多头排列**（看涨）：
```
MA5 > MA10 > MA20 > MA60 > MA250
```
- 短期>中期>长期
- 趋势向上
- 持股待涨

**空头排列**（看跌）：
```
MA5 < MA10 < MA20 < MA60 < MA250
```
- 短期<中期<长期
- 趋势向下
- 空仓观望

### 2. 均线交叉

**金叉**（买入信号）：
- 短期均线上穿长期均线
- MA5 上穿 MA10：短线金叉
- MA10 上穿 MA20：中线金叉
- MA50 上穿 MA200：长线金叉

**死叉**（卖出信号）：
- 短期均线下穿长期均线
- MA5 下穿 MA10：短线死叉
- MA10 下穿 MA20：中线死叉
- MA50 下穿 MA200：长线死叉

### 3. 均线粘合

**特征**：
- 多条均线聚集
- 股价窄幅震荡
- 选择方向前夕

**含义**：
- 多空平衡
- 即将变盘

**操作**：
- 等待突破
- 向上突破买入
- 向下突破卖出

### 4. 均线发散

**特征**：
- 多条均线分散
- 趋势明确
- 行情进行中

**含义**：
- 趋势强势
- 继续持有

**操作**：
- 顺势操作
- 不逆势

## 四、均线买卖信号

### 1. 买入信号

**信号一：金叉买入**
- 短期金叉长期
- MA5 上穿 MA10
- 成交量放大
- 买入

**信号二：回踩均线**
- 上涨趋势中
- 股价回踩均线
- 获得支撑
- 买入

**信号三：突破均线**
- 股价从下向上突破
- 突破 MA20/MA60
- 成交量放大
- 买入

**信号四：均线多头**
- 均线多头排列
- 趋势明确向上
- 持股或买入

### 2. 卖出信号

**信号一：死叉卖出**
- 短期死叉长期
- MA5 下穿 MA10
- 成交量放大
- 卖出

**信号二：跌破均线**
- 下跌趋势中
- 股价跌破均线
- 无法收回
- 卖出

**信号三：均线空头**
- 均线空头排列
- 趋势明确向下
- 空仓观望

**信号四：乖离过大**
- 股价远离均线
- 乖离率过大
- 可能回调
- 减仓

## 五、均线实战技巧

### 1. 葛兰碧八大法则

**买入法则**：
1. 均线从下降转平或上升，股价突破均线
2. 股价跌破均线，但均线仍上升
3. 股价回踩均线，获得支撑
4. 股价暴跌，远离均线（超卖）

**卖出法则**：
5. 均线从上升转平或下降，股价跌破均线
6. 股价突破均线，但均线仍下降
7. 股价反弹至均线，遇阻回落
8. 股价暴涨，远离均线（超买）

### 2. 均线支撑与压力

**支撑作用**：
- 上涨趋势中
- 均线是支撑位
- 回踩可买入

**压力作用**：
- 下跌趋势中
- 均线是压力位
- 反弹遇阻卖出

### 3. 均线周期选择

**短线**（1-2 周）：
- 使用 MA5、MA10
- 快速进出
- 严格止损

**中线**（1-3 月）：
- 使用 MA20、MA60
- 波段操作
- 适度止损

**长线**（3 月以上）：
- 使用 MA120、MA250
- 趋势投资
- 宽松止损

## 六、均线组合策略

### 1. 双均线策略

**组合**：MA5 + MA20

**买入**：
- MA5 上穿 MA20（金叉）
- 股价在双均线上方
- 成交量放大

**卖出**：
- MA5 下穿 MA20（死叉）
- 股价在双均线下方
- 成交量放大

### 2. 三均线策略

**组合**：MA5 + MA10 + MA20

**买入**：
- 三均线多头排列
- 股价回踩 MA10 或 MA20
- 获得支撑

**卖出**：
- 三均线空头排列
- 股价跌破 MA20
- 无法收回

### 3. 多均线策略

**组合**：MA5 + MA10 + MA20 + MA60

**买入**：
- 均线多头排列
- 股价回踩 MA20 或 MA60
- 获得支撑

**卖出**：
- 均线空头排列
- 股价跌破 MA60
- 无法收回

## 七、均线注意事项

### 1. 均线滞后性
- 均线是滞后指标
- 信号有延迟
- 需结合其他指标

### 2. 震荡市失效
- 震荡市中均线频繁交叉
- 产生虚假信号
- 减少操作或空仓

### 3. 需要确认
- 均线信号需成交量确认
- 需结合大盘环境
- 需结合其他指标

### 4. 周期匹配
- 短线用短周期均线
- 长线用长周期均线
- 不要混用

### 5. 止损纪律
- 买入后设止损
- 跌破均线止损
- 严格执行

---

## 八、总结口诀

> 均线系统要记清，短中长线分分明
> 多头排列持股涨，空头排列快空仓
> 金叉买入死叉卖，回踩支撑是买点
> 葛兰碧法八大则，灵活运用赢概率
> 均线滞后需确认，结合量价更准确
> 震荡市中少操作，趋势明确再进场
