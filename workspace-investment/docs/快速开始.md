# 快速开始指南

## 1. 安装

```bash
# 克隆仓库
git clone <仓库地址>
cd alice_quant

# 创建虚拟环境（推荐）
python -m venv venv
source venv/bin/activate  # Linux/Mac
# 或
venv\Scripts\activate     # Windows

# 安装依赖
pip install -r requirements.txt
```

## 2. 数据准备

AliceQuant 默认使用本地 SQLite 数据库 (`F:\market_data.db`) 作为主力数据源。

### 数据源配置

编辑 `config/default.yaml` 或在代码中配置：

```yaml
data:
  # 主力数据源: db(本地SQLite) / tencent / akshare / efinance
  primary_source: db
  
  # 备用数据源
  backup_sources: [tencent, akshare, efinance]
  
  # 本地数据库路径（仅 primary_source=db 时使用）
  db_path: 'F:\market_data.db'
  
  # 缓存大小（MB）
  cache_max_mb: 500
```

> 注意：腾讯/efinance/akshare 不需要 API KEY，可直接使用。

### 数据格式

`daily_k` 表需要包含以下字段：
- `code`: 股票代码 (sh.600000 / sz.000001)
- `date`: 交易日期 (YYYY-MM-DD)
- `open/high/low/close`: 价格
- `volume`: 成交量（股）

## 3. 运行回测

### 最简单的回测

```python
from alice_quant.core.config import ConfigManager
from alice_quant.data.datahub import DataHub
from alice_quant.features.engine import FeatureEngine
from alice_quant.backtest.engine import BacktestEngine
from alice_quant.strategies.pipeline import PipelineStrategy

# 1. 配置
config = ConfigManager()
config.load()  # 加载默认配置

# 2. 数据
datahub = DataHub(config)
datahub.initialize()

# 3. 特征引擎
engine = FeatureEngine(config, datahub)
engine.initialize()

# 4. 策略
strategy = PipelineStrategy(feature_engine=engine)

# 5. 回测
bt = BacktestEngine(config, datahub, engine)
result = bt.run(strategy, start='2025-01-01', end='2025-12-31')

# 6. 结果
print(result.summary())
```

### 自定义策略

```python
from alice_quant.strategies.base import BaseStrategy
from alice_quant.core.signal import Signal

class MyStrategy(BaseStrategy):
    def __init__(self, name='my_strategy', params=None, feature_engine=None, logger=None):
        defaults = {'ma_window': 20, 'rsi_threshold': 30}
        merged = defaults.copy()
        if params: merged.update(params)
        super().__init__(name, merged, feature_engine, logger)
    
    def on_start(self, context):
        self.watch_codes = context.watch_codes or []
    
    def on_bar(self, data, context):
        signals = []
        for code, bar in data.items():
            ma20 = self.get_cached_factor(code, 'ma_20', context.current_date)
            rsi = self.get_cached_factor(code, 'rsi_14', context.current_date)
            if ma20 and rsi and rsi < self.params['rsi_threshold']:
                signals.append(Signal(
                    date=context.current_date, code=code, direction='buy',
                    price=bar.get('close', 0), volume=0,
                    source=self.name, reason=f'RSI超卖{rsi:.0f}',
                    confidence=0.7
                ))
        return signals
```

## 6. 框架结构

```
alice_quant/
├── core/           # 核心: 配置/日志/数据标准/异常/信号/订单/账户/结果/Context
├── data/           # 数据层: DataHub/数据源(腾讯/efinance/akshare)/版本管理
├── features/       # 特征工程: 因子注册中心/35个因子/因子存储/IC监控
├── models/         # 模型训练: LightGBM/评估器/模型注册中心
├── strategies/     # 策略层: Pipeline/Trend/DaBan/MagicFormula/多因子
├── backtest/       # 回测引擎: 事件循环/订单管理/账户/绩效/过拟合/滑点/佣金
├── execution/      # 执行层: 信号处理/风控/模拟交易/紧急停止
├── dashboard/      # 监控层: 告警系统/系统监控
├── config/         # YAML配置管理
├── demos/          # 完整使用示例
└── tests/          # 测试用例
```
