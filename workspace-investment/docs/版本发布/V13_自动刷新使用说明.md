# V13.0 5 分钟自动刷新机制

**创建时间**: 2026-03-13 10:05  
**版本**: V1.0  
**状态**: ✅ 已启用

---

## 📋 功能说明

自动每 5 分钟刷新一次股票实时数据，确保数据实时性保持 100%。

### 核心功能
- ✅ **定时刷新**: 每 5 分钟自动执行
- ✅ **多数据源**: 新浪 + 腾讯双数据源备份
- ✅ **自动跳过模拟股票**: 只获取真实股票数据
- ✅ **数据备份**: 每次刷新自动保存带时间戳的备份
- ✅ **日志记录**: 完整的刷新日志（JSONL 格式）
- ✅ **交易时间检查**: 仅在交易时段执行（09:30-15:00）

## 🚀 启动方式

### 方式 1: Windows 计划任务（推荐）

**计划任务名称**: `OpenClaw_V13_AutoRefresh`

**执行频率**: 每 5 分钟  
**开始时间**: 10:10  
**工作目录**: `C:\Users\Administrator\.openclaw\workspace\stock-tools`

**管理命令**:
```bash
# 查看任务状态
schtasks /Query /TN "OpenClaw_V13_AutoRefresh"

# 立即执行一次
schtasks /Run /TN "OpenClaw_V13_AutoRefresh"

# 停止任务
schtasks /End /TN "OpenClaw_V13_AutoRefresh"

# 删除任务
schtasks /Delete /TN "OpenClaw_V13_AutoRefresh" /F
```

## ⚙️ 配置说明

**配置文件**: `data/refresh_config.json`

```json
{
  "interval_minutes": 5,           // 刷新间隔（分钟）
  "enabled": true,                 // 是否启用
  "start_time": "09:30",          // 开始时间
  "end_time": "15:00",            // 结束时间
  "data_sources": ["sina", "tencent"],  // 数据源
  "stock_pools": [                // 股票池文件
    "observation_pool.csv",
    "reserve_pool.csv"
  ],
  "last_refresh": "2026-03-13T10:05:55",  // 上次刷新时间
  "total_refreshes": 3            // 总刷新次数
}
```

## ⚠️ 注意事项

1. **交易时间**: 仅在交易日 09:30-15:00 执行
2. **网络依赖**: 需要稳定的网络连接
3. **数据源优先级**: 新浪 → 腾讯（自动切换）
4. **模拟股票**: 自动跳过，不获取数据
5. **请求频率**: 每只股票间隔 0.3 秒，避免被封 IP

## 🛠️ 故障排查

### 问题 1: 刷新失败
**检查**: 网络连接、数据源可用性  
**解决**: 检查日志 `data/refresh_log.jsonl`

### 问题 2: 计划任务未执行
**检查**: 任务状态 `schtasks /Query /TN "OpenClaw_V13_AutoRefresh"`  
**解决**: 重新创建计划任务

### 问题 3: 数据为空
**检查**: 股票池文件是否存在真实股票  
**解决**: 更新观察池/备选池
