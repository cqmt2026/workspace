## 概述

投资系统负责行情数据采集、策略测试、ML预测、持仓监控和日报推送。

## 六层架构

| 层级 | 模块 | 职责 |
|------|------|------|
| L1 | 数据采集层 | MX API、BaoStock、东方财富 |
| L2 | 数据处理层 | 清洗、去重、存储 |
| L3 | 策略引擎层 | 趋势跟踪、均值回归、动量 |
| L4 | ML预测层 | LightGBM、特征工程 |
| L5 | 风控层 | 止损、仓位管理、异常检测 |
| L6 | 推送层 | 微信、邮件、Obsidian |

## 核心脚本

| 脚本 | 功能 |
|------|------|
| market_collector.py | 行情数据采集 |
| strategy_runner.py | 策略回测执行 |
| ml_predictor.py | ML模型训练/预测 |
| holding_monitor.py | 持仓监控 |
| daily_report.py | 日报生成推送 |

## 数据流

```
MX API → 清洗 → SQLite → 特征工程 → ML模型 → 信号输出
                                    ↓
                              策略引擎 → 风控 → 推送
```
