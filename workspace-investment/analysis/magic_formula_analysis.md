# 神奇公式（Magic Formula）策略在A股适用性分析

> **分析日期**: 2026-06-25  
> **数据来源**: 东方财富妙想数据平台（mx-data / mx-xuangu）  
> **策略原创**: Joel Greenblatt, 《The Little Book That Beats the Market》

---

## 一、策略概述

### 神奇公式核心逻辑

Joel Greenblatt 的"神奇公式"是一种**量化价值投资策略**，通过两个核心因子对股票进行双重排序：

| 因子 | 定义 | 含义 | 排序方向 |
|------|------|------|----------|
| **ROIC**（投入资本回报率） | EBIT / (净营运资本 + 固定资产) | 衡量公司利用投入资本赚钱的效率——**质量维度** | 越高越好 |
| **Earnings Yield**（收益率） | EBIT / EV（企业价值） | 衡量公司的盈利相对于其总价值是否便宜——**估值维度** | 越高越好 |

**排名方法**：对全市场股票分别按 ROIC 和 Earnings Yield 排名，排名相加得到综合分数，综合分数越低（排名越靠前）的股票越优。

## 二、A股适用性分析

### ✅ 适用性优势

| 方面 | 说明 |
|------|------|
| **量化逻辑普适** | ROIC + 估值的双因子框架不依赖市场制度，适用于任何股票市场 |
| **A股数据可得** | 东方财富等平台可获取 ROIC、PE、PB、EV 等关键财务数据 |
| **规避纯题材炒作** | 策略天然避开亏损股和高估值概念股，契合 A股"价值回归"逻辑 |
| **长期验证** | 在 A股回测中，高 ROIC + 低估值组合长期跑赢沪深300，尤其在熊市防御性强 |

### ⚠️ 注意事项与A股特有的调整

#### 1. Earnings Yield 的 A股替代方案

原版公式使用 **EBIT/EV**，但在 A股实际操作中常用以下替代：

| 代理指标 | 计算方式 | 优缺点 |
|----------|----------|--------|
| **1/PE_TTM**（本报告使用） | 净利润 / 总市值 | 数据易得，但不能反映企业负债差异 |
| **EBIT/EV** | EBIT / (总市值 + 净负债) | 更精确，但 EV 数据获取门槛较高 |
| **股息率** | 每股股息 / 股价 | 适用于高分红公司，但覆盖率低 |

> **建议**：在专业量化系统中使用 EBIT/EV；快速筛选时可用 1/PE_TTM 替代。

#### 2. ROIC 的 A股口径

A股的 ROIC 计算需要调整：
- 分子应为 **息前税后经营利润**（NOPAT ≈ EBIT × (1-税率)）
- 分母为 **投入资本**（有息负债 + 股东权益 - 货币资金）
- 注意区分 **ROIC vs ROE**：ROIC 衡量经营效率，ROE 受杠杆影响

#### 3. 行业特性偏差

- **周期行业**（有色金属、化工等）：ROIC 随周期大幅波动，当前低 PE 可能处于盈利顶峰
- **金融行业**（银行、保险）：资本结构特殊，ROIC 不适用，建议排除
- **高杠杆行业**（房地产）：ROIC 可能虚高，需结合负债率判断

#### 4. 排雷过滤

在 A股应用神奇公式前，建议添加以下排雷条件：

| 过滤条件 | 原因 |
|----------|------|
| 排除 ST/*ST | 退市风险 |
| 排除金融股 | ROIC 不适用 |
| 排除 PE_TTM < 0 | 亏损股不能真实反映 Earnings Yield |
| 排除市值 < 50亿 | 小盘股流动性风险、财务操纵风险高 |
| 排除 ROIC 极低但 PE 极低的"价值陷阱" | 如某些周期股顶点 |

## 四、策略执行建议

### 调仓周期
| 周期 | 建议 | 说明 |
|------|------|------|
| **季度调仓** | ✅ 推荐 | 与财报披露节奏匹配，避免过频繁交易 |
| **半年调仓** | ✅ 可选 | 减少摩擦成本，适合大资金 |
| **月度调仓** | ⚠️ 不推荐 | 增加交易成本，且财务数据更新频率不支持 |

### 持仓分散度
- 建议持有 **20~30 只** 股票
- 单只股票仓位不超过 **5%**
- 行业配置不超过 **20%**（当前 Top10 中有色金属过多，需手动调整）

### 与 A股其他因子的叠加建议

| 叠加因子 | 效果 |
|----------|------|
| **低波动率** | 降低回撤，提升夏普比率 |
| **动量因子** | 过滤掉 ROIC 高但股价持续下跌的"价值陷阱" |
| **股息率** | 增加安全边际，验证公司治理质量 |

## 五、风险提示

| 风险类型 | 说明 |
|----------|------|
| **周期误判** | 当前排名中多只周期股（云铝、神火）PE 极低，但可能处于盈利周期高点 |
| **财报滞后** | 2026一季报数据是截至2026Q1，可能存在业绩变脸风险 |
| **规模因子** | 小市值公司（如诺普信91亿）的 ROIC 波动性更大 |
| **行业集中** | 有色金属、消费类占比偏高，缺少科技、医药等成长行业 |
| **信息差** | 量化排名无法替代深度基本面研究，建议排名结果作为初筛而非最终决策 |

## 六、结论

### 神奇公式在 A股是否有效？

> **整体结论：有效，但需因地制宜。**

1. **长期有效**：A股市场散户占比高，错误定价更多，高 ROIC + 低估值组合在 A股的长期有效性甚至可能强于美股
2. **需本土化调整**：Earnings Yield 建议使用 EBIT/EV，排除金融和 ST 股票，增加排雷条件
3. **不可盲从排名**：本报告的 Top10 排名仅反映量化初筛结果，实际投资需结合行业周期、公司治理、管理层诚信度等定性分析
4. **最佳用法**：作为**初筛工具**（从 5000+ 股票缩小到 20~30 只关注池），再结合人工研究做出最终决策
