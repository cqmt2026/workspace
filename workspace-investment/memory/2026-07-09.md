## bob同学 量化策略开发思路（2026-07-08视频）

### 核心观点
- 90%的人做量化一上来就扣代码扣模型，全搞反了。代码只是工具，策略才是灵魂
- 策略 = 把脑子里模糊的交易直觉，翻译成一套可以通过系统和数据执行的规则
- 功夫不在代码上，能把模糊的盘感拆成清楚能验证的规则，就算入门量化了

### bob框架：四块组成
1. **选股**（买什么）：确定范围 → 排雷 → 上因子 → 打分排序
2. **择时**（何时出手）：宏观开关 + 信号触发
3. **买卖**（怎么交易）：买入价/分批/分钱；止盈止损规则
4. **风控**（怎么保命）：单票仓位/单账户回撤/组合对冲

### 对我们系统的启发
两个明显短板：
1. **缺少大盘环境择时开关** — 大盘不好时应该自动降低仓位或空仓
2. **没有明确的止盈规则** — 目前只有5%止损，没考虑什么时候该卖

## 斌哥策略优化迭代记录

### 三次迭代过程
| 版本 | 条件 | 触发 | 胜率 | 收益 |
|------|------|------|------|------|
| v1 | 缩量<0.7+不破底 | 131 | 44.3% | -1.91% |
| v2 | 缩量<0.5+不破底+价>=10 | 212 | 42.9% | -0.96% |
| v3（最终） | 量<0.5+不破底+价>=10+价<100 | 212 | 42.9% | -0.96% |

### 关键发现
1. **价格比量能更重要** — 不破涨停最低价是关键因子
2. **缩量<0.5最优** — 比<0.7更精准
3. **剔除<10元低价股** — 胜率21%，亏损最严重
4. **盈亏比>1** — 0.98，略亏但好于基准-6.51%
5. **熊市能做到几乎保本** — 比无脑打板少亏5.55%

### 数据结论
- 缩量+不破底: 38.0%胜率, -1.02%收益, 盈亏比0.86
- 仅缩量: 39.4%胜率, -2.85%收益, 盈亏比0.64
- 仅不破底: 40.1%胜率, -1.27%收益, 盈亏比0.74
- 全部涨停(基准): 37.3%胜率, -6.51%收益, 盈亏比0.80

### 核心规律总结
缩量是锦上添花，不破底才是真门槛。价能双强才值得做。
