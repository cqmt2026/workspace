[5] 根本原因
  A股3日收益率本身极难预测:
    - 有效市场: 历史价格信息已被充分消化
    - 短期驱动: 政策/情绪/资金面 >> 技术形态
    - 36个技术指标在8年数据上训练: 99%学的是噪声，不是信号
    - 真正有效的特征: 行业轮动/北向资金/融资余额/情绪指标
    - 当前策略: 用技术指标预测3日收益 = 刻舟求剑

[6] 修复方案(按优先级)
  [P1] 降低预测难度: 改预测3日涨跌 -> 预测次日涨跌或纯多头选股排序
  [P1] 加入有效特征: 北向资金/融资余额/行业RPS/大盘指数收益率
  [P2] 简化模型: num_leaves=15~31, max_depth=5, n_estimators=100~200
  [P2] 引入早停验证集: 单独从训练集中切出10%作为早停验证，正确触发early stopping
  [P3] 滚动窗口CV: 2019-2022train / 2023val / 2024-2025test，分段验证
  [P3] 增加市场状态特征: 大盘收益率/波动率/行业轮动信号
  [P4] 根本重构: 从技术指标预测 -> 资金流+机构持仓+行业景气度选股
