# 学习计划

## 目标
提升编程和系统设计能力，让投资系统稳定可靠运行，不再靠修修补补过日子。

## 学习内容

### Phase 1 — Python功底（本周）
- [ ] 异常处理最佳实践：try/except/finally的正确用法、异常链、自定义异常
- [ ] 日志规范：logging模块的正确配置、分级、轮转
- [ ] 文件操作：路径处理、编码问题、临时文件、锁
- [ ] 并发基础：threading vs multiprocessing vs asyncio适用场景

### Phase 2 — 系统设计（下周）
- [ ] 错误恢复模式：retry/backoff/circuit breaker
- [ ] 任务编排：DAG调度、依赖管理、超时控制
- [ ] 健康检查：心跳、探针、自愈
- [ ] 配置管理：环境分离、配置验证、热加载

### Phase 3 — 测试与验证（下下周）
- [ ] 单元测试：pytest基础、fixture、mock
- [ ] 集成测试：端到端链路验证
- [ ] 监控告警：指标采集、阈值告警、告警收敛

## 执行方式
- 每天学习至少30分钟
- 学完一个知识点后，应用到投资系统的实际代码中
- 每周六检查学习进度，调整计划
