## 一、目标定义

### 核心目标

**短中线超额收益** = 持仓5-20日，目标年化Alpha > 10%（相对于沪深300）

### 成功标准

| 指标 | 目标值 | 说明 |
|------|--------|------|
| **期望收益** | > 0.5%/笔 | 扣除成本后仍为正 |
| **胜率** | > 40% | 赔率够高即可 |
| **单笔最大亏损** | ≤ -8% | 硬止损线 |
| **统计显著性** | p < 0.05 | t检验 + Bootstrap双重验证 |
| **样本外一致性** | 留出集与训练集收益差异 < 30% | Walk-forward验证 |

### 不追求

- ❌ 高胜率（>60%）—— 市场反身性会导致策略失效
- ❌ 日内交易——滑点/冲击成本过高
- ❌ 无脑全量持有——Alpha来源于选股，不来源于仓位

## 二、理论基础

### 2.1 欧奈尔口袋支点（Pocket Pivot）

**出处**: 威廉·欧奈尔《笑傲股市》(How to Make Money in Stocks)

**核心逻辑**:
> 股票从基部突破后，小幅回调形成"口袋"（整理期），口袋内缩量整理3-7天，
> 放量上涨日（口袋支点日）是最佳买入点。

**经济含义**: 
- 整理期 = 获利盘兑现，主力暗中吸筹
- 缩量 = 抛压减少（CM不卖）
- 放量上涨 = 主力启动拉升（真实需求）

**量化条件（参考）**:
- 股价处于基部突破后（20日新高附近）
- 回调幅度：15-35%
- 整理天数：3-7天
- 口袋支点日：缩量后放量上涨 > 1.5×5日均量
- 止损：口袋下方3%或MA5

**适配周期**: 5-10日短线

---

### 2.2 威科夫量价原理（Wyckoff Method）

**出处**: 理查德·威科夫（Richard Wyckoff），《陶氏理论》(1930s)

**核心逻辑**:
> 市场的本质是"供给与需求"的博弈。主力资金（CM）通过"震仓→吸筹→拉升→派发"循环操纵价格。
> 缩量回调是主力在吸筹，放量突破是主力在启动。

**关键概念**:
| 概念 | 定义 | 量化 |
|------|------|------|
| **Spring/UTAD** | 震仓后快速反弹，跌破支撑后收回 | 价格创局部新低，次日收阳 |
| **SOS (Signs of Strength)** | 放量突破回调高点 | 放量阳线突破前高 |
| **缩量回调** | 回调时成交量萎缩 | vol < vol5 × 0.85 |
| **LPS** | 最后的支撑点 | 回调底部缩量确认 |

**适配周期**: 5-15日短中线

---

### 2.3 缠论2买（次低点买入）

**出处**: 缠中说禅，《教你炒股票》(2006-2008)

**核心逻辑**:
> 走势必完整。上涨趋势第一次回调的最低点（次低点）是最佳买入点。
> 背驰判断：用MACD比较进入段vs离开段的力度。

**关键概念**:
| 概念 | 定义 |
|------|------|
| **1买** | 下跌走势背驰最低点（反转点，不推荐） |
| **2买** | 上涨趋势第一次回调最低点（推荐） |
| **3买** | 回调不破中枢上沿（最强但最难确认） |
| **背驰** | MACD柱状图比较，进入段力度 > 离开段 |

**经济含义**: 
- 回调次低点 = 主力拉升前最后一次洗盘结束
- MACD企稳 = 下跌动力衰竭，新动力凝聚

**量化条件**:
- 趋势确认：MA5 > MA20
- 回调幅度：5-25%
- MACD在0轴上方
- MACD柱状图较前1日扩大

**适配周期**: 5-20日中线

---

### 2.4 超跌反弹（Mean Reversion）

**出处**: 图尔斯·德雷曼（Thaler, 1992），行为金融学

**核心逻辑**:
> 投资者对坏消息过度反应（Loss Aversion），导致股价短期超跌。
> 当负面情绪达到极点时，买入安全资产能获得正向收益。

**经济含义**:
- 急跌 = 恐慌盘出逃，筹码快速分散
- 缩量 = 卖压衰竭，买卖双方平衡
- 企稳 = 主力入场信号

**量化条件**:
- 5日内跌幅 > 15%
- 缩量：当日成交量 < 20日均量 × 0.7
- MA5开始走平或上翘
- RSI(5) < 35 超卖区域

**适配周期**: 5-10日反弹

---

### 2.5 RPS板块动量

**出处**: Jegadeesh & Titman(1993), "Returns to Buying Winners"

**核心逻辑**:
> 短期动量效应：过去N日强势的股票，未来N日倾向于继续强势。
> 板块效应：强势板块中的股票，跑赢板块的概率更高。

**经济含义**:
- 强者恒强 = 资金持续流入强势板块
- 资金锚定效应 = 盈利预测上调后，股价不会立刻反应

**量化条件**:
- 个股RPS5 > 80（5日强于市场95%股票）
- 板块RPS5 > 70
- 板块内个股RPS排名靠前

**适配周期**: 10-20日中线

## 三、假设设计规范

### 3.1 核心原则

**每一个假设必须满足以下条件，否则不允许进入回测：**

| # | 原则 | 说明 |
|---|------|------|
| H1 | **有理论基础** | 必须有文献/理论支撑，不允许纯数据挖掘 |
| H2 | **逻辑可解释** | 每个条件都能用经济学原理解释 |
| H3 | **参数有边界** | 参数范围必须有物理意义，不允许无边界搜索 |
| H4 | **可证伪** | 必须有明确的失败标准（p>0.10即放弃） |
| H5 | **样本外验证** | 必须有留出集，不能全量回测直接声称有效 |

### 3.2 假设命名规范

```
H-XXX: [策略简称] [入场条件] [时间周期]
示例：
H-016: 威科夫缩量回调 纯量价 5日
H-017: 缠论2买+威科夫缩量确认 5日
```

### 3.3 假设文档模板

每个假设必须包含：

```markdown
# H-XXX：[策略名]

## 理论来源
- 文献/书籍 + 页码
- 核心逻辑抄录

## 入场条件
- 条件1：...
- 条件2：...

## 止损条件
- 硬止损：...
- 时间止损：...

## 预期样本
- 样本量：>100笔
- 市场环境：多头/震荡/空头

## 已知风险
- XX条件下可能失效
- 参数敏感性说明
```

## 五、验证流程（Walk-Forward）

### 5.1 标准流程

```
┌─────────────────────────────────────────────────────────┐
│                    验证流程                             │
├─────────────────────────────────────────────────────────┤
│                                                          │
│  Step 1: 理论设计（文档化）                              │
│            ↓                                             │
│  Step 2: 训练集回测（t检验）                             │
│            ↓ p≥0.05 → 放弃                               │
│  Step 3: 验证集回测（Walk-forward）                      │
│            ↓ 差异>30% → 放弃或重建                        │
│  Step 4: 留存集最终检验                                  │
│            ↓ p≥0.05 → 放弃                               │
│  Step 5: 参数稳定性检验（bootstrap）                      │
│            ↓ 不稳定 → 放弃                               │
│  Step 6: 实盘模拟（3个月，小仓位）                        │
│            ↓                                             │
│  Step 7: 正式实盘 + 实时监控                             │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

### 5.2 各阶段标准

| 阶段 | 通过条件 | 失败动作 |
|------|---------|---------|
| 训练集 | p < 0.05 | 放弃该假设 |
| 验证集 | 与训练集收益差异 < 30% | 重建或放弃 |
| 留存集 | p < 0.05 | 放弃 |
| 参数稳定性 | Bootstrap CI宽度 < 均收益绝对值 | 重建或放弃 |
| 实盘模拟 | 3个月跑赢指数 | 缩小仓位或放弃 |

## 六、统计检验标准

### 6.1 必须通过的三重检验

| 检验 | 通过标准 | 说明 |
|------|---------|------|
| **t检验** | p < 0.05 | 均收益显著不为零 |
| **Bootstrap CI** | 95%CI不包含0 | 均收益置信区间 |
| **Monte Carlo** | > 95%的模拟收益 < 策略收益 | 非随机 |

### 6.2 辅助诊断

| 检验 | 关注指标 | 阈值 |
|------|---------|------|
| 自相关检验（Q统计量） | p > 0.05 | 自相关显著则过拟合 |
| 胜率检验 | p < 0.05 | 胜率显著不为50% |
| 最大回撤 | 不设硬性阈值 | 用于风险评估 |

### 6.3 结论判定

```
三重检验全部通过 → "通过" → 可进入实盘模拟
t检验通过 + Bootstrap通过 + MC未通过 → "边缘通过" → 降低仓位慎用
任一检验失败 → "不通过" → 放弃该假设
```

## 七、实盘标准

### 7.1 上线标准

| 条件 | 要求 |
|------|------|
| 假设已通过六步验证流程 | 是 |
| 最近一个季度显著 | p < 0.10 |
| 实盘模拟期跟踪 > 3个月 | 是 |
| 主人明确授权 | 是 |

### 7.2 实时监控

| 监控项 | 触发条件 | 动作 |
|--------|---------|------|
| **收益率衰减** | 连续3个月跑输指数 | 触发审核，重新跑验证 |
| **自相关恶化** | 最近100笔Q统计量 p < 0.05 | 暂停，诊断原因 |
| **市场环境变化** | 大盘MA5 < MA20 持续10日 | 暂停所有策略 |
| **最大回撤预警** | 单笔浮亏 > -5% | 触发止损确认 |
| **样本外偏离** | 实盘收益与回测差异 > 50% | 立即审核 |

### 7.3 止损标准

| 类型 | 触发条件 | 动作 |
|------|---------|------|
| 硬止损 | 浮亏达到 -8% | 立即止损，无条件执行 |
| 时间止损 | 持仓 > 15日未触发止盈 | 强制评估是否持有 |
| 趋势止损 | MA5 < MA10 | 考虑减仓或止损 |
| 止盈 | 浮盈 > 15% | 分批减仓，收回成本 |

## 八、策略池管理

### 8.1 策略评级

| 评级 | 标准 | 操作 |
|------|------|------|
| **A级** | 通过全部验证 + 实盘3个月正Alpha | 正常持仓 |
| **B级** | 通过全部验证 + 实盘<3个月 | 小仓位观察 |
| **C级** | 边缘通过，谨慎使用 | 极小仓位，必须止损 |
| **观察级** | 新假设，等待验证 | 不入场，仅跟踪记录 |
| **放弃级** | 不通过 | 移出策略池 |

### 8.2 策略上限

| 类型 | 数量上限 | 单笔仓位上限 |
|------|---------|------------|
| 同时运行的假设 | 3个 | 单一假设不超过总仓位的40% |
| 同时持仓的股票 | 5只 | 单只不超过20%仓位 |

## 九、工作流程

### 9.1 日常流程（每日）

```
盘前（9:00-9:15）:
  1. 读取各A级/B级策略候选股
  2. 综合多策略输出推荐列表
  3. 主人人工决策，确认操作

盘中:
  1. 监控持仓股票走势
  2. 触发止损立即报告

盘后（15:30-16:00）:
  1. 更新日线数据到DB
  2. 运行信号扫描，更新候选股池
  3. 生成每日持仓报告
```

### 9.2 季度维护

```
每季度末:
  1. 对所有A级策略重新跑Walk-Forward验证
  2. 淘汰失效策略
  3. 根据近期市场环境，设计新假设
  4. 更新策略评级
```

## 十、关键规则

### 绝对规则

1. **无理论不回测** — 没有文献支撑的策略不进入回测流程
2. **无验证不上线** — 没有通过六步验证的策略不允许实盘
3. **无授权不操作** — 实盘操作必须主人明确确认
4. **无监控不持续** — 策略上线后必须持续跟踪，不允许放置不管

### 禁止事项

- ❌ 用训练集调参后直接声称有效（必须样本外验证）
- ❌ 用全量数据做参数敏感性分析（必须留出集）
- ❌ 在回测结果不显著的情况下声称策略有效
- ❌ 修改回测代码让结果变好看（数据造假）
