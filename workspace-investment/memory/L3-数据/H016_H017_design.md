# H-016 & H-017 假设设计方案
# 缠论 + 威科夫 融合假设
# 基于：缠论2买 + 威科夫量价缩量回调
# 设计时间：2026-05-25

---

## 背景理论

### 缠论核心
- **1买**：下跌走势背驰最低点
- **2买**：上涨走势第一次回调最低点（次低点）
- **3买**：回调不破中枢上沿（最强买入信号）
- **背驰**：MACD比较进入段vs离开段力度

### 威科夫核心
- **缩量回调** = CM在吸筹（主力不卖，缩量是好事）
- **放量突破** = CM在拉升（真实需求）
- **Spring/UTAD**：震仓后快速反弹（最佳买入机会）
- **SOS**：放量突破回调高点

## H-016：威科夫缩量回调（纯量价，无MACD）

### 核心逻辑
```
上升趋势中的股票回调时，
如果成交量萎缩（CM在吸筹，没卖），
之后放量反弹 = 最佳买入点
```

### 条件
```
买入：
  1. 大盘 MA5 > MA20（上升趋势）
  2. 个股 MA5 > MA20（上升趋势）
  3. 价格回调：5-20日内跌幅 5-25%
  4. 缩量：当日成交量 < vol5 * 0.85
  5. 当日涨幅 > 0（阳线）

出场：
  - MA5 < MA10（趋势破环）
  - 或持有10日
  - 止损：入场日最低价 - 3%
```

### 预期
- 方向：短线反弹（5-10日）
- 胜率预期：40-45%
- 均收益预期：+0.5~1.5%

## H-017：缠论2买 + 威科夫缩量确认

### 核心逻辑
```
缠论2买 = 第一次回调次低点
+ 威科夫缩量 = CM在吸筹确认
+ MACD在0轴上方企稳 = 买入确认
```

### 条件
```
买入：
  1. 大盘 MA5 > MA20（上升趋势）
  2. 个股 MA5 > MA20（上升趋势）
  3. 价格回调：5-20日内跌幅 5-25%
  4. 缩量：当日成交量 < vol5 * 0.85
  5. MACD在0轴上方（>0）
  6. MACD柱状图较前1日扩大（转折信号）

出场：
  - MA5 < MA10（趋势破坏）
  - 或持有10日
  - 止损：入场日最低价 - 3%
```

### 预期
- 方向：短线反弹（5-10日）
- 胜率预期：40-50%
- 均收益预期：+1~2%

## 设计理由

### 为什么H-016/H-017和H-014不同？
H-014用"5日涨幅<0"作为回调定义，太模糊。
H-016/H-017明确要求：
1. **明确回调起点**：近期有上涨高点
2. **明确回调幅度**：5-25%（不是无底线下跌）
3. **缩量+阳线**：CM在吸筹，不是逃跑

### 为什么加入MACD（H-017）？
缠论2买的核心是"转折"，
MACD柱状图扩大 = 动力转折点 = 最佳买入时机。
