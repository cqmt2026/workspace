## 🔄 调仓规则

### 【升级规则】
- **B → A**: 连续 3 个月盈利增长
- **A → A+**: 技术面突破 + 资金流入
- **A+ → A++**: 行业龙头地位确立

### 【降级规则】
- **A++ → A+**: 业绩不及预期
- **A+ → A**: 技术面破位
- **A → B**: 基本面恶化

### 【剔除规则】
- 连续亏损 2 年
- 重大利空事件
- 退市风险
