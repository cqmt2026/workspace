# H-013 低位首板涨停缩量回调买入 - 假设验证记录

> 策略来源：用户自定义（2026-05-25）
> 核心逻辑：低位首板涨停 → 缩量回调 → 放量阳线买入
> 数据样本：500只优质股票（2019-2026完整数据）

---

## 用户策略原文

```
低位首板涨停，缩量回调，调整周期不超过10个交易日
且回调价格不低于涨停版最低价，期间出现放量上涨就买入
```

## 最终结论

### ✅ 保留版本：D1（MA10死叉止盈）

**最终条件**：
```
买入条件：
  1. 低位首板涨停（30日涨幅<50%）
  2. 涨停后10个交易日内回调
  3. 回调不破涨停日最低价
  4. 回调幅度5-25%
  5. 放量阳线（量>5日均量1.5倍且股价涨）
  6. 大盘MA5>MA20

出场：
  止损：跌破涨停日最低价 或 -3%
  止盈：MA10死叉 或 持有15日
```

**最终结果**：
```
交易数: 217
胜率: 40.1%
平均收益: +1.53%
平均超额收益: +0.81%
最大盈利: +102.42%
最大亏损: -10.00%
盈亏比: 2.57
显著性: 不通过（但超额为正，有参考价值）
```

### ❌ 淘汰版本
- D2（连续缩量）：信号太少
- D4（第3天起买）：信号减半效果下降
- D1+D3（组合）：止损干扰，效果下降

---

## 教训总结

1. **MA10比MA5更适合作为止盈线**——MA5反应太快，容易被洗出
2. **连续缩量过滤太强**——把牛股也过滤掉了
3. **涨停后第2-3天买入**反而不如第1天就开始观察——说明"早回调早买入"更合理
4. **止损组合容易互相干扰**——简单止损最好
