## 一、核心原理：瓶颈狩猎（Bottleneck Hunting）

### 什么是瓶颈
供应链中**无法被轻易绕过、或绕过成本极高的单一卡点**。

瓶颈方拥有**定价权**——"你不需要生产3000%的增量，只需要涨价。"

### 判断标准（满足任一即为核心卡点）

| 条件 | 说明 |
|------|------|
| **无可替代供应商** | 下游必须用这家，找不到第二家能做 |
| **替代成本极高** | 切换供应商需要12+月认证周期，或需重新认证产品 |
| **扩产周期>>需求响应速度** | 上游扩产需2+年，下游需求可在数月内爆发 |
| **地理/资源天然集中** | 原料本身具有不可复制性（矿藏、专利、地域） |
| **客户合同锁死** | 下游离不开，无法轻易换供应商 |

### 关键信号

- 财报管理层频繁提及"产能不足""供应商高度依赖""认证周期长"
- 单一供应商占比 >30%，或前三大占 >70%
- 交货周期异常高于行业均值
- 涨价传导力强（客户离不开）

### 案例

- **AXTI（2025-12-26）**: "整个AI行业将受制于AXTI（$7亿市值）" → 6周+60%，2个月+310%
- **历史参照**: Neon gas +2000%（2022）；Dyprosium +2300%（2010）；HBM 2024-25

### 两个叠加维度

1. **资本主权**: 关键垄断企业被外资/中国控制 = 国家安全风险（欧洲尤其适用）
2. **架构转换期**: 瓶颈分析需判断下一代技术架构方向（例：光学互联取代铜缆）

## 二、多跳BOM供应链映射

### 核心方法
从下游品牌（GOOGL/MSFT/META/AMZN）Capex承诺 → 逆向追溯到上游原料，逐层找卡点。

### 信息来源优先级
1. 会议幻灯片（OFC、GTC、JP Morgan）
2. 投资者演示文稿
3. SEC文件（美股）
4. 公司公告/招股说明书（A股）
5. LinkedIn招聘帖子
6. 官网合作伙伴板块变更

### 操作步骤

```
1. 确认下游买家（Mag7） → 资本开支规模
2. 追溯到芯片/光模块层 → 估算BOM占比
3. 追溯到材料/设备层 → 找最上游卡点
4. 评估每个卡点的不可替代性
```

### 关键原则
光模块约占TPU BOM的8-12% → hyperscaler宁愿付高价也不削减AI Capex

### 案例
Ayar Labs官网悄悄移除LITE和MTSI，只保留SIVE → 解读为Sivers成为Ayar主激光供应商（2026年4月，无新闻稿）

## 三、signed-contract ARR vs. 市值错配

### 核心逻辑
用**签单合同的前向ARR**定价，不用TTM市盈率。

签合同 = 从"观察"升级为"高信念"。

### 操作方法

| 步骤 | 内容 |
|------|------|
| 1 | 找多年超大规模户合同（当前营收的倍数） |
| 2 | 对比合同隐含前向营收 vs. 市值 |
| 3 | 如300%+ ARR合同只让股价涨45% → 滞涨就是买点 |
| 4 | 自己算前向EPS/ARR，不依赖通用筛选器 |

### 案例
NBIS $170亿微软合同（2025-09）: 合同前$50是投机 →合同后"纯粹Scaling"，2026年预估$50-60亿营收/~70%毛利 vs. $240亿市值

## 四、Mag7客户集中度过滤器

### 核心原则
**小市值 + 多Mag7客户 = 护城河+需求持续性**（正面信号）

但需配对#8（交易对手质量）并关注反转风险（POET失去MRVL）。

### 信号
- 单一小市值公司系统性暴露于5家Mag7 → 极高信念
- 单一客户集中度高 → 风险（不是优势）

### 案例
ALAB（2025-07-28）: "唯一小型股有5家Mag7系统性暴露"

## 五、GAAP毛利率战争

### 核心原则
永远比GAAP毛利率，从不比non-GAAP。

大部分投资者用non-GAAP → 诚实披露者被系统低估。

### 操作
重新排名同类公司真实GAAP毛利率，再判断谁是最优。

软件/编排层是毛利率最大来源。

### 案例
IREN自称"92%毛利率" → 非GAAP（硬件特调）vs. NBIS 71.2% GAAP（真实披露） → "NBIS的质量被披露诚实度掩盖"

## 六、认证周期 vs. TTM营收

### 核心原则
**资格认证期（设计胜利、晶圆厂合作、指引语言）= 最佳买入时机**，批量增长未反映在报表营收中。

### 信号
- 会议设计胜利
- 晶圆厂资格认证
- 财报指引中TAM扩张语言

### 案例
SIVE、AEHR、LPK、AXTI都在上量前基于认证证据买入。"当前营收建模等于用Celestial $5000万建模因为2025年无CPO收入"

---

## 七、稀释/ATM日历作为排除项

### 核心原则
大规模活性ATM（尤其是搭配高管SBC）= 结构排除信号

### 信号
- ATM规模 vs. 市值
- 搭配SBC
- 管理层历史稀释记录

### 判断标准

| 类型 | 判断 |
|------|------|
| 破坏性稀释 | 开放市场ATM持续卖出 → 天花板 |
| 可接受稀释 | 小规模一次性战略挂牌稀释；战略投资人回购债务 |
| 案例 | IREN $60亿ATM @~$117亿市值 ≈ 51%稀释天花板 → "数据中心AMC"，明确看空 |

## 八、交易对手/融资质量光谱

### 核心原则
同一子行业，**租户信用度**和**融资结构**决定股权路径，不只是运营。

### 排序（从优到劣）
```
NBIS（NVDA + 可转债） > CIFR/WULF（colo，GOOGL/AMZN背书） > IREN（ATM） > CRWV（高额债务利息）
```

### 信号
- 谁backstop合同？AAA hyperscaler vs. 烧钱的AI实验室
- 资金来源？NVDA funding + convertibles > colo model > ATM > 信用卡债务

### 案例
ORCL/CRWV "OpenAI传染"崩盘（2025-12） → 买入MSFT/META背书的标的（NBIS、IREN），规避OpenAI依赖方

## 九、逼空格局（盈利增长型）

### 核心原则
**高short interest + 盈利增长 + 基本面改善** = 逼空解决向上；高SI + 僵尸公司 = 危险。

### 信号
- SI >35% float + borrow利用率接近极限
- 基本面改善 + 近 catalyst

### 案例
HIMS 42% SI @ "110亿，盈利，快速增长的公司...历史性逼空潜力"（2025-09-12）

## 十、关税/宏观冲击作为买点

### 核心原则
算法风险厌恶抛售 → 基本面承诺多年Capex不响应12个月内冲击 = 买入。

### 操作
区分"算法风险厌恶"和"基本面重新定价" → 买前者，敬畏后者。

宏观作为**倾斜**（降息 → 小盘/成长；战争 → 预先配置能源/防御，然后利润轮入高beta崩盘）

### 案例
2025-10-10 关税升级 → $98.8买入NBIS看涨 → "2025年最佳买点"
备注：2026年3月伊朗冲突真实伤害了XLU/EWY多头（利率路径改变）

## 十一、机构滞后/暗池与流向读取

### 核心原则
散户可先于机构4-6周发现供应链卡点；X评论滞后基本面1-3天；机构研究滞后2-4周。

窗口期：数据发布 → 叙事吸收 = 散户窗口。

### 信号
- 持续暗池/区块以折价成交
- 后续13F持仓披露确认，散户已经先行动

### 案例
Morgan Stanley最终持有SOI 6.5%；Point72/MTSI买入IQE float → 全部在 Serenity 公开论点之后（2026年4-5月）

## 十二、Vega/IV错误定价（期权结构）

### 核心原则
寻找ETF/指数，市场做市商按过期长期历史平均值定价IV，但结构性波动率已改变 → 买入长期价差获取Vega扩张。

### 信号
- 名称的已实现波动率或成分股敞口已结构性改变时，便宜的IV
- OTM长期价差获取凸性杠杆

### 案例
EWY 2028价差 @32% IV（按韩国十年平回报定价）实际=50%+三星/SK海力士；IV扩张至44-47%，一周内 → +300%+；2026-06-01 更新：EWY价差+485%，显式归因于IV扩张+方向性三星/SK海力士多头

⚠️ 高风险高级策略——杠杆期权，不适合复制

## 十三、信念分层、大小仓与择时

### 分层定义（S/A/B/C/D/F）

| 层级 | 定义 | 仓位 |
|------|------|------|
| **S** | 基本面解除风险（Mag7对手方 + 锁定保底合同） | 重仓 |
| **A** | 认证期/高信念但非绝对保底 | 中仓 |
| **B** | 增长逻辑成立但需等待催化 | 轻仓 |
| **C** | 中性观望 | 空仓 |
| **D** | 负面信号出现 | 回避 |
| **F** | 系统性排除（ATM过大/客户集中/融资质量差） | 绝不做 |

### 仓位大小原则
- 二元微市值 → 小仓位
- 可能归零（中国出口禁令风险） → 看涨期权而非股票

## 十四、反模式清单

以下情况**不投**：

1. ❌ 大规模活性ATM（>市值20%）配高管SBC
2. ❌ 单一客户集中度 >50%（除非客户是AAA hyperscaler）
3. ❌ 融资结构：信用卡债/高息债务支撑增长
4. ❌ 预营收量子计算（OKLO/QBTS/IONQ）
5. ❌ ORCL/CRWV类OpenAI依赖方（FCF覆盖不了承诺）
6. ❌ 管理层有历史稀释记录
7. ❌ 关税/宏观依赖利率路径（XLU/EWY）
8. ❌ 财报后第二天追高（机构已定价）
9. ❌ 用TTM营收建模认证期公司
10. ❌ 单一非GAAP指标（剥离SBC/折旧/限制性收入线）

## 十五、检查清单（适用任何新股）

```
[ ] 1. 瓶颈是什么？谁是真正的瓶颈？
[ ] 2. 上游原料是什么？下游依赖有多深？
[ ] 3. 有合同锁定吗？对手方是Mag7吗？
[ ] 4. GAAP毛利率真实多少？比non-GAAP诚实吗？
[ ] 5. 有ATM或稀释计划吗？
[ ] 6. 融资结构？可转债/ATM/colo/信用卡？
[ ] 7. 认证周期位置？当前营收还是设计胜利期？
[ ] 8. SI是多少？公司盈利吗？
[ ] 9. 关税/宏观冲击下的位置？利率路径敏感吗？
[ ] 10. 机构已经进场了吗？13F是否滞后？
[ ] 11. 信念层级：S/A/B/C/D/F？
[ ] 12. 仓位大小是否匹配信念层级？
```
