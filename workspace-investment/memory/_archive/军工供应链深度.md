## 一、供应链结构（方法论层面）

```
🌊 下游：军队/国防预算（年规模约1.5万亿元）
    ↑
    ↑
【整机层】（总装）
    → 战斗机/运输机/直升机总装
    → 航空发动机总装
    ↓
【分系统层】（子系统/设备）
    → 连接器/传感器/航电系统
    → 复合材料结构件
    → 发动机环件/锻件
    ↓
【材料层】（原材料/零部件）
    → 高温合金/钛合金/碳纤维
    → 特种钢材
    ↓
【元器件层】（电子/电气）
    → 被动器件（阻容感）
    → 军工芯片/功率器件
```

## 二、卡点识别方法（Serenity原则）

### 2.1 如何识别军工卡点

| Serenity原则 | 军工应用 |
|-------------|---------|
| **无可替代供应商** | 宇航级连接器/芯片只有1-2家能生产 |
| **替代成本极高** | 军品认证周期12+个月，下游不会轻易换 |
| **扩产周期>>需求响应** | 新型号量产需3-5年，需求爆发时产能跟不上 |
| **客户合同锁死** | 军品定价"成本+5%"，下游离不开 |

### 2.2 关键信号

- 财报管理层频繁提"产能不足""扩产周期长"
- 关联交易预付款大幅增加（订单确认信号）
- 型号立项/量产批准（长期需求确定性）
- 单一客户占比>50%（需判断是风险还是护城河）

## 四、投资逻辑（方法论层面）

### 4.1 Serenity卡点逻辑应用

| Serenity原则 | 军工场景 |
|-------------|---------|
| **瓶颈=定价权** | 整机层定价权在下游（军定价），材料层有一定传导力 |
| **扩产周期>>需求响应** | 新型号量产前产能建设需3-5年，需求确定性强 |
| **合同锁定** | 型号立项=多年订单，关联交易预付款是验证信号 |
| **认证周期** | 军品认证12-36个月，先进入者有先发优势 |

### 4.2 信号识别体系

**政策催化**：
- 国防预算增速>7.5% → 整机层订单爆发
- 预算增速5-7.5% → 配套层稳定增长
- 预算<5% → 全供应链承压

**实战消耗**：
- 实弹演练频率提升 → 导弹/弹药类受益
- 舰载机起降频率提升 → 发动机维修需求增加
- 新型号曝光增加 → 量产临近

**军转民**：
- 碳纤维 → 新能源车轻量化
- 高温合金 → 燃气轮机
- 连接器 → 新能源汽车/工业自动化
