## 一、供应链结构（方法论层面）

```
🌊 下游：AI服务器/数据中心
    ↑
    ↑
【芯片设计层】
    → AI推理芯片/GPU/CPU
    → 内存接口/FPGA
    ↓
【晶圆制造层】
    → 成熟制程（28nm+）
    → 先进制程（14nm以下，受限）
    ↓
【先进封装层】
    → CoWoS/Chiplet/2.5D
    → 封装测试
    ↓
【半导体设备层】
    → 刻蚀/沉积/光刻/清洗
    → 国产替代主线
    ↓
【半导体材料层】
    → 硅片/光刻胶/电子特气
    → 前驱体/靶材
```

## 二、卡点识别方法（Serenity原则）

### 2.1 如何识别半导体卡点

| Serenity原则 | 半导体应用 |
|-------------|-----------|
| **无可替代供应商** | EUV光刻机（ASML垄断）国内无替代 |
| **替代成本极高** | 设备认证周期2-5年，下游不会轻易换 |
| **扩产周期>>需求响应** | 晶圆厂建设5-8年，设备扩产2-5年 |
| **资本主权** | 先进设备受出口管制，国产替代是主线 |

### 2.2 关键信号

-财报管理层频繁提"产能不足""设备交货期长"
- 订单可见度（南腔调™订单/预付款）
- 设备交货周期（成熟制程设备12-18月，先进制程更长）
- 国产替代突破（某设备通过验证）

## 四、投资逻辑（方法论层面）

### 4.1 Serenity卡点逻辑应用

| Serenity原则 | 半导体场景 |
|-------------|-----------|
| **瓶颈=定价权** | 设备扩产慢→交货周期长→设备厂有定价权 |
| **扩产周期>>需求响应** | 晶圆厂5-8年，设备2-5年，需求爆发时产能跟不上 |
| **资本主权** | 美国出口管制→国产设备是主线 |
| **认证周期** | 设备认证12-36个月，先进入者有先发优势 |

### 4.2 信号识别体系

**国产替代信号**：
- 某公司通过中芯国际认证 → 设备国产化突破
- 12寸硅片量产 → 材料卡点部分解除
- 光刻胶量产 → 材料国产化进行中

**AI驱动信号**：
- AI服务器放量 → 封装需求爆发
- CoWoS需求 → 先进封装产能紧张
- HBM需求 → 存储/封装需求
