## 一、供应链结构（方法论层面）

```
🌊 下游：数据中心/AI服务器
    ↑
    ↑
【光模块层】
    → 800G/400G高速光模块
    → 电信光模块
    ↓
【光器件层】
    → PLC光器件
    → 光纤连接器
    → 波分复用器
    ↓
【激光器层】
    → 1550nm（光子学用，AI数据中心）
    → 1064nm（工业激光用）
    ↓
【光纤光缆层】
    → 光纤预制棒
    → 光纤光缆
    ↓
【光学材料层】
    → InP（磷化铟）基板 ← 美股AXTI垄断，A股无对标
    → 砷化镓/氮化镓
```

## 四、关键信号识别

**AI驱动信号**：
- 北美云厂商（GOOGL/MSFT/META）800G光模块招标
- AI服务器光互联需求爆发
- 光模块占AI服务器BOM约8-12%

**竞争格局信号**：
- 中际旭创 vs 剑桥科技 vs 光迅科技市场份额变化
- 华为内部化倾向（光迅可能受影响）
- 价格战信号（毛利率下降）
