## 一、估值体系

### 1. PE（市盈率）
```
PE = 股价 ÷ 每股收益
含义：回本需要多少年

判断标准：
- PE < 0：亏损公司，不适用
- PE < 15：低估值，可能被低估
- PE 15-30：合理区间
- PE > 30：高估值，需要成长性支撑
- PE > 50：泡沫区间，谨慎

行业差异：
- 银行/保险：5-10倍合理（利润稳定）
- 消费/医药：20-40倍合理（成长性好）
- 科技/券商：50倍+（高增长预期）
```

### 2. PB（市净率）
```
PB = 股价 ÷ 每股净资产
含义：股价相对于账面价值的溢价

判断标准：
- PB < 1：破净，价值被低估
- PB 1-3：正常区间
- PB 3-5：溢价较高
- PB > 5：泡沫区间

适用：银行、保险、券商（资产流动性好）
不适用：轻资产（互联网，软件）
```

### 3. PS（市销率）
```
PS = 股价 ÷ 每股营收
含义：营收倍数，衡量营收变现能力

判断标准：
- PS < 1：低估
- PS 1-5：合理
- PS 5-10：偏高
- PS > 10：泡沫

适用：电商、SaaS、营收稳定公司
```

### 4. PEG（成长性）
```
PEG = PE ÷ 净利润增长率
含义：成长性调整后的估值

判断标准：
- PEG < 1：成长被低估，买入
- PEG = 1：合理
- PEG > 1.5：成长被高估，卖出

例如：
  - 公司PE=30，增长率30%/年 → PEG=1，合理
  - 公司PE=30，增长率10%/年 → PEG=3，太贵
```

## 二、财务报表分析

### 1. 利润表（赚不赚钱）
```
核心指标：
- 营收：企业收入，增长>10%为佳
- 毛利：营收-成本，毛利率>30%为佳
- 净利：扣除所有费用后的利润
- EPS：每股收益 = 净利润÷总股本

危险信号：
❌ 营收下降
❌ 毛利率持续下降
❌ 依靠非经常性损益盈利（卖资产，政府补助）
❌ 应收账款大幅增加
```

### 2. 资产负债表（家底厚不厚）
```
核心指标：
- 总资产：企业全部资源
- 负债率：总负债÷总资产，<60%为佳
- 流动比率：流动资产÷流动负债，>1.5为佳
- 每股净资产：净资产÷总股本

优质特征：
✅ 资产负债率<60%
✅ 流动比率>1.5
✅ 商誉不要太高（<20%总资产）
✅ 没有大量有息负债
```

### 3. 现金流量表（真金白银）
```
核心指标：
- 经营现金流：主营业务赚的钱，>0为佳
- 投资现金流：投资支出
- 融资现金流：借款或分红

判断标准：
✅ 经营现金流持续为正
✅ 经营现金流 > 净利润（利润真实）
❌ 经营现金流多年为负
❌ 靠融资维持经营
```

## 三、选股标准（量化）

```
基本面选股标准：

1. 盈利能力
   □ 近3年净利润增长 > 10%
   □ ROE（净资产收益率）> 15%
   □ 毛利率稳定或上升

2. 财务健康
   □ 资产负债率 < 60%
   □ 流动比率 > 1.5
   □ 经营现金流 > 0

3. 估值合理
   □ PE < 30（行业平均值）
   □ PB < 5（行业平均值）
   □ PEG < 1.5

4. 行业地位
   □ 行业龙头或细分龙头
   □ 有定价权（提价不影响销量）
   □ 护城河清晰
```

## 五、基本面分析检查清单

```
每次买入前基本面检查：

□ 行业：好行业（医药，消费，新能源）？
□ 估值：PE/PB/PS在合理区间？
□ 业绩：净利润增长>10%？
□ 财务：负债率<60%，现金流为正？
□ 龙头：是行业龙头或有护城河？
□ 风险：商誉高？有息负债多？

基本面不好 → 技术面再好也要谨慎
基本面好 + 技术面好 → 最佳买点
```

## 六、基本面与技术面结合

### 最佳买入点

```
基本面：业绩好 + 估值合理
技术面：MACD零轴上方 + 底分型 + 中枢上方
共振 = 高概率上涨
```

### 危险信号

```
基本面：高估值 + 业绩下滑
技术面：MACD零轴下方 + 下降笔 + 中枢下方
共振 = 高概率下跌
```
