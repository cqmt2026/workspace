## 一、大盘重要性

```
为什么看大盘？
- 大盘影响80%的股票
- 大盘不好时，个股容易跌
- 大盘好时，个股容易涨

原则：
□ 大盘趋势 > 个股技术面
□ 大盘不好时，少操作
□ 大盘好时，积极操作
```

---

## 二、大盘趋势判断

### 上升趋势
```
特征：
- 指数不断创新高
- 低点不断抬高
- 均线多头排列
- 成交量温和放大

操作：积极做多，重仓持有
```

### 下降趋势
```
特征：
- 指数不断创新低
- 高点不断降低
- 均线空头排列
- 成交量萎缩

操作：空仓或轻仓，不逆势抄底
```

### 横盘震荡
```
特征：
- 指数在一个区间内波动
- 没有明显方向
- 成交量萎缩

操作：高抛低吸，精选个股，控制仓位
```

## 三、大盘与个股关系

| 大盘 | 个股 | 操作 |
|------|------|------|
| 上升 | 上升 | 最佳，满仓 |
| 上升 | 横盘 | 可操作，等突破 |
| 横盘 | 上升 | 可操作，精选 |
| 横盘 | 横盘 | 少操作，控制仓位 |
| 下降 | 上升 | 谨慎，可能是护盘 |
| 下降 | 横盘 | 减仓，等待 |
| 下降 | 下降 | 清仓，不操作 |

## 四、大盘见底信号

```
见底特征：
□ 成交量萎缩至地量（<前期高点20%）
□ MACD底背离
□ 均线开始走平
□ 恐慌情绪（涨跌比<0.5）
□ 多次测试前低不破

→ 分批建仓
```

---

## 五、大盘见顶信号

```
见顶特征：
□ 成交量暴增至天量
□ MACD顶背离
□ 均线开始空头排列
□ 贪婪情绪（涨跌比>2）
□ 连续创新高后放量滞涨

→ 分批减仓
```

## 六、大盘仓位控制

| 大盘趋势 | 仓位 | 操作 |
|----------|------|------|
| 上升趋势 | 70-100% | 积极做多 |
| 横盘震荡 | 30-50% | 高抛低吸 |
| 下降趋势 | 0-20% | 空仓等待 |

## 七、大盘分析检查清单

```
大盘检查（每天开盘前）：

□ 大盘趋势是什么？（上升/下降/横盘）
□ 均线多头还是空头？
□ MACD在零轴哪边？
□ 量能是放量还是缩量？
□ 情绪是恐慌还是贪婪？

记住：
- 大盘不好时，不操作就是赚钱
- 大盘 > 个股技术面
```
