## 技术分析买入检查清单

### 每次买入前必须检查

```
□ MACD在零轴上方？（DIF>0 且 DEA>0）
□ 站稳MA5？（收盘价 > MA5）
□ 不是空头排列？
□ KDJ不超买？（K < 80）
□ 止损位明确？
```

### 量化标准

| 指标 | 买入条件 | 说明 |
|------|----------|------|
| MACD | DIF > 0 AND DEA > 0 | 中期趋势向上 |
| MA5 | 收盘价 > MA5 | 短期强势 |
| 排列 | MA5 > MA10 > MA20 | 多头排列 |
| KDJ | K < 80 | 不追高 |
| 止损 | 明确到元 | 不明确不买 |

### 卖出检查清单

```
□ 止损：跌破-5%立刻止损
□ 移动止损：从最高点回落-3%
□ 持仓：不超过5天
□ KDJ超买：K>80考虑减仓
```

```
亏损持有 = 侥幸心理
止损出局 = 保护本金
```
