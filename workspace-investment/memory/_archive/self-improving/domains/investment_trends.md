## 一、趋势基础

```
三种趋势：
- 上升趋势：高点和低点不断抬高
- 下降趋势：高点和低点不断降低
- 横盘趋势：无明显方向
```

---

## 二、趋势线

### 上升趋势线
```
画法：连接两个或更多低点
作用：上升趋势的支撑位

跌破 = 趋势可能反转
```

### 下降趋势线
```
画法：连接两个或更多高点
作用：下降趋势的压力位

突破 = 趋势可能反转
```

---

## 三、支撑与阻力

| 类型 | 定义 | 特点 |
|------|------|------|
| 支撑位 | 下跌时遇到买盘支撑 | 前低、整数关口、均线 |
| 阻力位 | 上涨时遇到卖盘压力 | 前高、整数关口、均线 |

**转换**：支撑跌破后变阻力，阻力突破后变支撑

---

## 四、通道理论

```
上升通道：上轨（压力）+ 下轨（支撑）
下降通道：上轨（压力）+ 下轨（支撑）

操作：
- 触及上轨：减仓
- 触及下轨：加仓
- 轨道突破：趋势加速或反转
```

---

## 五、趋势跟踪核心

```
原则：
1. 顺势而为（上升做多，下降做空）
2. 趋势线止损
3. 趋势确认信号

买入：
趋势向上 + 回踩支撑 + MACD零轴上方

卖出：
趋势向下 + 反弹压力 + MACD零轴下方
```

---

## 六、趋势反转信号

### 上升趋势结束
```
1. 高点不再创新高
2. 低点跌破前低
3. 均线空头排列
4. MACD零轴下方死叉
5. 成交量萎缩
满足3个 → 大概率反转
```

### 下降趋势结束
```
1. 低点不再创新低
2. 高点突破前高
3. 均线多头排列
4. MACD零轴上方金叉
5. 成交量放大
满足3个 → 大概率反转
```

## 七、趋势 + 指标结合

```
趋势 + MACD：
- 上升趋势 + 回调支撑 + MACD零轴金叉 = 买入
- 下降趋势 + 反弹压力 + MACD零轴死叉 = 卖出

趋势 + 均线：
- 多头排列：回调到MA5/MA10买入
- 空头排列：反弹到MA5/MA10卖出
```

## 九、趋势交易检查清单

```
买入前检查：
□ 趋势方向（上升/下降/横盘）
□ 当前位置（支撑/阻力/中轨）
□ 趋势线是否完好
□ MACD是否配合
□ 成交量是否确认

公式：
上升趋势 + 回踩支撑 + MACD零轴上方 = 买入 ✅
下降趋势 + 反弹压力 + MACD零轴下方 = 卖出 ✅
```

## 十、趋势理论核心公式

```
上升趋势 = 高点更高 + 低点更高
下降趋势 = 高点更低 + 低点更低

止损原则：
买入后跌破支撑 → 止损
不侥幸，不逆势补仓
```
