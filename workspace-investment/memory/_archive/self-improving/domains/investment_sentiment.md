## 一、情绪基础

```
情绪：市场中投资者的群体心理状态

两种极端：
- 恐慌（Fear）：恐惧、抛售、踩踏
- 贪婪（Greed）：疯狂、追高、泡沫

最佳买卖时机：
- 恐慌底部 → 买入（多数人卖）
- 贪婪顶部 → 卖出（多数人买）
```

---

## 二、情绪周期

```
完整周期：

1. 恐慌期（底部）
   - 所有人都在卖，估值便宜
   - 操作：分批买入

2. 怀疑期（上涨）
   - 指数涨但很多人不信
   - 操作：持有或加仓

3. 乐观期（中部）
   - 赚钱效应扩散
   - 操作：持有

4. 贪婪期（顶部）
   - 所有人都在买，估值泡沫
   - 操作：分批卖出

5. 恐慌期（再次底部）
   - 循环...
```

## 三、情绪量化指标

### 涨跌家数比
```
计算：上涨家数 / 下跌家数
- 比值 > 2：市场热情高涨（可能顶部）
- 比值 < 0.5：市场恐慌（可能底部）
- 比值 = 1：正常
```

### 成交量
```
底部：天量见地量（地量是底部信号）
顶部：天量见天量（天量是顶部信号）
量能萎缩至前期高点20%以下 → 底部
量能暴增至前期低点5倍以上 → 顶部
```

### 均线系统
```
多头排列 → 市场乐观
空头排列 → 市场悲观
```

## 四、情绪与买卖点

```
恐慌底部买入：
□ 涨跌比 < 0.5
□ 量能萎缩（地量）
□ MACD底背离
□ 均线开始多头排列
→ 逆势买入

贪婪顶部卖出：
□ 涨跌比 > 2
□ 量能暴增（天量）
□ MACD顶背离
□ 均线开始空头排列
→ 逆势卖出
```

---

## 五、主力行为识别

```
散户特征：追涨杀跌、买便宜、容易恐慌
主力特征：低位吸筹、拉升、高位出货

识别：
- 下跌缩量 + 突然放量 → 主力吸筹
- 上涨放量 + 缩量回调 → 主力拉升
- 高位放量 + 滞涨 → 主力出货
```

## 六、情绪纪律

```
□ 不在恐慌时卖
□ 不在贪婪时买
□ 逆人群操作（人弃我取，人取我弃）
□ 设定买卖规则，不被情绪左右

口诀：
- 恐慌时买，分批买
- 乐观时持有
- 贪婪时卖，分批卖
```

---

## 七、情绪分析检查清单

```
情绪状态判断：
□ 涨跌比是多少？
□ 量能是放量还是缩量？
□ 均线多头还是空头？
□ 融资余额是否创新高？

买入情绪：恐慌 + 地量 + 底背离 = 逆势买入
卖出情绪：贪婪 + 天量 + 顶背离 = 逆势卖出
```
