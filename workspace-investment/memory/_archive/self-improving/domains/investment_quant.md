## 一、量化投资基础

```
量化投资：用数学模型和计算机程序进行投资决策

特点：系统性、纪律性、可回测、可复制
```

## 二、核心策略

### 均值回归
```
原理：价格偏离均值会回归
操作：低买高卖
适用：震荡市
```

### 趋势跟踪
```
原理：顺势而为
操作：追涨杀跌
适用：单边市
```

### 配对交易
```
原理：相关资产价差会回归
操作：买低卖高
```

## 三、简单策略代码

### 双均线策略
```python
df['MA5'] = df['close'].rolling(5).mean()
df['MA20'] = df['close'].rolling(20).mean()
df['signal'] = (df['MA5'] > df['MA20']).astype(int)
```

### MACD策略
```python
df['DIF'] = df['close'].ewm(span=12).mean() - df['close'].ewm(span=26).mean()
df['DEA'] = df['DIF'].ewm(span=9).mean()
df['buy'] = (df['DIF'] > df['DEA']) & (df['DIF'] > 0)
```

## 四、回测指标

| 指标 | 合格 | 优秀 |
|------|------|------|
| 年化收益 | >10% | >20% |
| 夏普比率 | >1 | >2 |
| 最大回撤 | <20% | <10% |

---

## 五、回测陷阱

```
❌ 未来函数（用未来数据）
❌ 过度拟合（参数太多）
❌ 幸存者偏差（只看活下来的）
❌ 滑点忽略（忽略交易成本）
```

---

## 六、量化入门原则

```
1. 先回测再实盘
2. 策略不过度复杂
3. 风险管理是核心
4. 持续优化改进
```
