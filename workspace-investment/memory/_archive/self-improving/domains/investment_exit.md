## 一、卖出原则

```
卖出分类：
1. 止损卖出（错了）→ 承认错误，控制亏损
2. 止盈卖出（对了）→ 保住利润，落袋为安
3. 换股卖出（优化）→ 卖出弱势股，换强势股
4. 移动止损（保护）→ 保护已有利润
```

---

## 二、止损卖出

```
止损原则：
□ -5%固定止损（无条件）
□ -3%移动止损（有利润后）
□ 跌破支撑位止损

止损心态：
❌ 不侥幸（再等等反弹）
❌ 不摊平（补仓降低成本）
✅ 错了就认，快速止损
```

---

## 三、止盈卖出

```
止盈方法：

1. 固定比例法
   - 盈利+10% → 卖1/3
   - 盈利+15% → 卖1/3
   - 盈利+20% → 清仓

2. 移动止盈法
   - 从最高点回落8% → 卖1/2
   - 从最高点回落12% → 清仓

3. 技术信号法
   - KDJ超买（K>80）→ 减仓
   - 顶分型出现 → 减仓
   - 跌破MA5 → 减仓
```

## 四、卖出信号清单

```
必须卖出的信号：

1. 止损信号
   □ 亏损-5%（无条件止损）
   □ 亏损-3%（有利润后移动止损）

2. 止盈信号
   □ 盈利+10%（考虑卖1/3）
   □ 盈利+15%（考虑卖1/3）
   □ 从最高点回落8%（移动止盈）

3. 技术信号
   □ KDJ超买（K>80）
   □ 顶分型出现
   □ 跌破MA5
   □ 均线空头排列

4. 趋势信号
   □ 趋势破位（跌破上升趋势线）
   □ 高点不再创新高
   □ 下降趋势确立
```

---

## 五、分批卖出策略

```
理想卖出节奏：

- 盈利+8% → 卖1/3（收回成本）
- 盈利+15% → 卖1/3（利润落袋）
- 盈利+20% → 清仓（或留1/3趋势股）

关键：不一次性卖完，分批操作
```

## 六、卖出决策流程

```
持仓中需要决策时：

1. 当前盈亏？
   - 亏损 → 止损（-5%无条件）
   - 盈利 → 继续

2. 有无卖出信号？
   - KDJ超买？→ 减仓
   - 顶分型？→ 减仓
   - 跌破MA5？→ 减仓

3. 趋势是否完好？
   - 上升趋势 → 持有
   - 下降趋势 → 清仓

4. 情绪是否贪婪？
   - 市场贪婪 → 减仓
   - 市场恐慌 → 持有
```

## 七、不同情况处理

```
情况1：买入后立刻下跌
→ 跌-5%止损，不侥幸

情况2：买入后震荡
→ 不动，等待方向

情况3：买入后上涨
→ 持有，等止盈信号

情况4：买入后暴涨
→ 分批止盈，不贪

情况5：买入后慢慢涨
→ 移动止损，趋势不破不走
```

## 八、卖出系统检查清单

```
持仓检查（每天）：

□ 当前盈亏是多少？
□ 是否有止损信号（-5%）？
□ 是否有止盈信号（+10%/+15%）？
□ 是否有技术卖出信号？
□ 趋势是否破位？
□ 市场情绪是否贪婪？

卖出决策：
- 亏损-5% → 无条件止损
- 盈利+10%+KDJ超买 → 减仓
- 盈利+15%+顶分型 → 减仓
- 趋势破位 → 清仓
- 市场贪婪 → 减仓
```
