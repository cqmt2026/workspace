## 一、行业分类

### 按周期分类
| 类型 | 特点 | 代表行业 | 投资策略 |
|------|------|----------|----------|
| 强周期 | 波动大 | 有色、钢铁、煤炭、券商 | 高抛低吸 |
| 弱周期 | 稳定 | 消费、医药、食品 | 长期持有 |
| 防御型 | 抗跌 | 电力、水务、公用 | 稳健持有 |
| 成长型 | 高增长 | 科技、新能源 | 趋势投资 |

### 按产业链
```
上游：原材料（锂矿、稀土）
中游：制造加工（零部件）
下游：消费品（整机、品牌）
```

## 二、行业景气度

### 景气度指标
```
领先指标：政策、资本开支、订单、库存
同步指标：营收、毛利、价格指数
滞后指标：业绩、股价
```

### 上升周期信号
```
□ 政策加码
□ 需求旺盛
□ 价格上涨
□ 扩产加快
```

### 下降周期信号
```
□ 政策收紧
□ 需求萎靡
□ 价格下跌
□ 库存积压
```

## 三、板块轮动规律

### A股常见轮动顺序
```
1. 券商 → 行情启动
2. 科技 → 风险偏好
3. 消费 → 复苏预期
4. 周期 → 业绩改善
5. 医药 → 防御配置
6. 公用 → 行情尾声
```

### 周期不同策略
```
经济复苏：券商→周期→消费→科技
经济衰退：医药→公用→消费
政策蜜月：新能源→科技→题材
```

## 四、竞争格局

| 格局 | 特点 | 投资价值 |
|------|------|----------|
| 完全竞争 | 产品同质 | 低利润，难投 |
| 寡头垄断 | 龙头主导 | 龙头享受溢价 |
| 完全垄断 | 一家独大 | 定价权强 |

### 龙头特征
```
□ 份额 > 30%
□ 定价权
□ 规模效应
□ 品牌护城河
```

## 五、行业研究检查清单

```
□ 行业周期（上升/下降/底部）
□ 政策环境（支持/打压/中性）
□ 竞争格局（集中度/龙头）
□ 景气度（向好/向坏）
□ 估值（贵/合理/便宜）
□ 催化剂（政策/事件/业绩）

好行业 + 好公司 + 好价格 = 买入
烂行业 + 任何 = 不碰
```

## 六、主人持仓行业分析

### 厦门钨业（有色/稀土）
```
周期：强周期
状态：新能源需求支撑，稀土价格高位

关注：新能源车销量、稀土价格、政策管控
风险：价格波动大、政策风险
```

### 通策医疗（医疗服务）
```
周期：弱周期（消费属性）
状态：扩张期，利润率受压

关注：口腔需求、门店扩张、集采影响
优势：行业空间大、连锁模式
风险：扩张投入大、医疗纠纷
```

## 七、行业轮动应用

```
1. 顺应景气度（买上升周期）
2. 规避下降周期（不接飞刀）
3. 轮动切换（热点转换时换仓）
4. 龙头优先
```

## 八、三个层次

```
自上而下：宏观→政策→行业→公司（选赛道）
自下而上：公司→行业→宏观（选个股）
事件驱动：政策/事件→行业→公司（炒题材）
```

## 九、核心公式

```
好行业 + 上升周期 + 合理估值 = 买入
好行业 + 下降周期 + 任何估值 = 观望
烂行业 + 任何周期 = 不碰
```
