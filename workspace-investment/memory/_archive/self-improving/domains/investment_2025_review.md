## 三、亏损模式分析

### ❌ 模式1：长期持有深套（三星医疗型）

**数据**：
- 亏损：-11,657元 (-15.79%)
- 持仓：19天
- 教训：持有时间越长，亏得越多

**错误链条**：
```
买入 → 下跌 → 持有等反弹 → 继续下跌 → 恐慌卖出
         ↓            ↓
       -5%          -15%
```

**核心教训**：
```
❌ 亏损持有是最危险的行为
❌ 时间不是解药，止损才是
❌ 止损-5%出局 = 保护本金
```

### ❌ 模式2：短线追高被套

**代表股票**：
- 会通股份：-7,772元 (-10.74%)，持仓3天
- 东方电热：-5,609元 (-10.84%)，持仓2天
- 联瑞新材：-8,855元 (-12.20%)，持仓14天

**特征**：
- 买入后快速下跌
- 持股3-14天
- 亏损10%+

**核心教训**：
```
❌ 追高买入 = 主动买套
❌ 短线变中线，中线变长线，长线变股东
```
