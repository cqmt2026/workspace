## 二、逐笔深度复盘

### 🏆 第1笔：海南矿业（核心盈利来源）

**数据**:
- 买入时间: 2026-03
- 卖出时间: 2026-04
- 盈亏: **+15,875元 (+52.5%)**
- 持仓天数: **最长**（超过其他所有交易）

**成功经验** ✅:
1. **敢于持仓**: 在出现盈利后没有急于卖出，持仓时间远超平均（平均2.4天）
2. **趋势跟踪**: 说明买入了上升趋势的股票，且守住了趋势
3. **重仓出击**: 单笔盈利15,875占总收益绝大部分，说明仓位不轻

**可复用模式**:
```
成功 = 选对趋势 + 重仓 + 长期持有
     = 耐心等待利润奔跑
```

- 等回调后企稳再买

### ❌ 第8笔：九丰能源（最大亏损）

**数据**:
- 盈亏: **-1,385元 (-5.9%)**
- 持仓天数: **5天（最长）**

**失败教训** ❌:
1. **持仓最长但亏损最大之一**: -1,385元
2. **应该止损但没有**: 5天都没卖，亏损从5%扩大
3. **侥幸心理**: 期待反弹，结果越亏越多

**致命错误**:
```
期望反弹 → 持有不动 → 亏损扩大
         ↓
    最终割肉亏损-5.9%
    
正确的做法：
- 设置止损点（如-5%）
- 跌破止损立刻卖出
- 不抱有侥幸心理
```

**教训总结**:
```
九丰能源的教训：
1. 亏损持有是最危险的行为
2. 5天足够亏损从3%到6%
3. 止损是保护自己的唯一方法
```

## 四、核心失败教训

### 1. 九丰能源教训（最深刻）

**错误链条**:
```
买入 → 下跌 → 持有等反弹 → 继续下跌 → 恐慌卖出
         ↓            ↓
      -2%         -5.9%
```

**正确做法**:
```
买入即设止损：
- 止损位: -5%
- 跌破止损，无条件卖出
- 不抄底，不补仓，不持有
```

---

### 2. 频繁交易教训

**问题**:
- 12笔交易中有4笔是小额亏损
- 每笔都要交手续费
- 分散了精力和资金

**改进**:
```
减少交易频率：
- 没有明确机会就空仓
- 只做高概率的股票
- 宁缺毋滥
```

## 五、实盘操作规则（从教训中提炼）

### 止损纪律（必须执行）

| 规则 | 说明 |
|------|------|
| 单笔止损 | -5%（固定） |
| 日内止损 | -3%（移动） |
| 止损执行 | 跌破就卖，不犹豫 |

### 持仓纪律

| 规则 | 说明 |
|------|------|
| 短线持仓 | 1-3天，不超过5天 |
| 盈利持盈 | 趋势不破不走 |
| 亏损不补 | 不抄底 |

### 买入纪律

| 规则 | 说明 |
|------|------|
| 不追高 | 涨幅>5%不买 |
| 等回调 | 回调企稳再买 |
| 看趋势 | 下降趋势不买 |

## 六、验证检查清单

每次交易前检查：

```
□ 止损位设好了吗？（-5%）
□ 移动止损设好了吗？（-3%）
□ 买入理由明确吗？
□ 不是追高吧？（涨幅<5%）
□ 下跌趋势吗？（不追）
□ 有明确的目标价吗？
□ 仓位合理吗？（不重仓单一股票）
□ 手上有现金吗？（不满仓）
```
