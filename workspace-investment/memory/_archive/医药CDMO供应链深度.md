## 一、供应链结构（方法论层面）

```
🌊 下游：创新药/仿制药企
    ↑
    ↑
【CXO层】（医药外包）
    → CRO（研发外包）
    → CDMO（制造外包）
    → CMO（生产外包）
    ↓
【原料药层】
    → 特色原料药
    → 大宗原料药
    → 中间体
    ↓
【药用辅料/包装层】
    → 药用辅料
    → 药用包装
    ↓
【制药设备层】
    → 分离纯化设备
    → 冻干机
    → 制剂设备
```

## 二、卡点识别方法（Serenity原则）

### 2.1 如何识别CDMO卡点

| Serenity原则 | CDMO应用 |
|-------------|-----------|
| **无可替代供应商** | 药明康德是全球CXO龙头，客户粘性极强 |
| **替代成本极高** | 换CDMO需要重新验证工艺，周期6-12月 |
| **扩产周期>>需求响应** | 生物药CDMO扩产2-3年，需求爆发时产能紧张 |
| **客户合同锁死** | 大药企与CXO签多年合约，退出成本高 |

### 2.2 关键信号

- 大药企与CXO签长约（3-5年）
- 临床管线推进（早期→III期→商业化）
- 生物药CDMO产能利用率>80%（紧张信号）
- 美国《生物安全法》进展（药明康德/药明生物风险）

## 四、Serenity卡点逻辑应用

| Serenity原则 | CDMO场景 |
|-------------|-----------|
| **瓶颈=定价权** | 全球CXO稀缺（药明康德/药明生物），大药企依赖 |
| **认证周期** | CDMO认证新客户需6-12月，先进入者有先发优势 |
| **合同锁定** | 多年合约，大药企退出成本高 |

**重要风险**：美国《生物安全法》对药明康德/药明生物的影响是最大变量。
