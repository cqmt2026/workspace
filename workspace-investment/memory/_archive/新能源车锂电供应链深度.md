
## 二、卡点识别方法（Serenity原则）

### 2.1 如何识别锂电卡点

| Serenity原则 | 锂电应用 |
|-------------|-----------|
| **无可替代供应商** | 恩捷股份（湿法隔膜）产能全球领先 |
| **替代成本极高** | 电池厂认证隔膜/正极周期6-12月 |
| **扩产周期>>需求响应** | 锂矿扩产3-5年，需求爆发时价格暴涨 |
| **资源天然集中** | 锂矿（盐湖/锂辉石）地理分布极不均匀 |

### 2.2 关键信号

- 碳酸锂价格波动（2022年60万→2023年10万→2024年回升）
- 宁德时代电池招标 → 设备/材料商受益
- 固态电池进展 → 对隔膜/电解液的威胁
- 电池厂毛利率趋势 → 上下游博弈

## 四、Serenity卡点逻辑应用

| Serenity原则 | 锂电场景 |
|-------------|-----------|
| **瓶颈=定价权** | 锂矿是强周期品，扩产周期长→价格暴涨暴跌 |
| **资源天然集中** | 锂矿分布不均（智利/澳大利亚/中国盐湖） |
| **扩产周期>>需求响应** | 盐湖提锂3-5年，需求爆发时供不应求 |

**重要区别**：锂电是强周期品，Serenity对资源品（锂矿）的投资逻辑不同于制造业卡点。
