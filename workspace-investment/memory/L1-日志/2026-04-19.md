## 使用方式

### 1. 添加持仓
```bash
cd workspace-investment/src
python position_add.py 000591.SZ 太阳能 10000 6.50 2026-03-01
```

### 2. 记录交易
```bash
python transaction_add.py buy 000591.SZ 太阳能 10000 6.50 2026-03-01
python transaction_add.py sell 000591.SZ 太阳能 5000 7.20 2026-04-15
```

### 3. 生成报告
```bash
python portfolio_report.py
```
