## 一、核心论点

**90%的人做量化，一上来就扣代码扣模型，全搞反了。**

代码只是工具，真正决定收益的灵魂是**策略**。

### 什么是策略？

把脑子里模糊的交易直觉，翻译成一套可以通过系统和数据执行的规则。

人会由于会上头，但电脑不会，它只会严格按照制定好的策略去执行交易。

## 三、第一块：选股（回答"买什么"）

### 四步法

#### 第1步：确定范围

先确定在哪些票里选，这个决定了策略的**基因**。

| 范围 | 策略性质 |
|------|---------|
| 中证2000成分股 | 小盘股策略 |
| 沪深300 | 大盘蓝筹 |
| 某个行业 | 行业主题 |

**三个策略案例的范围差异：**
- **小市值因子**：全A剔除科创北交后，市值最小的一批
- **行业轮动**：候选标的升级为板块，从主流行业/一级行业中提取规模、热门板块
- **打板**：范围每天变，只看当天涨停或即将封板的强势股

> 范围一变，策略性质就不同了。

#### 第2步：排雷

把不能要的踢出去，保证选出来的票都能真实交易、不暴雷。

| 策略 | 排雷内容 |
|------|---------|
| 小市值因子 | 剔除ST、停牌、新股、市值太低有退市风险 |
| 行业轮动 | 剔除成交冷淡、规模太小、流动性差的冷门板块 |
| 打板 | 剔除一字板、ST、流动性差的 |

#### 第3步：上因子

因子就是量化的尺子，把模糊的判断翻译成能计算的指标。

| 模糊判断 | 量化因子 |
|---------|---------|
| "这票便宜" | 市盈率、市净率 |
| "这票最近很强" | 近20日涨幅动量 |
| "这票能赚钱" | ROE、利润增速 |

一个因子是一把尺子，多把尺子一起量就是多因子。

**三个策略的因子差异：**
- **小市值因子**：总市值、市盈率、换手率
- **行业轮动**：板块动量、资金流
- **打板**：封单强度、连板高度、量能配合

#### 第4步：打分排序

按分数从高到低，选前几只。

- 多因子策略可以给每个因子增加**权重**
- 比如：A因子占15%，B因子占30%，C因子占20%
- 加权算出综合分，再排序，取前几名

> 走完这四步，脑子里的模糊感觉就能变成清晰的、可执行的规则了。

## 四、第二块：择时（判断"何时出手"）

选出好票之后，不代表现在就该买。择时就是判断当下环境到底该不该出手。

### 两个层次

1. **宏观开关**：大环境能不能做（如大盘指数跌破均线就空仓）
2. **信号触发**：在能做的前提下，看具体什么时机出手

### 三个策略的择时差异

| 策略 | 择时方式 |
|------|---------|
| 小市值因子 | 平时不择时，但怕踩踏，加一个小盘指数跌破20日均线的开关 |
| 行业轮动 | 择时是灵魂，盯着板块动量排名，走弱就切，新的上来就换 |
| 打板 | 看情绪，涨停家数、连板高度、跌停家数，决定今天打不打 |

> ⚠️ 择时不是必须的。想不清楚就像不错。如果策略害怕大跌，可以添加这个开关。

## 五、第三块：买卖（决定"怎么交易"）

### 买入要确定三件事
- 以什么价买（限价/市价）
- 一次性买完还是分批
- 几只票怎么分钱

### 卖出要确定
- 止盈止损怎么调
- 谁有触发

### 三个策略的买卖差异

| 策略 | 买卖规则 |
|------|---------|
| 小市值因子 | 每月按选股结果机械换仓，没有情绪，按月照锁 |
| 行业轮动 | 等全火的按照动量强弱加权切换强势板块 |
| 打板 | 进出主要靠速度，买卖考虑的是怎么赚 |

## 六、第四块：风控（"怎么保命"）

### 为什么做风控？

赚钱和亏钱在数学上本身就是不对等的：
- **亏50%，不是赚50%就能回本**
- **得赚100%（一倍）才能回本**

所以要提前想好最坏的情况来了怎么保命。

### 风控的三个层次
1. **单票仓位控制** — 单只票不超过多少比例
2. **单账户回撤控制** — 整体回撤到多少停止交易
3. **组合对冲** — 不同策略组合分散风险

### 三个策略的风控差异

| 策略 | 主要风险 | 风控方式 |
|------|---------|---------|
| 小市值因子 | 流动性踩踏 | 分散持仓，控制单票仓位 |
| 行业轮动 | 板块追高 | 单边追高，仓位限制 |
| 打板 | 追高 | 更严格止损 |

## 七、完整框架总结

```
一个完整的量化策略框架 = 选股 + 择时 + 买卖 + 风控
```

> **功夫不在代码上。能把模糊的盘感拆成清楚能验证的规则，就算入门量化了。**

## 八、与我们系统的对照分析

| bob框架 | 我们的系统 | 状态 |
|---------|-----------|------|
| **选股-范围** | 67只核心股票池 + 尾盘策略全市场筛选 | ✅ 有 |
| **选股-排雷** | 排除ST、北交所、涨幅/量比过滤 | ✅ 有 |
| **选股-因子** | 35个因子（Pipeline v2） | ✅ 有 |
| **选股-打分** | 6维度评分（0~100分） | ✅ 有 |
| **择时-宏观** | ❌ 缺少大盘环境开关 | ❌ 缺失 |
| **择时-信号** | 14:30尾盘信号触发 | ✅ 有 |
| **买卖-买入** | 尾盘买入，次日卖出 | ✅ 有 |
| **买卖-卖出** | ❌ 没有明确的止盈规则 | ❌ 缺失 |
| **风控-单票** | 5%机械止损 | ✅ 有 |
| **风控-回撤** | 15%总回撤风控 | ✅ 有 |
| **风控-组合** | 多策略并行 | ✅ 有 |

**两个明显短板：**
1. **缺少大盘环境择时开关** — 如果大盘不好，应该自动降低仓位或空仓
2. **没有明确的止盈规则** — 目前只有止损没有止盈

## 九、启发：把斌哥策略纳入bob框架

刚才验证的斌哥"缩量+不破底"策略，用bob的框架来看：

| 环节 | 斌哥策略对应 |
|------|------------|
| 选股-范围 | 昨日涨停的票 |
| 选股-排雷 | 剔除<10元低价股 |
| 选股-因子 | 量比<0.5（缩量因子）、价比>=0.995（不破底因子） |
| 选股-打分 | 两因子加权 → 综合分 |
| 择时 | 涨停次日确认 |
| 买卖 | 次日开盘买入，持5日 |
| 风控 | 不破底本身也是一种风控（破底直接否决） |

说明我们走的路径是对的——先有模糊的交易直觉（斌哥），然后抽象成规则，再用数据验证，最终集成到系统中。bob这套方法论就是把这个过程讲清楚了。
