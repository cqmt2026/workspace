# 科学投资研究方法论 v1.0

**创建时间**: 2026-05-25
**版本**: v1.0（2026-05-25整合）
**目标**: 中短期超额收益（**短线1-5日，少量中线最长20日**，不做长线）

---

## 核心原则（最高优先级）

> **每一项假设都要被数据验证，错的扔掉，对的留下，最终得到一整套经过验证的方法论。**
>
> **除真实数据外，所有工具和方法都只是假设，必须通过数据验证才能作为决策依据。**
>
> **未经数据验证的结论 = 假设，不是事实。**

---

## 核心原则

> 所有结论必须附带：数据来源 + 验证方式 + 置信度
> 未经回测验证的判断 = 假设，不是结论
> 投资建议必须基于客观真实数据和经过回测验证的结论

---

## 研究流程（5步）

```
假设生成 → 数据验证 → 回测验证 → 显著性检验 → 实盘决策
```

---

## 第1步：假设生成

> **站在巨人肩膀上**：成熟策略/理论（学术/专业/经验）作为假设来源，用数据验证后留下。

**假设来源**：

| 来源 | 说明 | 举例 |
|------|------|------|
| 市场成熟策略 | 行业内经过验证的经典策略 | 动量效应、均值回归 |
| 主人建议 | 基于新闻/直觉提出的假设 | "AI板块异动能炒吗？" |
| 从已有结果推导 | 从回测数据中发现的规律 | "动量失效后是否反转？" |

**规则**：
- 每个假设明确表达：`当X发生时，Y股票/板块有上涨倾向`
- 禁止"感觉会涨"作为假设
- 假设必须可证伪
- 所有假设进入假设日志（`hypothesis_log.md`）

---

## 第2步：数据验证

**重要性**：数据质量决定回测结论的可信度

### 数据质量标准

| 检查项 | 标准 |
|--------|------|
| 复权类型 | 必须前复权（不复权数据存在除权缺口） |
| 覆盖度 | ≥4000只股票 |
| 时间跨度 | ≥5年日K |
| 保鲜度 | 最近5个交易日内有更新 |
| OHLCV完整性 | 无0值/负值 |
| 停牌/退市 | 北交所/退市股已筛除 |

### 数据质量监控Cron

- **时间**: 每日16:10（收盘后）
- **脚本**: `scripts/data_quality_monitor.py`
- **输出**: `out_data/data_quality/report_YYYY-MM-DD.json`
- **异常处理**: 异常股票加入重下载队列

### 数据修复流程

1. 质量监控检测出异常股票
2. 加入重下载队列（`pct_exceed_detail.csv`）
3. 使用前复权（`adjustflag='1'`）重新下载
4. 替换原有数据

---

## 第3步：回测验证

**工具**：`scripts/backtest_v2.py`

### 回测标准

| 环节 | 标准 |
|------|------|
| 市场状态判断 | 沪深300 MA5/MA20三档（强势/弱势/震荡） |
| 选股数量 | 每期10-20只 |
| 持仓周期 | 5-20日（固定） |
| 买入 | 信号次日开盘价买入 |
| 卖出 | 固定持仓期到期/止损/止盈 |

### 成本模型（已确定，2026-05-25）

| 成本项 | 费率 |
|--------|------|
| 佣金 | 万1（双向，最低5元/笔） |
| 印花税 | 千1（卖出时） |
| 滑点 | 0.1% |

**单笔交易合计约：0.3%**

### 止损规则

| 类型 | 条件 |
|------|------|
| 固定止损 | 亏损-3%必须止损 |
| 时间止损 | 5个交易日不涨离场 |
| 目标止盈 | +5%~8%分批离场 |

### 市场过滤

| 市场状态 | 条件 | 动作 |
|---------|------|------|
| 强势市场 | RPS>70板块≥3个，沪深300站稳MA5 | 正常做多 |
| 弱势市场 | RPS>70板块=0，沪深300空头排列 | 禁止开仓 |
| 震荡市场 | 不满足以上 | 降低仓位至50% |

### 回测报告必须包含

```
1. 策略参数（信号周期/持仓周期/选股数量）
2. 样本信息（时间范围/交易笔数/股票数）
3. 收益指标（总收益/年化/超额收益）
4. 风险指标（夏普/最大回撤/波动率）
5. 胜率统计（胜率/盈亏比/平均盈亏）
6. 基准对比（沪深300同期收益）
7. 显著性检验（p值/Monte Carlo）
8. 交易明细（每笔交易记录）
```

## 第4步：显著性检验

**工具**：`scripts/significance_test.py`

### 检验方法

| 检验 | 作用 | 通过标准 |
|------|------|---------|
| t检验 | 收益是否显著不为零 | p < 0.05 |
| 95%置信区间 | 收益落在哪个范围 | 不含0 |
| Monte Carlo | 策略 vs 随机组合 | >95%随机 |
| Bootstrap | 小样本重采样 | 不含0 |
| 胜率检验 | 胜率是否>50% | p < 0.05 |
| 序列相关 | 是否存在过拟合 | p > 0.05 |

### 结论判定

| 条件 | 结论 |
|------|------|
| t检验显著 + Monte Carlo显著 | **通过** |
| 仅一项显著 | **边缘通过**（谨慎） |
| 都不显著 | **不通过**（策略不可信） |

---

## 第5步：实盘决策

| 条件 | 动作 |
|------|------|
| 回测通过 + 夏普≥1.5 + 最大回撤≤15% | 仓位≤5%试跑 |
| 边缘通过 | 模拟盘跟踪≤3个月 |
| 不通过 | 仅记录观察，不操作 |

---

## 策略优先级

| 优先级 | 要求 | 仓位上限 |
|--------|------|---------|
| P1 主策略 | 回测5年+，夏普≥1.5 | 10-15% |
| P2 辅助 | 回测3年+，夏普≥1.0 | 5-10% |
| P3 观察 | 回测1年+或理论支撑 | ≤3% |
| P4 试验 | 仅有假设/短期数据 | 不操作 |

---

## 策略追踪与迭代

- **每周**: 实盘表现 vs 回测对比
- **每月**: 策略是否失效
- **淘汰**: 连续4周跑输基准 → 降级；连续8周无优势 → 淘汰
