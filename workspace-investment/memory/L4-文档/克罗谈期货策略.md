# 克罗谈期货策略（Market Wizards - Stanley Druckenmiller访谈）

> 克罗（Stanley Druckenmiller），1986-2000年连续30年，年化30%
> 徒弟：Paul Tudor Jones学生辈，徒弟的门徒
> A股实战可行性：⭐⭐⭐（宏观+趋势逻辑，参数需调整）

---

## 一，核心理念

**专注宏观趋势，不做日内**

```
核心：
  1. 顺势而为，等趋势来了满仓
  2. 止损要小，持有要狠
  3. 每天复盘，错了立即认
  4. 不抄底不摸顶
```

---

## 二，入场规则

### 趋势判断（宏观+技术）

```
宏观面：
  1. 利率方向（降息=牛市，升息=熊市）
  2. 流动性释放
  3. 政策信号

技术面：
  1. 突破重要压力位
  2. 趋势线确认
  3. 放量突破
```

### 具体入场

```
入场：
  1. 宏观+技术共振 → 重仓
  2. 宏观支持，技术模糊 → 轻仓试错
  3. 方向不明 → 空仓
```

---

## 三，止损规则（最重要）

**止损是克罗成功的唯一原因**

```
规则：
  1. 入场24小时内必须盈利，否则立即走
  2. 单笔最大亏损：总资金2%
  3. 止损不幻想，不等反弹

克罗原话：
  "I cut losses immediately. I never average losers."
```
