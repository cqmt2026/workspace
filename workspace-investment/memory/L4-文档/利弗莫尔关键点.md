# 利弗莫尔关键点理论

> 杰西·利弗莫尔（Jesse Livermore），传奇投机者《股票作手回忆录》作者  
> A股实战可行性：⭐⭐⭐⭐（关键点/板块联动原理通用）

---

## 一、核心思想

**股票投机的本质是追随趋势，而趋势的核心是"关键点"**

利弗莫尔认为：股价总是朝着最小阻力的方向运动。找到这个方向，就是投机的全部秘密。

---

## 二、关键点（Key Point）

### 什么是关键点？
```
股价突破某一价位时，放量上涨——
这个突破点就是"关键点"
一旦突破，股价将加速上涨
```

### 三类关键点
| 类型 | 形态 | 操作 |
|------|------|------|
| **启动点** | 长期横盘后放量突破 | 立即买入 |
| **加速点** | 上升趋势中突然放量创新高 | 加仓 |
| **反弹点** | 大跌后缩量企稳，放量反弹 | 抄底 |

### 如何确认关键点突破？
```
1. 价格必须带量突破（成交量是前一日2倍以上）
2. 突破后不能快速回落（2天内站稳）
3. 突破时股价创新高
```

## 三、板块效应

**利弗莫尔最重要的发现之一：板块联动**

```
核心原理：
- 龙头股上涨 → 板块内其他股票跟涨
- 龙头股下跌 → 整个板块开始调整
- 第一个涨的股票 = 最强主力
```

### A股应用
```
1. 发现某板块异动 → 找板块龙头
2. 龙头先动 → 跟进小弟（弹性更大）
3. 龙头滞涨 → 整个板块行情结束
```

## 四、读盘能力（The Tape）

利弗莫尔每天花数小时看报价纸带（类似现在的Level-2）

### 盘口语言（Price Action）
```
- 股价涨但成交量萎缩 → 主力可能在出货
- 股价跌但成交量放大 → 有人在吸筹
- 放量突破关键位 → 趋势确认
- 缩量创新高 → 虚假突破，警惕
```

### 分时图解读
```
- 早盘30分钟内：判断当日方向
  · 高开高走 → 多头控盘
  · 高开低走 → 空头反扑
  · 低开低走 → 弱势行情
  
- 午后14:30：关键决策点
  · 主力尾盘拉升 → 次日可能冲高
  · 尾盘放量大跌 → 次日继续下探
```

## 五、趋势线与频道

```
上升趋势：股价在平行通道内运行
- 触碰上轨可能调整
- 跌到下轨是买入机会

下降趋势：股价在下降通道内
- 触碰上轨是卖出机会
- 跌破下轨加速下跌
```

## 六、利弗莫尔操盘四阶段

```
第一阶段：建仓（Accumulation）
- 股价长期横盘
- 成交量极度萎缩
- 机构悄悄买入

第二阶段：试盘（Test）
- 向上突破关键点
- 成交量放大
- 确认方向

第三阶段：拉升（Mark-up）
- 股价快速上涨
- 成交量持续放大
- 趋势加速

第四阶段：出货（Distribution）
- 高位放量大涨
- 股价创新高但成交量异常
- 主力撤退
```

## 七、资金管理

### 金字塔买入法
```
第一次买入：10%仓位
第一次加仓：20%仓位（盈利后）
第二次加仓：30%仓位（再次盈利后）
保留40%现金不动
```

### 止损铁律
```
总持仓亏损≤10%必须止损
单笔交易亏损≤7%必须止损
绝不使用摊平成本策略
```

## 九、A股实战要点

| 利弗莫尔法则 | A股应用 |
|-------------|--------|
| 关键点突破 | 放量突破前高/平台/均线 |

| 维度 | 利弗莫尔 | 欧奈尔 |
