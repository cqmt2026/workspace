# A股生态观察笔记

> 2026-05-25 主人观察整理

## 一，A股三层力量

| 力量 | 特征 | 波动 | 行为 |
|------|------|------|------|
| 量化/柚子 | 程序化/秒级/封板/天地板 | 大 | 脉冲/不延续 |
| 机构/主力 | 大单/趋势跟随 | 中大 | 抱团/板块轮动 |
| 散户 | 情绪化/题材/消息 | 小 | 追涨杀跌 |

---

## 二，核心原则

**三层决策优先级**

```
Layer 1：谁在主导（波动/量/舆情）
Layer 2：机构在哪个方向
Layer 3：技术指标确认买点

技术分析是第三层，不是第一层
```

---

## 三，不追高原则

**永远等回调买，不追突破**

```
追高 = 跟柚子一样被动
机构在时追高 = 次日砸盘
量化主导时追高 = 触发止损
```

---

## 四，机构抱团行情

**特征**：
- 少数板块持续跑赢指数
- 讨论少（机构建仓不高调）
- 涨跌同步（相关性高）
- 趋势延续性强

**抱团瓦解信号**：
- 龙头放量大跌
- 板块开始分化
- 讨论热度达顶峰（散户接盘）
- 政策转向

---

## 五，散户集中股特征

```
波动小 ≠ 机构不在
波动小 ≠ 无方向

机构在时：波动放大，趋势形成
散户在时：方向不明，等信号
```
