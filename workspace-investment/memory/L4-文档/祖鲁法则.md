# 祖鲁法则（Zulu Process）

> Keith Anderson，2000年代，趋势跟踪+板块轮动
> A股实战可行性：⭐⭐⭐（板块轮动逻辑适配，参数需调整）

---

## 一、核心理念

**专注行业板块，不抄个股底**

```
核心：
  1. 选强势板块，不抄弱势板块底
  2. 趋势来了满仓，趋势破立即走
  3. 止损要狠，不抱幻想
  4. 只做上升趋势的板块
```

---

## 二、选板步骤

### 第一步：判断大盘

| 大盘MA5>MA20 | 操作 |
|-------------|------|
| 是 | 做多 |
| 否 | 空仓等待 |

### 第二步：选强势板块

```
条件：
  1. 板块RPS前20%（相对强弱）
  2. 板块内有涨停股
  3. 板块整体涨幅 > 大盘
  4. 板块成交额放大
```

### 第三步：板块内选龙头

```
条件：
  1. 板块内成交额最大（前3）
  2. 突破20日新高
  3. 量价配合（涨时放量）
  4. 非ST/北交所
```

---

## 三、入场规则

| 触发 | 操作 |
|------|------|
| 突破20日新高 | 次日开盘买 |
| 突破时放量 > 5日均量1.5倍 | 确认信号 |
| 大盘跌破MA20 | 触发止损 |

---

## 四、止损规则

```
止损线：入场价 - 8%
硬止损：大盘MA5<MA10 → 必须走
不幻想：不找借口，跌破就走
```

---

## 五、仓位管理

| 条件 | 仓位 |
|------|------|
| 大盘+板块共振 | 50-60% |
| 仅板块强势 | 30-40% |
| 大盘震荡 | 20%或空仓 |

---

## 六、优缺点

### 优势
- 板块轮动思路适合A股结构性行情
- 选强势板块避免抄底思维
- 止损清晰（8%硬止损）
- RPS量化可验证

### 劣势
- 8%止损对A股偏宽（建议5%）
- 需要实时板块RPS数据
- 板块切换需要工具支持

---

## 七、与海龟法则对比

| 维度 | 祖鲁法则 | 海龟法则 |
|------|---------|---------|
| 入场 | 板块强势+突破新高 | 价格突破20日新高 |
| 止损 | 8%硬止损 | 2%ATR止损 |
| 仓位 | 板块强弱分级 | ATR计算 |
| 适合市场 | A股板块轮动 | 期货/外汇/商品 |
| 难度 | 中（需板块数据） | 低（纯价格） |
