> 尼古拉斯·达瓦斯（Nicolas Darvas），舞蹈家出身的传奇投资者  
> 1960年代通过箱体理论2万刀变成200万刀  
> A股实战可行性：⭐⭐⭐⭐⭐（A股题材炒作完美适配）

## 一、核心原理

**股价不是涨就是跌，不是在箱体里震荡**

达瓦斯发现：股价运动由一系列**箱体（Box）** 组成。
- 股价在箱体内震荡整理
- 突破箱体上沿 = 买入信号
- 跌破箱体下沿 = 卖出信号

```
        ┌───── 上沿（阻力位）
        │    ×  ×
   ─────┤  ×      ×
        │ ×        ×
        │×          ×
        └───── 下沿（支撑位）
```

---

## 二、箱体三要素

| 要素 | 说明 | 判断 |
|------|------|------|
| **横有多长** | 箱体震荡时间 | 震荡越久，突破越猛 |
| **竖有多高** | 突破后的涨幅 | 通常是箱体宽度的1-3倍 |
| **量能配合** | 突破时必须放量 | 缩量突破=假突破 |

### 最佳箱体特征
```
· 高度：股价的15-30%
· 时间：3-8周
· 突破时成交量放大2倍以上
· 突破后回踩箱体上沿（缩量）
```

---

## 三、箱体操作手册

### 第一步：识别箱体
```
1. 找出近期股价密集成交区
2. 画上轨（高点连线）和下轨（低点连线）
3. 确认上下轨平行（水平箱体最佳）
4. 等待突破
```

### 第二步：突破买入
```
突破箱体上沿 + 放量 = 买入
止损位：箱体下沿下方1-2%
```

### 第三步：持有
```
· 不预测高度，跟随趋势
· 用移动止损保护利润
· 跌破上升趋势线 = 离场信号
```

### 第四步：止盈
```
方法1：涨幅达到箱体高度的2倍时减半仓
方法2：高位放量大阴线 = 全出
方法3：RSI>85 = 分批卖出
```

## 四、箱体类型

### 1. 横盘箱体（整理箱体）
```
最常见，股价在固定区间震荡
突破后趋势延续性最强
```

### 2. 上升箱体（倾斜箱体）
```
股价逐步抬高，每次回调都在更高位置获得支撑
上升趋势中的常见形态
```

### 3. 下降箱体（下跌中继）
```
股价下跌过程中的横盘整理
向下突破概率大，避开
```

### 4. 三角形收敛
```
上下轨不平行，逐渐收窄
突破方向不确定，等待确认
```

## 五、达瓦斯的2%止损法则

```
单笔交易最大亏损 ≤ 总资金 × 2%
如果止损幅度是10%，则仓位 = 账户20%
如果止损幅度是5%，则仓位 = 账户40%
```

**计算示例**：
```
账户10万元，单笔最大亏损2000元
某股买入价10元，止损9.5元（-5%）
仓位 = 2000 / (10-9.5) = 2000 / 0.5 = 4000股
需投入 = 4000 × 10 = 4万元（40%仓位）
```

## 六、箱体理论 × A股题材炒作

**这是A股最赚钱的散招之一**

```
1. 发现热点题材（政策/事件驱动）
2. 找板块龙头（通常连续涨停）
3. 回调到5-10日均线时买入（箱体下沿）
4. 放量涨停突破前高 = 加仓信号
5. 高位放量大阴线 = 离场
```

### A股箱体实战要点
```
· 涨停板突破箱体 = 最强信号
· 连续缩量回调到均线 = 最佳买点
· 题材发酵初期 + 箱体突破 = 高胜率
· 回避下降箱体
· 弱势行情箱体高度普遍较小（10%以内）
```

## 七、箱体失败模式

| 形态 | 特征 | 应对 |
|------|------|------|
| **假突破** | 突破后快速回落 | 止损在箱体上沿下方 |
| **长阴破位** | 放量大阴线跌破下沿 | 立即离场 |
| **横久必跌** | 箱体震荡过久（>3个月） | 放弃，等待突破确认 |
| **久盘不跌** | 横盘后缩量 | 可能向上突破 |

## 九、箱体 vs 其他理论

| 维度 | 箱体理论 | 趋势线 | 均线 |
|------|---------|--------|------|
| 适用场景 | 震荡整理/突破 | 趋势跟踪 | 趋势确认 |
| 买点 | 突破时 | 回调到趋势线 | 均线支撑 |
| 止损 | 箱体下沿 | 趋势线下方 | MA5/MA10 |
| 优势 | 明确 | 直观 | 简单 |

## 十、达瓦斯箱体检查清单

```
□ 股价在箱体内震荡≥3周
□ 上下轨基本水平
□ 突破时成交量放大≥2倍
□ 突破后回踩缩量
□ 止损设在箱体下沿下方1-2%
□ 单笔亏损≤2%总资金
□ 涨幅达箱体高度2倍时分批止盈
```
