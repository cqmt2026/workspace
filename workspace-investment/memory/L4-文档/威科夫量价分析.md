# 威科夫量价分析（Wyckoff Phase Analysis）

> 理查德·威科夫（Richard Wyckoff），1900年代，华尔街量价分析之父
> A股实战可行性：⭐⭐⭐⭐（量价关系原理通用，中国主力行为模式吻合）

---

## 一，核心理念（进阶）

**量价是主力行为的唯一窗口**

```
威科夫核心发现：
  1. 主力吸筹 → 价格跌但不放量
  2. 主力拉升 → 缩量回调是洗盘
  3. 主力派发 → 价涨量缩
  4. 主力测试 → 最后一跌或最后一涨
```

---

## 二，吸筹六阶段（Phase A-D）

### Phase A：初跌（Preliminary Decline）

```
特征：
  下跌开始，成交量放大
  振幅加大
  止损被扫

信号：初跌开始
操作：不要抄底
```

### Phase B：吸筹（Accumulation）

```
特征：
  价格区间震荡
  放量涨，缩量跌
  每次下跌都缩量（主力在买）
  每次反弹都放量（反弹出货）

关键：成交量是识别主力行为的核心工具
```

### Phase C：测试（Test）

```
特征：
  主力测试支撑位
  最后一次下探低点
  成交量大幅萎缩
  快速反弹

信号：Phase C的反弹高度 > Phase B的50%
操作：Phase C止跌时买入
```

### Phase D：拉升（Markup）

```
特征：
  放量突破Phase B高点
  回调缩量不破Phase C低点
  涨幅加大，涨势确认

操作：放量阳线突破 → 追涨买入
```

---

## 三，派发六阶段（Phase A'-D'）

### Phase A'：初涨（Preliminary Rally）

```
特征：
  突破Phase B区间
  成交量放大
操作：不要追涨
```

### Phase B'：派发（Dsitribution）

```
特征：
  高位震荡
  价涨缩量（主力在卖）
  放量跌，缩量涨

关键信号：
  放量滞涨 = 主力出货
  缩量急跌 = 主力洗盘
```

### Phase C'：测试（Test）

```
特征：
  主力测试接盘力度
  最后一次上冲高点
  成交量是平日1/3或1/5

信号：滞涨出货
```

### Phase D'：下跌（Markdown）

```
特征：
  放量跌破派发区间
  趋势确认空头

操作：立即止损/空仓
```

## 四，支撑阻力（SR Levels）

### 关键价位

| 类型 | 说明 | 操作 |
|------|------|------|
| POC | 持仓成本集中区 | 放量突破做多 |
| VA高 | 成交量加权价格高点 | 反弹受阻做空 |
| VA低 | 成交量加权价格低点 | 回调支撑做多 |
| Point of Control | 最大量能日 | 核心价位 |

## 五，强势股特征（WY

```
强势股信号：
  1. 上涨时放量，回调缩量（控盘良好）
  2. 弱势板块中的强势股 = 领头羊
  3. 缩量创新高 = 主力高度控盘
  4. 跌破支撑不缩量 = 主力出货

弱势股特征：
  1. 价跌量平/放量 = 主力出货
  2. 反弹缩量 = 无力反弹
  3. 弱势板块中的弱势股 = 绝不做
```

## 七，量价关系口诀

```
价升量增 → 真实需求，后市看涨
价升量缩 → 主力控盘，或出货
价跌量缩 → 主力震仓，或见底
价跌量平 → 主力出货，看跌
```
