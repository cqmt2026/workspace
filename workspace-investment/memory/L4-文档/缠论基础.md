## 一、核心概念

缠论是**纯数学化**的技术分析体系，核心是用**级别+中枢+背驰**精确定位买卖点。

**三个核心构件**：走势、级别、中枢

---

## 二、走势类型

### 1. 笔（Bi）
```
定义：相邻两笔（一上一下），中间有独立的高低点
最少：5根K线（1根上涨 + 1根回调 + 1根上涨）
笔是缠论最小的构建单元
```

### 2. 线段
```
定义：连续三笔以上，上涨/下跌方向一致
线段比笔更稳定，用于构建中枢
```

### 3. 走势
```
上涨走势：高低点不断抬高
下跌走势：高低点不断降低
盘整走势：高低点横移（无趋势）
```

---

## 三、级别

**级别是缠论的核心**——不同级别的走势叠加分析

| 级别 | 周期 | 用途 |
|------|------|------|
| 1分钟 | 1min K线 | 短线精确买卖 |
| 5分钟 | 5min K线 | 日内操作 |
| 30分钟 | 30min K线 | 波段操作 |
| 日线 | 日K线 | 中线趋势 |
| 周线 | 周K线 | 大趋势 |

**操作原则**：看大做小（大级别定方向，小级别找买点）

## 四、中枢（最核心概念）

### 什么是中枢？
```
中枢 = 连续三次价位的重叠区间
类似"箱体"，是筹码密集成交区

上涨中：回调的低点构成中枢
下跌中：反弹的高点构成中枢
```

### 中枢画法
```
        D
   ──────
  C    │
        │  ← 高点
B ──────┘
  A
  ↑ 高点连续重叠3次，形成AB=CD的中枢
```

### 中枢的实战意义
```
1. 中枢内震荡 = 主力吸筹/派发阶段
2. 离开中枢时力度 = 行情大小
3. 回到中枢时 = 可能出现3买/3卖
```

## 五、买卖点（三类）

### 第一类买点（1买）
```
位置：下跌走势背驰后的最低点
特征：
  - 创新低
  - 但下跌力度比前一波弱（背驰）
  - MACD黄白线在0轴以下金叉
确认：之后必须涨回最后一个中枢
风险：最高
```

### 第二类买点（2买）
```
位置：上涨走势第一次回调的最低点
特征：
  - 在1买之后
  - 不创新低
  - MACD在0轴上方金叉更可靠
确认：突破前高后上涨延续
风险：中等
```

### 第三类买点（3买）
```
位置：上涨走势离开中枢后，回调不破中枢上沿
特征：
  - 在中枢上方震荡
  - 回调低点在中枢上沿以上
  - MACD在0轴上方
确认：放量突破前高
风险：最低（最强信号）
```

### 三类卖点（反过来）
```
1卖：上涨走势背驰后的最高点
2卖：反弹后的次高点
3卖：跌破中枢后，反弹不能回到中枢下沿
```

## 六、背驰（背离）

### 什么是背驰？
```
同级别比较：
  上涨：创新高，但力度（MACD红柱/黄白线高度）比前一波弱
  下跌：创新低，但力度比前一波弱

背驰 = 动力衰竭 = 行情反转信号
```

### 判断标准
```
1. 空间：新高低与前一高低比较
2. 力度：MACD红柱/绿柱面积比较
3. 辅助：RSI/KDJ背离
```

### 实战口诀
```
"进入段必须进入中枢，离开段必须离开中枢"
"背驰段是行情转折点"
"三买是强势信号，三卖是离场信号"
```

## 七、实战应用流程

### 选股流程
```
1. 日线/周线：找明显趋势（上涨或下跌走势）
2. 画中枢：30分钟找最近的中枢区间
3. 看背驰：比较进入段和离开段的力度
4. 找买卖点：1买/2买/3买
5. 止损：跌破最近中枢下沿
```

### 持仓管理
```
买点买入 → 持有 → 出现1卖/2卖信号 → 分批离场
止损：跌破最近中枢下沿
```

## 九、核心金句

> **"走势终完美"** —— 任何走势都会结束<br>
> **"买点买，卖点卖"** —— 不要逆势<br>
> **"看大做小"** —— 大级别定方向，小级别操作<br>
> **"中枢为王"** —— 中枢是判断走势的核心

## 十、A股实战适配

缠论在A股非常流行，原因是：

1. **数学化**：精确到K线级别，不模糊
2. **适合震荡市**：中枢震荡阶段有3买3卖
3. **量化友好**：条件明确，容易程序化

### 简化应用（散户版）
```
1. 日线找趋势（均线多头/空头）
2. 30分钟找中枢
3. 30分钟回调不破中枢下沿 = 3买
4. 止损：中枢下沿下方1%
5. 止盈：出现1卖信号
```
