# CAN SLIM 投资体系（欧奈尔）

> 源自《笑傲股市》《股票买卖法则》，威廉·欧奈尔创立  
> A股实战可行性：⭐⭐⭐⭐（经过验证，强势股逻辑通用）

---

## 一、核心理念

**牛股来自每股收益大幅增长 + 股价大幅上涨**

欧奈尔的核心发现：**1870-1975年500只大牛股，97%在大幅上涨前季报每股收益增长20%以上**

---

## 二、CAN SLIM 七字口诀

### C = Current Quarterly Earnings（当季每股收益）
- **最近一季EPS同比大幅增长**（≥20%，越多越好）
- 营收也要增长（≥25%）
- **避开季报发布后的"买入陷阱"**（利好兑现即下跌）
- 重点：看趋势，不看绝对值

### A = Annual Earnings Growth（年度每股收益）
- **过去5年每年EPS增长**
- 优选增长加速的公司（后一年比前一年更好）
- ROE ≥ 15% 作为辅助指标

### N = New Products, New Highs（新製品・新規高値）
- **新产品、新管理层、新赛道**
- 股价创出**52周新高**（不是低位横盘）
- 行业/市场领导者的突破最可信

### S = Supply and Demand（供需関係）
- **流通盘小 + 成交量放大 = 筹码供不应求**
- 股价上涨时成交量是前一日1.5-2倍
- 缩量回调是买入机会

### L = Leaders or Laggards（リーダーか後れ組か）
- **只买行业龙头/强势股**
- 相对强弱指数（RS）> 70
- 回避弱势股（RS<50的股票）

### I = Institutional Sponsorship（機関投資家）
- **有机构买入支撑**（基金、社保、QFII等）
- 机构持仓比例适中（太多是出货，太少是无人关注）
- **关注机构持仓变化**（新建仓>增持>保持>减持）

### M = Market Direction（市場方向）
- **顺势而为**（大盘下跌时不抄底）
- 每天看大盘主要指数
- 识别市场领涨板块

## 三、买入法则（关键点）

### 1. 基部突破（Base Breakout）
```
形态：杯柄形态（Cup with Handle）
- 杯部回调幅度：30-35%（不应超过50%）
- 杯柄回调幅度：不超过10-15%
- 柄部成交量：缩量
- 突破时成交量：放大50%以上
- 最佳买点：柄部高点上方1/8处
```

### 2. 高而狭窄旗形（High Tight Flag）
- 前期股价短时间内涨超20-25%
- 然后小量回调3-4周（幅度10%以内）
- **爆发力最强，失败率也较高**

### 3. 双底形态（Double Bottom）
- W底，第二个底不低于第一个底
- 中间高点被突破时买入

---

## 四、止损法则

**铁律：亏损7-8%必须止损**

```
买入点上方1/8处设止盈
跌破买入价7%必须止损
不允许任何"等反弹"思维
```

---

## 五、卖出法则

| 信号 | 说明 |
|------|------|
| 高位放量大跌 | 机构出货 |
| 涨到目标价 | 参考：口袋支点+20-25% |
| 跌破MA10 | 短线离场 |
| 股价13周均线走平 | 中线离场 |
| RSI>85 | 超买区域，分批卖出 |

## 六、A股实战适配

### 欧奈尔 → A股映射

| 欧奈尔指标 | A股替代 |
|-----------|--------|
| EPS增长 | 季报净利润增长≥20% |
| RS>70 | RPS>80（相对强弱） |
| 52周新高 | 创一年新高 |
| 机构持仓 | 基金/QFII/社保重仓 |
| 基部突破 | 缩量调整后放量突破前高 |
| 杯柄形态 | 对应A股"旗形整理""楔形整理" |

### A股实战要点
- **强势股回调到10日均线**是常见买点
- **板块效应比美股更强**（A股羊群效应明显）
- **季报前买，季报后卖**（A股预期效应）
- 配合**板块RPS**选股效果更好

## 七、CAN SLIM 选股检查清单

```
□ 当季EPS增长≥20%
□ 当季营收增长≥25%
□ 年度EPS连续增长5年
□ ROE≥15%
□ 股价创52周新高
□ RS≥80（相对强弱）
□ 突破时成交量放大≥50%
□ 有机构持仓（基金/QFII/社保）
□ 大盘处于上升趋势
□ 止损设在-7%
```
