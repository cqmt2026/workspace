## 一、核心理念

**趋势线是核心工具，突破即离场**

```
三大理论：
  1. 趋势线交易
  2. 123法则（判断趋势反转）
  3. 2B法则（假突破止损）
```

---

## 二、趋势线交易

### 画线规则

```
上升趋势线：
  连接两个以上回调低点
  延伸后成为支撑线

下降趋势线：
  连接两个以上反弹高点
  延伸后成为压力线

操作：
  回调到趋势线附近企稳 → 买
  反弹到趋势线附近受阻 → 卖
```

### 趋势线被突破 = 趋势改变信号

---

## 三、123法则（最核心）

**趋势反转的判断**

### 做多转空（上升→下降）

```
123法则（做多结束）：
  1. 趋势线被跌破
  2. 创出新低后反弹后再跌
  3. 价格跌破前期低点

123全部满足 → 做空/离场
```

### 做空转多（下降→上升）

```
123法则（做空结束）：
  1. 趋势线被涨破
  2. 创出新高后回踩后再涨
  3. 价格突破前期高点

123全部满足 → 做多/离空
```

---

## 四、2B法则（止损核心）

```
2B法则：
  价格创出新高后未能延续，反转跌破前期高点 → 做空
  价格创出新低后未能延续，反转突破前期低点 → 做多

操作：
  在前期高点/低点外侧下单
  止损设在前高/低内侧
```

### 与海龟止损对比

| 法则 | 止损位置 |
|------|---------|
| 海龟 | 2ATR（波动率止损） |
| 2B法则 | 前期高点/低点外 |

## 五、综合交易系统

### 做多步骤

```
1. 画趋势线
2. 等待价格回调到趋势线附近
3. 123法则确认支撑有效
4. 趋势线止损（跌破离场）
5. 2B法则加仓/止损
```

### 做空步骤

```
1. 画下降趋势线
2. 等待反弹到趋势线附近
3. 123法则确认压力有效
4. 趋势线止损（涨破离场）
```

## 七、止损设计

```
核心：亏损不超过总资金2%/笔

止损计算：
  止损价格 = 入场价 × 0.98
  止损股数 = 总资金×2% ÷ (入场价-止损价)
```

## 十、实操关键

1. **趋势线必须手工画**（程序难以自动画准）
2. **2B适合短线止损**，不适合长线
3. **123是辅助**，不是主信号
