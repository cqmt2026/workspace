# 海龟交易法则（Turtle Trading System）

> 理查德·丹尼斯（Richard Dennis），1983年实验
> 教一批"海龟"学生用这套规则在期货市场赚钱
> A股实战可行性：⭐⭐⭐（趋势跟踪原理通用，参数需调整）

---

## 一、核心理念

**趋势跟踪**——在市场趋势开始时顺势建仓，趋势反转时离场。

```
核心理念：
  1. 趋势是稀缺的，来了就满仓
  2. 截断亏损，让利润奔跑
  3. 机械执行，不凭感觉
  4. 活得久比赚得快重要
```

---

## 二、入场规则

### 第一个买入信号

```
规则1：突破20日高点 → 做多
规则2：突破20日低点 → 做空

操作：
  当日收盘价突破20日最高价 → 次日开盘做多
  当日收盘价跌破20日最低价 → 次日开盘做空
```

### 加仓规则（4次）

```
首仓入场后，价格每向有利方向移动0.5N（波动率单位）→ 加仓一次
最多加仓4次，总持仓不超过6个单位
N = ATR(20)（20日真实波幅均值）
```

---

## 三、止损规则

```
首仓止损：入场价 - 2N（总风险 ≤ 总资金2%）
加仓止损：逐仓止损，每次加仓后上调止损线
最终止损：10日最低价（做多）
```

---

## 四、出场规则

| 操作 | 做多 | 做空 |
|------|------|------|
| 入场 | 突破20日最高 | 跌破20日最低 |
| 出场 | 跌破10日最低 | 突破10日最高 |
| 止损 | 入场价-2N | 入场价+2N |

---

## 五、仓位管理（海龟核心）

```
单笔风险上限：总资金 × 2%
N = ATR(20)

每次买入股数 = 总资金 × 2% ÷ (入场价 × 2N)

示例：
  总资金10万，N=1元，入场价20元
  股数 = 2000 ÷ (20 × 2) = 50手
  实际风险 = 50 × 2 × 1 = 1000元（1%，符合2%上限）
```

---

## 六、关键指标

| 指标 | 计算 | 用途 |
|------|------|------|
| N（ATR） | ATR(20) = EMA(Tr, 20) | 波动率，仓位依据 |
| 20日最高/最低 | 近20日极值 | 入场信号 |
| 10日最高/最低 | 近10日极值 | 出场信号 |
| 单位U | 2%资本 ÷ (入场价×2N) | 仓位大小 |

---

## 七、优缺点

### 优势
- 规则简单机械，执行零歧义
- 趋势来时满仓启动，利润惊人
- 亏损时立即止损，存活率高
- 多市场通用（期货/外汇/股票）

### 劣势
- 震荡市反复止损，连续亏损可达20+次
- 需要足够耐心等待趋势
- ATR参数需根据市场调整
- 熊市只有做空信号（A股难以做空）

|---------|-----------|------|
| 20日突破 | 20日 | 保持 |
| 10日出场 | 10日 | 保持 |
| ATR(20) | ATR(20) | 通用 |
| 2%止损 | 2-3%止损 | 保留 |
| 4次加仓 | 1-2次（手续费+流动性） | A股T+1限制 |
