# 科学回测框架 v1.0

**创建时间**: 2026-05-25
**目标**: 中短期超额收益（5-20日持仓）
**数据要求**: 前复权数据（进行中）

---

## 框架原则

1. **统一标准**：每次回测用同一套规则，结果才可比较
2. **成本计入**：佣金/印花税/滑点全部计入，才真实
3. **基准对照**：每次必须有沪深300对比
4. **显著性验证**：结果必须通过显著性检验才可信

---

## 回测标准

### 1. 市场状态判断（前置过滤）

| 信号 | 条件 | 动作 |
|------|------|------|
| 强势市场 | RPS>70板块≥3个，沪深300站稳MA5 | 正常做多 |
| 弱势市场 | RPS>70板块=0，沪深300空头排列 | 禁止开仓 |
| 震荡市场 | 不满足以上条件 | 降低仓位至50% |

### 2. 选股标准

| 因子 | 要求 |
|------|------|
| 动量 | 20日涨幅前20%（RPS模拟） |
| 成交量 | 当日成交量 > 5日均量1.5倍 |
| 板块 | 所在板块RPS≥板块中位数 |
| 趋势 | 均线多头排列加分 |

每期选股数量：10-20只

### 3. 买入规则

| 规则 | 说明 |
|------|------|
| 买入时机 | 信号次日开盘买入 |
| 仓位 | 单只≤5%，总仓位≤50% |
| 买入价 | 开盘价 |

### 4. 止损规则

| 类型 | 条件 |
|------|------|
| 固定止损 | 亏损-3%必须止损 |
| 时间止损 | 5个交易日不涨离场 |
| 均线止损 | 收盘跌破MA5离场 |

### 5. 卖出规则

| 条件 | 动作 |
|------|------|
| 目标收益 | +5%~8%分批止盈 |
| 均线破坏 | 多头排列破坏离场 |
| 到期 | 20日自动卖出 |
| 止损 | 触发即离场 |

### 6. 成本模型

| 成本项 | 费率 | 说明 |
|--------|------|------|
| 佣金 | 万1（双向） | 最低5元/笔 |
| 印花税 | 千1（卖出时） | 仅卖方 |
| 滑点 | 0.1% | 预期冲击成本 |

**单笔交易成本合计约：0.3%**

> 参数确认时间: 2026-05-25

### 7. 基准对照

| 基准 | 说明 |
|------|------|
| 沪深300 | 每次回测必须同步计算沪深300同期收益 |
| 超额收益 | 策略收益 - 沪深300收益 |

---

## 回测结果评估标准

| 指标 | 合格线 | 说明 |
|------|--------|------|
| 超额收益 | >0 | 跑赢沪深300 |
| 夏普比率 | ≥1.0 | 风险调整后收益 |
| 最大回撤 | ≤15% | 极端风险 |
| 胜率 | ≥50% | 概率基础 |
| 盈亏比 | ≥1.5 | 平均盈利/平均亏损 |
| 显著性 | p<0.05 | 必须通过统计检验 |

---

## 回测报告标准格式

每次回测报告必须包含：

```
1. 策略参数（信号周期/持仓周期/选股数量）
2. 样本信息（时间范围/交易笔数/股票数）
3. 收益指标（总收益/年化/超额收益）
4. 风险指标（夏普/最大回撤/波动率）
5. 胜率统计（胜率/盈亏比/平均盈亏）
6. 基准对比（沪深300同期收益）
7. 显著性检验（p值/Monte Carlo）
8. 交易明细（每笔交易记录）
```
