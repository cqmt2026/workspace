# 利弗莫尔关键点（Livermore Key Points）

> 杰西·利弗莫尔（Jesse Livermore），1900-1940年投机之王
> 核心：《股票大作手操盘术》+操盘手法则
> A股实战可行性：⭐⭐⭐⭐（关键点+板块/指数共振，通用）

---

## 一，核心理念（已整理版补充）

**"板块是关键，不是个股"——利弗莫尔自己后期领悟**

```
核心升级：
  1. 板块是股票的领导，个股是板块的跟随
  2. 买入时：选最强板块，买最强股
  3. 卖出时：板块见顶，个股领先下跌
  4. 只在板块启动时入场，不抄底
```

## 二，利弗莫尔六点操盘系统（整理版）

### 第一点：确定大势

```
操作：
  1. 大盘MA5>MA20 → 做多
  2. 大盘MA5<MA20 → 做空/空仓
  3. 大盘横盘 → 等待，不入场

这是六点系统最重要的一条
```

### 第二点：板块（已升级为利弗莫尔核心）

```
操作：
  1. 只做最强板块
  2. 板块内选龙头股
  3. 板块RPS前3才入场
  4. 板块走弱立即换板块或空仓
```

### 第三点：个股关键点买入

```
关键点定义：
  个股突破时放量创N日新高
  典型：20日新高放量

操作：
  1. 板块强 → 个股突破关键点时买
  2. 止损设在关键点下方
  3. 等回调确认再买（次级机会）
```

### 第四点：等个股领头羊

```
规则：
  1. 板块启动时，只有领头羊值得买
  2. 领头羊特征：率先突破，量最大
  3. 领头羊跌，板块也弱
```

### 第五点：止损

```
止损三线：
  1. 关键点下方3-5%
  2. 大盘跌破MA20
  3. 板块RPS掉出前3

不幻想，不补仓，不摊成本
```

### 第六点：加仓

```
加仓条件：
  1. 板块持续强势
  2. 个股继续领涨
  3. 每次加仓都要重新确认

关键：盈利时才加仓，浮亏不加
```

## 七，A股难点

```
1. 个股T+1限制 → 突破后次日才能买
2. 板块轮动快 → 需每日确认
3. 领头羊切换快 → 需实时跟踪
4. 停牌/涨跌停 → 关键点可能被封
```
