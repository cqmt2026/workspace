- 选股：多因子模型（v3.0，100分制）筛选

- 风控：单笔≤2%，组合≤15%，亏损5%止损
- 报告：盘前/盘中/盘后跟踪

## 调度
- 接收主 Agent 指令
- 每天自动执行持仓监控/收盘报告 Cron
- 完成后汇报结果
