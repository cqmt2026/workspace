# 短中线复利系统

**建立时间**: 2026-05-24
**状态**: 待验证
**目标**: 小资金快速做大

---

## 核心理念（基于中国A股理解）

1. 政策市 - 政策是第一驱动力
2. 散户市 - 情绪市特征明显，利用情绪反向
3. 择时 > 选股
4. 机器纪律 > 人性判断
5. 超额收益来源：政策底/情绪底/困境反转/择时/止损

---

## 系统参数（2026-05-24确认）

| 模块 | 参数 |
|------|------|
| **持有周期** | 3-5天 |
| **止损** | -5% |
| **止盈** | +10%减半 / 跌破5日线清 |
| **仓位** | 30%/单笔，最多3只 |
| **选股** | 强势板块 + 趋势股 |
| **买点** | 回调到5日线买（非追高） |
| **技术指标** | 以5日线为核心 |
| **连续亏损处理** | 连续3次 → 回测修正策略 |

---

## 资金使用

- 单笔：30%
- 最多同时持有：3只（90%仓）
- 剩余：10%现金

---

## 操作规则

```
选强势板块 → 找趋势股回调到5日线 → 买入
持有3-5天
  ├── 涨10% → 减半仓
  ├── 跌破5日线 → 清仓
  └── 跌5% → 止损
连续亏3次 → 停止操作 → 回测验证策略
```

---

## 策略验证规则

1. 策略未经回测验证不给出建议
2. 实盘前先跑模拟验证
3. 连续亏损3次必须回测修正，不硬扛
