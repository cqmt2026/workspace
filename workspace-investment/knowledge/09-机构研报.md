# 机构研报摘要模块

**标签**: 研报 | 机构评级 | 券商
**文件**: `scripts/research_report.py`
**状态**: ⚠️ 接口不稳定

---

## 核心功能

| 功能 | 说明 |
|------|------|
| 个股研报 | 获取单只股票机构研报 |
| 评级统计 | 统计买入/增持/中性/减持 |

---

## 注意事项

akshare研报接口数据质量不稳定，部分字段返回"无"。

建议结合东方财富网手动查阅研报。

---

## 使用方法

```python
from research_report import stock_research_summary

r = stock_research_summary('600519')
print(f"研报数量: {r.get('report_count')}")
print(f"评级分布: {r.get('ratings')}")
```
