# 数据库模块

**标签**: 数据库 | SQLite | 行情存储
**文件**: `scripts/market_db.py`
**状态**: ✅ 已完成

---

## 核心功能

| 功能 | 说明 |
|------|------|
| 初始化 | `init_db()` 创建表结构 |
| 保存K线 | `save_kline(code, df)` |
| 读取K线 | `get_kline(code, start, end)` |
| 保存概要 | `save_profile(code, name, industry, market_cap)` |
| 统计 | `get_stats()` |

---

## 表结构

### daily_kline（每日K线）
- code TEXT
- date TEXT
- open/high/low/close/volume REAL

### daily_profile（股票概要）
- code TEXT PRIMARY KEY
- name TEXT
- industry TEXT
- market_cap REAL
- updated TEXT

---

## 使用方法

```python
from market_db import init_db, save_kline, get_kline

# 初始化
init_db()

# 保存数据
df = ak.stock_zh_a_hist(symbol='600519')
save_kline('600519', df)

# 读取数据
df = get_kline('600519', start='2026-01-01')
```
