# 量化回测模块

**标签**: 量化 | 回测 | 策略 | backtest
**文件**: `scripts/backtest.py`
**状态**: ✅ 已完成

---

## 策略

| 策略 | 说明 |
|------|------|
| MA均线策略 | MA5>MA20买入，MA5<MA20卖出 |
| MACD策略 | DIF>0金叉买入，死叉卖出 |

---

## 性能指标

| 指标 | 说明 |
|------|------|
| 总收益率 | 策略总收益 |
| 交易次数 | 买入+卖出总数 |
| 持仓天数 | 平均持仓时间 |

---

## 使用方法

```python
from backtest import backtest, get_kline

# 获取数据并回测
df = get_kline('600519')
result = backtest(df, initial_capital=100000)
print(f"收益率: {result['total_return']}%")
```
