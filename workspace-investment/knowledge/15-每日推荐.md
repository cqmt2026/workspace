# 每日股票池跟踪与买入推荐模块

**标签**: 每日推荐 | 选股 | 自动化
**文件**: `scripts/daily_recommend.py`
**状态**: ✅ 已完成

---

## 核心功能

| 功能 | 说明 |
|------|------|
| 股票池跟踪 | 每日收盘后分析所有689只标的 |
| 技术分析 | MA/MACD/KDJ/RSI综合评分 |
| 行业热度 | 结合当日板块资金流向 |
| 买入推荐 | 筛选最优20只进入推荐池 |

---

## 分析维度与评分

| 维度 | 指标 | 得分规则 |
|------|------|----------|
| 均线 | 多头排列 | +20 |
| 趋势 | 上升趋势 | +10 |
| MACD | 零轴上方多头 | +25 |
| KDJ | 超卖反弹 | +15 |
| RSI | 超卖 | +10 |
| 行业 | 资金净流入 | 动态加分 |

---

## 定时任务

| 项目 | 内容 |
|------|------|
| Cron ID | `54694d4d-5557-4624-bb4d-32b248ea971d` |
| 执行时间 | 每天 16:00（周一至周五） |

## 使用方法

```bash
# 手动执行
python scripts/daily_recommend.py

# 输出前10推荐
TOP10 = daily_recommend()[:10]
```
