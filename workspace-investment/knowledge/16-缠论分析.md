# 缠论分析模块

**标签**: 缠论 | 分型 | 笔 | 中枢 | 15分钟 | 60分钟
**文件**: `scripts/chan_analysis.py`
**状态**: ✅ 已完成

---

## 核心概念

| 概念 | 说明 |
|------|------|
| 分型 | 顶分型（中间最高）/ 底分型（中间最低） |
| 笔 | 连接相邻异向分型的线段 |
| 中枢 | 三笔重叠区域（盘整区间） |
| 向上笔 | 底分型 → 顶分型 |
| 向下笔 | 顶分型 → 底分型 |

---

## 分析周期

| 周期 | 说明 | 用途 |
|------|------|------|
| 15分钟 | 短线精细 | 精确入场点 |
| 60分钟 | 中线趋势 | 判断方向 |

---

## 信号判断

| 信号 | 含义 |
|------|------|
| 向上突破中枢 | 强势，可能延续上涨 |
| 上升笔延续 | 趋势向上 |
| 向下突破中枢 | 弱势，可能继续下跌 |
| 下降笔 | 趋势向下 |
| 向上共振 | 15分钟+60分钟同向上涨 → 强买入信号 |
| 向下共振 | 15分钟+60分钟同向下跌 → 观望/卖出 |

---

## 评分体系

| 条件 | 加分 |
|------|------|
| 60分钟上升笔 | +30 |
| 15分钟上升笔 | +15 |
| 60分钟中枢突破 | +20 |
| 15分钟中枢突破 | +10 |
| 向上共振 | +25 |

---

## 使用方法

```python
from chan_analysis import chan_analyze, chan_score

# 综合分析
result = chan_analyze('600519')
print(result['15分钟']['signal'])
print(result['60分钟']['signal'])
print(result['共振'])
print(result['买入信号'])

# 评分
score = chan_score('600519')
```
