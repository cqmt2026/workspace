# 监控告警模块

**标签**: 监控 | 告警 | 健康检查
**文件**: `scripts/monitoring.py`
**状态**: ✅ 已完成

---

## 核心功能

| 功能 | 说明 |
|------|------|
| Gateway内存 | 检查Gateway进程内存使用 |
| 磁盘空间 | 检查磁盘剩余空间 |
| 脚本完整性 | 检查脚本数量 |
| 数据新鲜度 | 检查数据文件更新时间 |

---

## 告警阈值

| 项目 | 阈值 | 说明 |
|------|------|------|
| Gateway内存 | >800MB | WARNING |
| 磁盘空间 | <5GB | WARNING |
| 数据过期 | >24小时 | WARNING |

---

## 健康检查

```python
from monitoring import system_health_check

result = system_health_check()
print(result['overall'])  # OK / WARNING
```
