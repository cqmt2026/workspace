# 风控模块

**标签**: 风险管理 | 止损 | 仓位
**文件**: `scripts/risk_management.py`
**状态**: ✅ 已完成

---

## 核心功能

| 功能 | 说明 |
|------|------|
| 止损检查 | 单笔亏损超过阈值时提醒 |
| 止盈检查 | 盈利达到目标时提醒 |
| 仓位计算 | 根据风险比例计算持仓量 |
| 风险评估 | 总仓位/风险等级/最大亏损 |

---

## 使用方法

```python
from risk_management import RiskManager

rm = RiskManager(portfolio_value=100000)
rm.add_position('600549', shares=500, cost_price=20.0)
rm.update_price('600549', 18.5)

# 检查止损
if rm.stop_loss_check('600549', stop_loss_pct=5):
    print('触发止损')

# 风险评估
print(rm.risk_assessment())
```

---

## 风控参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 单笔风险 | 2% | 占总资产比例 |
| 止损阈值 | 5% | 单笔最大亏损 |
| 止盈阈值 | 20% | 单笔最大盈利 |
| 仓位上限 | 30% | 单只最大仓位 |
