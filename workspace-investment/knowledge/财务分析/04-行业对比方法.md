## 核心理念

**脱离行业谈财务指标没有意义，必须在同行中找异常**

行业对比核心：**找差异 + 识别异常 + 判断竞争力**

## 行业分类框架

### 按盈利模式分类
| 类型 | 特征 | 核心指标 |
|------|------|----------|
| 周期股 | 业绩随经济波动 | 关注PB、景气周期位置 |
| 消费股 | 稳定、弱周期 | 品牌力、渠道力、市占率 |
| 科技股 | 高增长、高波动 | 研发费用、用户数、渗透率 |
| 金融股 | 杠杆经营 | 资产质量、资本充足率 |
| 医药股 | 刚需、研发驱动 | 研发管线、专利壁垒 |
| 制造业 | 成本驱动 | 产能利用率、毛利率 |

### 按生命周期分类
| 阶段 | 营收特征 | 估值特征 |
|------|----------|----------|
| 初创期 | 营收小，可能亏损 | PS估值 |
| 成长期 | 营收高增长 | PE/PS |
| 成熟期 | 稳定增长 | PE+股息率 |
| 衰退期 | 营收下降 | PB或清算价值 |

## 行业对比财务指标

### 1. 盈利能力对比
```python
# 毛利率对比（同行中找异常）
相对毛利率 = (公司毛利率 - 行业平均毛利率) / 行业平均毛利率
# 正值表示高于行业平均，负值表示低于

# ROE对比
相对ROE = 公司ROE - 行业平均ROE
```

### 2. 成长性对比
```python
# 营收增速对比（判断行业地位）
营收增速差 = 公司营收增速 - 行业平均营收增速
# 持续为正：市场份额在提升
```

### 3. 运营效率对比
```python
# 周转率对比
存货周转率行业排名 = rank(公司存货周转率, 行业内)
应收账款周转率行业排名 = rank(公司应收账款周转率, 行业内)
```

### 4. 财务健康对比
```python
# 资产负债率对比
相对负债率 = 公司资产负债率 - 行业中位数
# 显著高于同行：经营更激进
```

## 竞争对手分析矩阵

### 主要对比维度
| 维度 | 权重（示例） | 说明 |
|------|--------------|------|
| 毛利率 | 25% | 定价权体现 |
| 营收增速 | 20% | 成长性 |
| ROE | 20% | 资本回报 |
| 现金流 | 15% | 盈利质量 |
| 负债率 | 10% | 财务稳健 |
| 周转率 | 10% | 运营效率 |

### 评分方法
```python
# Z-Score标准化
Z_i = (X_i - μ) / σ
# 0 = 行业平均，正数 = 优于平均，负数 = 劣于平均

# 加权综合得分
综合得分 = Σ(权重_i × Z_i)
```

## 异常识别方法

### 1. 单一指标异常
**识别**：某指标显著偏离行业均值
```
异常度 = |公司指标 - 行业中位数| / 行业标准差
异常度 > 2：显著异常
```

### 2. 趋势异常
**识别**：与行业趋势相反
```python
# 行业向上，但公司向下
if 行业营收增速 > 0 and 公司营收增速 < 0:
    异常 = True

# 行业毛利率稳定，但公司持续下降
if 行业毛利率变化 < 5% and 公司毛利率变化 < -10%:
    异常 = True
```

### 3. 结构性异常
**识别**：财务结构与行业模式不符
```python
# 轻资产行业出现重资产
if 行业固定成本占比 < 30% and 公司固定成本占比 > 50%:
    异常 = True

# 高负债行业出现低负债（可能是造假或资金闲置）
if 行业平均负债率 > 70% and 公司负债率 < 30%:
    异常 = True
```

## 行业地位判断

### 市场份额分析
```python
市场份额 = 公司营收 / 行业总营收

# 市场份额变化
份额变化 = 本期份额 - 上期份额
# 正值：竞争力提升
# 负值：竞争力下降
```

### 定价权判断
| 指标 | 说明 |
|------|------|
| 毛利率高于同行 | 品牌溢价或技术壁垒 |
| 净利率高于同行 | 费用控制好 |
| 周转率高于同行 | 运营效率高 |

### 护城河在财务上的体现
| 护城河类型 | 财务特征 |
|------------|----------|
| 品牌护城河 | 高毛利 + 稳定营收 |
| 技术护城河 | 高研发费用 + 高净利率 |
| 网络效应 | 用户增长快 + 高转换成本 |
| 规模效应 | 毛利率随规模提升 |
| 渠道护城河 | 高应收账款周转 + 预收账款 |

## 行业对比实战

### 步骤1：确定可比行业
```python
# 同行业A股公司（东方财富行业分类）

    '山西汾酒', '古井贡酒'

```

### 步骤2：获取行业数据
```python
# 行业平均指标

    '毛利率': 75.5,
    '净利率': 35.2,
    'ROE': 28.5,
    '营收增速': 15.3,
    '负债率': 32.1
}
```

### 步骤3：计算相对指标
```python
公司 = {
    '贵州茅台': {
        '毛利率': 91.9,  # +16.4 vs 行业平均
        '净利率': 50.5,  # +15.3 vs 行业平均
        'ROE': 38.2,     # +9.7 vs 行业平均
        '营收增速': 17.5,  # +2.2 vs 行业平均
        '负债率': 18.8    # -13.3 vs 行业平均（更稳健）
    }
}
```

### 步骤4：得出结论
```
贵州茅台：各项指标显著优于行业平均
- 毛利率高于平均16.4个百分点：强定价权
- ROE高于平均9.7个百分点：高资本回报
- 负债率低于平均13.3个百分点：财务稳健
综合评价：行业绝对龙头，护城河深厚
```

## 行业配置决策

### 行业轮动参考
| 宏观环境 | 受益行业 |
|----------|----------|
| 经济复苏 | 周期股（钢铁/煤炭/化工） |
| 消费升级 | 消费股（白酒/医疗/教育） |
| 科技创新 | 科技股（半导体/软件/新能源） |
| 利率下行 | 金融股（银行/保险） |
| 通胀预期 | 资源股（有色/煤炭） |

### 行业相对强弱
```python
# 计算行业指数相对强弱
相对强弱 = 行业指数涨幅 - 大盘指数涨幅

# 筛选强势行业
强势行业 = 相对强弱 > 10% and 成交量放大
```

## 注意事项

1. **会计准则差异**：不同地区会计准则可能影响对比
2. **业务结构差异**：多元化公司需拆分业务对比
3. **季节性因素**：季度对比要同季度比较
4. **会计政策**：折旧方法、存货计价等会计政策差异
5. **汇率影响**：海外业务多的公司受汇率影响大
