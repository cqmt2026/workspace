# 价值投资体系（巴菲特体系）

**标签**: 财报分析 | 价值投资 | 巴菲特 | 长期持有
**创建时间**: 2026-04-30
**更新**: v1.0

---

## 核心理念

**好公司 + 好价格 + 长期持有 = 价值投资**

巴菲特选股核心：**护城河**（竞争优势） + **合理价格** + **优秀管理层**

---

## 财务核心指标

### 1. ROE（净资产收益率）— 最重要
```
ROE = 净利润 ÷ 股东权益 × 100%
```
- **ROE > 15%**：优质公司门槛
- **ROE > 20%**：优秀公司
- **ROE持续稳定**：比忽高忽低更好
- **杜邦分析**：ROE = 净利率 × 资产周转率 × 权益乘数

### 2. 自由现金流（FCF）
```
FCF = 经营活动现金流 - 资本支出
```
- 自由现金为正：能持续分红/回购
- 现金流 > 净利润：盈利质量高
- 多年稳定FCF：护城河证据

### 3. 净利润率
```
净利润率 = 净利润 ÷ 营收 × 100%
```
- 反映定价权（护城河在财务上的体现）
- 稳定或逐步上升 > 波动大

### 4. 资产负债率
```
资产负债率 = 总负债 ÷ 总资产 × 100%
```
- **< 50%**：稳健
- **行业平均对比**：不同行业标准不同
- 警惕：负债率突然大幅上升

### 5. 股息率
```
股息率 = 股息 ÷ 股价 × 100%
```
- 稳定分红 > 忽有忽无
- 股息率 > 银行存款利率

---

## 护城河识别（定性）

| 护城河类型 | 财务特征 |
|------------|----------|
| 无形资产 | 高毛利率（如品牌/专利） |
| 转换成本 | 高客户留存率 |
| 网络效应 | 用户数量增长快 |
| 成本优势 | 多年稳定高ROE |

---

## 估值方法

### 1. 市盈率（PE）
```
PE = 股价 ÷ 每股收益（EPS）
```
- PE < 15：相对便宜
- PE 15-25：合理区间
- PE > 25：偏贵

### 2. PEG比率
```
PEG = PE ÷ 净利润增长率
```
- PEG < 1：被低估
- PEG > 1.5：被高估

### 3. 市净率（PB）
```
PB = 股价 ÷ 每股净资产
```
- 金融股常用PB估值
- PB < 1：股价低于净资产

---

## 财报阅读顺序

1. **利润表**：营收、净利润、毛利率
2. **现金流量表**：经营现金流是否>净利润
3. **资产负债表**：负债率、应收账款变化
4. **附注**：会计政策、关联交易、诉讼

---

## 红旗警示（避开）

| 红旗 | 含义 |
|------|------|
| 净利润增长但经营现金流为负 | 盈利质量差 |
| 应收账款大幅增长 | 赊销过多，可能是假营收 |
| 存货大幅增长但营收不增长 | 产品滞销 |
| 毛利率突然下降 | 竞争加剧，护城河被侵蚀 |
| 频繁更换会计事务所 | 可能有问题 |
| 大股东质押比例过高 | 风险信号 |

---

## 实战应用

**三步筛选法**：
1. **财务筛选**：ROE>15%，连续5年正盈利，FCF>0
2. **行业筛选**：不投看不懂的行业
3. **估值筛选**：PE<20买入，PE>30卖出

**持仓原则**：
- 持仓3-5只行业分散
- 单只仓位不超过20%
- 每年重新审视，不频繁交易
