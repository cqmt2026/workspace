## 盈利能力指标

### ROE（净资产收益率）
```python
ROE = 净利润 / 平均股东权益 * 100%
```
- 筛选：ROE > 15%
- 优质：ROE > 20%
- 警惕：ROE < 10%

### ROA（资产收益率）
```python
ROA = 净利润 / 平均总资产 * 100%
```
- 筛选：ROA > 5%
- 优质：ROA > 10%

### 净利率
```python
净利率 = 净利润 / 营收 * 100%
```
- 筛选：净利率 > 10%
- 稳定或上升趋势

### 毛利率
```python
毛利率 = (营收 - 营业成本) / 营收 * 100%
```
- 筛选：毛利率 > 20%
- 稳定或上升

## 成长性指标

### 营收增速
```python
营收增速 = (本期营收 - 上期营收) / 上期营收 * 100%
```
- 筛选：营收增速 > 15%
- 优质：营收增速 > 25%

### 净利润增速
```python
净利润增速 = (本期净利润 - 上期净利润) / 上期净利润 * 100%
```
- 筛选：净利润增速 > 10%
- 与营收增速匹配

### 季度环比
```python
Q环比 = (本季度营收 - 上季度营收) / 上季度营收 * 100%
```
- 成长股要求连续2-3个季度环比增长

## 财务健康指标

### 资产负债率
```python
资产负债率 = 总负债 / 总资产 * 100%
```
- 筛选：< 60%
- 优质：< 40%
- 行业标准不同（银行/地产除外）

### 流动比率
```python
流动比率 = 流动资产 / 流动负债
```
- 筛选：> 1.5
- 优质：> 2

### 速动比率
```python
速动比率 = (流动资产 - 存货) / 流动负债
```
- 筛选：> 1

## 现金流指标

### 经营现金流 / 净利润
```python
盈利质量 = 经营现金流 / 净利润
```
- 优质：> 1（净利润有现金支撑）
- 警惕：< 0.5（可能是假利润）

### 自由现金流
```python
FCF = 经营现金流 - 资本支出
```
- 筛选：FCF > 0
- 稳定正值更佳

---

## 运营效率指标

### 存货周转天数
```python
存货周转天数 = 365 / (营业成本 / 平均存货)
```
- 对比行业平均
- 周转天数大幅上升需警惕

### 应收账款周转天数
```python
应收账款周转天数 = 365 / (营收 / 平均应收账款)
```
- 筛选：< 90天
- 大幅上升：赊销过多

### 现金循环天数
```python
现金循环天数 = 存货周转天数 + 应收账款周转天数 - 应付账款周转天数
```
- 越短越好
- 缩短趋势更佳

## 估值指标

### PE（市盈率）
```python
PE = 总市值 / 净利润
```
- 筛选：PE < 30
- 合理：PE 10-20
- 行业横向对比

### PB（市净率）
```python
PB = 总市值 / 净资产
```
- 筛选：PB < 5
- 金融股：PB < 1

### PS（市销率）
```python
PS = 总市值 / 营收
```
- 成长股筛选：PS < 10

### EV/EBITDA
```python
EV/EBITDA = 企业价值 / 息税折旧摊销前利润
```
- 综合估值：< 15

## 综合筛选公式

### 价值股筛选
```python
条件 = (
    ROE > 15% &
    资产负债率 < 60% &
    盈利质量 > 0.8 &
    PE < 20 &
    营收增速 > 0 &
    股息率 > 2%
)
```

### 成长股筛选
```python
条件 = (
    营收增速 > 25% &
    净利润增速 > 20% &
    毛利率 > 30% &
    经营现金流 > 0 &
    PE < 50 &
    现金循环天数缩短
)
```

### 低估蓝筹筛选
```python
条件 = (
    ROE > 12% &
    营收增速 > 5% &
    PE < 15 &
    PB < 2 &
    资产负债率 < 50% &
    股息率 > 3%
)
```

## 财报异常检测

### 利润表异常
| 异常 | 公式 | 阈值 |
|------|------|------|
| 毛利率骤降 | 本期毛利率 - 上期毛利率 < -5% | 警惕 |
| 净利率异常高 | 净利率 > 行业均值 + 15% | 核查 |
| 营收与税前利润不匹配 | 税前利润增速 >> 营收增速 | 警惕 |

### 资产负债表异常
| 异常 | 公式 | 阈值 |
|------|------|------|
| 应收账款暴增 | 应收增速 - 营收增速 > 30% | 警惕 |
| 存货暴增 | 存货增速 - 营收增速 > 20% | 警惕 |
| 商誉占比过高 | 商誉 / 总资产 > 30% | 警惕 |
| 负债率骤升 | 本期负债率 - 上期负债率 > 15% | 警惕 |

### 现金流量表异常
| 异常 | 公式 | 阈值 |
|------|------|------|
| 经营现金流持续为负 | 连续3年经营现金流 < 0 | 排除 |
| 盈利质量差 | 经营现金流 / 净利润 < 0.3 | 警惕 |
| 资本支出异常 | 资本支出 / 营收 > 50% | 核查 |

## 实战筛选流程

```python
# Step 1: 初筛（财务指标）
候选 = 财报筛选(
    ROE > 15%,
    营收增速 > 10%,
    资产负债率 < 60%,
    盈利质量 > 0.5
)

# Step 2: 排雷（异常检测）
候选 = 异常检测(候选,
    排除: 经营现金流持续为负,
    排除: 应收账款暴增,
    排除: 商誉占比 > 30%
)

# Step 3: 估值排序
候选 = 估值排序(候选, PE升序)

# Step 4: 人工复核
最终标的 = 人工审核(候选[:20])
```

## 注意事项

1. **行业对比**：指标要在同行业内对比
2. **季度跟踪**：单年数据可能被调节，持续跟踪
3. **非财务因素**：政策风险、管理层诚信也要考虑
4. **组合分散**：单指标筛选有局限性，建议组合5-10只
