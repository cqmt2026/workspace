## 核心理念

**选择高速增长的赛道，在渗透率提升阶段买入**

成长股核心：**行业空间大 + 公司份额提升 + 营收利润双增长**

---

## 核心财务指标

### 1. 营收增速（最重要）
```
营收增速 = (本期营收 - 上期营收) ÷ 上期营收 × 100%
```
- **营收增速 > 30%**：高速成长
- **营收增速 20-30%**：稳健成长
- **营收增速 < 15%**：成熟期

### 2. 净利润增速
```
净利润增速 = (本期净利润 - 上期净利润) ÷ 上期净利润 × 100%
```
- 净利润增速应与营收增速匹配
- 净利润增速 >> 营收增速：规模效应/降本增效
- 净利润增速 << 营收增速：增收不增利

### 3. 毛利率
```
毛利率 = (营收 - 成本) ÷ 营收 × 100%
```
- 成长股毛利率应稳定或上升
- 毛利率下降：竞争加剧信号
- 高毛利 > 低毛利（护城河体现）

### 4. 渗透率判断
| 渗透率阶段 | 特征 | 投资策略 |
|------------|------|----------|
| < 10% | 导入期，风险高 | 高风险高回报 |
| 10-40% | 高速成长期 | 最佳买入时机 |
| 40-70% | 成熟期，增速放缓 | 持有但警惕 |
| > 70% | 饱和期 | 考虑退出 |

## 成长股财务密码

### 规模效应（净利润增速 > 营收增速）
- 营收增长快，同时成本增幅更小
- 说明：固定成本摊薄、管理效率提升
- 典型：互联网平台、SaaS软件

### 现金循环天数缩短
```
现金循环天数 = 存货周转天数 + 应收账款周转天数 - 应付账款周转天数
```
- 天数缩短：话语权增强，商业模式优秀
- 天数拉长：资金被占用，成长质量存疑

### 预收账款/合同负债增长
- 预收账款增长：产品供不应求，先款后货
- 典型：白酒、房地产、教育

## 成长股筛选标准

### 基础筛选
| 指标 | 标准 |
|------|------|
| 营收增速 | > 25% |
| 净利润增速 | > 20% |
| 毛利率 | > 30% |
| 研发费用占比 | > 5%（科技类） |
| 经营现金流 | 正数 |

### 进阶筛选
| 指标 | 标准 |
|------|------|
| 市场份额 | 提升中 |
| 员工数量 | 持续增长 |
| 客户数量/客单价 | 提升 |
| 应收账款增速 | < 营收增速 |

## 行业空间测算

### TAM-SAM-SOM模型
```
TAM（总市场规模）：整个市场的天花板
SAM（可服务市场）：公司能触达的目标市场
SOM（可获得市场）：实际能拿到的市场份额
```

### 市占率法
```
潜在市值 = 行业空间 × 预期市占率 × 市销率倍数
```

### 渗透率法
```
当前市值 = 当前渗透率 × 稳态渗透率市值
成长空间 = 稳态渗透率市值 ÷ 当前市值 - 1
```

## 成长股红旗警示

| 红旗 | 含义 |
|------|------|
| 营收增长但现金流恶化 | 成长质量差，可能是赊销 |
| 毛利率持续下降 | 护城河被侵蚀 |
| 客户集中度高 | 大客户风险 |
| 应收账款暴增 | 可能存在刷单/虚假营收 |
| 研发费用资本化 | 虚增当期利润 |
| 商誉占总资产比例 > 30% | 收购整合风险大 |

## 估值方法

### 1. 市销率（PS）
```
PS = 总市值 ÷ 总营收
```
- 成长股常用PS估值
- PS < 10：合理
- PS > 20：偏贵

### 2. PEG
```
PEG = PE ÷ 净利润增速
```
- 成长股PEG > 2需谨慎

### 3. EV/Revenue
```
EV/Revenue = 企业价值 ÷ 营收
```
- SaaS公司常用

## 实战应用

**成长股投资步骤**：
1. **选赛道**：政策支持、市场空间大、渗透率提升
2. **选龙头**：市场份额最大、研发最强
3. **等买点**：估值合理时买入（大盘调整时）
4. **跟踪验证**：每季度财报验证成长逻辑是否延续

**持有原则**：
- 逻辑不变：不因短期波动卖出
- 逻辑破坏：立即止损（毛利率骤降、核心人员离职）
