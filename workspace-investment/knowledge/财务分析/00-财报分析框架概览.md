## 一、核心原则

**核心逻辑**：盈利真、现金流实、成长稳、估值低、风险小

**核心方法**：三表联动 + 关键指标 + 趋势/同业对比，先排雷，再找机会

---

## 二、前期排雷（5分钟快速筛选）

| 检查项 | 标准 | 结果 |
|--------|------|------|
| 审计意见 | 标准无保留意见 | ❌排除保留/否定/无法表示 |
| 商誉/净资产 | ≤10% | >10% = 减值雷区 |
| 现金+交易性金融资产 | ≥有息负债 | < 有偿债压力 |
| 经营现金流 | 连续2年为正 | 连续2年负 = 直接排除 |
| 财务可信度 | 无异常 | 频繁变更会计政策/应收暴增 = 造假嫌疑 |

## 三、三大报表核心看点

### 1. 利润表（盈利能力与质量）

| 科目 | 关键指标 | 阈值 |
|------|----------|------|
| 营业收入 | 增速 | 连续3年≥15%，单季度环比/同比正增长 |
| 扣非净利润 | 增速≥营收增速 | 扣非/净利润≥80% |
| 毛利率 | 稳定或上行 | 同行高3-5个点=护城河；骤降=风险 |
| 净利率 | 与毛利率匹配 | 毛利高+净利低=费用失控 |
| 研发费用率 | 持续提升 | = 成长信号 |

### 2. 资产负债表（家底与风险）

| 科目 | 关键指标 | 阈值 |
|------|----------|------|
| 现金类资产 | 货币资金+交易性金融资产 | 充足保障短期偿债 |
| 应收账款 | 增速≤营收增速 | 周转天数≤行业均值；占比>30%警惕 |
| 存货 | 增速≈营收增速 | 周转天数稳或降，跌价准备充分 |
| 资产负债率 | 制造业≤60%、消费≤50% | 过高有风险，过低可能扩张不足 |

### 3. 现金流量表（真金白银与造血能力）

| 现金流 | 判断 | 含义 |
|--------|------|------|
| CFO（经营活动） | 持续为正且CFO≥净利润 | 现金造血指数>1 = 优质 |
| CFI（投资活动） | 负=扩张，正=收缩 | 看项目回报率 |
| CFF（筹资活动） | CFO为负+CFF正=高危 | 靠融资续命 |

## 四、五类核心指标汇总

| 类型 | 指标 | 优质阈值 |
|------|------|----------|
| 盈利能力 | ROE | 连续3年≥15% |
| 盈利能力 | 毛利率/净利率 | 稳定或上行，优于同行 |
| 成长能力 | 营收/扣非净利增速 | 连续3年≥15%，逐季改善 |
| 成长能力 | 合同负债（预收账款） | 增速≥营收增速 |
| 运营效率 | 应收/存货周转率 | 周转天数≤行业均值 |
| 偿债能力 | 流动比率/速动比率 | ≥1.5/≥1.0 |
| 现金流质量 | 现金造血指数 | >1优质，0.5-1一般，<0.5警惕 |

## 五、30分钟高效分析流程

| 步骤 | 时间 | 内容 |
|------|------|------|
| 1 | 5分钟 | 排雷：审计/商誉/现金流/财务可信度 |
| 2 | 10分钟 | 盈利与成长：营收/扣非增速、ROE、毛利率趋势 |
| 3 | 10分钟 | 现金流与运营：CFO≥净利润，应收/存货周转健康 |
| 4 | 5分钟 | 估值与同业对比：PE/PB低于行业均值和自身3年中枢 |
| 5 | 辅助 | 非财务验证：行业景气度、管理层、研发投入 |

## 六、三类投资机会识别

### 🔍 高成长+低估值（戴维斯双击）
**信号**：连续3年营收/扣非净利20%+、ROE≥18%、CFO>净利、PE<行业均值

### 🔍 困境反转（预期差）
**信号**：营收触底回升、毛利率止跌回升、CFO由负转正、减值风险出清

### 🔍 高股息+低波动（防御性）
**信号**：现金流稳定、资产负债率低、分红率≥5%、PE<15倍

## 七、发现机会的具体信号

### 🔍 成长性机会信号
| 信号 | 含义 |
|------|------|
| 主营业务大幅扩张 | 收入增长源于核心业务，而非并表或非经常性收益 |
| 重金投资朝阳行业 | 资本支出方向符合政策导向和产业升级趋势 |
| 毛利率持续提升 | 竞争优势强化，定价权增强 |

### 🔍 价值低估信号
| 信号 | 含义 |
|------|------|
| CFO持续优于净利润 | 市场可能低估了利润质量 |
| 低负债+高现金 | 财务稳健，抗风险能力强，有并购或分红潜力 |
| 预收账款增加 | 产品供不应求，未来收入有保障 |

### 🔍 业绩拐点信号
| 信号 | 含义 |
|------|------|
| 存货下降+营收增长 | 去库存完成，景气度回升 |
| 应收账款周转加快 | 下游客户回款积极，行业地位提升 |
| 费用率下降+营收增长 | 规模效应显现 |

## 八、避坑指南（直接拉黑）

| 红旗 | 具体表现 |
|------|----------|
| 利润虚增 | 净利大增但CFO为负、应收暴增、存货积压 |
| 主业萎缩 | 营收下滑，靠政府补助/资产处置撑利润（扣非净利为负） |
| 高风险续命 | 资产负债率>70%，CFO为负、持续融资 |
| 财务不可信 | 频繁变更会计政策、审计意见非标 |
| 审计非标 | 标准无保留意见以外 |
| CFO<净利润长期 | 利润含金量低，可能赊销膨胀 |
| 其他应收/预付异常 | 可能资金占用或财务操纵 |
| 有息负债升+现金未增 | 偿债压力加大 |

## 九、核心公式速查

```
ROE = 净利率 × 资产周转率 × 权益乘数
现金造血指数 = CFO / 净利润
应收增速 = (本期应收 - 上期应收) / 上期应收
扣非占比 = 扣非净利润 / 净利润
毛利率变化 = 本期毛利率 - 上期毛利率
```
