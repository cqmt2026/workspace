## 核心理念

> 工具可以替代劳动，但无法替代判断与决策。

OpenClaw让「一人量化团队」成为现实：
- 数据获取自动化
- 策略生成AI辅助
- 回测分析自动输出
- 智能监控24/7
- 成本低廉

---

## 我们的系统架构（已实现）

```
数据源层
├── dfcf-stock-intraday  → 分时/实时行情（API）
├── em-stockpick         → 条件选股（API+浏览器）
└── iwencai-extractor    → 涨停数据（浏览器）

分析层
├── 688只股票池全量分析   → 尾盘策略筛选
├── 持仓异动监控         → Server酱推送
└── ML模型训练           → 辅助决策（过拟合，慎用）

推送层
└── Server酱微信推送     → 持仓异动/尾盘信号
```

## 量化安全铁律（必须遵守）

| 规则 | 要求 |
|------|------|
| 1 | 禁止存储明文交易密钥 |
| 2 | 所有投资决策必须人工复核 |
| 3 | 小资金测试后再放大 |
| 4 | 保本比盈利更重要 |
| 5 | 验证数据来源和准确性 |

## 策略定位原则

- 波段3-7天，不追求最低买最高卖
- 单笔最大亏5%，不止损不操作
- ML模型仅辅助参考，不单独使用
- 策略论据记录在`knowledge/策略论据.md`
