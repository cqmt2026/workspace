# 技术指标库

**标签**: 技术分析 | 指标 | K线 | 量化
**文件**: `scripts/technical_indicators.py`
**状态**: ✅ 已完成

---

## 支持指标

| 指标 | 函数 | 说明 |
|------|------|------|
| MA均线 | `ma(closes, period)` | 简单移动平均 |
| EMA均线 | `ema(closes, period)` | 指数移动平均 |
| MACD | `macd(closes)` | DIF/DEA/MACD柱 |
| KDJ | `kdj(highs, lows, closes)` | K/D/J值 |
| RSI | `rsi(closes, period)` | 相对强弱 |
| BOLL | `boll(closes)` | 布林带上下轨 |
| ATR | `atr(highs, lows, closes)` | 平均波幅 |

---

## 买卖信号

| 信号 | 条件 |
|------|------|
| 金叉 | DIF>0 且 DIF>DEA |
| 死叉 | DIF<0 且 DIF<DEA |
| 超买 | RSI>70, KDJ>100 |
| 超卖 | RSI<30, KDJ<0 |
| 多头排列 | MA5>MA20>MA60 |
| 空头排列 | MA5<MA20<MA60 |

---

## 使用方法

```python
from technical_indicators import signal, analyze

# 综合分析
result = analyze('600519')
print(result)

# 买卖信号
result = signal('600519')
print(result['信号'])
```
