# 量化因子合集（下）- 西西量化
来源：抖音图文作品 | 提取时间：2026-06-24

## 概述
量化因子是以数据指标形式呈现、能解释资产价格变化和收益差异的因素。

---

## 七类因子详解

### 一、宏观与行业因子

| 子类 | 具体因子 | 核心逻辑 |
|------|---------|---------|
| **宏观经济** | 10年期国债与1年期利差 | 期限利差扩大→利好周期股 |
| | 社融规模同比增速 | 社融增速回升→流动性宽松→利好成长股 |
| | M1-M2增速差 | 活期存款活跃度 |
| | 政策收紧次数 | 政策收紧压制板块估值 |
| **政策因子** | 行业政策支持力度 | 政策支持→行业盈利预期增加 |
| | 税率调整幅度 | |
| **行业景气** | 行业PMI (>50扩张) | PMI连续3月扩张+库存见底→行业上行 |
| | 库存周期 | |
| **国际联动** | RMB汇率中间价 | RMB贬值1%→出口30%公司净利增2-3% |
| | 美股标普500收益 | |
| **科技产业** | 研发投入强度 | 研发+专利+营收增速推动产业升级 |
| | 新兴技术专利数量 | |
| **地缘因子** | 地缘风险指数 | 风险指数影响市场风险偏好 |

### 二、质量因子

| 子类 | 具体因子 | 核心逻辑 |
|------|---------|---------|
| **盈利质量** | 现金流/净利润 (>1为真实) | 现金流匹配利润→财务造假风险低 |
| | 扣非净利润占比 (>90%) | |
| **治理因子** | 股权集中度 | 股权集中+治理规范→代理成本低 |
| | 关联交易占比 (<5%) | 过高可能利益输送 |
| **抗周期** | 毛利率波动率 (<5%稳定) | 稳定代表护城河深厚 |
| | 营收在经济下行期增速 | 抗周期公司（如公用事业）熊市跑赢 |
| **分红因子** | 股息支付率 (30%-70%合理) | 高股息+连续分红→现金流稳定 |
| | 连续分红年数 (>10年) | |
| **可持续发展** | 研发人员占比 | 研发投入、人力储备判断技术壁垒 |

### 三、另类因子

| 子类 | 具体因子 | 核心逻辑 |
|------|---------|---------|
| **ESG** | 碳排放强度 | 高ESG→长期回撤小 |
| | 员工流失率 (<10%) | |
| **地理与供应链** | 供应商集中度 | 供应商集中→易受供应链冲击 |
| | 区域GDP增速 | 长三角制造业受益区域经济 |
| **物理信号** | 卫星遥感、商场客流量 | 客流量增长先于零售营收增长 |
| | 工厂开工率 | |
| **数字行为** | 搜索引擎指数 | 搜索量激增→短期热度增加 |
| **运营关联** | 社交媒体情感导向 | 侧面反映品牌影响力 |

### 四、市场结构与资金流动因子

| 子类 | 具体因子 | 核心逻辑 |
|------|---------|---------|
| **资金流向** | 北向资金净买入(5日累计) | 北向连续净买入→外资长期看好 |
| | 主力资金净流入(大单>500手) | 主力净流入+散户流出→更易上涨 |
| **杠杆资金** | 融资余额/流通市值 (>5%高杠杆) | 高杠杆股票行情波动时易踩踏 |
| | 两融余额差值 | |
| **市场宽度** | 行业上涨家数/总家数 | 市场宽度增长→行情可持续 |
| | 新高股数量占比 | 新高股集中→热点方向（如AI） |

### 五、时间效应因子

| 子类 | 具体因子 | 核心逻辑 |
|------|---------|---------|
| **日内效应** | 尾盘收益效果(14:30-15:00) | A股常见尾盘拉升（机构调仓） |
| | 早盘收益效果(9:30-10:30) | 早盘冲高回落（散户追涨） |
| **周期效应** | 月末效应(最后5日均收益0.5%) | 月末资金面宽松推高股价 |
| | 季度末调仓效应 | Q4末高估值股易被抛售 |
| **事件效应** | 财报公布日前后收益 | 财报预增个股公布前常被炒作 |
| | 限售股解禁日收益 | 解禁前5日均跌0.5% |

### 六、横截面关系因子

| 子类 | 具体因子 | 核心逻辑 |
|------|---------|---------|
| **市值因子** | 总市值、流通市值、小盘股溢价 | A股过去10年小盘股收益超大盘5% |
| **风格暴露** | 价值风格得分 | 个股风格暴露度决定风格轮动表现 |
| | 成长风格得分 | |
| | 动量风格得分 | |
| **相关性** | 个股与沪深300的Beta系数 | Beta>1.5牛市弹性大 |
| | 行业内相关性 | 与龙头协方差高→随龙头波动 |
| **比价关系** | 行业市盈率相对比率 | 反映估值合理性 |
