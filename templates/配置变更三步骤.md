# 配置变更三步骤

## 步骤1: 备份
```powershell
copy <原文件> <原文件>_backup_<日期>
```

## 步骤2: 小范围测试
- 先修改1个模型/1个配置项
- 验证是否生效
- 确认无误后再扩展

## 步骤3: 全量验证
- 运行 `openclaw models list` 确认
- 运行 `session_status` 确认
- 执行一次实际调用测试

---

**示例：更新 sensenova 模型配置**

步骤1: 备份
```
copy models.json models.json.backup_20260925
```

步骤2: 小范围测试
- 先改1个模型ID
- 测试调用是否成功

步骤3: 全量验证
```
openclaw models list
openclaw models auth list --json
```
