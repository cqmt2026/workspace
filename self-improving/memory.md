### 📐 2026-04-13 几何计数题系统方法（EP010 失败案例）
**问题**: 三角形计数题连续错 4 次（6→6→8→10→16），靠感觉数，没有系统方法。
**教训**:
- ❌ 禁止凭感觉数几何图形（三角形/正方形/长方形等）
- ✅ 必须用以下三种方法之一：

**方法 1：按大小分类**
```
1. 最小单位三角形（不可再分）：逐个计数
2. 由 2 个小三角形组合：找出所有组合
3. 由 3 个小三角形组合：找出所有组合
4. ... 依此类推
5. 整体图形：1 个
总计：各类相加
```

**方法 2：按顶点枚举**
```
1. 列出所有顶点（如 A,B,C,D,E,F,G）
2. 按是否包含某特殊点分类（如含重心 G / 不含 G）
3. 逐类计数，确保不重不漏
```

**方法 3：系统枚举法（最可靠，适合编程验证）**
```
1. 列出所有顶点：n 个点
2. 计算 C(n,3) = n!/(3!*(n-3)!) 种三点组合
3. 排除共线的组合（三点在一条直线上不能构成三角形）
4. 剩余即为三角形数量
公式：三角形数 = C(n,3) - 共线组合数
```

**验证规则**:
- 连续错 2 次 → 立即停下来查资料/问人
- 输出前必须画图验证
- 检查三点是否共线（共线不能构成三角形）

**适用范围**: 所有几何计数题（三角形/正方形/长方形/角等）

### ⚠️ 2026-04-13 纠正：黑体字体符号支持限制（重复犯错）
**问题**: ✓ 符号在黑体(simhei.ttf)下显示为方框，每次都犯同一个错。
**原因**: 黑体不支持 U+2713 (✓) 和大多数 emoji。
**教训**:
- ❌ 禁止在 draw.text() 中使用：✓ ✓ ✔ 🅾 ❌ ⭕ 🔴 🟢 ⭐ ❗ ❓ 💡 🚀 及任何 emoji
- ✅ 正确做法：
  - 勾号用 "√" (U+221A) 或 "(对)" "(正确)"
  - 序号用 "①" "②" "③" 或 "(1)" "(2)" "(3)"
  - 星星用 "★" "☆" 替代 "⭐"
  - 强调用 "!", "!!!" 或 "⚠" (Unicode 9888)
- **适用范围**: 所有 PIL.ImageDraw.text() 渲染的文字
