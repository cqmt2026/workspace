## 八、面试时可能被问的问题

### Q1：你为什么选择低空经济这个方向？
```
"因为我做调研时发现，重庆低空经济正处于政策红利期，
但百度推广几乎是空白——这是一个蓝海市场。
普通销售看到的是'卖广告'，我看到的是'帮企业获客'。
这个认知差异就是我的机会。"
```

### Q2：如果企业说"不需要百度推广"怎么办？
```
"我会先问他们现在靠什么获客，然后指出他们的获客渠道有什么局限。
比如培训机构如果只靠抖音，我会说抖音算法不稳定，百度用户带着需求来，转化率更高。
如果对方坚持不需要，我会建议先小预算测试一个月，没有效果随时停。"
```

### Q3：你之前有什么销售经验？
```
"我之前做过获客系统，帮企业搭建抖音+百度的整合营销方案。
虽然没直接卖过百度广告，但我懂企业的获客痛点，也懂百度的推广逻辑。
再加上我对低空经济行业的深入研究，我相信能快速上手。"
```

### Q4：你的薪资期望是多少？
```
"我理解这个岗位的底薪是3000-4500元。我希望至少能达到4500元的底薪，
因为我对自己的销售业绩有信心。
另外，我希望公司有清晰的提成机制和晋升通道，让我能通过业绩说话。"
```

### Q5：你对末位淘汰怎么看？
```
"我理解公司的考核机制。但末位淘汰也应该有缓冲期，
比如第一个月以学习为主，第二个月开始考核，给新人适应的时间。
我会用业绩证明自己，不会让自己落到末位。"
```
