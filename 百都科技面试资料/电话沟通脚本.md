# 百都科技·重庆低空经济销售电话脚本

> 用途：面试前练习 + 入职后直接使用
> 核心逻辑：先证明你了解行业 → 指出百度空白机会 → 给出具体方案

---

## 一、通用开场白（30秒内）

```
"您好，请问是XX公司吗？我是百都科技的[你的名字]，专注做重庆低空经济和新能源板块的百度推广。

今天打电话主要是想跟您同步一个信息——我们在做重庆低空经济市场调研时发现，目前百度搜'重庆无人机培训'和'重庆充电桩安装'，前5页都没有你们公司的广告，但深圳、成都的同行已经投了半年以上。

想跟您简单介绍一下我们百度的推广方案，大概占用您2分钟时间，可以吗？"
```

### 🎯 目标1：重庆云翼智航科技有限公司（培训业务）

**背景**：电话19332234194，联盟会员，培训业务明确

**脚本**：
```
"您好，请问是云翼智航吗？我是百都科技的，看到你们是重庆市无人机产业创新联盟的会员单位，专门做无人机培训的对吧？

我这边有个数据想跟您同步一下——2025年重庆培训飞手超1万人，但就业率从80%跌到了不足40%。这说明什么？说明培训机构数量在暴增，但学员来源成了问题。

我们现在搜'重庆无人机培训'，百度上没有几家本地机构投广告，大部分都是教育宝这样的聚合平台在占位置。这意味着什么？意味着谁先入局，谁就能抢占这个搜索关键词的第一名。

我们百都是百度在重庆、贵州、四川的三星代理商，有1000多人团队，专门做中小企业的百度推广。像深圳的大疆培训、成都的纵横股份，都已经投了半年以上，效果不错。

我想问一下，你们现在主要靠什么渠道获客？抖音？还是老学员介绍？"

【根据回答继续】
→ 如果对方说抖音：
"抖音确实有流量，但抖音的算法不稳定，今天爆明天就不爆。百度不同，用户搜'无人机培训'就是带着需求来的，转化率比抖音高3-5倍。你们可以尝试小预算测试一下，比如一个月投3000-5000元，看效果再说。"

→ 如果对方说老学员介绍：
"老学员介绍确实靠谱，但增长太慢了。现在重庆有25家持牌培训机构，竞争在加剧。百度推广可以帮助你们突破圈子，触达那些主动搜索的新学员。"
```

## 三、常见问题应对

### Q1：对方说"我们不需要百度推广"

```
"理解，很多企业一开始都有这个想法。但我建议先做一个小测试——比如先投一个月，预算3000元，看看效果。如果没有效果，随时可以停掉，没有任何损失。但如果有效果，你们就抢占了一个竞争对手还没意识到的获客渠道。"
```

### Q2：对方说"百度已经没人用了"

```
"这个说法不准确。百度在中国搜索引擎市场占比还是60%以上，特别是B2B和中小企业客户，百度仍然是首选搜索工具。抖音、小红书适合C端品牌曝光，但B端客户找供应商，还是习惯用百度搜。"
```

### Q3：对方说"我们已经在投了，效果不好"

```
"那说明之前的投放方式可能有问题。很多公司投百度只是开了个户，没有做关键词优化、没有做落地页优化、没有做数据分析，相当于花钱买教训。我们可以帮你们做一次免费的账户诊断，看看问题出在哪里，再决定要不要调整。"
```

### Q4：对方说"太贵了，投不起"

```
"我理解。但换个角度想，你们现在获客的成本是多少？如果是熟人介绍，时间成本和机会成本其实更高。百度推广的CPM（千次展示成本）大概在5-15元，CPC（单次点击成本）在2-8元，如果一个客户带来的产值是几万甚至几十万，这个投入产出比是非常划算的。"
```

### Q5：对方说"我要考虑一下"

```
"没问题，这种事确实需要慎重考虑。这样，我加您个微信，把我们的方案和案例发给您参考。您看完之后有任何问题，随时联系我。另外，我这周三下午正好在你们公司附近，方便的话我可以过来拜访一下，当面给您详细介绍。"
```

## 四、电话沟通流程总结

```
1. 开场（10秒）：表明身份 + 说明来电目的
2. 引起兴趣（20秒）：抛出数据/发现，制造好奇心
3. 痛点挖掘（30秒）：提问对方当前获客方式
4. 方案呈现（30秒）：给出百度推广的具体方案
5. 处理异议（按需）：根据对方反应灵活应对
6. 行动号召（10秒）：约见面/加微信/发资料
```
